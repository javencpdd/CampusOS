# CampusOS 文档门户

本目录保存项目计划、进度和内部详细资料。面向普通使用者和插件开发者的官方文档前端位于 [`docs-site/`](../docs-site/README.md)，默认运行在 `http://localhost:3002`，后续可迁移到独立仓库。仓库根目录的 [README](../README.md) 只保留当前基线、最短启动路径和必要入口。

## 文档分类

| 路径 | 内容 |
| --- | --- |
| `help/` | 运行、插件、集成、风格包、数据库和贡献的实用说明。 |
| `skills/` | 项目 Skills 的调用、维护、验证和同步说明。 |
| `api/` | API 入口、契约状态和协议参考。 |
| `architecture/` | 当前模块边界、运行拓扑、存储职责和安全约束。 |
| `项目计划v1` 至 `项目计划v6` | 历史计划、审查和后续规划；历史计划不会被回写为“后来已经完成”。 |
| `进度/` | 任务级交付记录和验证结果。 |
| `Todo/` | 未排期工作笔记和样例，不是当前产品承诺。 |
| `../docs-site/` | 对外官方文档站，包含项目介绍、部署、API 和插件开发教程。 |
