## 1. 本版结论

v0.11 完成了计划中定义的可靠命令主线：CampusOS 仍保持模块化单体，但高风险数据库
命令现在有明确事务边界，提交后的异步工作进入持久 Outbox，并能在 worker 重启、
lease 接管、重复消费和外部失败后保留可处理证据。

这不是一次“全系统重写”。v0.10 的权限、内容、插件和资源边界保持兼容，v0.11 通过
`core.reliability`、TxKernel、适配器和追加 migration 逐步接入。

原 Final 后的逐项复审补齐了可靠任务列表的真实分页与查询限流、安全响应 DTO，以及
`000027` 隔离 up/down/up 自动演练。它们修正的是原 A3/A10 验收缺口，不是新增产品
范围；补齐后，计划中的实现状态与验收状态均已闭环。

## 3. 当前架构边界

```text
Core Modules
  Identity / Community / Moderation / User Storage / Reliability
Built-in Features
  Personal Space / RichText / Schedule / Appearance / Webhook / Integrations
External Plugin
  Host API / Gateway / Manifest / Runtime / Managed data
Resource Package
  themes / homepage packs / space styles / skills / prompt / persona metadata
```

Reliability 是 Core，不可停用。Webhook 是 Built-in Feature，但它只通过 Reliability
Service 注册 consumer；External Plugin 与 Resource Package 不得到 TxKernel、Outbox
表、内部 Repository、JWT 私钥、CampusOS 用户 Token 或任意宿主机文件访问。

## 4. 兼容性审查

| 对象 | v0.11 处理 | 删除条件 |
| --- | --- | --- |
| v0.10 API、路由和响应包络 | 只增加可靠任务字段/接口，旧路径保留。 | 另行版本化弃用。 |
| 旧 EventBus | 作为兼容 fallback；新高风险 producer 写 Outbox。 | 有消费者迁移与遥测证据。 |
| 旧权限目录 | 继续 fallback 并计数。 | 连续版本无调用、迁移与回滚完成。 |
| 旧 Built-in/Manifest 名称 | 仍兼容读取并记录。 | 明确 deprecation 计划。 |
| Legacy Resource Source | Appearance 可读、可迁移，未直接删除。 | 用户回滚和 layout 证据完整。 |
| 用户数据与 Feature 数据 | 功能停用不删除数据。 | 需备份、恢复、审批和对账。 |

## 5. 仍然受控的限制

这些不是 v0.11 漏交，而是明确保留到后续版本的边界：

1. Webhook 和任何 HTTP 外部副作用只能做到至少一次；接收方必须幂等。
2. endpoint rate/concurrency 是单进程保护，尚未实现集群共享 limiter。
3. 可靠性页使用持久状态和进程内基础计数；没有 Prometheus、全局告警、SLO 或自动
   dead-letter 修复。运维查询限流同样是单进程保护，不是集群共享配额。
4. retention 只有 inventory/dry-run；未开放物理删除、审批、分批执行、取消或法定
   保留策略。
5. v0.11 不做邮箱验证、多级板块 scope 继承、互助/二手交易、容量压测、标准 MCP Server
   或标准 protobuf gRPC Runtime。

## 6. v0.12 进入条件

v0.12 不应因为 v0.11 发布而自动开始。每个候选能力先满足以下条件：

| 候选工作 | 开始前必须明确 |
| --- | --- |
| 邮箱验证 | 新旧账号验证语义、邮件 provider secret、验证码保留/速率、登录回退与迁移策略。 |
| 多级板块 | parent/child 数据约束、`self/subtree` scope、不扩大既有版主权限、查询/缓存/迁移方案。 |
| retention 执行 | 法定保留、审批、分批上限、取消、备份/恢复、数量和 checksum 对账。 |
| 多实例 Webhook | 共享 rate/concurrency adapter、worker ownership、健康与告警、压测基线。 |
| 指标与告警 | 指标后端、固定低基数标签、访问控制、告警阈值、演练和数据保留。 |

所有 v0.12 写路径继续使用 v0.11 的 Command/Tx/Outbox 边界；不得为了新功能绕过审计、
作用域或可靠任务状态。
