迁移前共发现 152 个仓库文件引用 `项目计划v0.1` 至 `项目计划v0.14`：

| 引用范围 | 文件数 | 处理方式 |
| --- | ---: | --- |
| `docs/` | 140 | 更新 Markdown 链接、内联路径和历史进度中的追溯路径 |
| `docs-site/` | 2 | 更新公开路线与文档生命周期中的仓库路径 |
| 根 `README.md` | 1 | 更新项目入口链接 |
| `scripts/` | 3 | 更新文档链接检查和 v0.13 容量预算脚本路径 |
| `skills/` | 6 | 更新开发工作流、项目导览和路径约定 |

从 74 个计划文件的可解析 Markdown 链接中，识别出：6 个跨版本同级计划链接、60 个指向 `docs/` 其他目录或仓库根目录的相对链接、56 个计划目录内本地链接，以及 149 个外部或页内链接。

## 路径调整规则

1. 所有仓库内计划路径统一由 `docs/项目计划v0.N/...` 调整为 `docs/项目计划书v0/项目计划v0.N/...`。
2. 移动后的计划文件仍以 `项目计划v0.N` 为同级目录，因此跨版本链接（例如 `../项目计划v0.13/...`）保持不变。
3. 移动后的计划文件访问 `docs/进度/`、`docs/help/`、`docs/api/`、`docs/architecture/` 或仓库根文件时，已按新增的一层目录深度重新计算相对路径，例如 `../进度/...` 调整为 `../../进度/...`。
4. `scripts/check-doc-links.py` 的检查范围已改为整个 `docs/项目计划书v0/`，使全部 14 个版本计划持续接受本地链接校验；v0.13 容量门禁与容量演练脚本已改用新证据目录。
5. 仓库根 README、Docs 门户、计划治理文档、公开文档站、历史进度记录和仓库内 Skill 源文件均已同步到新路径；Skill 的动态计划目录解析也已更新。
6. 发现并修复一个原有的根 `LICENSE` 相对链接：移动后采用 `../../../LICENSE`，使其指向仓库根许可证文件。

没有保留旧目录的重定向副本：所有受影响的仓库内路径均已改为新根目录，避免“双权威目录”和文件重复。
旧根路径仅在本 README 的“原路径 → 新路径”迁移清单和调整规则中作为历史映射保留，不再被任何运行脚本、链接检查器、Skill 或文档入口用作实际目标。
