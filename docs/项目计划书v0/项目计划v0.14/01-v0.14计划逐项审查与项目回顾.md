## 4. 本次审查补齐的内容

1. **可恢复对象对账与分页**：`storage reconcile` 不再把全量对象、Reservation、账户和文件树载入内存。新实现以稳定 keyset 批次扫描，checkpoint 只保存游标、聚合数和有界差异样本；根目录或 schema 不一致不能 resume，样本截断时不能 `--apply`。Object List 同时改为数值 ID cursor 和 `id < cursor` 范围查询，避免字典序错页并恢复 `(owner_user_id, id DESC)` 索引的可用性。
2. **历史数据迁移证据**：新增隔离脚本，从 v0.13 的 `000001-000043` 建库、保留旧课表 JSON，升级到 `000049` 后执行 `schedule adopt --apply` 和只读 storage reconcile，验证原 JSON hash 未改变。
3. **文档版本可靠事件**：文档创建、保存和历史恢复均通过 Reliability 事务提交版本、预览状态和最小化 Outbox 事件；Memory Repository 的 snapshot/restore 也覆盖该原子性。未启用 Converter Runner 时，内置安全降级消费者只严格校验允许字段并记录 receipt，不读取私有内容、不调用外部转换器，也不会让合法事件因“无消费者”反复 retry/dead-letter。
4. **学期删除可解释性**：AcademicTerm 管理列表批量加载引用数，前端在引用存在时禁用删除；数据库 FK 继续防止竞态删除。
5. **架构图完整性**：Admin 数据架构视图增加 `personal_document_versions -> personal_document_previews` 与 `storage_objects -> personal_document_previews` 关系，避免预览表成为无关联孤点。
6. **用户错误可操作化**：课表导入的空文件、读取失败、学期参数、版本参数和超限错误使用中文安全原因；超限响应含 `max_bytes`、`actual_bytes` 和下一步。新增 HTTP Handler 测试锁定该合同。
7. **G0 事实边界**：基线采集器补齐 v2 字段，但没有把当前 v0.14 工作树的 hash 或 bundle 倒灌进 2026-08-28 的 v1 历史快照，避免产生伪造的历史发布证据。

## 5. 已完整实现的功能清单

- 管理员治理的春/秋 AcademicTerm、默认学期、关闭历史、版本冲突和引用删除保护。
- 用户只能在开放受管学期创建、保存或导入课表；历史关闭学期按本人绑定可读。
- 课表不可变 Object 版本、原子引用切换、兼容 JSON 镜像、用户查看偏好和幂等历史采用。
- 私有 Object 元数据、所有权检查、持久配额账本、Reservation、原子本地写、失败清理、数值 keyset 分页、低基数指标与可恢复对账。
- 私有个人文档、不可变版本、乐观锁、回收站、认证下载、TXT/Markdown/CampusDoc 安全编辑与预览。
- PDF/DOCX 的格式预检、认证上传/下载和安全降级；没有隔离 Runner 时不会执行危险的本地转换。
- 文档版本可靠 Outbox 事件、安全降级 receipt 和有界预览状态；Admin 不显示用户正文、文件名、路径或下载 Token。
- 统一中文、安全、可操作的 v0.14 学期/文档/上传相关错误；更新后的 API、架构、Help 和官方文档。
