## 当前状态

原 A15 完成记录之后的专业复审发现了授权、配额、MIME、导入同步和 CI 证据缺口。A16 已修复这些实现问题；当前为“计划功能完成、最终环境复验待补跑”，不能无条件表述为所有验收均已完成。

## 已完成能力

- 多端：Web 与 Admin 增加组件测试并接入 CI，动态 UI 具有组件回归；A15 核心流程完成五固定视口真实 Chrome 回归，A16 前端修改仍需补跑。
- 性能：Element Plus 改为按需导入，Web/Admin 入口 JS/CSS 均受体积门禁约束。
- 插件合同：新增 `campusos.plugin/v2`、Host API v2、JSON Schema、Go/TypeScript SDK 类型与可验证示例；v1 继续保持兼容而不会获得新个人数据权限。
- 受管数据：External Plugin 通过 Host/Gateway 使用严格 schema、乐观锁、分页、数量/大小/总量配额、声明式字段和审计，不能取得 PostgreSQL 或其他用户身份。
- 文件：用户插件文件进入 User Storage 命名空间，联合校验后缀、声明 MIME、实际内容和配额，返回受控文件入口而不泄露宿主路径。
- 治理：管理员安装和用户授权独立；Catalog 发布、Runtime 运行、版本化 Grant 和每次调用校验形成闭环，搜索使用独立可撤销授权。
- 插件中心：Admin 管理目录、Runtime、权限、占用、申请、发布和审计；用户管理授权、搜索、占用、导出、个人数据删除及安装建议。
- 安全：包摘要、Ed25519 签名、信任库、必签名拒绝、篡改检测及既有代码 snapshot 回滚可用。
- 部署：Local 文件/SQLite 的多写模式在启动前明确拒绝；迁移、数据库检查与隔离恢复演练完成。
