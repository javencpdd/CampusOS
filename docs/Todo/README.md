# CampusOS Todo 目录说明

`docs/Todo/` 保存未排期需求、问题草稿、思考记录和测试样例。这里的内容不是正式版本计划，也不表示功能
已经实现或承诺实现。

## 使用规则

1. 不在 Todo 中保存密码、Token、邮箱授权码、真实用户数据或生产数据库转储。
2. `tmp/` 下的图片、Excel 和富文本样例只用于复现或设计，不作为产品资源。
3. 确认要实施的需求必须迁入正式版本计划，说明范围、非目标、兼容、测试和回滚。
4. 实施完成后在 `docs/进度/` 保存证据；不要仅在 Todo 文本上打勾。
5. 已解决且没有历史价值的临时问题可以删除；仍用于回归的样例应在测试或文档中说明所有者。

## 当前子目录

| 路径 | 用途 |
| --- | --- |
| `bug/` | 尚未进入正式缺陷阶段的问题记录 |
| `thinking/` | 架构或产品思考 |
| `tmp/` | 临时复现输入和样例 |
| `admin`、`plugins`、`sys`、`user` | 按领域收集的原始需求 |

正式版本状态从 [计划书总结](../计划书总结/README.md) 和 [进度证据](../进度/README.md) 判断。
