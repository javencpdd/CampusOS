## 当前与历史的边界

当前架构由总览、源码装配、配置边界与模块专题构成。九份旧版本专题不再保留旧正文，
只保留短导航，避免旧路径、迁移编号和完成状态继续误导读者。

文件在计划、进度、ADR 或当前文档中仍有引用，因此未删除或移动这些路径。
本轮引用扫描未发现这些旧专题的章节锚点引用；替换正文不改变文件级链接目标。
历史正文可从 Git 历史追溯，不在当前目录复制另一份同样过时的完整说明。
