## 6. 数据目录

冻结的持久化根目录为：`data/config`、`data/dist`、`data/images`、`data/personal-space`、`data/plugin_data`、`data/plugins`、`data/skills`。

- `data/personal-space/<user-id>/` 保持现有 file/img/excel/word/pdf 分类和 URL 语义。
- `data/plugin_data/<feature>/style-packs` 是现有风格资源源，A7 前不得搬迁或删除。
- `data/plugins/<plugin-id>` 当前同时存在 legacy builtin 与外部插件实现，后续依赖兼容映射渐进分类。
- `data/resources` 是 A7 的新增目标目录，不属于本次冻结前结构。

## 7. 兼容与回滚基准

后续阶段至少比较路由/OpenAPI/权限合同、18 个 migration、9 个兼容 Manifest、持久化根目录、三类插件模板、恢复演练和浏览器流程。架构改造回滚只切换装配或 Adapter，不执行 migration down、不删除 Feature 数据，也不移动现有用户文件。
