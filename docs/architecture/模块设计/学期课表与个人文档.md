# 学期课表与个人文档

> 更新时间：2026-09-15（Asia/Shanghai）
> 实现基线：v1.1-dev
> 返回：[当前架构概览](../当前架构概览.md)

## 职责划分

[AcademicTerm](../../../internal/modules/core/academicterm) 是学期事实所有者，管理学年、春秋学期、第一周开始日期、
开放状态和默认学期。[Schedule](../../../internal/modules/features/schedule) 管理用户课表；
[Personal Documents](../../../internal/modules/features/personaldocuments) 管理私有文档、版本与回收站。

三者不能分别维护相互矛盾的默认学期；文档列表也不等同于头像、文章附件的通用资产清单。

## 学期与课表流程

管理员创建学期、设置第一周周一、开放或关闭，并可选择默认开放学期。
写操作检查权限、操作原因、状态和并发版本；冲突应反馈用户重新读取，不以覆盖并发修改解决。

用户选择允许的学期 → 保存或导入课表 → 经学期状态校验 → 创建存储对象并更新课表元数据。
课表实现同时保留按学期的兼容 JSON 镜像；对象与镜像的持久化规则以 Schedule Service 为准，
不得把镜像当成可绕过权限的共享目录。

## 文档流程与边界

创建或上传 → 所有权与格式验证 → 写入受配额约束的内容对象 → 保存元数据及版本。
修改、历史版本恢复、回收和恢复均使用当前用户范围；文档下载不是公开静态路径。

TXT、Markdown、CampusDoc 使用受控编辑与预览。PDF 可由第一方受管 `builtin.pdf-viewer`
在用户明确点击后在线阅读：Personal Documents 只将当前 owner 的 document ID 置入十分钟 Invocation，
PDF.js 的每次 Range 读取都重新核验 owner、版本格式、插件状态和 Grant/Consent。它不等于将 PDF 转为可编辑
文档，也不提供长期下载链接。DOCX 的通用在线转换 Runner 仍不能标注为已交付，继续安全下载降级。

## 主要接口

统一前缀 /api/v1；请求字段由 [路由合同](../../api/HTTP路由与授权矩阵-v0.6.md) 定义。

| 方法与路径                                  | 职责                                                                |
| ------------------------------------------- | ------------------------------------------------------------------- |
| GET /schedule/terms                         | 可用学期                                                            |
| GET、PUT /schedule/me                       | 当前用户课表读取、保存                                              |
| POST /schedule/me/import                    | 导入课表                                                            |
| POST /schedule/me/terms/activate            | 激活用户学期                                                        |
| GET、POST /admin/academic-terms             | 管理端查询、创建学期                                                |
| POST /admin/academic-terms/:id/default      | 设置默认开放学期                                                    |
| POST /admin/academic-terms/:id/open、/close | 状态转换                                                            |
| GET、POST /documents                        | 私有文档列表与创建                                                  |
| POST /documents/upload                      | 上传文档                                                            |
| POST /documents/:id/pdf-invocations         | 为 owner 的当前 PDF 创建短期第一方 Viewer 上下文                    |
| GET /documents/:id/versions                 | 历史版本                                                            |
| GET /documents/:id/download                 | owner-only 下载；Web 使用带登录凭据的 Blob 请求，不以新窗口裸开 URL |

## 依赖与验证

依赖 Identity、PostgreSQL、Content Editor、Storage Object 和可靠事务。
重点验证关闭学期写入拒绝、默认唯一性、并发冲突、文档 owner 越权、PDF Invocation 跨用户复用、插件撤权后
Range 读取拒绝、配额、版本恢复和失败后的对象清理。
数据库错误应在服务端记录可排查信息，用户端不能泄露 SQL 或凭据。
