# 插件平台与授权体系

> 更新时间：2026-09-14（Asia/Shanghai）
> 实现基线：v1.1-dev
> 返回：[当前架构概览](../当前架构概览.md)

## 职责与信任分类

[插件平台](../../../internal/plugin) 管理 Manifest、安装、授权、运行状态、宿主能力和扩展入口。
Core、内置 Feature、外部 Plugin、无运行时 Resource Package 使用不同生命周期。
停用、撤权、卸载和删除持久数据不是同一个操作。

当前装配注册 grpc、process、wasm 三个 Runtime 名称；grpc 与 process 共用受管进程适配器，
wasm 使用 wazero。grpc 的兼容名称不能解释为完整标准 protobuf gRPC 服务。
宿主 API 不提供核心 JWT、数据库连接串或用户存储根；受管进程本身仍需操作系统权限隔离，不能视为完整沙箱。

## 三层授权流程

1. 插件 Manifest 声明 Capability 和作用域。
2. 管理员批准平台允许的能力范围。
3. 代用户处理数据时，用户明确同意相应范围。

[授权服务](../../../internal/plugin/authorization.go) 对声明、管理授权、用户同意和当前策略进行交集验证。
普通用户通过授权界面确认，不需要自己制作密钥或长期 Token。短期委托凭据由平台管理，
不应把浏览器用户登录令牌转交插件。版本、策略或授权状态变化后不能继续沿用已失效授权。

Host API 的具体能力、参数与权限见 [API 文档入口](../../api/README.md)；
宿主受管文件或插件数据不能被等同于核心业务表访问权。

## 运行接口与依赖

| 接口或代码 | 职责 |
| --- | --- |
| GET /api/v1/ui/runtime-manifest | 输出当前可用界面贡献 |
| GET /api/v1/ui/events | 运行状态变更通知 |
| /api/v1/extensions/:plugin/*path | 认证后的 Extension Gateway |
| internal/plugin/hostapi | 受授权限制的宿主接口 |
| internal/plugin/ui_contract.go | Plugin UI 声明及校验 |

依赖 Identity、插件授权持久化、秘密管理、受管运行目录和运行时适配。
插件秘密不得明文进入日志；错误与监控应保留诊断能力而不泄漏 Token 或用户内容。

## 界面弹窗与新标签页

[Surface Host](../../../web/src/campus-ui/PluginSurfaceHost.vue) 支持 modal、drawer、fullscreen、new-tab 等呈现方式。
宿主决定可打开的 Surface 与受控路径，不接受任意远程 URL、动态 Vue 代码或插件注入脚本。

PDF 当前声明见 [PDF Viewer 模块](../../../modules/features/pdf-viewer/module.yaml)，
实现见 [PDF Viewer 页面](../../../web/src/modules/pdf-viewer/pages/PdfViewerView.vue)。
它是第一方编译内置、由可信白名单装配的 Viewer，使用 PDF.js 同源 Worker；
通过 Plugin UI 宿主与短期 Invocation 连接文章和个人资产两种入口。

因此，“使用 Plugin UI”不等于“已经交付可安装的外部 PDF 插件”。
若要求独立外部包，仍需设计与实现安全装载、沙箱/Bridge、包验证、生命周期和授权撤销验收，
不能通过把内置 Feature 改名为插件完成。当前正式计划将第三方动态 UI 列为后续范围。

## 验证重点

覆盖越权 Capability、过期或撤销委托、版本/策略变化、功能停用、恶意跳转、无效 Surface、
Invocation 跨用户复用及进程退出。文章下架后已有预览也应重新受阅读权限约束。
