## 应用职责

| 应用 | 职责 | 开发默认端口 |
| --- | --- | --- |
| [Web](../../../web) | 社区浏览、发帖、个人空间、课表、文档与预览 | 3000 |
| [Admin](../../../admin) | 用户、权限、审核、模块、资产与运维治理 | 3001 |
| [文档站](../../../docs-site) | 使用说明与开发文档的独立静态站点 | 3002 |

Web/Admin 使用 Vue 页面与模块路由，通过 API 访问业务，不直连数据库或把磁盘路径当下载链接。
开发代理将 /api 请求转发到 API 服务；生产需配置对应同源反向代理与 TLS。

## 运行清单与界面流程

[Campus UI](../../../web/src/campus-ui) 从运行清单构建可用入口，通过事件更新运行状态；
[可信模块表](../../../web/src/campus-ui/trustedModules.ts) 映射编译时存在的模块。
清单不是动态下载和执行第三方 Vue 的授权。

用户打开入口 → 路由或 Surface Host 选择受信组件 → 使用当前会话请求 API → 展示数据或可操作错误。
新标签页走受控同源路径；Invocation ID 不替代服务端鉴权。

前端按钮状态用于解释操作条件，不能代替后端权限检查。
首次路由按需加载和整页重载是不同现象；排查刷新应分别检查路由导航、资源加载和开发热更新。

## 资源外观与个人主页

个人主页、头像、平台 Logo、页面风格包与应用主题有不同所有者和访问范围。
风格/主题资源包无独立业务 Runtime，不应通过样式配置注入脚本或读取私有对象。

当前资源接口在 [Router](../../../internal/transport/httpapi/router.go) 注册：
/api/v1/web-themes/:name/assets/*path 和 /api/v1/appearance/space-style-packs/:name/assets/*asset_path
用于对应资源资产，不是任意目录静态托管入口。

## 接口与错误呈现

- GET /api/v1/ui/runtime-manifest：界面可用能力。
- GET /api/v1/ui/events：运行变化事件。
- 业务接口由对应专题和 [API 合同](../../api/README.md) 定义。
- 上传错误应展示允许格式、单文件/总量/配额等可操作限制；未知内部错误保留安全兜底，不展示服务器秘密。

## 依赖与验证

依赖运行清单、身份会话、Feature 门控、构建依赖和资源合同。
修改路由、Surface 或 Viewer 时应检查 Web/Admin 构建与真实浏览器行为，
包括新标签页认证、功能停用、无权限状态、移动端和下载失败降级；不能仅以构建成功代替浏览器验收。
