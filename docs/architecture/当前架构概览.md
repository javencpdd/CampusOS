# CampusOS 当前架构概览

> 更新时间：2026-09-21 18:16（Asia/Shanghai）
> 适用范围：当前工作区 v1.1-dev 实现；不是 v1.1 Final 发布声明。
> 应用启动与既有合同仍使用 v0.13.0 标识；这不表示架构停留在 v0.13。

## 系统定位与拓扑

CampusOS 是模块化单体：Go API 在一个进程中装配核心模块与内置功能；Web、管理端和文档站独立构建。
外部插件通过受控运行时和 Host API 扩展，不直接接管核心数据库或用户文件。

本轮审查补齐平台通用预览上下文、owner 游标分页、独立认证下载降级、附件引用原子失效及有界清理。
范围与未完成验收见 [v1.1 审查回顾](../项目计划书v1/项目计划v1.1/01-v1.1代码完成情况审查与项目回顾.md)；
process 插件的目标 OS/网络隔离仍未完成，不能把开发容器当作第三方代码沙箱。

```text
Web（3000）／Admin（3001）
          ↓ 同源代理 /api/v1
     Gin HTTP → 认证与授权 → 应用服务 → 模块仓储
                               ├─ PostgreSQL：业务事实、事务、审计与任务
                               ├─ 用户存储：对象字节、配额与资产引用
                               ├─ Outbox／Worker → 邮件、Webhook 等外部副作用
                               └─ Plugin Host／Extension Gateway → 受控外部插件
Redis、NATS：按运行配置提供基础设施能力
文档站（3002）：VitePress 静态文档，不是业务 API 服务
Plugin UI（3003）：仅服务校验后的 v4 不可变插件静态产物，和主站保持跨 Origin
```

端口为开发环境默认值；生产地址、TLS 和数据挂载应单独配置。路由装配见
[HTTP Router](../../internal/transport/httpapi/router.go)，依赖装配见
[服务启动](../../internal/server/bootstrap.go)。

## 设计原则

1. **模块拥有自己的业务事实**：跨模块通过明确的 Port、应用服务或事件协作，不绕过所有者直接修改表。
2. **授权在服务端闭环**：菜单隐藏不是权限；会话、管理员准入、资源所有权及插件授权分别验证。
3. **字节与业务引用分离**：Storage Object 保存字节，User Asset 表示用户资产，文章附件是显式业务绑定。
4. **事务与外部副作用分离**：数据库内用事务；邮件、Webhook 采用可重试的持久任务。文件系统与数据库不宣称跨介质 ACID。
5. **扩展有信任边界**：内置可信界面不等于第三方任意脚本；资源包不等于可执行插件。
6. **代码与生成合同优先**：计划描述目标，进度记录证据，历史文档保留决策背景，不能替代当前实现。

## 模块分类

| 类型 | 职责与生命周期 | 主要位置 |
| --- | --- | --- |
| 核心模块 | 身份、社区、审核、学期、存储等基础能力，常驻 | internal/modules/core |
| 内置功能 | 图文、互助、二手、个人主页、课表、文档等，编译装配并受功能门控 | internal/modules/features |
| 插件平台 | 外部、自包含插件的发现、授权、受控 Host API 与目录投影；旧 builtin 仅保留兼容运行时代码，不代表当前 PDF Viewer | internal/plugin |
| 资源包 | 主题、样式等非运行时代码资源 | 资源目录及外观管理模块 |

模块声明与运行分类以 [模块目录](../../modules/catalog.go) 为准。功能停用不等于删除历史数据。

## 当前边界与维护规则

- 插件存储限定为已开放平台通用表、自身 SQLite/config。子进程环境白名单、私有 SQLite/config 布局和 PDF 阅读记录
  的通用表持久化已按 [最新存储设计](../help/系统设计相关/插件存储边界与平台通用数据设计.md) 实施；OS/网络隔离及
  通用 Invocation 服务仍在后续范围，不能被前述实现替代。

- PDF Viewer 的用户界面已迁至 `plugins/campusos.pdf-viewer`，以 `runtime: none` 的已校验 release 通过跨 Origin iframe 和宿主 Bridge 加载；图文文章附件、个人 Asset 与 owner-only Personal Documents 仍使用同一受控预览上下文。Admin 动态 Host、用户安装状态机、升级/卸载和完整浏览器验收尚未完成，不能把当前实现当作完整插件市场。
- Admin 的“外部插件运行管理”是包/运行/管理员授权的权威入口；“用户目录与授权”只是同一当前快照生成的用户可见目录、请求与聚合用量视图。同步会移除当前未发现的历史目录条目，因此 PDF Viewer 只能保留一个 `campusos.pdf-viewer` 外部插件条目。
- 插件版本与授权记录的 Snowflake `BIGINT` ID 在浏览器 API 中一律按十进制字符串传递；不得转换为 JavaScript number，否则会损失精度并指向错误版本。
- v4 用户端的隔离 UI Bundle、sandbox iframe/Bridge 已交付；任意第三方 Runtime、Admin 动态 UI、通用文档转换 Runner 仍不应标注为已交付。
- 当前架构描述不替代 Linux、浏览器、恢复、容量与发布验收证据；详见
  [插件重构计划](../项目计划书v1/项目计划v1.1/02-v1.1插件自包含与动态加载重构计划书.md)。
- 公开 API 的字段和错误合同查阅 [API 文档](../api/README.md)，实际路由以 Router 为准；生成合同需通过检查才能认定与工作区一致。
- 修改模块、存储或安全边界时，更新相关专题与本页日期；新增决策保留原因，不重写历史日期。

本次源码核对与清理记录见 [架构事实同步进度](../进度/v1.1-dev/v1.1.9-dev.md)。
