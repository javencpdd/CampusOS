## 配置入口与优先级

[pkg/config/config.go](../../pkg/config/config.go) 的 Config.Load 读取进程工作目录的 .env：
非空进程环境变量优先，其次 .env 非空值，最后代码默认值。空字符串不是强制覆盖值。
该文件解析不等于把 .env 全部导出进程环境；直接 os.Getenv 的模块有自己的读取路径。

| 文件/来源 | 职责 |
| --- | --- |
| [.env.example](../../.env.example) | 原生 API 配置示例，不被程序当作实际 .env 自动加载 |
| [开发模板](../../deploy/docker/.env.dev.example) | Docker 开发 setup 输入模板 |
| deploy/docker/.env.dev.local | 本机开发实际配置；由脚本选作 Compose 插值来源，不纳入 Git |
| [部署模板](../../deploy/docker/.env.example) | 部署配置示例，不是开发 local 的别名 |
| modules/*/*/module.yaml | Feature 默认配置与配置 Schema |
| builtin_feature_states | 持久化的功能配置/启停状态，由 Feature Registry 读取 |

修改开发 local 后应通过 docker-dev up 重新应用容器配置；API 并不直接解析该文件。
查看 Compose 的 environment 映射才能确认某个变量是否真的进入 API 进程。

## 主要配置项

| 配置键 | 默认或读取方式 | 所有者/影响 |
| --- | --- | --- |
| SERVER_HOST / SERVER_PORT | 0.0.0.0 / 8080 | API 监听；不是宿主端口发布规则 |
| DATABASE_DSN | config.Load 的数据库连接配置 | PostgreSQL；连接失败可能使用内存 |
| REDIS_ENABLED / REDIS_ADDR / REDIS_PASSWORD | true / localhost:6379 / 空 | 缓存；DB 字段在当前 Load 中固定为 0 |
| NATS_URL | nats://localhost:4222 | 事件总线，失败回退内存 |
| HOST_API_ENABLED / HOST_API_ADDR | true / 127.0.0.1:18080 | 插件宿主接口 |
| OBSERVABILITY_PROMETHEUS_ENABLED | false | 独立指标出口 |
| OBSERVABILITY_PROMETHEUS_ADDR / OBSERVABILITY_PROMETHEUS_PATH | 127.0.0.1:9091 / /metrics | 指标地址与路径 |
| JWT_SECRET / JWT_ACCESS_TTL / JWT_REFRESH_TTL / JWT_ISSUER | TTL 默认 15m / 720h | 会话凭据，生产需独立秘密 |
| AUTH_CHALLENGE_* / AUTH_SESSION_IP_HASH_SECRET | Config.Load 与部署校验 | 验证码及 IP 摘要安全配置 |
| AUTH_MFA_ACTIVE_KEY_ID / AUTH_MFA_ENCRYPTION_KEYS | 开发/测试有开发默认值 | MFA 加密密钥组 |
| AUTH_BOOTSTRAP_ADMIN_SECRET | 默认空 | 管理员初始化，生产校验要求至少 16 字符 |
| EMAIL_PROVIDER | fake | development/test 才允许 fake；其他环境需要 smtp |
| EMAIL_SMTP_HOST / EMAIL_SMTP_PORT / EMAIL_SMTP_FROM | 主机与发件人必需，端口默认 587 | SMTP 连接与身份 |
| EMAIL_SMTP_USERNAME / EMAIL_SMTP_PASSWORD | 默认空 | 提供方认证；不得写入日志或公开 API |
| EMAIL_SMTP_TIMEOUT / EMAIL_SMTP_STARTTLS | 10s / true | SMTP 超时与 TLS |
| PLUGIN_DATA_DIR | data/plugin_data | 插件私有数据、SQLite KV |
| CAMPUSOS_PLUGIN_SECRET_KEY / CAMPUSOS_PLUGIN_SECRET_KEY_VERSION | Secret Service 直接读取进程环境 | 密钥为 32 字节（十六进制或 Base64 编码）；缺少时 Secret Service 不启用 |
| CAMPUSOS_ENV / CAMPUSOS_INSTANCE_MODE | development / single | 部署校验 |
| AI_ENABLED / AI_PROVIDER / AI_BASE_URL / AI_MODEL / AI_API_KEY | Config.Load 中的 AI 配置 | AI 提供方；默认不启用 |
| AI_TIMEOUT / AI_MAX_REQUESTS_PER_MINUTE / AI_MAX_CONCURRENT | 30s / 60 / 4 | AI 限流与并发 |
| WEBHOOK_ALLOWED_HOSTS / WEBHOOK_ALLOW_PRIVATE_NETWORK | 空列表 / false | 出站地址约束 |

秘密字段不通过此文档提供可用于生产的值。

## 文件根与持久化边界

bootstrap 显式以 corestorage.DefaultRoot 构造 User Storage，当前为 data/personal-space。
**Config.Load 没有一个全局 USER_STORAGE_ROOT 配置项**，不能仅在 .env 写入自造变量就搬迁 Object 存储。
历史 Feature 的 file_storage 配置与 Core Object 根也不能混为一谈。

相对路径相对于 API 工作目录。开发脚本 [dev-api.sh](../../deploy/docker/dev-api.sh) 切换到 /workspace，
[Compose](../../compose.dev.yml) 绑定仓库到 /workspace。新附件位于
data/personal-space/<用户ID>/file/objects/<对象ID>.bin；业务名称保存在元数据中。

## 部署限制与健康检查

[部署校验](../../internal/server/deployment.go) 明确拒绝 multi-instance 写模式，
原因是本地 User Storage 与旧 SQLite KV 没有共享多写协调能力。
production 校验 JWT、管理员初始化、安全密钥等配置；这不是自动 TLS、HA 或生产数据库可用性保证。

GET /api/v1/health 的 [实现](../../internal/modules/core/identity/handler/user_handler.go)
返回 status、service、version，不逐一探测数据库、邮件和插件。因此 HTTP 200 不等于所有依赖正常。

## 热加载的实际行为

Docker Go watcher 是 dev-api.sh 内的指纹轮询，不是容器中的 Air：
扫描 Go、migration SQL、module YAML 和 go.mod/go.sum；默认轮询一秒。
变化后构建候选二进制，执行 migrate.sh up，成功后替换 API 进程；
编译或迁移失败会保留上一成功运行进程，所以页面可访问不一定代表新代码已生效。

Web/Admin/文档站由各自开发进程处理源码更新。依赖、镜像构建文件或容器入口变化使用 rebuild。
CAMPUSOS_DEV_API_HEALTHCHECK_INTERVAL 是 Compose 健康探测间隔；
CAMPUSOS_DEV_POLL_INTERVAL 是 Go 源码轮询间隔，两者都不是浏览器心跳。
