# v1.2 公开集合与本机模型引用问答合同

> 更新时间：2026-10-24（Asia/Shanghai）
> 范围：V12-14b 的一个纵向切片；整阶段尚未完成。Windows 延期。

## 入口与模型边界

正常 Server 在装配根通过 `LocalAnswerModel` 将 Knowledge 接入 AI 的 `ai.local-checked-chat/v1`。Knowledge 不导入 AI 实现、不增加对 AI 的模块启动依赖；普通公开检索在 AI 不可用时继续工作。发布的是内部 `knowledge.public-local-rag/v1` Port，没有新 User/Admin HTTP、页面、Host/MCP 或 SDK 接口。

调用 `Answer(ctx, currentUserResolver, PublicLocalQuestion)`，请求仅包含公开 `collection_id`、问题 `question`、随机 `ar_` 加32位小写十六进制 `run_id` 和十进制 Binding 修订。当前 User 会话由可信 Identity Port 逐次解析；Admin/机器或相同数字 ID 不能混用。调用方不能指定端点、模型、Provider、Source、私人文档、owner、系统提示词或权限。

必须已选择并启用内置 `local-chat` Profile，且 Definition 为 `builtin.local-openai.text`。远程 Profile 即使在14a中可用，本接口也拒绝，不隐式切换提供方。模型守护进程仍由运维预先运行，网关只访问部署固定 literal loopback HTTP 端点，不执行命令。

## 证据与调用链

固定流程为：当前 User/Knowledge/本机模型计划 → 公开集合词法检索 → 最多3条当前证据 → 精确来源/投影快照 → 受管预算和必需审计 → 有界本机模型 → 缓冲响应结构校验 → 所有证据与身份/模型计划重验 → 返回。

问题沿用公开检索的1024字节、Unicode和词数限制。仅从指定公开集合和当前原域 G1 允许的来源检索。搜索结果不是独立授权：捕获当前 IndexDocument、完整代次/规则/成员/来源修订以及精确 snippet；后续重新读取当前文档和原来源可见性修订。最多3份当前投影快照保存在本次调用内存，不建立跨请求正文、查询或 allow 缓存。

没有当前证据时返回 `status=refused, reason=no_evidence`、空答案和空引用，不预留预算、不连接模型。不可用/未完成索引返回安全错误，不拿旧片段或全局模型知识作降级答案。

发送模型的 user 消息只有问题与 `id/title/excerpt` 证据 JSON，整体最多16KiB；来源链接、会话、权限和密钥不交给模型。宿主固定 system 消息明确这些内容是不可信数据。模型不会执行工具、获取任意 URL、改变 Profile 或扩大集合范围。私人索引同意不授权本接口读取私人数据，本片不读取私人来源 Port。

AI 内部必需源检查在预留前/事务内、分发前/事务内、实际 HTTP 前后、执行中的100ms检查周期和返回前运行。当前 User、Knowledge/AI Feature、Profile/Binding或任一证据变更均取消调用或拒绝结果；不会为了让长模型调用继续而长期持有跨网络数据库锁。并发数据库提交与网络不可组成原子事务，检查失败后不再发送下一步，已分发调用取消并保守计费。

## 缓冲响应与引用

模型正文必须是封闭 JSON，仅允许 `answer` 字符串和 `citations` 字符串数组；拒绝未知/重复/null/非法 Unicode 字段。正文最多8192字节，答案最多4096字节，引用最多3个。非空答案必须引用宿主本次分配的 `E1` 至 `E3`，未知或重复 ID 拒绝，不能提供自选 URL/Scope。空答案加空引用是明确模型拒答，返回 `reason=model_no_evidence`。

宿主自行将 ID 映射为 `RAGEvidence`，包括纯文本 title/excerpt 与真实 SearchCitation：集合、成员、可见性修订、SourceReference、索引 generation/chunk 和来源 URL。输出合同 `campusos.knowledge-public-local-rag/v1`，包含 status、answer、可选 reason/run_id、citations。所有候选证据在交付前重验；模型只引用其中一项也不能忽略其他已送出证据的撤权。

答案仍是不可信纯文本，调用者不得将其作为 HTML/工具调用、权限事实或官方结论执行。宿主验证引用的来源与当前性，不声称已证明每句话的语义蕴含或真实 LLM 问答质量；模型可能拒答，质量评测仍属14b后续。

## 取消、预算与生命周期

沿用14a持久请求单位预算、并发上限、版本化模型事件和必需 Command/Outbox。模型成功不等于 RAG 答案已交付：结构不合格、来源变化或引用失效会拒绝已缓冲答案，但实际模型请求仍结算。未分发失败0，分发后未知/取消保守1，不自动重试、重放或 fallback；token不是货币计价。

结算审计失败时不交付答案；常驻租约只补未知结果结算，不再调用模型。RAG 不持久保存问题、片段、答案或新的会话凭据；模型 run/event/audit/Outbox 只保存既有低敏元数据。未发生模型调用的拒答不会消耗 run nonce；发生调用后重复 nonce 由 AI 持久唯一约束拒绝。

Knowledge Stop 取消并等待本片活动调用完成必要结算，Start 建立新生命周期。AI 停用或本机 Binding/Profile 变更使新旧调用关闭；完整进程重启保留模型绑定、预算及公开索引，不复活旧 RAG 上下文。没有新 Schema、依赖或持久目录，仍为35/next36、132总表/143FK；恢复边界沿用[受管 AI 合同](v1.2受管AI模型与执行合同.md)。

## 后续与验收范围

本片不实现私人 RAG、本人对精确端点/内容/修订/步骤的独立外发同意、远程 RAG、Embedding/Rerank/外部解析、流式输出或插件 AI 接口。它们不能借公开集合或14a模型可用性获得授权。

[验收 runner](../../scripts/v12-14b-public-local-rag-drill.py)使用正常生产模块、真实 PostgreSQL/Identity/常驻索引器、本机 HTTP 模型协议端及真实引用 HTTP；模型流量走真实本机 HTTP，来源、身份与调用链来自正常模块，没有验收出站注入。确定性协议端用于检查调用与拒绝边界，不代表真实模型权重、质量或公网服务认证。阶段完整退出和私人/远程同意链仍须后续独立完成。
