# v1.2 公开 RichText 正文来源 Port 合同

> 更新时间：2026-10-21 13:01（Asia/Shanghai）
> 范围：V12-09a 的公开 RichText 正文候选切片；依赖[社区文本首片](v1.2公开社区文本来源候选Port合同.md)。集合、选择规则、官方资料和索引仍待后续。

RichText 在可信进程内 AppContext 提供 `richtext.public-text-source`（`richtext.PublicTextSourceReader`），Knowledge 在生产模块组装中消费该 Port 并提供 `knowledge.public-article-candidates`（`knowledge.PublicArticleCandidates`）。Knowledge 默认关闭、可热停用；RichText 按自身 restart 合同启停。没有新增 HTTP、MCP、Host API、Integration 或 Web/Admin 入口，外部插件不获得 AppContext。

```go
// RichText 所属域：始终匿名读取公开正文，不接受 owner/Admin 覆盖。
ReadPublicTextSource(ctx context.Context, threadID string) (PublicTextSource, error)

// Knowledge：逐项预览与当前版本复核。
PreviewPublicArticle(ctx context.Context, threadID string) (PublicArticleCandidate, error)
RecheckPublicArticle(ctx context.Context, ref SourceReference) (PublicArticleCandidate, error)
```

来源 kind 为 `richtext.article`，引用 ID 使用原 Community thread ID；RichText 内容行 ID 绑定在修订中。社区 discussion 的 `community.thread` 引用不能替换文章引用。来源链接为同源 `/threads/<threadID>`。两类来源方法各自拒绝错误类型，不把 Community 的 500 字摘要当成 RichText 正文。

RichText 先经 Community 当前匿名公开 Policy 和原子事实版本读取，再读取本人所属的文章行，要求两者 thread/author/title 一致、文章和帖子非零事实版本、当前 `published/clear/active` 且未删除。即便 Context 携带 User 或 Admin resolver，本 Port 仍使用匿名分支；私密、草稿、待审、下架、回收站或任一所属行已删除都拒绝。读取后再次加载完整快照，变化时返回空结果。

正文取自文章原始 `ContentHTML`，使用既有 Core Content Editor 有界 sanitizer 的纯文本结果；存储的 `sanitized_html`、render 缓存、summary、cover、ContentJSON 和 Community 摘要均不作为正文。只返回可见文本，不返回 HTML/JSON、作者、治理原因、附件/图片字节或资产 URL；链接保留文字，不抓取目标。脚本、样式、iframe 等按既有 sanitizer 去除；图片不做 OCR/附件展开，也不调用模型。纯文本仍是不可信数据，下游须按 text 安全处理。

| 限制 | 当前值与失败行为 |
| --- | --- |
| 原始 HTML | 最多 100000 字节，沿用所属编辑器上限 |
| 转换结构 | 既有 sanitizer 最多 1000 节点、48 层；超限拒绝 |
| 来源正文/标题 | 65536/1024 字节；有效 UTF-8、非空；超限拒绝、不裁剪 |
| 来源 ID/修订 | 规范正 int64 thread ID、明确 kind、64 位小写 hex 修订 |

RichText 修订绑定转换合同、thread/article ID、板块、标题/完整纯文本以及**帖子与文章各自不可复用的 facts_version**。Knowledge 再绑定自身候选合同和整个受限来源投影。仅修改文章正文、内容改回原值的同事务 ABA、原帖公开→私密→公开、移板块或标题更新均使旧引用失效；计数和单独更新时间不改变语义版本。候选和引用均不代表集合成员、索引许可、模型出站同意或永久可读能力，消费端仍须在自己的返回/提交边界核验当前授权。

Knowledge 关闭时返回 `ErrDisabled`；RichText 关闭、当前源不可读/不一致或底层失败统一为 `ErrSourceUnavailable`，不泄露私密标题或数据库错误。原始/纯文本大小超限为 `ErrSourceTooLarge`，当前读取或旧引用版本不同为 `ErrSourceChanged`，引用类型/格式错误为 `ErrInvalidReference`。Context 取消原样终止，所有失败返回空候选。RichText restart 变更先呈现 pending；实际重启应用关闭后，文章引用拒绝，而普通 Community 文本来源可继续读取；显式重新启用并重启后仍要读取当前事实。

无新增持久表、migration、目录或第三方依赖。验收入口为[原生 PG16 演练](../../scripts/v12-09a-richtext-source-drill.py)，结果见[.138进度](../进度/v1.2-dev/v1.2.138-dev.md)及[切片证据](../项目计划书v1/项目计划v1.2/evidence/v12-09a-richtext-source-linux.json)。本范围是生产模块组装中的原生来源组件；09a完整出口、集合/成员持久化、HTTP/浏览器、索引和 Windows 实机不由本切片追认。
