# v1.2 G1：其他资源与动作 Policy 目标合同

> 状态：G1 的五个命名资源决策合同已离线验收；V12-02a 已交付 Go 纯 Policy Port、严格 host codec 和 Linux 原生组件验收。生产 Authorizer、数据仓储及业务入口尚未接入，02a 整阶段仍未完成。

本合同复用[主体上下文](v1.2主体上下文合同.md)作为唯一 Principal 形状。业务拥有者在当前调用/事务中构造[ResourceFacts 与请求](resource-policy-v1.schema.json)：资源类型、owner、版块、状态、可见性和版本均不可由客户端或插件自填。作者编辑只认 user Principal 与当前 owner；后台身份不是用户，不能代替作者或读取个人文档。版块治理执行要求目标版块的有效精确 grant，并在要求 MFA 时满足认证强度；执行 grant 不推出转授权权，后者见[委托上限](v1.2版块治理委托上限合同.md)。个人文档首版仅本人可读；插件实例没有借代理身份直接读取私有文档的入口。公开知识来源必须仍公开发布且原来源当前可见，索引/集合不是可放宽的授权事实。

[决策 Schema](resource-policy-decision-v1.schema.json)绑定 request、facts 版本与 policy 版本；允许写操作同时要求提交前事实复核与 required audit。事实移动、撤权、主体/策略变化后旧决策失效。目标错误见[错误目录](resource-policy-v1.errors.json)，SDK DTO 见[类型定义](../../sdk/typescript/src/resource-policy.ts)。离线[检查器](../../scripts/check-v12-resource-policy-contract.mjs)中的 evaluate/consume 是规范样本，不是生产 Authorizer；V12-02a/02b/02d 须在 PostgreSQL/Memory/HTTP 中实现权威事实加载、事务顺序、列表/计数/分页一致性和审计失败关闭，09a 补知识来源真实 ACL。

执行：node scripts/check-v12-resource-policy-contract.mjs。

## V12-02a 纯资源策略 Port

[Go DTO、严格解析与决策结构](../../internal/modules/core/identity/port/resource_policy.go)实现五个已命名动作的宿主事实输入。输入限制为 32 KiB 与 64 层，拒绝重复键、未知/缺失/null 字段、尾随值、非法 UTF-8、孤立 UTF-16 surrogate 及时间的浮点舍入或溢出。`evaluated_at_ms` 和 `expires_at_ms` 以精确 `int64` 毫秒处理；资源 ID/版本按本合同的 1–128 Unicode 字符约束，不借用 Principal 的 ASCII 限制。

[纯求值器](../../internal/modules/core/identity/policy/resource.go)没有缓存、仓储、全局事实加载器、环境时钟或凭据读取。它只允许：user 对自己的 active/draft/private 帖子编辑；具有同一条当前精确 grant 的 user/admin 对对应版块下架帖子或删除回帖；user 读取自己的 active 个人文档；以及任何主体读取仍公开发布且来源可见的知识来源。Admin 和 plugin/worker 不能借相同 ID、`effective_subject` 或公开来源扩张作者/个人文档权限。写操作 allow 返回 `recheck_facts` 和 `required_audit`，只读 allow 仅返回 `recheck_facts`。

`CheckResourceDecision` 将 allow 与初始命名动作、完整 Principal（含 credential/代理字段）、事实、grant 列表和 policy 版本精确绑定。它只允许时间前进，重新求值当前快照；撤销、过期、认证降级、资源/owner/版块/状态/版本或 grant 任何变化都拒绝。该函数不加载当前数据、不加事务锁且不写 audit，应用服务仍须在自身事务中重载事实、复核、写入必需审计并决定读取/返回顺序。

[Linux 演练](../../scripts/v12-02a-resource-policy-drill.sh)先运行冻结 G1 合同，再以其独立 oracle 生成 397 个输入（22 个命名夹具、75 个原矩阵、300 个主体域/状态组合）；Go 原生 race 二进制在 `env -i` 下输出实际结果，由 Ajv 和该 oracle 再核对。证据在[原始报告](../项目计划书v1/项目计划v1.2/evidence/v12-02a-resource-policy-linux.json)与[.28 进度](../进度/v1.2-dev/v1.2.28-dev.md)。本验收不表示 PostgreSQL、Memory、HTTP、浏览器、真实凭据或授权写入路径已接入。
