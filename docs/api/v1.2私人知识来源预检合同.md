## 请求与身份

`POST /api/v1/knowledge/private/sources/preflight` 使用当前 User access JWT 和实时会话证明。请求示例：

```json
{"document_id":"123","version_id":"456"}
```

两项都必须是正数 int64 的规范十进制字符串，无前导零、正负号或空格；最大值 `9223372036854775807`。严格 JSON 不超过 1024 字节，拒绝未知/重复/缺失/null 字段、非法 Unicode、额外 JSON 和任何 URL 查询参数。请求不能指定 owner、权限、提供方、保护标记或 consent。

组合根只向 Knowledge 注入 PersonalDocuments 的当前本人元数据适配器，不暴露仓储、文件路径或 Object reader。两次 checked metadata 读取复核 owner、当前版本、文档生命周期和个人文档 Feature；绑定同一 User principal 与 credential，返回前复核当前会话、Knowledge Feature 与取消状态。个人文档本身沿用 restart 启停；新私人预检要求该 Feature 的 effective 与 desired 均启用，因此待重启的停用请求也立即关闭本入口，启用请求则不能提前开放。恢复旧版本也不会使旧 version_id 成为当前版本。独立 Admin（即使数值 ID 相同）、Integration key、插件凭据和匿名请求没有入口权限。MCP/Host/SDK 能力目录保持公开范围。

## 响应与禁止入库

成功的预检返回普通平台数据包络中的五个字段：

```json
{"document_id":"123","version_id":"456","format":"text","can_index":false,"reason":"private_storage_unavailable"}
```

`text`、`markdown`、`campusdoc` 表示原文档的已知类型；当前统一报告 `private_storage_unavailable`。`pdf`、`docx` 报告 `unsupported_format`。上传支持某格式不代表已有可用于私人索引的解析器；本片不读取正文、附件或预览，也不声明文本解析已验收。所有类型的 `can_index` 均为 false，不能通过配置布尔值、公开 Knowledge 启用或传入请求字段变为 true。

HTTP 200 表示完成只读预检，**不是选入成功、本人同意记录、排队成功或未来读取授权**。默认没有私人选择、索引、任务或查询缓存；预检不新建这些数据，不写审计/Outbox，不联系外部解析器、Embedding、模型或遥测提供方。响应不含标题、正文、owner、Object ID、摘要、密钥或宿主路径。

私人词法片段也是敏感派生数据。现有公开索引使用明文 JSONB；UserStorage 的 owner 目录及平台 AES-GCM Keyring 单独存在，均不能证明私人投影、WAL、备份、密钥、撤回及恢复生命周期已经保护。本片不复用该明文索引接收私人数据。

## 错误与当前事实

| HTTP | 行为 |
| --- | --- |
| 400 | 请求结构、大小或 ID 非法；不访问来源 |
| 401 | 缺失、错误身份域、失效/撤销会话或请求内身份改变而无法建立当前 User 证明 |
| 404 | 不存在、非本人或已回收的文档；不区分这些事实 |
| 409 | 请求版本不是当前版本，或本次读取期间来源/已验证权限事实改变；清空旧预检后重新取得当前文档版本 |
| 503 | 任一 Feature 关闭、适配器不可用或服务停止；不能降级到公开索引或绕过保护 |

成功及失败响应都设置 `Cache-Control: private, no-store`，包括路由鉴权前拒绝。预检结果不能在以后请求中当作 allow 缓存。

## 验收与后续

定向 race 覆盖有界请求、五种已知类型恒拒绝索引、读取期间会话/owner/credential/版本/格式变化、Feature 热停用、停止和取消。Linux 原生目标使用正常 Server 模块图、生产 router、真实 PostgreSQL-backed User 会话和个人文档元数据；逐次检查 Knowledge 选择/成员/投影/任务、文档/Object、审计/Outbox 与文件摘要没有因预检新增或变更。报告及命令见 [.150 进度](../进度/v1.2-dev/v1.2.150-dev.md)。这不是独立 cmd/server 部署或浏览器验收；本片无 UI 变化，Windows 沿用用户延期。

后续 V12-13 仍需受保护私人派生数据与密钥/备份恢复设计、本人逐项选择文档/帖子、受支持格式解析及完整任务/检索、撤回后的新请求拒绝与任务/缓存/备份清理。本片无新迁移、依赖或持久目录，current33/next34 不变。回退可移除该预检路由、组合适配器和 Knowledge 预检服务；没有数据库或私人数据需要回滚。
