# v1.2 帖子作者生命周期接入合同

> 更新时间：2026-10-12 19:54（Asia/Shanghai）
> 责任阶段：V12-02b；本人trash/restore/submit-review，不代表创建或typed Feature编辑完成。

独立纯合同 `campusos.thread-owner-lifecycle/v1` 只允许当前user域本人对真实线程执行三个命名操作：trash要求active；restore要求trashed；submit_review要求active且moderation为taken_down或rejected。purged、其他用户、Admin/匿名/插件均拒绝；未知操作失败关闭。实际owner、board、raw发布/审核/删除状态和非复用facts_version由Community加载。它不扩张冻结五动作的ResourcePolicy，不借owner_read获得写入权限。

允许决策同时要求recheck_facts和required_audit，绑定完整Principal、事实、操作、请求与策略版本。HTTP固定操作：DELETE `/threads/:id`、POST `/threads/:id/trash/restore`、POST `/threads/:id/submit-review`；请求中的owner/action/认证强度不影响授权。必须重新验证当前User Session，缺Port不回退裸actor。

命令沿用真实账号/会话/线程行锁、facts_version+revision CAS与事务内内容修订/平台审计/outbox。提交前复核完整会话与实际新资源版本、owner/board/结果生命周期。恢复保留原publication和moderation，不直接解除审核或下架；重新提交进入pending。失效/换credential、owner/board/state/ABA变化及审计失败回滚，不返回旧允许结果。缓存与外部事件在提交后处理。Core拥有删除/审核状态，typed Feature正文/Detail编辑另经本模块命令。
