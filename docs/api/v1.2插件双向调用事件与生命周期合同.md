## V12-03c 首片：宿主类型化贡献查询与选择

更新时间：2026-10-18 11:49（Asia/Shanghai）；实现/自动化与Linux原生+独占PG16目标通过，8项共同门禁通过，见[.117](../进度/v1.2-dev/v1.2.117-dev.md)与[报告](../项目计划书v1/项目计划v1.2/evidence/v12-03c-directory-linux.json)。

`plugin.v5.contributions`是编译入宿主的`V5ContributionDirectory`，无新增HTTP入口、插件注册回调或SDK凭据。宿主适配器从当前身份上下文取得owner；不能把插件/请求体中的owner直接传入。按当前扩展目录严格识别`preview.renderer@v1/pdf`、`ai.chat@v1/text`、`knowledge.source@v1/public_text`，当前Host能力目录继续为空，不接管内置AI/RAG。

查询先通过03b的`ExecutionFacts`重新验证当前包字节/签名/信任、版本安装、Grant、所需Consent、active用户和全局/用户ready代次、受管配置准备摘要；再从不可变版本Manifest投影贡献元数据。pending/停用/撤权/未安装的贡献不返回。返回声明仅是查询快照，不代表存在可调用Runner，更不替代Feature、资源ACL、实例凭据和调用预算。

同一查询多个匹配返回`plugin.contribution_selection_conflict`，不按安装顺序选默认。明确选择使用publisher/plugin_key/version/local provides ID全坐标；所选版本或声明缺失返回`plugin.target_unpublished`，不回退其他版本/提供者。`Recheck`每次重新查询当前事实；自动选择还重核唯一性，旧实例/全局代次或Grant修订变化拒绝，不能原地刷新绑定。绑定不可序列化为权限凭据，描述符只含贡献元数据及字符串代次，没有owner、配置值、Secret引用或物理路径。

自动发现按稳定游标最多20页、每页50个已安装且获批全局包族；未完成全目录扫描时返回`plugin.call_budget`，不能宣称唯一。明确选择直接复核对应坐标。目录不缓存Provider；宿主启动必须先完成03b对账，失败时目录保持不可用，需修复后重启。

首片退出时，后续责任包括完整双向Dispatcher、当前Feature/资源权限/凭据及每次调用预算；其中prompt-only Chat子路径现见下文。后续仍需受管运行贡献发布和取消/排空、白名单元数据事件独立重试/死信。当前无事件载荷处理，因此不宣称事件隐私或事务不阻塞已经验收；没有真实Runner、浏览器或Windows声明。

## V12-03c 第二片：prompt-only ai.chat 宿主 Dispatcher

更新时间：2026-10-18 12:33（Asia/Shanghai）；实现/定向race完成，Linux原生/独占PG目标通过，8项共同门禁通过，见[.118](../进度/v1.2-dev/v1.2.118-dev.md)与[报告](../项目计划书v1/项目计划v1.2/evidence/v12-03c-chat-dispatch-linux.json)。

宿主Port `plugin.v5.chat-dispatcher`接收目录产生的不可伪造绑定、冻结`ai_chat_request`原始JSON及当前User会话resolver。只接受`context_class=none`和调用者明确输入的prompt；此限制是本入口的授权子集，不修改冻结DTO中的`public`取值。没有宿主资源读取，也不承接public/private上下文拼装或Preview/Knowledge调用。外层G1双向调用envelope、插件实例凭据及插件到Host API后续交付，当前Host能力目录仍为空。

Consumer的当前Feature reader/ID和Transport由编译宿主适配器绑定，不能来自插件/请求。AI Gateway当前不在可切换FeatureRegistry中，不能猜测ID；生产装配不绑定Consumer与Transport，返回`plugin.runtime_unavailable`。内置AI/RAG维持原路径。目标测试显式注册`contract-chat-consumer`并使用编译契约Transport，未冒充实际业务Feature、Wasm/Container Runner或14c集成。

调用前与IO返回后重新验证当前User会话主体、凭据ID、owner、Feature、目录唯一/显式选择、包/信任、Grant/所需Consent、配置及实例/全局代次；调用中撤权/停用/卸载/配置变化或会话失效时丢弃结果。Transport只取得明确owner/发布坐标/代次、prompt DTO和受限Writer，不取得用户Token、配置、Secret或数据库。数据库事务不跨Transport IO。

请求最多64KiB，prompt最多12000 Unicode字符；响应Writer最多256KiB且写入超限错误不可被Transport忽略，DTO text最多50000字符。输入/输出拒绝重复字段、未知/大小写别名、null、坏Unicode、第二JSON、负Token数量和非法finish_reason；响应request ID/contribution ID/generation必须匹配。错误不回显Transport内部信息。

冻结扩展DTO的`deadline_ms`在此宿主入口表示剩余毫秒，范围1–300000；绝对期限由Context承载，和外层G1决策envelope的绝对deadline语义分开。请求不得超过当前Grant timeout或部署30秒上限，父Context可进一步缩短；期限覆盖准入/IO/返回校验，过期/取消不返回部分响应。当前Grant按版本/owner/实例代次限制并发，部署总并发上限8，拒绝排队且结束释放计数。计数只在本进程，不是跨宿主账本、累计计费或CPU/内存沙箱。

Transport必须协作遵守Context，Dispatcher同步调用且不额外启动后台goroutine；不宣称能强制抢占不合作的插件代码。管理发布、撤下/主动取消排空、真实进程隔离与硬终止、事件重试/死信仍属于后续切片/05/06。当前无新HTTP、迁移或SDK字段，生产desired enable仍pending/runtime_unavailable。
