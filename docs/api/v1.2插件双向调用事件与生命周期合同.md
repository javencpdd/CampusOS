# v1.2 插件双向调用、事件与生命周期目标合同

状态：V12-G1 冻结目标 DTO、错误与 Linux 离线合同验收；V12-03b/03c 负责持久 Operation、真实目录/授权、Dispatcher、Runner、Outbox 和故障恢复，14c 负责真实 AI/知识业务接入。

## 双向调用

机器合同：[调用 Schema](plugin-v5-dispatch-v1.schema.json)、[调用错误](plugin-v5-dispatch-v1.errors.json)、[SDK DTO](../../sdk/typescript/src/plugin-v5-dispatch.ts)、[离线检查](../../scripts/check-v12-plugin-v5-dispatch-contract.mjs)。宿主到贡献、插件到 Host API 都带 request ID、合同版本、目标 ID、实例代次、deadline、请求/响应大小预算。真正的安装、Grant、Consent、功能状态、贡献选择、目录发布、实例凭据和当前代次是宿主权威事实，插件不得通过调用体自填角色、ACL、数据库连接或用户 Token。每次调用时重新求交；撤权、代次变化和 Feature 停用后的新调用拒绝。贡献选择冲突明确报错，后安装者不能抢占默认绑定。

## 事件与生命周期

机器合同：[事件 Schema](plugin-v5-event-v1.schema.json)、[事件错误](plugin-v5-event-v1.errors.json)、[生命周期 Schema](plugin-v5-lifecycle-v1.schema.json)、[生命周期错误](plugin-v5-lifecycle-v1.errors.json)、[SDK DTO](../../sdk/typescript/src/plugin-v5-events.ts)、[离线检查](../../scripts/check-v12-plugin-v5-events-contract.mjs)。事件只允许插件状态、公开帖子和公开知识源的有限元数据与版本；无原始 Outbox、私有正文、Prompt、Secret 或 ACL。只有核心事务已提交、订阅/Grant 有效、实例代次一致且大小/有效期受限才投递。失败进入独立重试或死信，不反压已提交的核心事务。

desired、observed、安装、Grant、当前代次、贡献目录发布各自独立。启用必须已安装、获批、Runtime ready 后才发布。撤权、停用和卸载先停止新调用、撤下贡献句柄，之后取消或排空在途调用。升级要以新代次准备并在 ready 后切换；有配置或私有数据变更时必须先有可验证快照，不能把不可逆数据变更称为可一键回退。重复 Operation、崩溃恢复、事务排序和真实 Runner 隔离留给 03b/03c 验收。

离线检查覆盖 30 个双向调用夹具及 4 次撤权/代次复核、20 个事件和 19 个生命周期夹具。此证据不能证明真实投递、签名验真、跨进程取消或持久化恢复。
