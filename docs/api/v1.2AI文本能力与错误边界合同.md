## Definition 与当前入口

内置 OpenAI 兼容 Adapter 声明 `version=campusos.ai-text/v1`、`id=builtin.openai-compatible.text`，输入/输出仅 `text`，`tools=false`、`streaming=false`。每次取得独立能力值，不能通过修改数组影响后续声明。Gateway 构造及每次调用复核；缺失/未知版本、类型、额外模态或开启 tools/streaming 均拒绝，不默认为支持。

现有独立 Admin `/api/v1/ai/status` 的只读状态增加 `definition` 元数据，未建立 Gateway 时省略；既有 `ai.read`/当前 Admin 域授权不变。`ready` 沿用初始化状态，不代表 Profile 授权、预算已预留或真实模型健康。没有新增 Chat HTTP、用户问答、MCP/Host/SDK 入口。

本片只建立编译宿主的文本 Definition。动态 Profile/Instance/Binding、双内置 Profile 切换、版本化执行事件、持久预算预留/结算、必需审计、当前身份/Feature 生命周期和 Egress/Secret Broker 的完整调用链仍属 14a 后续。03c 的可选插件 Provider 接入留待14c，不能由这里的 Definition 越过现有 Grant/Consent 或当前资源 ACL。

## 输入与固定模型

JSON `ChatRequest` 只接受现有 `messages` 及可选 `model/temperature/max_tokens/source/metadata`；消息只接受 `role/content`。拒绝未知/重复/大小写别名字段、null 必填/顶层可选值、非法 Unicode、额外 JSON、深度超限及数组/对象正文。图片、tools、function、stream 等请求字段不能被标准 JSON 解码器静默丢弃。

- JSON 请求上限128 KiB；1–64条消息，总原始文本不超过64 KiB。
- 角色仅 system/user/assistant；正文为非空 UTF-8 字符串。
- temperature 为有限的0–2；max_tokens 为0–65536，0表示沿用当前省略语义，不是免费或无限预算。
- model最多256字节，source最多128字节；metadata最多16项，键最多64字节、值最多256字节。
- 现有 source/metadata 为宿主侧元数据，不是提供方输入、身份或授权；不把它们作为模型上下文发送。

Go 类型调用也执行相同的语义/字节边界。Gateway 的 model/source 由宿主配置固定；调用者非空覆盖必须完全匹配，否则在 Limiter/Provider 前拒绝。直接 OpenAI Adapter 同样拒绝不同的 model。消息、temperature 和 metadata 在交付 Adapter 前复制，防止 Adapter 改写调用者持有的对象。此处的固定模型限制不冒充受管 Binding 生命周期。

## 提供方输出与错误

现有 OpenAI Chat wire 仅固定 POST `/chat/completions` 和宿主配置的 Bearer。客户端不跟随重定向，也不自动切换提供方或重放失败 POST。当前完整受管网络目标/DNS/Secret Broker 接入尚未完成；这不是允许任意生产出站的安全声明。

响应有完整读取上限，验证包装及 JSON 不超过1 MiB；超过预算即整个失败，不将截短后仍可解析的 JSON 前缀当成功。重复字段、非法 Unicode、未知顶层/消息字段和非字符串正文拒绝。只接受一项 assistant 文本、stop/length 终态及非负 token 计数；非空工具调用、function/audio/refusal/annotations 等非文本内容拒绝，已知可选字段的 null 或空数组视为未使用。文本按数据返回，不执行 HTML、图片、模型工具调用或自动 Agent 循环。

稳定 `GatewayError.Code` 包括 invalid_request、unsupported_capability、provider_config、provider_request、provider_response、rate_limited、context_cancelled、context_deadline。Gateway 将提供方错误归一到有限代码/HTTP状态，不返回其原始正文、URL、密钥或包装错误；非2xx正文不拼入错误。成功、失败调用日志只使用宿主固定标签、状态、用量和安全错误码，不保存 Prompt/响应正文。直接 Adapter 的非2xx错误同样使用固定消息。

取消在入队/执行前与提供方返回后检查；即使提供方无视取消并返回文本，也不能交付迟到结果。执行结束和日志处理后再次检查当前取消。未知失败和取消均不自动重试，不把未知费用当零费用。既有调用日志仍为 best effort：取消期间持久日志可能失败；本片不声称已有 required audit、耐久事件流或费用结算。

## 验收边界

Linux 目标使用当前冻结 race ELF、正常 Server 模块组装、独占 PostgreSQL 和本机实际 HTTP 协议测试端；检查固定 POST/模型/auth/纯文本/用量、未知模态无网络、错误和日志无合成敏感标记、工具/超限/重定向拒绝、当前取消和零插件独立运行。协议测试端是确定性受控夹具，不是真实 LLM、模型质量评测、完整 Egress 验收或官方 OpenAI 认证。

本片没有新增迁移、平台表、持久目录、第三方依赖、Web/Admin页面或路由。current34/next35，126总表/138FK不变；不重复运行无变更的 Web/Admin 构建或浏览器，Docs构建与当前Go/合同/架构门禁单独记录。私人索引/检索的既有同意不会自动授权本片向任何模型发送内容。
