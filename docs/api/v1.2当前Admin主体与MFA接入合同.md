> 责任阶段：V12-02b；治理前置的当前主体与强度证明三态通过，治理业务接入继续。

`ResolveAdminSessionPrincipal` 仅接受可信Admin域JWT入站提供的签名subject/session tuple。Identity从独立Admin账号与会话加载当前active状态、撤销/过期及正版本，提供不含credential hash、refresh材料或MFA秘密的窄 `AdminSessionAuthorityReader`。两次当前完整authority快照必须一致，MFA指针深拷贝，返回前检查取消；验证/DTO解析本身不授予治理权限。冻结 `campusos.principal/v1` wire字段不变，账号/会话版本、过期时间和MFA时间留在宿主Port内。

命令事务使用实际Admin账号→会话锁，缺lock适配器失败封闭，PG必须有实际SQL事务；Memory通过事务标记隔离验证。旧 `VerifyAccess` 也复用该验证边界。Admin JWT的AuthVersion为协议版本1，不能与可变的会话CAS版本相等比较；MFA升级后的原有效JWT仍能解析当前升级强度。

MFA强度来自真实会话时间：当前窗口为15分钟，准确到期边界或超过窗口降为password，会话仍可用于基础账号访问，治理规则需重新step-up。mfa状态缺时间、零值或未来时间拒绝。过期会话/撤销会话/停用账号不能产生主体。HTTP适配器输出同一当前派生强度，中间件比较签名subject与实际会话account，不接受不同主体、未知strength或非版本1；可信auth_version也传入后续resolver，请求头不能替换身份或加强认证。

7项新增必需顶层覆盖纯绑定/指针漂移、真实Memory身份生命周期、真实User/Admin JWT HTTP及两个真实PG测试。120必需=7新+107既有业务回归+6Admin登录/刷新/MFA/HTTP回归，无FAIL/SKIP/race，24真实PG。新增8个已提交账号停用/ABA、会话撤销/版本/owner/过期及MFA时间变化拒绝；第二连接NOWAIT证明账号/会话实际锁，升级后仍绑定AuthVersion1。
