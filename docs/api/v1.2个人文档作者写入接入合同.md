HTTP 只使用当前 User Session proof 的 checked 方法。服务从已验证主体及实际 Document/Version 加载 owner、状态、版本与源引用；保存/历史恢复/回收要求实际 active，恢复要求实际 trashed。跨 owner 返回404，同ID Admin、缺proof或撤销会话返回401。此处是本人写入规则，不由 `personal.document.read` 的 allow 推出写许可，不扩展冻结五动作。

新对象通过有界 ObjectPort 在 SQL 外保存。命令事务先复核并锁定 User/Session，再锁定 Document、当前/选中的历史 Version、新对象及历史源对象；比较初始完整快照与当前事实。历史恢复还绑定实际源格式、大小和摘要，复制后产生新的不可变版本；返回前核对实际完整 Document、新 Version/Object receipt 和当前完整 Principal。回收仅返回脱敏元数据，隐藏版本与字节引用。

Document/Version、二进制 unsupported preview、必需平台审计及preview outbox同事务；审计以实际 `document.author.<operation>` 记录用户域主体。失败无部分结果，按新对象的原始 receipt 执行有界补偿；取消请求不取消清理。若独立事务已改变该对象版本，删除 CAS 必须拒绝，返回明确 compensation-pending 错误，保留仍归属本人、未进入文档引用的对象供受管清理；不得用新版本强行删除。此边界在4个真实PG竞争中验证，不宣称改变过的对象已经清理。

定向Memory/race与实际User/Admin JWT SessionService HTTP六路径通过。Linux owned PostgreSQL16/tmpfs共107必需顶层（10新+97回归）、22真实PG，无FAIL/SKIP/race；新增26已提交credential/document ABA/version/Object变化拒绝、6必需审计回滚。第二连接NOWAIT证明凭据、文档、当前/历史版本和源/新对象实际锁。失败日志 `.6tQeGZ`/`.Knm9Pl` 保留；最终新对象版本从真实UPDATE RETURNING读取，不按初始版本猜测。
