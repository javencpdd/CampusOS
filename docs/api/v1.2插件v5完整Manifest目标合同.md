# v1.2 插件 v5 完整 Manifest 目标合同

状态：V12-G1 冻结单一 wire Manifest 与拒绝语义；V12-03a 实现包解析/SDK/CLI，03b 完成验签、安装与状态持久化。

机器合同：[完整 Manifest Schema](plugin-v5-manifest-v1.schema.json)、[错误目录](plugin-v5-manifest-v1.errors.json)、[SDK DTO](../../sdk/typescript/src/plugin-v5-manifest.ts)、[离线检查](../../scripts/check-v12-plugin-v5-manifest-contract.mjs)。签名、不可变包摘要和版本冲突采用[发布外封](plugin-v5-release-v1.schema.json)，发布外封不放进包内自签内容。完整 Manifest 复用已冻结的[包形态](v1.2插件v5包形态与版本协商合同.md)、[consumes](v1.2插件v5消费能力与范围合同.md)、[provides](v1.2插件v5贡献点与调用DTO合同.md)、[宿主资源](v1.2插件宿主资源与非侵入式安装合同.md)和[配置](v1.2插件配置Schema与Secret分流合同.md)语义。

顶层固定 api_version、publisher/key/version、host_contracts、runtime、consumes、provides、configuration、data；无运行后端的 UI 包只含 UI，wasm/container 后端必须声明对应 artifact 和 host_resources。data 声明系统/用户配置域、私有 KV/对象配额及升级 Schema 版本、变更方式和可恢复性。声明资源、能力和贡献不等于授权；宿主实时目录、管理员 Grant、用户同意、Runner 强制边界仍须逐层求交。插件不得通过 Manifest 注入安装脚本、数据库连接、宿主文件或未发布 extension point。

有数据变更的 migrate 不能直接宣称可快照回退，除非 03b 提供可验证的真实快照和恢复语义。本离线合同保守拒绝这种组合。Schema 可校验包结构与目录投影，不能验证包字节、签名、真实授权或真实运行。03a/03b 必须用真实目录、验签和安装替换合成夹具。
