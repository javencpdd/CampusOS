# v1.2 独立管理员空间配额与管理读取合同

> 更新时间：2026-10-16 03:01（Asia/Shanghai）
> 状态：本切片实现、自动化与 Linux PostgreSQL 目标三态通过

三个实际入口为 `PUT /spaces/admin/users/:user_id/storage`、`GET /spaces/admin/users/:user_id/storage` 和 `GET /spaces/admin/summary`；路径以生成的 HTTP 路由矩阵为准。固定权限为 `personal_space.space.manage`，服务端分别构造目标配额、目标存储状态、全局摘要三个精确 Scope。

写入使用当前独立 Admin 账号、会话、角色绑定、permission17 与十五分钟 MFA，命名配额 Policy 绑定完整目标 User 和配额24事实。目标 User 可为停用状态，不借用同 ID User 角色。窄事务数据 Port 保留真实 User/配额行与 owner admission 锁，以预期版本 CAS 写入 actor18 管理员归属，使用实际返回的精确版本回执重核结果。必需 audit/outbox 与写入原子；仅提交后发布单调缓存提示，当前授权始终读取持久化事实。

配额请求仅接受有界严格 JSON，额度范围 1 MiB–100 GiB。安全 ACK 只含 `owner_id`、`quota_bytes`。额度低于已用空间允许成功，可用空间归零；不删除字节或文件。Admin 页面验证 ACK 后重新读取当前存储状态，失败清除旧状态、保留草稿；旧用户/旧对话框的晚到响应不得覆盖当前选择。

两条 GET 使用命名管理元数据 Policy，接受当前 password 会话，禁止请求正文并返回 private/no-store。存储状态绑定完整目标 User、Space23/default、Quota24/default、配置与当前使用量；摘要仅加载库存版本和聚合谓词。初次、资源读取后及整份结果返回前重新验证完整当前 Admin 权限，空集亦然。响应不含标题、样式正文、禁用原因、原始同步错误、文件内容或宿主路径。

前向迁移24仅增加既有配额表完整行非复用事实版本；任何字段或主体归属变化均推进版本，删除重插也不能复用。down 保留所有原配额、旧 User FK、actor18 历史及序列高水位。使用一次性 PostgreSQL 专属库验证23/24往返；禁止用测试脚本重置共享数据库。

实际证据与尚待验收项记录于 [v1.2.106-dev](../进度/v1.2-dev/v1.2.106-dev.md)。组件测试与 Windows 交叉编译分别只证明本地组件行为和编译，不替代实际 PostgreSQL 或浏览器验收。
