# v1.2 空间源码样式目录读取合同

> 更新时间：2026-10-15 21:57（Asia/Shanghai）
> 状态：本切片实现、自动化和 Linux PG 目标三态通过

本切片仅接入 `GET /spaces/me/styles/packs/sources`。生产 `PersonalSpace.Module → Appearance.Application → AuthenticatedSpaceStyleCatalog → Service` 显式转发完整当前 SessionResolver；固定服务端 owner/style_catalog 规则，不接受客户端 owner、scope、operation、path 或事实。缺当前证明返回401，缺新 Port/typed nil 返回503，不回落旧裸 userID 方法。GET 不接受正文，成功使用 `private, no-store`。

读取由当前 Identity UserReader 完整七字段投影（含既有Email，不含凭据或账户内部字段）、Space23 原始行或默认无行、Owner、当前 Feature 启用状态和源码目录事实组成。规则只允许当前 user 读取自己的目录；与资料读取一致，空间禁用时仍允许检查目录，不授予样式应用权限。相同 Policy 在投影前后重新构造，会话/凭据在返回前复核。真实无目录与已存在空目录均绑定其根和存在性，不能因结果为空而跳过证明。

私有目录快照记录实际绝对根、解析后的根、全部候选条目及同一次加载产生的完整 strict Package（含隐藏 RawFiles）。比较完整已加载内容，不只依赖公开 checksum；正文、manifest、预览、额外资源、条目增删或根变化均拒绝。校验器遍历 map 产生的提示按字段排序，提示顺序不构成资源变化。对不可读取包只产生安全的无效结果，不读取外部链接。

目录读取器使用 Go 1.25 `os.OpenRoot` 将文件读取限制在包根内，拒绝符号链接和非普通文件，保持80文件/4MiB单文件/16MiB总量约束；读取前后校验实际打开文件身份、大小和修改时间，实际读取受字节上限约束。文件系统失败使用固定安全提示，不能将宿主路径错误返回API。快照是一次请求内的重复观察，不是外部管理员文件修改的持久 watcher 或跨文件系统串行化事务。

显式 `SpaceSourceStylePackList` DTO 保留名称、版本、目标、显示信息、checksum、预览、manifest、validation；删除旧响应条目的物理 `path`，没有 RawFiles。空列表编码为 `[]`。Web 源码目录类型同步移除 path，已有预览继续使用公开的已声明资源 URL；当前目录刷新失败会清除旧选项，不能继续按过期目录应用。

目录属于管理员分发的公开 UI 包；其公开已声明资源语义保留。本切片没有空间/快照/audit/outbox/容量/文件写入，无新 DDL（current23/next24）。其他样式 validate/preview/export/examples、独立 Admin 与阶段退出仍待接入。证据：[进度 .103](../进度/v1.2-dev/v1.2.103-dev.md)、[隔离复跑](../../scripts/v12-02b-space-style-catalog-drill.sh)。
