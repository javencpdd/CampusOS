# v1.2 插件 v5 包字节与签名合同

> 更新时间：2026-10-16 20:34（Asia/Shanghai）
> 范围：V12-03a；安装持久化、Dispatcher和Runtime按后续阶段实现。

唯一当前包wire为`campusos.plugin/v5`。源码与发布树以`plugin.json`为入口，完整字段沿用[Manifest合同](v1.2插件v5完整Manifest目标合同.md)。主CLI和服务器不从旧YAML、v4安装目录或开发源开关回退，也不把v5转换成旧Manager Manifest。

## 字节与归档

发布文件仅包括`plugin.json`、`dist/`、`schemas/`及可选`README.md`、`LICENSE`。源码、node_modules、本地数据及根目录环境配置不随包发送。路径必须规范、相对、ASCII且最多512字符；源码捕获拒绝符号链接，使用受根目录约束的文件句柄与inode复核，捕获后只验证和打包同一份内存字节。

包使用按路径排序的USTAR＋gzip，固定文件mode和零时间戳。同一输入得到同一压缩字节。压缩/展开上限均为64 MiB，单文件32 MiB、最多1024文件；源码最多4096项、32层目录。归档不提取到磁盘，拒绝重复、路径穿越、绝对/非规范路径、目录项、软硬链接、设备、PAX扩展、未知文件范围、超限、坏CRC、截断、隐藏尾随字节和拼接gzip流。

UI入口、Wasm和引用配置Schema必须存在且摘要匹配；Wasm须有正确版本头，配置Schema使用封闭有界子集。Container只接受固定`@sha256`引用，包检查不拉取或执行镜像。完整Wasm ABI与隔离由05/06验证。

## 信任与发布身份

[发布外封](plugin-v5-release-v1.schema.json)在包外，`package_digest`是完整压缩包字节的`sha256:<hex>`。发布者、key和version必须与包内完全一致。签名为标准base64的64字节Ed25519签名。消息为以下ASCII域前缀（末尾一个NUL字节）后接UTF-8 JSON，字段顺序固定、无空白：

```text
campusos.plugin-release/v5\0
{"publisher":"…","key":"…","version":"…","package_digest":"sha256:…","key_id":"…"}
```

前缀和JSON实际直接拼接，中间无换行。字段的ASCII约束来自Manifest和key_id校验。Go与独立Node已做双向互操作。

[信任文件Schema](plugin-v5-trust-v1.schema.json)按publisher＋key_id固定公钥，严格验证base64、长度、重复键和active/revoked状态；不信任包自行携带的公钥，不复用User/Admin JWT、Host Token或Integration凭据。签名失败、缺失、已撤销、跨发布者或摘要不符均失败关闭。错误目录见[package errors](plugin-v5-package-v1.errors.json)。

宿主`PluginV5PackageCatalog`独立于旧Manager，持有当前信任与不可变发布索引。同一publisher/key/version的同一摘要可幂等核对，不同摘要拒绝；校验与记录和信任切换在同一锁内线性化。信任撤销后的新核对不能使用缓存允许。该索引是当前进程的包验证基础；03b负责入库、安装/Operation、恢复和重启后的持久身份，不由03a内存索引代替。

## 目录与生产切换

[当前Host目录](plugin-v5-host-catalog-current.json)及[扩展DTO目录](plugin-v5-extension-catalog-current.json)由真实Go工厂生成，并供主CLI/源码检查器使用。当前尚无可调用v5 Host能力，目录items为空；三类扩展DTO可以检查声明，不能据此认定有已安装Provider。生产不注册G1合成集合/能力。03c负责Dispatcher和可调用目录，Knowledge的实际生产者归09a/14c。

旧v4→Manager适配和启动发现已移除；旧CLI流水线已删除。HTTP包导入、预检、导出、回退返回503，直到03b接入操作状态机。历史旧DTO/校验代码仅供旧记录、基线检查和测试，不能作为当前入口；退役责任由冻结的[G1替换清单](v1.2旧机制删除与替换清单.json)叠加[03a退役覆盖](v1.2-03a旧机制退役覆盖.json)及自动门禁核对；历史G1文件和摘要保持原样。原资源下载独立于插件，未新增安装或运行授权。
