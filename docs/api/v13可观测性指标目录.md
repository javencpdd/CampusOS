# CampusOS v13 可观测性指标目录

> 由 `go run ./cmd/campusos-contracts --write` 从 `pkg/observability` 生成。指标名、类型、单位、标签和 series 上限属于稳定合同。

| 指标 | 类型 | 单位 | 标签白名单 | Series 上限 | 说明 |
| --- | --- | --- | --- | ---: | --- |
| `campusos_db_pool_acquire_duration_seconds_total` | `counter` | `seconds` | 无 | 1 | Cumulative PostgreSQL pool acquire duration. |
| `campusos_db_pool_acquire_errors_total` | `counter` | `errors` | `kind` | 4 | Cumulative PostgreSQL pool acquire failures. |
| `campusos_db_pool_acquire_total` | `counter` | `acquires` | 无 | 1 | Cumulative PostgreSQL pool acquires. |
| `campusos_db_pool_connections` | `gauge` | `connections` | `state` | 8 | Current PostgreSQL pool connections. |
| `campusos_db_pool_empty_wait_seconds_total` | `counter` | `seconds` | 无 | 1 | Cumulative wait while the PostgreSQL pool was empty. |
| `campusos_email_delivery_duration_seconds` | `histogram` | `seconds` | `provider`, `result` | 32 | Email provider delivery duration. |
| `campusos_email_delivery_total` | `counter` | `deliveries` | `provider`, `result` | 32 | Total email delivery outcomes. |
| `campusos_external_requests_total` | `counter` | `requests` | `integration`, `result` | 128 | Total bounded external integration requests. |
| `campusos_http_in_flight` | `gauge` | `requests` | 无 | 1 | Current CampusOS HTTP requests in flight. |
| `campusos_http_panics_total` | `counter` | `panics` | `operation` | 512 | Total recovered CampusOS HTTP panics. |
| `campusos_http_request_duration_seconds` | `histogram` | `seconds` | `method`, `operation`, `status_class` | 512 | CampusOS HTTP request duration. |
| `campusos_http_requests_total` | `counter` | `requests` | `method`, `operation`, `status_class` | 512 | Total CampusOS HTTP requests. |
| `campusos_http_response_size_bytes` | `histogram` | `bytes` | `method`, `operation`, `status_class` | 512 | CampusOS HTTP response body size. |
| `campusos_identity_challenges_total` | `counter` | `challenges` | `operation`, `result` | 32 | Total Identity challenge outcomes. |
| `campusos_identity_mfa_total` | `counter` | `operations` | `operation`, `result` | 48 | Total Identity multi-factor authentication outcomes. |
| `campusos_identity_sessions_total` | `counter` | `sessions` | `operation`, `result` | 48 | Total Identity session outcomes. |
| `campusos_module_operation_duration_seconds` | `histogram` | `seconds` | `module`, `operation`, `result` | 512 | CampusOS module operation duration. |
| `campusos_module_operations_total` | `counter` | `operations` | `module`, `operation`, `result` | 512 | Total bounded module operations. |
| `campusos_reliability_consumer_duration_seconds` | `histogram` | `seconds` | `consumer`, `result` | 256 | Durable-event consumer execution duration. |
| `campusos_reliability_oldest_pending_age_seconds` | `gauge` | `seconds` | 无 | 1 | Age of the oldest pending or retryable durable event. |
| `campusos_reliability_operations_total` | `counter` | `operations` | `operation`, `result` | 64 | Total durable-event worker operations. |
| `campusos_reliability_queue_events` | `gauge` | `events` | `status` | 8 | Current durable events by queue status. |
| `campusos_runtime_goroutines` | `gauge` | `goroutines` | 无 | 1 | Current Go runtime goroutine count. |
| `campusos_runtime_heap_alloc_bytes` | `gauge` | `bytes` | 无 | 1 | Current Go runtime allocated heap bytes. |

禁止把用户 ID、邮箱、IP、帖子 ID、完整 URL、错误文本、Token、Secret 或任意配置值写入标签。External Plugin 不能直接取得 Meter。
