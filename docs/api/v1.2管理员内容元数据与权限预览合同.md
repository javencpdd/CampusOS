# v1.2 管理员内容元数据与权限预览合同

> 更新时间：2026-10-16 04:16（Asia/Shanghai）
> 状态：本切片实现、自动化与 Linux PostgreSQL 目标三态通过

| 入口（/api/v1） | 请求 | 返回 |
| --- | --- | --- |
| `GET /admin/threads` | page/page_size、版块/作者/数字ID及现行内容状态筛选 | 当前有权读取的 active 管理元数据和同谓词总数 |
| `GET /admin/threads/trash` | 同上，固定 trashed | 当前有权读取的回收站元数据和总数 |
| `GET /admin/threads/:id/moderation-actions` | page/page_size | 当前父帖的治理元数据和总数 |
| `POST /admin/threads/permissions-preview` | 严格 `{thread_ids:[...]}`，1–20个不同ID，至多8192 bytes | `{items:[{id,permissions:{...}}]}` |

当前独立 Admin、会话及完整角色/绑定/permission17 在服务端重新加载；User Token、同号 User、User 角色及客户端事实不产生管理权限。前三条 GET 不接收正文，四条均 private/no-store。读取使用 `community.thread.read` 的固定库存 Scope 和实际版块 Scope；命名元数据 Policy 不要求写入的十五分钟 MFA。

列表先过滤权限和已知业务状态，再计数、排序和分页，每页至多100项；关键字仅为数字ID，不能通过私有正文搜索结果推断内容。响应只含ID、作者ID、版块ID、内容类型、发布/治理/删除状态、置顶/锁定、创建/更新时间，不含标题、正文、标签、用户资料或事实版本。所有库存和空页在响应前完整重验。

治理历史每页至多100项，只含记录ID、帖子ID、命名动作、主体域、主体ID和时间；不加载或返回原因、前后自由文本或修订正文。未知历史动作归为 `legacy_unknown`，不合法主体归属不输出原值。父帖当前事实和完整历史/库存/当前权限均在整份响应返回前重验；purged 记录只提供有权读取的历史元数据。

预览只允许固定帖子类型和固定十一项操作：pin/unpin/lock/unlock、approve/reject、take_down/direct_restore、trash/restore_trash/purge。调用执行命令使用的同一纯 Policy 和当前实际版块权限；password、MFA过期或缺少写权限时对应布尔值为false。不存在、重复、空批、未知字段或整批事实变化时不返回部分结果。输入独立复制，较早条目也不能逃过最终重验。预览没有写副作用，结果不是可转交的执行凭据；实际命令继续在事务内重核当前来源和所需 MFA。

Admin 每页20项，读取后检查精确相同ID的有界预览；预览失败或错目标即清除当前行/计数/操作权限。单项和批量按钮消费当前布尔值，批量选项仅保留全部选中项共同允许的动作；实际批量执行沿用逐项命令与逐项失败结果。旧列表、历史、预览响应不得覆盖新的选择。

无新DDL；当前24，下一25。进度见 [.107](../进度/v1.2-dev/v1.2.107-dev.md)，PostgreSQL 编译跳过不作目标证据；完整 SPA 身份与真实浏览器另行收口。

Admin内容/回收列表、治理历史与有界权限预览三态通过：当前独立Admin/permission17、实际版块与命名元数据Policy，窄SQL不载标题/正文/标签/原因/用户资料，过滤在count/page前，完整库存/空页/历史最终重验。1–20不同实际ID预览复用十一操作的执行Policy，整批/较早条目复核，安全booleans无副作用、无执行凭据；Admin按当前结果限制单项/批量并拒绝旧响应。244必需/72真实PG、13新增/72纯规则/67真实JWT、216状态矩阵读取/23读取变化/18预览场景、八Admin组件，原231回归和共同门禁通过；无新DDL，current24/next25，23/24完整数据/actor18/高水位保留。
