# v1.2 主体上下文合同：campusos.principal/v1

> 状态：V12-G1 首个合同切片已冻结；Schema、SDK DTO 和离线验收已交付。
> V12-02a 已实现 Go 主体结构校验与公开帖子纯 Policy 切片；当前 HTTP/Session 仍使用原身份实现，未接入生产认证，不表示 V12-02a/02d 完成。

## 1. 范围与信任边界

本合同固定一个请求的**认证主体及凭据用途**，供后续 Policy、Integration、Plugin Gateway 对接。
[架构决策第 3 节](../项目计划书v1/项目计划v1.2/01-v1.2架构审查与扩展合同决策.md)中的
`actor_kind/actor_id` 在 wire DTO 中统一表达为 `actor.kind/actor.id`；不同时接受两套字段。
[JSON Schema](principal-context-v1.schema.json) 是字段级权威，
[TypeScript DTO](../../sdk/typescript/src/principal.ts) 经 SDK 公共入口导出，
[错误目录](principal-context-v1.errors.json) 属于目标合同，尚未加入当前 HTTP 错误目录。

只有宿主认证适配器可在验证凭据后构造权威上下文。请求体、插件响应、模型、索引或 SDK
自行构造的同形 JSON 均不可信。**Schema 合法不等于认证成功，更不等于资源可读。**
不得提供接受该 JSON 后直接授权的公共端点。对外投影只在具体调用合同明确需要时发送最少字段；
完整上下文不是默认广播给插件的载荷，不带密码、Token、摘要、密钥、邮箱或私人正文。

边界保持：资源 owner/版块/状态由所属业务服务实时加载；Policy Core 只接收可信事实 DTO，
不查找 Feature Service；SDK 不导入宿主 `internal/*`。本切片不定义 ResourceFacts、Policy 决策、
授权查询或委托 Scope 的表示，也不修改 DB、路由和当前鉴权。

## 2. DTO 与组合约束

| 字段 | 类型 / 约束 | 宿主事实来源 |
| --- | --- | --- |
| `contract` | 必填，精确为 `campusos.principal/v1` | 支持的合同版本 |
| `actor` | 必填，`{kind,id}`；匿名仅 `{kind:"anonymous"}` | 已验证凭据对应主体；不能从角色推导 kind |
| `audience` | 必填，取下表唯一对应值 | 验证后的凭据用途；不是页面、请求自报值或路由标签 |
| `authentication_strength` | 必填，取下表对应值 | 认证适配器验证结果；声明 `mfa` 不证明挑战已通过 |
| `credential_id` | 除匿名外必填；匿名禁止 | 活跃 Session、机器凭据或短期工作负载凭据的不透明引用；不是凭据原值 |
| `effective_subject` | 可选，仅 `plugin_instance` / `worker` 可携带 `{kind:"user",id}` | 经宿主重载验证的代理用户；不得代入 admin |
| `delegation_id` | 与 `effective_subject` 同时存在或同时缺省 | 绑定 actor、目标用户、用途、期限、动作及范围的受管委托引用 |

| `actor.kind` | `audience` | `authentication_strength` | 代理用户 |
| --- | --- | --- | --- |
| `anonymous` | `public` | `none` | 禁止 |
| `user` | `user` | `password` / `mfa` | 禁止 |
| `admin` | `admin` | `password` / `mfa` | 禁止 |
| `integration` | `integration_api` | `credential` | 禁止 |
| `plugin_instance` | `host_api` | `workload` | 可选，必须有委托引用 |
| `worker` | `worker` | `workload` | 可选，必须有委托引用 |

作者是资源关系，版主是用户角色，均不是新的主体类型。管理员与普通用户即使 ID 或邮箱相同也
不合并身份；比较、审计及缓存必须使用 `(kind,id)` 对，禁止仅以 ID 作主体键。后台治理由 admin
对目标资源执行命名动作，不使用 `effective_subject` 冒充被治理用户。Worker 的管理任务由受限
任务动作授权，不能借代理 admin 获得后台 Session。

已登录用户访问公开资源时仍保持 `user/user` 上下文；路由的 public 标签不把其凭据用途改为 public。
Schema 接受 password 强度的 admin，只表示类型正确；高风险动作是否必须 MFA、是否过期仍由
命名策略决定。机器或工作负载强度不是“比 MFA 更高”的全序等级，不能据此替代交互式认证。

ID 为大小写敏感的不透明字符串，1～128 个 ASCII 字符，首字符为字母或数字，后续允许
`A-Z a-z 0-9 . _ : -`。不 trim、不转数字、不按冒号拆解，也不解释为路径或权限 Scope。
未知字段、未知主体/用途/强度、显式 null、数字 ID、空值、空白、路径和通配符均拒绝；
可选字段不用时必须省略。所有对象禁止额外属性，不能注入 roles、owner 或旧 user_id。
TypeScript 表达组合约束；运行时的长度、字符和额外字段检查必须使用 Schema。

## 3. 版本、错误和宿主接入责任

v1 使用精确匹配，不自动降级、不将旧 user_id 视作 admin，也不通过忽略新字段容忍未知合同。
增加主体种类、用途、字段或改变约束时发布新合同版本，由调用双方明确协商支持后使用。
这不改变产品版本、当前 `/api/v1` 或 v4 插件合同。

目标适配器的结构检查顺序：先解析单个 JSON 对象；如果 `contract` 为未知字符串，返回
`principal.contract_unsupported`；其他结构错误返回 `principal.context_invalid`。目标 HTTP 映射
均为 400、`retryable=false`，仅返回错误目录中的通用文案，不回显上下文。解析器必须拒绝重复
键和尾随第二个 JSON 值；这属于后续 ingress 适配器责任，Schema 测试只接收已解析值，未声称
完成字节级解析。当前无该 HTTP 接口，本轮验收器中的错误分类只验证目标映射。

宿主接入时仍须按顺序完成：

1. 对应域验证器验证签名、issuer、audience、用途、到期和权威撤销状态；User/Admin 使用独立
   key/issuer/audience，Refresh/MFA/恢复票据不能作为该 DTO 的访问凭据。
2. 重载 `credential_id` 并匹配 `(actor.kind,actor.id)`；不能只验证引用存在。插件凭据绑定实例代次，
   不将 Package ID 当作实例身份；旧代次/停用后的凭据拒绝。
3. 有代理时重载委托并匹配实际 actor、effective_subject、期限和用途；权限是调用者、被代理用户、
   Scope、Grant/Consent 与当前业务事实的交集。无代理的机器/Worker 不继承用户身份。
4. 调用业务服务构造当前事实，再由 Policy 决定动作。撤权后的新请求必须拒绝；需要返回前复核的
   链路仍须复核。上下文对象不是可缓存的授权结果，认证强度也不能替代资源权限。

```bash
pnpm --dir sdk/typescript install --frozen-lockfile

node scripts/check-v12-principal-contract.mjs --report docs/项目计划书v1/项目计划v1.2/evidence/v12-g1-principal-linux.json
```

## 6. V12-02a 首个实现切片

[严格 JSON 解析](../../internal/modules/core/identity/port/strict_json.go)在版本分流前拒绝重复键（含嵌套/转义同名）、尾随值和非法 UTF-8，限制 32 KiB/64 层；随后拒绝未知/缺失/null 字段。错误只含固定代码，不回显凭据或上下文。
