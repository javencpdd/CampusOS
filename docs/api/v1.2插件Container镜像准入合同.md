## 2. 签名声明捕获

只接受 `runtime: container`、`backend.artifact.kind: container`、`transport: http|grpc` 及声明的宿主资源。捕获重新经过现行信任/签名和 publisher/key/version 的 write-once 包身份核验；同版本更换镜像导致包摘要冲突，撤销签名信任后再次捕获拒绝。没有源码目录再发现、解包安装、镜像拉取或启动。

`V5ContainerProgram` 私有字段保存镜像引用、传输、坐标、**签名包摘要**及资源/consumes。访问器返回资源和 Scope 数组副本。零值不能进入镜像核验。对象只是快照，后续真正创建实例前仍须重新核对当前信任/安装/Grant/所需 Consent/配置/代次，不能把旧快照当作实时授权。

本片采用冻结 Manifest wire 允许语法中的保守部署子集，不修改 G1 Schema：

- 必须包含明确 registry 与仓库，registry 为小写 DNS/IPv4 形式或 `localhost`，可带1–65535规范端口。
- 仓库路径为小写规范组件；镜像精确绑定 `@sha256:<64位小写hex>`。
- 拒绝默认仓库推断、可变标签、`repo:tag@digest`、scheme、空/点/父路径组件、参数、空白、大小写修正和非规范端口。
- 只声明 HTTP/gRPC 传输，不接受 Wasm 的 `host-call`。传输声明不构成实际服务端点。

引用最多512字节；解析不做 DNS、registry 或文件访问。更宽 wire 字符串可在包结构检查通过，仍被该部署入口拒绝；不能静默归一化到另一地址。

## 3. 本地 Docker 映射

首片验收时入口只支持原生 Linux 宿主，固定 `/usr/bin/docker` 与 `unix:///var/run/docker.sock`，仅执行 `image inspect`。每次创建0700临时空 CLI 配置目录，用有限 PATH/HOME/DOCKER_CONFIG；不继承应用环境、Docker context/远端地址、代理或 registry 登录配置，结束清理该目录。默认最长3秒并受调用者更短 deadline/取消约束，stdout最多64KiB，stderr不回传。

首片只投影镜像 ID、RepoDigests、OS 与 architecture，不读取或记录 image Env/Secret。返回必须满足：

1. `RepoDigests` 精确包含签名声明的完整仓库与 digest，不因相同摘要接受其他仓库。
2. 配置 ID 为完整小写 `sha256:<64hex>`，OS为Linux，architecture与当前Go宿主一致。
3. 元数据单对象、无未知字段/尾随JSON，RepoDigests最多64项，输出未超限。

Manifest/RepoDigest 与平台配置 ID 是不同摘要命名空间，不能直接比较两者 hash。核验依赖本地 Docker daemon 的内容寻址存储及其 RepoDigest 记录，不冒充独立 OCI blob/cosign 供应链验签。包签名绑定引用，不包含镜像层字节。

缺失镜像直接拒绝，不拉取、不回退到标签、其他仓库或配置ID。流式输出限额也作用于 `io.Copy` 路径，不能通过嵌入 Buffer 的 `ReadFrom` 绕过。

| 内部错误 | 含义 |
| --- | --- |
| `plugin.container_image_identity_invalid` | 零值程序、缺少精确 RepoDigest、非法元数据结构/项数或配置 ID |
| `plugin.container_image_platform_unsupported` | 非Linux入口、非Linux镜像或架构不匹配 |
| `plugin.container_image_unavailable` | 本地daemon/CLI不可用、缺失镜像、命令/输出接收失败或内部期限耗尽 |
| 调用者 Context 错误 | 调用者取消/期限；不返回迟到映射 |

这些是尚未发布到 HTTP 的内部错误，不回显 Docker 原始输出、宿主路径或凭据。

## 4. 验收及后续06边界

[scripts/v12-06-container-image-drill.sh](../../scripts/v12-06-container-image-drill.sh) 按 `target`、`common`、`documents`、`final` 运行。每次 target 使用 `.cache/v12-06-container-image/acceptance.*` 新目录，并设置绝对路径 `CAMPUSOS_V5_CONTAINER_IMAGE_DIR`。脚本冻结源码、HEAD、05/03c/01b三份依赖和开工核验，构建独占 scratch 测试镜像及两份 Linux race ELF，用 `env -i` 验证真实签名包→本地RepoDigest→配置ID；不会执行镜像的 `/not-executed` EntryPoint。结束只删除本任务独占镜像标签，并核对验收前后容器清单相同，不操作共享栈/数据。

原生必需测试集合不得 FAIL/SKIP/race，11项共同门禁及5项最终文档门禁通过才封存。目标包含签名/当前信任/不可变发布冲突、引用子集/副本、摘要命名空间区分、错仓库/错摘要/OS/架构拒绝、输出预算、实际本地镜像缺失与错误宿主 Docker 环境。未新增数据库路径或迁移，不用旧05运行证据冒充本片测试。

完整06仍需：实际 Container 创建与CPU/RSS/目录/网络/PID/凭据隔离；有限 HTTP/gRPC 端点和 Host Broker；当前授权/配置/代次与真实readiness、发布/撤下、取消/退出/重启一致性；Windows/Linux执行目标验收。此次镜像预检不满足这些退出条件，不进入07。

当前执行扩展额外投影并拒绝镜像声明的 VOLUME，避免匿名目录卷；支持固定本地 CLI 的 Windows 实现分支，但真实 Windows 目标尚未验收。Linux 运行、传输、授权与生命周期的当前证据见 [执行合同](v1.2插件Container执行沙箱合同.md)与 [.125](../进度/v1.2-dev/v1.2.125-dev.md)。上述首片报告保持历史字节，不代表后续实现缺失。
