## MCP 入口

`POST /api/v1/integration/knowledge/collections/:id/mcp` 使用 MCP **2025-11-25** 的无会话 Streamable HTTP、JSON 响应模式。该固定版本是支持合同，不宣称最新协议或全部可选能力。`GET` 同一路径在当前机器/集合授权后返回405/Allow: POST；无 SSE、会话分配、OAuth发现、通知推送或客户端采样。既有 Community `/integration/mcp/tools/:name/call` 保留原合同，不能将其当成此标准协议入口。独立后台 `/api/v1/mcp/*` 不接受机器凭据。

请求须单个 `Authorization: Integration <key>`、`Content-Type: application/json`，Accept 同时包含 `application/json` 与 `text/event-stream`；后续调用带 `MCP-Protocol-Version: 2025-11-25`。拒绝 Origin（含空头）、Cookie、URL query、多重凭据/协议头、不支持版本、批量JSON、重复或未知字段、null、非法Unicode。JSON不超过32KiB，安全整数或不超过128字节的非空字符串ID。返回直接JSON-RPC，不套平台data信封，Cache-Control为private/no-store。

独立白名单规则：`integration_mcp / knowledge.public.read / knowledge.source.read / public_collection / 精确集合ID`。HTTP `knowledge.search`、`knowledge.source.read` 和社区端点规则不能借给它；允许MCP不自动授权HTTP。规则、机器主体/凭据、有效期和集合/原来源事实每次重验。普通读取使用同一机器事务，来源锁、必需typed审计与Outbox提交后才返回，失败丢弃整个结果。

支持 `initialize`（选择上述协议版本、只声明tools）、`notifications/initialized`（202空体）、`ping`、`tools/list`、`tools/call`、`notifications/cancelled`。工具固定两项，无分页目录或动态注册：

| 工具 | 封闭arguments | structuredContent |
| --- | --- | --- |
| `knowledge_search` | query、page 1～100000、page_size 1～50 | KnowledgeSearchPage，完整当前候选终检后total/分页 |
| `knowledge_source_read` | member_id（km_32hex）、revision（64hex） | 当前VisibleSource，字段revision；过期引用不读取历史 |

工具结果同时提供text JSON和structuredContent，均为不可信公开资料，不执行正文指令/链接。未知方法-32601、未知工具/参数-32602；工具执行失败`isError:true`及固定`knowledge.*`文本，无内部错误/部分Total/正文。机器或Scope错误另用HTTP401/403；握手/目录/GET等非工具失败返回HTTP404/409/503的JSON-RPC error，不能返回伪造的工具result。

总在途请求上限16、同凭据4、每次5秒；活跃重复ID拒绝，不持久保存token/调用结果/allow。取消按凭据摘要+集合+规范化ID定位，不能取消initialize/其他凭据/集合；未知或已结束ID忽略。取消通知用无行锁的当前机器范围前后校验，避免被同一读取持有的主体行锁阻塞，不开放数据、不产生读取票据；成功202空体。实际读取仍走完整事务/必需回执。取消或期限后响应不包含原结果。

协议依据：[transport](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)、[tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)、[cancellation](https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/cancellation)。本轮使用独立wire客户端验证，不冒充官方SDK客户端认证。

## Managed Knowledge Host API

固定能力 `knowledge.public.search` 与 `knowledge.public.source.read`；manifest consumes 的scope必须为 `collection`、collection_ids为显式ID，不能用public/self通配。搜索请求为collection_id/query/page/page_size；引用请求为collection_id/member_id/revision。结果复用同一公开Port/当前引用DTO，不返回私人文档、原来源私密正文或特权owner视图。

调用经过当前受管实例凭据、签名包声明∩typed Grant∩需要时的本人Consent、安装/配置/代次/生命周期、Feature及精确集合Scope；插件不能提交owner/principal/ACL扩权字段。Host端点在授权、调用、100ms Runtime守卫和返回前重读当前结果，并比较包含来源修订/索引代次的完整摘要；无跨请求正文/allow缓存。已缓冲的结果遇到撤权、来源变化、Feature关闭、取消、期限或响应预算失败一律丢弃。

静态 `plugin-v5-host-catalog-current.json` 发布已实现的能力及**空可用集合清单**，不是实时集合目录。离线源码/签名包验证只检查已知能力、Scope形状和声明意图；不会伪造可用集合，亦不授予权限。显式快照验证器 `ValidatePluginV5Manifest` 仍严格要求collection_ids属于宿主提供的当前catalog。实际安装Grant与每次Host读取的当前Knowledge Port决定能否访问，收藏/删除/下架/原来源ACL变化不依赖重打包撤权。

## 作者 SDK 和示例

Go提供 `V5HostTransport`、`KnowledgeSearch`、`KnowledgeSource` 及完整强类型DTO；TypeScript提供同名小写helper与DTO，transport由运行环境提供，不携带URL或原始平台凭据。64位代次为十进制字符串。来源DTO字段为`revision`，检索citation中为`visibility_revision`。

`ServeV5ContainerChatWithHost` 在宿主已有独占stdin/stdout上同步yield Host并接收HostResult，保持原Invoke期限，至多32次，单JSON64KiB、帧96KiB；只允许两个Knowledge和既有Community公开reader。普通 `ServeV5ContainerChat` 保持不接受HostResult。SDK不监听、拨号或读凭据环境；任意第三方handler仍由既有原生容器期限/kill边界约束。

[示例程序](../../plugins/campusos.knowledge-reader/main.go)、[声明模板](../../plugins/campusos.knowledge-reader/plugin.json)、[离线构建器](../../scripts/build-v5-knowledge-reader.sh)。操作员须把模板collection_to_select替换为实际允许的集合，并把零digest替换成实际镜像RepoDigest后打包、签名和授权。独立构建仅公有Go SDK+标准库，不导入宿主internal。示例通过typed chat贡献承载验收请求；生产没有任意插件调用URL，也没有接入内建AI/RAG，外部Provider消费属14c。
