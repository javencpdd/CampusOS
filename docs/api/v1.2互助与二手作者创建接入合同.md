# v1.2 互助与二手作者创建接入合同

> 更新时间：2026-10-12 23:06（Asia/Shanghai）
> 责任阶段：V12-02b；本切片覆盖互助、二手创建，其他 Feature 写入仍待接入。

POST 互助、二手创建入口使用 `CreateForPrincipal`，由真实 Identity User Session 导出当前作者及完整 Principal。请求正文严格拒绝 author/created_by/Principal 等额外字段；查询 owner、认证强度或 X-Actor-ID 不影响身份。同 ID Admin 也不能作为用户作者。当前显示名来自 JWT 中间件实际会话校验，不能由客户端选择。

Community 发布窄 `AuthenticatedThreadCreator`，两个已启动的 ContentGateway 适配器实现它。缺新端口、审计/事务装配或实际类型配置时失败关闭，不回退裸 ID 创建。新资源尚无编辑事实，不套用已存在帖子的 edit/read 权限。

Community 加载 raw 当前版块/group 的 ID、类型、active 生命周期、正版本、开放状态、默认标签与明确的 typed 配置；不使用兼容默认值补成允许。事务内锁实际用户、会话、版块、上级 group 及类型配置行，复核初始权限事实与完整 Principal。`ThreadTypePolicyLocker` 只在实际事务中工作，PG 不接受 Memory active 标记作为 SQL 行锁。原 discussion 创建同步使用这一锁与实际写入后资源版本复核，由后继回归覆盖。

Feature 仍拥有结构化 Detail：类型及枚举、creator、ThreadID、version=1、初始业务状态和完整持久化明细都须匹配。ThreadID 由 Community 分配；事务内保存后及最终身份检查时重读明细，版本或内容变化拒绝。Community 再加载真实插入行的 facts_version/owner/category/type/active，拒绝 participant 对底层帖子的额外篡改。时间以 PG 微秒精度和 UTC 规范化比较。

帖子、Feature Detail、内容修订、平台必需审计和 outbox 原子提交；任意检查、明细写入或必需审计失败均回滚，失败不返回部分结果。HTTP 使用安全错误映射，缺 proof=401、权限拒绝=403、非法输入=400、事实变化=409、缺检查端口=503；不暴露数据库诊断或宿主路径。
