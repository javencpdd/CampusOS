# v1.2 资产管理员读取合同

> 更新时间：2026-10-14 18:26（Asia/Shanghai）
> 状态：本切片实现、自动化与 Linux PG 目标三态通过

GET /admin/assets/summary 使用当前独立 Admin 的 personal_space.asset.read_audit、固定 summary scope 和纯 summary Policy；password 可读取低敏汇总。GET /admin/assets/:id/purge-preview 使用当前 manage、实际资产 scope 与15分钟 MFA，并复用固定 purge 元数据 Policy。User 角色或前端 actor/scope/eligibility 不是事实来源。

两个 GET 不接受请求体。汇总仅 statuses(status/count/size_bytes)、actions(action/count)、expired_invocations 和 generated_at；预览仅 asset_id/status/size_bytes/reference_count/eligible/reason。不返回文件名、用户身份、对象 key 或原文。

汇总固定时间的两次完整投影与最终完整当前 authority/config 必须一致；空结果返回数组且同样复核。汇总相等只表示报告的 aggregate 相等，直接 metadata ABA 恢复相同报告数据可被允许。预览另绑定完整 Asset22/非复用 nonce/引用与完整性守卫，并在返回前重新加载完整事实。

eligible 只表示当前元数据状态与零引用满足清除规则，不是执行凭证、原文读取权或删除回执。实际清除必须使用同一纯 Policy 并重验当前对象与必要事务审计。读操作没有业务/审计/outbox 变更。无 DDL，current22/next23。见[进度 .92](../进度/v1.2-dev/v1.2.92-dev.md)。

独立 Admin 资产汇总/清除预览三态通过：当前 read_audit 固定 aggregate scope 与 manage/实际 Asset scope/MFA、固定 summary 与共享 purge 元数据 Policy；固定时间两次完整汇总及空结果最终 authority/config，预览完整 Asset22/nonce/引用与守卫/最终证明；no-body/safe DTO，无私有文件信息或写副作用。99 必需/36 真实 PG、320+16纯策略/99精确权限组合、26当前与状态场景/19实际读取后反例/16 signed JWT、14当前PG/两最终权限变化及第三真实空DB的三 current/revoke/ABA、原92回归与共同门禁通过。
