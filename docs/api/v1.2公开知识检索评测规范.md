## 范围与标注

[中文黄金集](../项目计划书v1/项目计划v1.2/evidence/v12-10-chinese-golden.json)版本 `2026-10-22.1`，包含人工编写的 30 条校园 FAQ、100 个固定查询及预先标注的相关来源。主题覆盖图书馆、宿舍、校园卡、网络、校医院、体育、食堂、教务、考试、资助、交通、就业、社团、邮件与无障碍服务。所有服务时间、办理规则及账号均为合成夹具，不作为真实校园办事信息。

90 个正例由每条 FAQ 的一个完整字面问句与两个显式关键词查询组成，另外 10 个查询应无证据返回。`question` 保存用户问题语境，`query` 才是发给搜索接口的实际输入；关键词查询是用户显式输入，没有测试端或服务端隐形自然语言改写。相关标签来自 FAQ 事实，不从检索结果反推；全部 100 项必须执行，不抽取通过子集。此集验收 v1.2 的字面词法搜索，不声称通用中文语义理解、真实用户研究、模型问答或 RAG 质量通过。

质量阈值：Top-1 命中率 ≥90%，Recall@5 ≥95%，MRR@5 ≥0.90，无证据准确率 100%，返回的前五项引用经实际来源 HTTP 精确重开正确率 100%，越权来源/正文/片段/计数泄露为零。保留逐条实际查询、预期来源、前五项、名次、总数与耗时，不仅保留聚合分数。

## 容量与隔离

[容量配置](../项目计划书v1/项目计划v1.2/evidence/v12-10-capacity-profile-linux.json)在执行前固定实际宿主 CPU、内存、内核、Go 并发与数据范围：10000 原帖子、两个 owner 的 200 个不入索引私人文档、零外部插件；单公开集合满额 1000 个投影，去重后 999 来源（979 discussion、10 RichText、10 官方）。其中一个来源重复选入，用于验证来源去重与分页计数；另外十篇已私密原帖不能入索引。集合全文仍受 4MiB 上限约束。

以普通非 race 二进制的正常生产 Server 模块图、HTTP router 和回环监听测性能；race ELF 单独用于安全/并发回归。8 并发分别测选择性查询、广泛命中第一页和精确引用重开，各 100 次，成功请求 p95 ≤1000ms，失败和越权成功均为零，API 进程观测峰值 RSS ≤512MiB。索引由常驻 worker 正常运行，首次完整就绪 ≤180 秒，完整重启后就绪 ≤120 秒。不得手工推进生产索引页或注入预计算结果。原生组装目标与独立 cmd/server、浏览器目标分别标识，不互相冒充。

该测试是固定规模的工程验收，不是生产 SLA。G0 的其他 HTTP 路径仅提供绝对预算参考，不能将不同端点的 p95 作同比回归结论。保留全部原始样本、进程 RSS 观测、索引/重启时限和准确硬件配置；超限则修复或保持阶段未验收，不能事后放宽冻结阈值。

## 方案选择与失败关闭

先运行当前完整复核扫描作为基线，同时测 PostgreSQL 参数化字面候选提示（只用绑定参数、不执行查询语言）。候选提示的 SQL 耗时不是包含来源授权的总耗时，也不能作为输出权限。仅在实测需要时修改检索后端；不因其他产品采用向量而安装扩展或调用外部模型。

任何优化都须保留原域 G1、当前集合/规则/成员/板块代次、正文修订及完整索引代次的约束；引用、去重、计数与分页统一，返回前再次检查。跨请求缓存不得复用旧 allow 或正文；无事件撤权、Feature 热停用、取消、停止/重启、其他集合及歧义输入都必须有独立正负证据。Windows 沿用用户明确延期，不计当前 Linux 阶段的跨平台通过。
