# v1.2 其他 Scope 与委托边界目标合同

状态：V12-G1 冻结非版块 Scope 的目标结构、拒绝码与离线验收；V12-02a 已交付 Go 纯 Policy Port、严格 host codec 与 Linux 原生组件验收（见文末）。02c/03b 才实施仓储、机器/插件主体与真实出站限制。[版块治理](v1.2版块治理委托上限合同.md)继续使用其独立合同。

机器合同：[Schema](scope-delegation-v1.schema.json)、[错误目录](scope-delegation-v1.errors.json)、[SDK DTO](../../sdk/typescript/src/scope-delegation.ts)、[定向检查](../../scripts/check-v12-scope-delegation-contract.mjs)。

首批非版块授予只允许公开知识集合 ID、系统配置键与精确 HTTPS 端点三个 Scope，分别绑定 knowledge.source.read、plugin.config.system.read、integration.webhook.invoke。个人文档首版仅本人，明确不可委托；未知动作、通配符端点和空范围均拒绝。插件、Integration 不是用户或管理员 Session，不能凭借一个 grant 获得另一个能力。

授权者必须是已通过 MFA 的独立 Admin，且拥有与收件域相应的管理动作。每个候选动作必须由同一条当前有效、可委托的上限完整覆盖：动作与 Scope 类型相同，ID 是精确子集，起点不早于当前或上限起点，终点不晚于上限终点，认证要求不可降级。不能跨不同上限拼接动作、ID、期限或 MFA。User 收件人的版块治理另走专用合同，不通过此合同扩大能力。

输入中的 actor、管理权、上限、时钟和 facts_version 由宿主构造；浏览器/插件只能提出有限候选意图。允许的离线结果仍须在同一事务内重读事实、版本与时钟，写入授予与必需审计；撤权提交后的新调用必须拒绝。离线 23 夹具、4 次变更复核只证明合同规则，不证明持久化与出站 Broker 已接入。

## V12-02a 纯 Scope 委托策略 Port

[Go DTO、严格解析与校验](../../internal/modules/core/identity/port/scope_delegation_policy.go)实现本合同的宿主事实输入。输入限制为 32 KiB 与 64 层，拒绝重复键（含转义同名）、未知/缺失/null 字段、尾随值、非法 UTF-8 与孤立 UTF-16 surrogate；时间以精确整数毫秒处理，拒绝小数、负数与溢出，绝不把时间舍入授权窗口。ID 长度按 Schema 的 UTF-16 单元 1–128 计数，不借用 Principal 的 ASCII 限制；本合同没有独立的不支持版本码，合同字符串不符即 `scope.input_invalid`。

[纯求值器](../../internal/modules/core/identity/policy/scope_delegation.go)没有缓存、仓储、凭据读取或环境时钟，按冻结次序判定：actor 域与 MFA、按收件域映射的管理动作、个人文档不可委托、user 收件人移交版块治理合同、bound 当前有效性，最后是单条 bound 对动作/Scope 类型/ID 子集/期限/认证强度的完整覆盖；endpoint 候选逐个校验精确 HTTPS 形状（禁通配、localhost 与 IP 字面量）。接受只表示提案在当前事实下成立，不是已提交授予。

[Linux 演练](../../scripts/v12-02a-scope-delegation-drill.sh)先运行冻结 G1 合同，再以其独立 oracle 生成 70 个输入（23 个夹具、47 个收件域/管理动作/主体/生命周期/窗口/Scope/端点/强度组合）；Go 原生 race 二进制在 `env -i` 下输出实际结果，由该 oracle 再核对（17 accepted、49 deny、4 输入拒绝）。证据在[原始报告](../项目计划书v1/项目计划v1.2/evidence/v12-02a-scope-delegation-linux.json)与[.30 进度](../进度/v1.2-dev/v1.2.30-dev.md)。本验收不表示 PostgreSQL、Memory、HTTP、真实机器/插件主体、出站 Broker 或授权写入路径已接入；生成语料数值保持 JS 安全整数范围，更大 int64 仅由 codec 单测覆盖。
