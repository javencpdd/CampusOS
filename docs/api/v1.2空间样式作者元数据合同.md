`PersonalSpace.Module → Appearance.Application → AuthenticatedSpaceStyleCommands → checked Service` 显式转发完整当前 SessionResolver。缺新 Port、当前证明或目标时关闭，不回落旧裸 ID StyleApplication，也不使用旧 TrackOperation 包装本来可以原子提交的元数据操作。旧兼容方法保留；HTML/ZIP/source 及样式预览/导出/校验仍需后续逐条接入。

固定 owner/style_apply、style_default、style_rollback 规则，从当前 User 与完整 Space23/default、Owner 以及全部 Snapshot23 行构造事实。实际 User/Session/Space、全部既有快照行和 owner admission（含空库存）锁中重建同一规则；当前凭据/Feature config 和完整最终结果重验。默认无行时间规范化为零，真正创建才赋宿主 ID/UTC 微秒时间。

apply/default 保存唯一一条精确旧样式快照，只允许预期 style 字段和创建 bookkeeping 变化。请求、预期模型、写给仓储的参数互相去别名；旧历史原始行完整保留，新快照为23正向非复用 nonce。rollback 从实际全部库存按 created_at、事实 nonce 确定最新记录，不接受客户端选行，不依赖旧 Memory append 与 PG 无 tie 排序的差异；不回滚到不安全历史 manifest。空间/历史/必需 audit/outbox 原子，响应及事件不含私有样式内容。
