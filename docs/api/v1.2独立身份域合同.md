# v1.2 独立 User/Admin 身份域目标合同

状态：V12-G1 冻结目标 DTO、错误与离线拒绝矩阵；当前运行时仍为 v1.1 共用用户账号路径。V12-02d 负责 PostgreSQL、Memory、HTTP、Session/Refresh、MFA、邮件挑战、恢复与审计的真实切换。

机器合同：[输入 Schema](identity-domains-v1.schema.json)、[错误目录](identity-domains-v1.errors.json)、[TypeScript DTO](../../sdk/typescript/src/identity-domains.ts)、[离线检查](../../scripts/check-v12-identity-domains-contract.mjs)。

User 和 Admin 的账号、凭据、角色绑定、会话、恢复存储分别独立；签名 issuer、audience、key ID 亦分别独立。同一数字 ID 或邮箱不能合并主体或角色。Token、Refresh、MFA、邮件挑战、恢复凭据只能在签发域及目标账号消费。任何用户角色分配、后台入口或插件声明都不能自动创建 Admin 准入。

管理员创建、停用、撤销、恢复由 Admin 主体并以 MFA 执行；首次显式 bootstrap 只允许无有效安全管理员且 bootstrap 已启用时由受控系统入口执行。撤销或停用最后一位有效安全管理员拒绝。所有管理操作必须提供审计原因；02d 还须将操作者、目标、提交顺序和恢复步骤写入可核查审计。Schema 仅定义传输结构；仓储唯一约束、密钥隔离和认证强度由 02d 实施。

离线检查构造 32 个正反例，覆盖五类挑战跨域、五种身份绑定字段混用、七种域配置共享、同 ID 不混权、最后管理员和 bootstrap。此证据不能替代 02d 的 PostgreSQL/Memory 与真实 HTTP 验收。
