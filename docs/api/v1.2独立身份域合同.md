# v1.2 独立 User/Admin 身份域目标合同

状态：V12-G1 冻结目标 DTO、错误与离线拒绝矩阵；V12-02d 已交付 Go 纯 Policy Port、严格 host codec 与 Linux 原生组件验收（见文末）；当前运行时仍为 v1.1 共用用户账号路径。02d 后续切片负责 PostgreSQL、Memory、HTTP、Session/Refresh、MFA、邮件挑战、恢复与审计的真实切换。

机器合同：[输入 Schema](identity-domains-v1.schema.json)、[错误目录](identity-domains-v1.errors.json)、[TypeScript DTO](../../sdk/typescript/src/identity-domains.ts)、[离线检查](../../scripts/check-v12-identity-domains-contract.mjs)。

User 和 Admin 的账号、凭据、角色绑定、会话、恢复存储分别独立；签名 issuer、audience、key ID 亦分别独立。同一数字 ID 或邮箱不能合并主体或角色。Token、Refresh、MFA、邮件挑战、恢复凭据只能在签发域及目标账号消费。任何用户角色分配、后台入口或插件声明都不能自动创建 Admin 准入。

管理员创建、停用、撤销、恢复由 Admin 主体并以 MFA 执行；首次显式 bootstrap 只允许无有效安全管理员且 bootstrap 已启用时由受控系统入口执行。撤销或停用最后一位有效安全管理员拒绝。所有管理操作必须提供审计原因；02d 还须将操作者、目标、提交顺序和恢复步骤写入可核查审计。Schema 仅定义传输结构；仓储唯一约束、密钥隔离和认证强度由 02d 实施。

离线检查构造 32 个正反例，覆盖五类挑战跨域、五种身份绑定字段混用、七种域配置共享、同 ID 不混权、最后管理员和 bootstrap。此证据不能替代 02d 的 PostgreSQL/Memory 与真实 HTTP 验收。

## V12-02d 纯身份域策略 Port

[Go DTO、严格解析与校验](../../internal/modules/core/identity/port/identity_domains_policy.go)实现本合同的宿主事实输入。输入限制为 32 KiB 与 64 层，拒绝重复键（含转义同名）、未知/缺失/null 字段、尾随值、非法 UTF-8 与孤立 UTF-16 surrogate；字符串按 Schema 的 UTF-16 单元 1–128 计数；本合同无独立不支持版本码，合同字符串不符即 `identity.domain_invalid`。

[纯求值器](../../internal/modules/core/identity/policy/identity_domains.go)没有缓存、仓储、凭据读取或环境时钟，按冻结次序判定：域隔离（两域任一签名/存储字段相同即拒绝）、角色自动开通后台禁止、账号状态、凭据五元组绑定目标域、挑战域与目标账号绑定，然后是管理员生命周期规则（bootstrap 仅限受控 system 入口且无有效安全管理员；非 bootstrap 要求 admin 主体 + MFA；停用/撤销最后一位安全管理员拒绝）。接受只表示本次消费在域隔离上成立，不是认证成功。

[Linux 演练](../../scripts/v12-02d-identity-domains-drill.sh)先运行冻结 G1 合同，再以其独立 oracle 生成 95 个输入（32 个夹具、63 个生命周期/安全管理员/bootstrap/挑战/状态矩阵组合）；Go 原生 race 二进制在 `env -i` 下输出实际结果，由该 oracle 再核对（24 accepted、70 deny、1 输入拒绝）。证据在[原始报告](../项目计划书v1/项目计划v1.2/evidence/v12-02d-identity-domains-linux.json)与[.35 进度](../进度/v1.2-dev/v1.2.35-dev.md)。本验收不表示 PostgreSQL/Memory 账号、Session、JWT issuer/key 分离、恢复或 HTTP 中间件已切换。
