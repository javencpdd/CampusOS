# v1.2 插件 UI Host 与 Bridge 合同

> 更新时间：2026-10-18（Asia/Shanghai）
> 范围：V12-04；真实 Wasm/Container Runner 和硬资源隔离仍归 V12-05/06。

## 当前入口与授权

Admin `/plugins` 显式导入签名包、选择版本，分别批准业务消费与运行资源；安装、批准、启用是独立操作。审批记录当前 Admin、原因、截止时间（页面最长 30 天），能力必须逐项匹配该不可变版本的声明，资源数值和网络目标只能收紧。期限作用于整个版本 Grant，过期与撤销均关闭新 UI 和资源读取。界面展示当前声明的 Scope；Profile/公开集合尚无生产目录时，不提供任意 ID 输入或虚构选项。

User `/plugins` 只操作自己的安装和用途同意，不能放宽 Admin 限制。撤销或期限届满后，本人已安装的版本仍可见以便停用/卸载；其他 owner 的安装不会进入该列表。旧 Admin `/plugin-center` 跳转当前管理页。安装状态、操作状态和后端 observed 独立；UI-only 可以加载，但不能写出虚假的 Runner ready。

UI 读取复用当前两域 read Operation 权限：`GET /[admin/]plugin-v5/ui?parent_origin=...&after=...`、`GET /[admin/]plugin-v5/:publisher/:key/:version/ui`。前者有限分页并返回宿主分配的路由/界面、资产租约和父页 `frame_src` 策略；插件不能注入宿主组件或任意路由。当前页面每页 50，最多读取 4 页，超过范围明确失败。后者返回当前证明，不能作为 bearer token 使用。列表不返回配置或 Secret，详情只返回当前域/owner 的普通配置和引用。

## 独立资源域

原生必须同时设置 `CAMPUSOS_PLUGIN_UI_LISTEN`、`CAMPUSOS_PLUGIN_UI_ORIGIN`、`CAMPUSOS_PLUGIN_UI_PARENTS`。Origin 必须形如 `https://{isolation}.plugins.example.edu`，随机 32 位十六进制租约是独立子域；不同版本、owner、当前会话、授权/配置证明不共用页面 Origin。父页面是精确允许列表，不能位于同一插件隔离命名空间。部署须提供通配 DNS/TLS，开发默认 `http://{isolation}.localhost:3003`。

专用监听只提供 `/ui/<租约>/<不可变产物>`，不提供平台 API、源码、Manifest、宿主路径或配置文件。租约最长 10 分钟，最多 2048，4 个并发资产请求；每次资源访问重新核对当前包摘要/签名信任、身份、全局与本人安装代次、Grant、Consent、配置修订。Host 必须精确匹配该租约域，复制路径到其他租约域仍拒绝。仅 GET/HEAD，拒绝顶层 document 与 Service Worker。

资产 CSP 默认拒绝所有，脚本/样式/Worker 仅允许当前产物（PDF Worker 可用 blob），`connect-src 'none'`、禁止表单/子框架/对象和 base。父页在加载前安装有限 `frame-src` CSP，防止 iframe 导航到外域传送内容；iframe sandbox 仅有脚本和独立同源能力，无弹窗、顶层导航或下载权限。资源无缓存，不设置 Cookie；Docker Node 网关仅转发有限资源路径，剥离 Cookie/Authorization，不发布本地目录。

## 受限连接与调用

宿主先验证资源 URL 与预期 Origin，再核对 `event.source` 等于当前 iframe、精确 Origin、插件 key/version、surface、audience 和协议版本。随机 challenge 与单次 MessageChannel 建立连接；重复 ready 不替换活跃 Port。导航、卸载、src/身份变化、10 分钟期限到达即关闭旧 Port。异步执行捕获原 Port、原 handler 和身份条件，返回前重验，不能把旧结果发给替换后的 iframe。

每个消息最多 64 KiB、ID 最长 96 字符，每 Port 最多 4096 个唯一请求、32 个并发请求，单请求最长 30 秒。未知 envelope 字段、重复 ID、任意路径/URL、未知资源参数、非法范围拒绝。错误仅返回固定的安全信息，不泄漏内部异常或 Secret。

当前编译宿主仅实现：

- `config.read`：空参数；返回当前普通配置修订与精确数字 JSON 字符串 `values_json`，不返回 Secret 引用/原值；读取前后重新核对 UI 证明。
- `resource.describe`：仅当前 opaque invocation handle；资源必须属于当前 owner、插件和 surface，返回 PDF 名称与长度。
- `resource.readRange`：同一 handle、非负安全整数 offset、正整数 length（最多 1 MiB且不越界）；原业务 ACL/修订与 UI 证明在返回前再次验证。

SDK 的协议保留名不能产生能力；`config.update`、`backend.invoke`、`ui.requestSurface`、`records.*` 在没有本阶段编译适配器时明确拒绝。配置写入走宿主表单；新界面只能由宿主响应用户动作打开。不能恢复旧 Host Token 或把 User/Admin JWT 交给插件。

## PDF 三入口与展示

`campusos.pdf-viewer@3.0.0-dev.2` 为 UI-only，声明必需的 `ui.resource.selected.read` / `ui.surface.open` self 用途。文章附件、个人资源和个人文档由各自原业务服务决定 ACL；invocation 只保存有期限的不透明引用与当前证明，不携带路径/凭据。资源 AuthorityProof 绑定 owner 和当前授权，合法会话轮换不改变 owner；资产及 Port 另绑定当前凭据，旧会话仍拒绝。

PC/移动端均由宿主提供弹窗、侧边、全屏与新标签页。新标签页使用同源 BroadcastChannel 的单次内存交接：URL 只含 10 秒随机票据与 invocation，接收后立即去掉票据，令牌只经同源内存通道并由真实 `/auth/me` 复核，不写 URL、Cookie、持久存储或插件消息，也不会为打开预览轮换共享 refresh cookie。缺少该浏览器能力时明确提示使用弹窗或下载。

Grant/Consent 撤销、配置/安装变化、会话失效后旧资源/资产拒绝，宿主撤下已加载界面。无可用插件仍保留三条正常业务下载路径，下载 ACL 不因有无插件改变。

配置精确数值、选择器、Secret 分流见[配置合同](v1.2插件配置Schema与Secret分流合同.md)；部署见[配置与端口](../../docs-site/deployment/configuration.md#v5-插件与隔离界面)。前一切片 [.120](../进度/v1.2-dev/v1.2.120-dev.md) 的历史证据保持原样，完整阶段的当前三态以主计划及对应进度/机器报告为准。
