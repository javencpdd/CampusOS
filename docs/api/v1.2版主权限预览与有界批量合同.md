GET /moderation/me?thread_id=actual：当前签名User/current Session，实际Thread scope、与置顶/锁定命令相同命名UserPolicy和当前模块配置；低敏flags，delete_post恒false，不返回类别名称、owner或角色。

POST /moderation/threads/:id/access：严格16KiB JSON post_ids数组，最多50不同ID，固定community.post资源类型和post.delete动作；thread固定pin/lock。未知字段/客户端actor/scope/facts/action、重复/超量/跨帖拒绝。仅返回thread_id/pin/lock/posts[id,delete]；空posts仍复核当前User/完整关系/parent/config，非客户端能力。

实际受管Thread16/Post19，Identity current User完整凭据/作用域四表关系非复用版本，post.delete单条实际Grant65，采用与命令相同Policy。条目加载后、整批和空批最终完整复核；证明、权限、resource ABA、grant、Config变化关闭，显示counter变化允许。无写入/计数/审计副作用。后续执行仍重新认证和读取，旧true预览不能执行撤权后的写入。

Web以当前页实际Post IDs请求，逐Post决定删除按钮；ID/order/布尔形状及请求/viewer/page变化必须匹配，失败关闭。API模拟Vue组件不是实际浏览器。独立Admin及其他业务批量/预览另行验收，不扩大冻结Principal/G1/BoardGovernance动作。证据见[.82](../进度/v1.2-dev/v1.2.82-dev.md)。
