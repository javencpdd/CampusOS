# v1.2 个人空间作者资料合同

> 更新时间：2026-10-15 00:15（Asia/Shanghai）
> 状态：本切片实现、自动化与 Linux PG 目标三态通过

`GET/PUT /spaces/me` 从当前已验证 User Session 构造完整 Principal。实际本人范围由该 User ID 与完整 Space23/default absence 确定；请求的 actor/owner/scope/rawfacts 不授予权限。固定 `personal-space-owner-1` 支持本人资料读取与资料变更；已停用空间仍可本人读，拒绝资料变更。无当前凭据401，无本人/当前可写状态403，事实竞争409，数据/命令端口不可用503。

PUT 严格接受资料字段，服务层再次规范化和校验，不接收主体域/禁用字段/nonce。SDK 实际事务中重建同一规则事实并锁定 User/Session/Space 与 owner admission。无记录时使用独立默认事实，不重复比较每次生成的时钟；真正创建才分配宿主 ID/时间。仅请求选择的字段可变，no-op 保持事实版本，显式空筛选数组清空。

原始空间23完整私有行/nonce、预期模型、current User/config 与最终完整结果保持同源复核；传给仓储的是独立深拷贝，额外 metadata/actor/凭据变更使整条资料/必需 audit/outbox 回滚。命令响应/事件严格为 `{space_id, owner_id}`；不携带资料正文、样式、私有路径或可消费能力。

GET 使用相同固定本人域规则，前后完整资源和当前会话复核，默认空资料不创建数据库行。Web 保存后等待 ACK，再 GET 当前资料；写失败不覆盖已有配置。当前空间元数据读取不表示头像/样式/Admin命令已接入。

current23/next24，无新 DDL；证据：[.97进度](../进度/v1.2-dev/v1.2.97-dev.md)。全部V12-02b剩余路径和阶段退出继续。
