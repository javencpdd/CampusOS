# v1.2 插件 RSS 订阅与图文交接合同

> 最新更新时间：2026-11-15（Asia/Shanghai）
> 当前版本：RSS Publisher 2.1.0；旧 1.0.0 专用接入已退役。

RSS 的订阅槽位、RSS 2.0/RSS 1.0/Atom 解析、列表、图文预览和条目选择全部位于 `plugins/campusos.rss-publisher/frontend/`。宿主仅提供[通用网页读取与编辑器交接](v1.2插件通用网页读取与编辑器交接合同.md)，不包含 RSS 解析器、固定插件名工具栏或 RSS 专用路由。

2.1.0 是 runtime:none 的 UI-only 包，声明 ui.surface.open、web.public.read、community.article.compose 及可选 web.local.read，并以 isolation:opaque 加载。用户在普通浏览器中添加最多 6 个公开 HTTPS 订阅，插件通过 web.read 取得有界 XML，再由自身 JS 解析。DTD/实体声明、无效 XML、过深/过大结构拒绝；每次最多 20 篇，正文最多 40000 UTF-8 字节、最多 8 张图片。

插件预览清除脚本、事件属性、表单、iframe、SVG 等主动内容。远端图片 src 保持惰性，仅加载 web.read(image) 返回的 Blob。导入通过通用 editor.article.import，将内容作为不可信输入交给宿主二次清洗、确认和图片转存，再进入原生编辑器手动发布。

不再提供 `/rss`、`/rss-readers`、`rss-reader-agent/*`、`rss-reader-tools/*` 及 rss.feed/rss.media/rss.compose。旧专用助手、分发脚本、RSS 工具栏和服务端解析包已移除。新的通用本机助手供任意获批插件使用；默认服务器读取无需下载。

已有 1.0.0 不修改原包字节或冒用版本号。管理员按标准签名包流程导入、升级至 2.1.0，批准新声明；用户再按当前用途同意并启用。配置 schema 与本人 feed_1 至 feed_6 字段保持，正常升级沿用既有配置；旧不兼容版本不能继续取得 UI/能力，仍可卸载。升级不会自动替用户批准能力或发布文章。

源码入口：`plugins/campusos.rss-publisher/frontend/parser.js`、`main.js`、`plugin.json`。通用平台入口：`internal/plugin/v5_ui_actions.go`、`v5_ui_opaque.go`、`web/src/campus-ui/pluginHostActions.ts`。独立发布者使用相同标准接口，不需要在宿主增加插件名称判断。

## 读取位置与代理边界

服务器策略由管理员统一维护，用户不能提交代理地址/编号或关闭策略。2.1.0 可通过 web.clients.* 标准接口配对并明确选择本人客户端；该客户端的 HTTP/HTTPS/SOCKS5 代理仅在自己的电脑上配置，地址及口令不上传。

web.read 和 editor.article.import 可带 client_id，统一用于 XML、预览和导入图片；不选择客户端时使用服务器策略。来源网址不改写，原 feed_1 至 feed_6 保持。选择客户端后失联不回退服务器，登录会话轮换后保留不可用选择并要求重新配对；UI 配置刷新保留有效连接。

普通插件不能取得 User/Admin JWT、助手 token 或控制任意本地程序。旧专用接口不能复用。权限、下载、期限和公网校验见[通用助手合同](v1.2本机公开资源读取助手合同.md)。
