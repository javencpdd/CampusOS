# v1.2 插件 RSS 订阅与图文交接合同

> 最新更新时间：2026-11-15（Asia/Shanghai）
> 当前版本：RSS Publisher 2.0.0；旧 1.0.0 专用接入已退役。

RSS 的订阅槽位、RSS 2.0/RSS 1.0/Atom 解析、列表、图文预览和条目选择全部位于 `plugins/campusos.rss-publisher/frontend/`。宿主仅提供[通用网页读取与编辑器交接](v1.2插件通用网页读取与编辑器交接合同.md)，不包含 RSS 解析器、固定插件名工具栏、本机配对或 RSS 专用路由。

2.0.0 是 runtime:none 的 UI-only 包，声明 ui.surface.open、web.public.read、community.article.compose，并以 isolation:opaque 加载。用户在普通浏览器中添加最多 6 个公开 HTTPS 订阅，插件通过 web.read 取得有界 XML，再由自身 JS 解析。DTD/实体声明、无效 XML、过深/过大结构拒绝；每次最多 20 篇，正文最多 40000 UTF-8 字节、最多 8 张图片。

插件预览清除脚本、事件属性、表单、iframe、SVG 等主动内容。远端图片 src 保持惰性，仅加载 web.read(image) 返回的 Blob。导入通过通用 editor.article.import，将内容作为不可信输入交给宿主二次清洗、确认和图片转存，再进入原生编辑器手动发布。

不再提供 `/rss`、`/rss-readers`、`rss-reader-agent/*`、`rss-reader-tools/*` 及 rss.feed/rss.media/rss.compose。对应原生助手、分发构建脚本、宿主 RSS 工具栏和服务端 RSS 解析包已移除；普通使用不依赖 Windows 下载工具。

已有 1.0.0 不修改原包字节或冒用版本号。管理员按标准签名包流程导入、升级至 2.0.0，批准新声明；用户再按当前用途同意并启用。配置 schema 与本人 feed_1 至 feed_6 字段保持，正常升级沿用既有配置；旧不兼容版本不能继续取得 UI/能力，仍可卸载。升级不会自动替用户批准能力或发布文章。

源码入口：`plugins/campusos.rss-publisher/frontend/parser.js`、`main.js`、`plugin.json`。通用平台入口：`internal/plugin/v5_ui_actions.go`、`v5_ui_opaque.go`、`web/src/campus-ui/pluginHostActions.ts`。独立发布者使用相同标准接口，不需要在宿主增加插件名称判断。

## 服务器出站策略

服务器代理由部署管理员统一维护 CAMPUSOS_PLUGIN_WEB_PROXY_PROFILES 与 CAMPUSOS_PLUGIN_WEB_PROXY_PROFILE，不能写入 RSS 本人配置，也不能由插件在 web.read 或图片导入时覆盖。插件界面只显示“读取位置：CampusOS 服务器”，不提供服务器代理选择或开关；原 feed_1 至 feed_6 配置保持。

管理员选定的 HTTP/HTTPS/SOCKS5 端点统一用于订阅、预览与导入图片；原站公网 IP 固定和 TLS 校验不变，故障不自动直连，来源网址不改写。详见[通用合同](v1.2插件通用网页读取与编辑器交接合同.md)。

旧本机助手在用户电脑抓取，属于另一条路径，其代理应由用户本人控制。2.0.0 不提供该旧助手，也不修改客户端或服务器的系统代理、hosts、浏览器或 Clash 配置。
