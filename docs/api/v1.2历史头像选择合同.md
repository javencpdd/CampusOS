只允许 Avatar 及默认空间创建必需字段变化，必需 audit/outbox 与元数据原子提交。选择不写入、不删除文件，不改变容量；审计、outbox 或最终事实失败回滚元数据。缺失/链接/越界文件关闭，HTTP 错误不返回物理路径。`GET /spaces/me` 使用 private/no-store。
