> 更新时间：2026-10-14 17:30（Asia/Shanghai）

POST `/assets/:id/trash`、`/assets/:id/restore` 固定 operation 为 http.feature.richtext.asset.owner_trash/owner_restore。入口当前实际 User Session，不接受请求体；query/header 中 actor/owner/scope 不成为权限来源。独立 Admin 无法代理 User。

独立固定 owner lifecycle Policy 使用实际 Asset kind/status/owner/nonce/reference count。trash 仅本人 active 且真实引用数为零；restore 仅本人 trashed，实际 ready Object 与 Asset owner/reference/size/MIME/完整 receipt 匹配。写权限不推出读取权限。

真实命令事务加载完整 Asset22、当前 Principal，并锁 Asset。两个引用表的 validated immediate FK 与有效约束触发器必须存在，Asset FOR UPDATE 阻止零引用时的新 FK KEY SHARE admission。恢复同时锁 owned Object；最终完整 raw 字段、预期 status/version/date/nonce、引用/Object/current session/config 再复核。

Asset audit 与必需平台 audit/outbox 原子；失败全部回滚。User 兼容历史与迁移18的 typed actor 一致。成功仅 asset_id/status，事件 richtext.asset.updated 同样低敏。回收保留所有 bytes，即使旧 Object 已不可用；恢复要求实际可用 Object。不删除文件、不修改 quota。

无 DDL，current22/next23。独立 Admin 隔离/恢复/清除继续后继路径，详见[进度 .90](../进度/v1.2-dev/v1.2.90-dev.md)。
