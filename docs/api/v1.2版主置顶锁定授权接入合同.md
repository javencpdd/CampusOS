POST /moderation/threads/:id/pin、unpin、lock、unlock使用当前真实签名User JWT绑定的subject/session/auth_version。动作由入口固定，actual board来自实际Thread；body不接受，query/header actor/scope不影响授权。成功仅返回id/is_pinned/is_locked，不因执行权返回私有标题、正文或owner。

Identity内部命名UserScopedExecutionQuery仅支持community.thread.pin/lock和community.board。当前完整User/Session、显式global/category角色assignment、role/link/definition完整关系及非复用版本，执行前、事务内锁定和最终复核。隐式member、角色名、裸owner、同号独立Admin不授权。旧User admin角色的旧准入限制保留，并锁定其版本化实际行；它不成为管理域身份。Memory保守epoch可因其他授权变更要求重试。

Core独立UserThreadFlag Policy检查actual active Thread、scope/动作/flags/当前期限，nonce与revision CAS；typed User及旧User列历史、必需平台审计和薄事件outbox、Moderation必需审计在同一事务。模块当前enabled/config在写入前后重验；回调参数去别名。审计失败、撤权、作用域/正文ABA或状态变化全回滚。

冻结G1五动作、BoardGovernance/User grants两治理动作及七字段Principal wire保持原合同。此内部执行事实及decision不导出客户端，不可作为跨请求能力。证据见[.81](../进度/v1.2-dev/v1.2.81-dev.md)。文件/空间写入、Admin列表、批量/预览与阶段退出继续。
