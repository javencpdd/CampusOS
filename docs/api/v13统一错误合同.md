# CampusOS v0.13 统一错误合同

> 由 `go run ./cmd/campusos-contracts --write` 从 `pkg/apperror` 生成。旧顶层 `code`、`msg`、`data`、`request_id` 保持兼容；新客户端应优先读取 `error.code`。

## 响应包络

```json
{
  "code": 10001,
  "msg": "invalid request",
  "error": {
    "code": "request.invalid",
    "message": "invalid request",
    "details": {},
    "request_id": "...",
    "retryable": false
  },
  "request_id": "..."
}
```

未知错误与 panic 只能返回 `internal.error`，原始 cause 只进入服务端日志。客户端不得依赖内部错误文本。
