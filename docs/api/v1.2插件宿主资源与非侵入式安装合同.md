# v1.2 G1：插件宿主资源与非侵入式安装目标合同

> 状态：目标 Schema、SDK DTO 和 Linux 离线拒绝矩阵已交付；V12-01b 已提供关闭明文读取的宿主 Secret 代用 Port、Egress 及资源决定/用途预算组件；Runner 和安装器接入仍归后续阶段，完成三态以主计划和阶段退出报告为准。

业务 Host Capability 与运行环境资源许可是两层独立上限。[资源决定输入](plugin-v5-host-resources-v1.schema.json)分别保存包请求、宿主部署上限和管理员批准；纯资源 Port 在三者之外加入当前部署安全上限，数值取四方最小值，网络目标取精确交集。撤销和到期优先拒绝，不因包声明或管理员批准而绕过部署上限。目标网络必须为明确 HTTPS Origin；不接受通配符、loopback、IP 字面量、URL 凭据或附加路径。V12-01b 的共享 Egress 已实现每次连接 DNS 与公共 IP 复核、固定拨号地址、禁代理/连接复用、同源有界重定向以及字节/时间上限；Secret 代用额外禁止所有重定向并精确批准完整 URL。Linux 目标组件验收使用真实 loopback TLS 与受控 DNS/dial，不代表公网端点或 Runner 隔离已验收；Runtime 接入归 V12-05/06。数据库连接、宿主目录、JWT/Token、Docker socket、特权容器和 shell 没有可授予字段；Secret 只能由 Broker 按当前批准的名称/ref/Profile/完整 URL/用途代用；同版本跨用途并发受资源上限约束，预算预留、结算和未知结果计费为宿主单进程组件，CPU/内存与持久分布式记账由后续 Runtime 实现。

[非侵入式安装计划](plugin-v5-install-plan-v1.schema.json)只允许插件包、受管配置/数据以及安装、授权、操作和审计记录的命名空间写入；未知 mutation 和跨插件命名空间拒绝。宿主源码、依赖锁文件、二进制、前端产物和核心 Schema 五类指纹必须安装前后相同。它是 V12-08a/08b 真实只读宿主比对的合同，不是已发生的安装。UI 走已发布 UI Host，后端走固定 Gateway；卸载保留/清理策略和代次收敛在 V12-03b/07 实现。

[错误目录](plugin-v5-resource-install-v1.errors.json)、[SDK 类型](../../sdk/typescript/src/plugin-v5-resource-install.ts)与[离线检查器](../../scripts/check-v12-plugin-v5-resource-install-contract.mjs)固定失败关闭语义。当前 v4 安装器不因目标合同改变。执行：node scripts/check-v12-plugin-v5-resource-install-contract.mjs。

## V12-01b Broker 使用审计

宿主代用 Port 在预留和发送前必须成功写入 `platform_operation_runs`（`plugin.secret.use`），完成后持久化版本 ID、owner、purpose、outcome、预留/扣费单位、计费确定性、HTTP 状态与稳定错误码；不记录 Secret 名、ref、Profile、完整 URL、请求/响应或凭据。一次 POST 预留一个请求单位；响应成功扣一个，网络结果未知时保守扣预留全额并标记未知。无法确认结算的 `charged_units=null` 不是零费用。

缺审计或写入初始记录失败时禁止发网；发网后的最终审计失败返回失败，初始 running 行保留为不确定状态，必须人工对账，不能自动重发。当前宿主边界为请求体最多 1 MiB、URL 最多 8 KiB，Egress 可进一步收紧。这里只交付宿主共享 Port；Runtime 装配、真实模型 token/费用记账及多节点账本由后续阶段验收。
