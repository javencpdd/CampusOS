# v1.2 G1：插件宿主资源与非侵入式安装目标合同

> 状态：目标 Schema、SDK DTO 和 Linux 离线拒绝矩阵已交付；真实 Egress、Runner 和安装器尚未接入。

业务 Host Capability 与运行环境资源许可是两层独立上限。[资源决定输入](plugin-v5-host-resources-v1.schema.json)分别保存包请求、宿主部署上限和管理员批准；数值上限取三者最小值，网络目标取精确交集。撤销和到期优先拒绝，不因包声明或管理员批准而绕过部署上限。目标网络必须为明确 HTTPS Origin；不接受通配符、loopback、IP 字面量、URL 凭据或附加路径。真实 DNS、重定向和连接复核由 V12-01b/06 的 Egress Broker 执行，本离线合同不宣称这些检查已生效。数据库连接、宿主目录、JWT/Token、Docker socket、特权容器和 shell 没有可授予字段；Secret 只能由 Broker 按批准用途代用。

[非侵入式安装计划](plugin-v5-install-plan-v1.schema.json)只允许插件包、受管配置/数据以及安装、授权、操作和审计记录的命名空间写入；未知 mutation 和跨插件命名空间拒绝。宿主源码、依赖锁文件、二进制、前端产物和核心 Schema 五类指纹必须安装前后相同。它是 V12-08a/08b 真实只读宿主比对的合同，不是已发生的安装。UI 走已发布 UI Host，后端走固定 Gateway；卸载保留/清理策略和代次收敛在 V12-03b/07 实现。

[错误目录](plugin-v5-resource-install-v1.errors.json)、[SDK 类型](../../sdk/typescript/src/plugin-v5-resource-install.ts)与[离线检查器](../../scripts/check-v12-plugin-v5-resource-install-contract.mjs)固定失败关闭语义。当前 v4 安装器不因目标合同改变。执行：node scripts/check-v12-plugin-v5-resource-install-contract.mjs。
