> 更新时间：2026-10-22 11:15（Asia/Shanghai）

## 搜索入口

`GET /api/v1/knowledge/collections/:id/search?query=图书馆%20开放&page=1&page_size=20`，Operation 为 `http.knowledge.search.public`，由 `feature.knowledge` 拥有。与现有公开来源入口相同，面向匿名公开读取；每次查询仍须通过集合、当前 G1 原来源及完整索引代次检查。客户端身份、声称的管理员角色、ACL、Provider、URL、其他集合参数均不能扩大公开范围。此路径不发布 Host/SDK/MCP/Integration 能力，机器入口由 V12-11 单独交付。

只接受 `query`、`page`、`page_size` 三个查询参数，每键至多一次；`query` 必填，分页缺省为 1/20。页码规范十进制 1–100000，页大小 1–50，拒绝符号、前导零、空值和溢出。完整编码查询串至多 3200 字节；严格解析 URL，错误转义、未编码分号、重复的解码键、未知字段、GET 请求体均拒绝。查询本身为至多 1024 UTF-8 字节、1–16 个不同 Unicode 字母/数字词，拒绝非法 UTF-8、控制字符和纯标点。多个字面子串为 AND；`OR` 只是普通词，不执行 SQL 通配符、查询语言或模型改写。

响应沿用平台 `code/msg/data/request_id` 信封；`data` 是闭合的 `KnowledgeSearchPage`：`items`、去重后 `total`、`page`、`page_size`、固定 `provider=builtin.lexical/v1` 和字符串 `generation`。命中包含 `title`、至多 240 Unicode 码点的原文 `snippet`、`score`、4/1 标题/最佳块词解释及 `citation`。空结果为 `items: []`、`total: 0`，超出末页仍返回当前总数和空列表，不回退其他集合。跨请求分页不承诺静态快照。

排序、来源去重、计数与片段都由[内置 Port 合同](v1.2公开知识词法检索Port合同.md)约束。进入排名前及返回前均重核当前来源；私密、撤回、删除、移板块或正文修订立即拒绝旧内容，不等待异步清理。只使用当前集合版本的完整 ready 代次，构建中不返回部分结果。5 秒、1000 投影行及 4MiB 当前公开文本预算超限时整次失败，不输出部分总数。片段是非可信纯文本，可能包含 Markdown 字面字符，调用方不能作为 HTML、指令或工具调用执行。

## 精确引用重开

`citation` 提供 `collection_id`、`member_id`、`visibility_revision`、原来源 `kind/id/revision`、字符串完成 `generation`、`chunk_index` 和宿主复核的当前 `url`。引用使用已有入口：

`GET /api/v1/knowledge/collections/{collection_id}/sources/{member_id}?revision={visibility_revision}`

`revision` 若提供，必须是非空 64 位小写十六进制摘要。参数至多一次，无其他参数或请求体；完整编码查询串至多 256 字节，先限制长度再严格解析。非法转义、未编码分号或空证明不能被忽略后降级为未固定修订读取。当前关系或正文已变化时旧证明失败；调用方应重新搜索，不能把旧引用对应到新的正文。省略 `revision` 保留现有“读取当前可见来源”语义。普通原文 URL 仍按原业务域授权，它本身不是精确历史证明。

## 错误和缓存

搜索及引用的成功与业务错误均为 `Cache-Control: private, no-store`。Knowledge Feature 默认关闭；路径守卫与请求中途的服务端复核都返回同一脱敏 `knowledge.disabled`，不依赖令牌才能识别禁用状态。其他 Feature 保持既有错误行为。公开 OpenAPI 不要求 bearer；资源授权标注 `none+current-origin-policy`，管理与其他身份域仍保留各自安全方案。

| HTTP | machine code | 语义 |
| --- | --- | --- |
| 400 | `request.invalid` | 非法或歧义输入、错误的规范 ID/引用证明 |
| 404 | `resource.not_found` | 集合或当前公开来源不可用，不返回私密事实 |
| 409 | `resource.conflict` | 引用证明与当前公开事实冲突 |
| 409 | `knowledge.capacity_exceeded` | 当前受支持集合/文本预算超限 |
| 503 | `knowledge.disabled` | Feature 已关闭 |
| 503 | `knowledge.unavailable` | 索引尚未就绪、停止、取消、超时或内部 Provider 故障 |

错误不返回部分页面、总数、原始 Provider 错误、内部路径或凭据。路由矩阵、生成 JSON 和 OpenAPI 同步为唯一现行合同，见[HTTP 授权矩阵](HTTP路由与授权矩阵-v0.6.md)、[OpenAPI](openapi-v0.6-current.yaml)。
