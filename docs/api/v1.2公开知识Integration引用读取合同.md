# v1.2 公开知识 Integration 当前引用读取合同

> 更新时间：2026-10-23 02:29（Asia/Shanghai）

## 入口与授权

`GET /api/v1/integration/knowledge/collections/:id/sources/:member_id/revisions/:revision` 只读取一个集合的一条当前公开来源。`id` 为 `kc_` 加32位小写十六进制，`member_id` 为 `km_` 加32位小写十六进制，`revision` 必须为当前可见性修订的64位小写十六进制摘要。修订来自当前公开来源或检索引用；该路径不提供历史快照，也不自动改读新修订。

仅接受一个 `Authorization: Integration <token>`。沿用 Identity 摘要凭据和独立机器域；Bearer/User/Admin/插件凭据、重复头、Cookie、浏览器 Origin 和任何查询参数拒绝。请求不得带正文。整个读取限时5秒，成功和错误均为 `private, no-store`；错误不附带正文、秘密、摘要或内部存储信息。

固定宿主目录条目为通道 `integration_http`、端点 `knowledge.source.read`、动作 `knowledge.source.read`、资源种类 `public_collection`。一条当前有效规则须完整包含该组合和精确集合 ID；社区规则、MCP 通道、未知端点、空规则与其他集合不能拼接授权。规则允许读取该集合的当前公开成员，不单独授予原来源权限。当前后台规则表单只提供社区规则；本片知识规则通过既有独立 Admin API 签发、轮换和更新，不计后台表单或浏览器流程验收。

三层范围是 **当前宿主端点白名单 ∩ 凭据精确集合范围 ∩ Knowledge 与原来源的实时公开 ACL**。集合、成员、选择规则、官方资料及 Community/RichText 当前公开状态仍由所属服务检查。私人文档、私有/待审/下架/删除来源、停用集合及失效选择不会因机器规则放行。Knowledge Feature 关闭后拒绝新读取，返回正文前再次检查 Feature 和取消状态。

## 事务与结果

Identity `ReadForIntegration` 在读取前和后重新检查当前摘要凭据、主体状态、期限、完整规则和版本。`CollectionService.Source` 的 `CheckedRead` 复用该事务；机器行、集合/成员/选择及 Community 原帖共享锁保持到必需 typed Integration 审计、Outbox 和提交。RichText 正式写服务先操作所属原帖；这里不额外宣称直接锁定全部 RichText 原始内容行。

撤销先提交时，后续请求不能进入原来源回调；读取已持机器锁时，撤销等待该读取提交。审计、Outbox、凭据复核或提交失败时丢弃缓冲正文；不返回已读数据。不缓存机器授权、凭据事实或正文。

成功沿用 [OpenAPI](openapi-v0.6-current.yaml) 的 `KnowledgeSource`：`member_id`、`collection_id`、`revision` 和公开来源 `source`，不包含 Admin 身份/凭据/私有文档。输入错误400、凭据错误401、范围拒绝403、隐藏或不存在404、修订/事实冲突409、Feature停用或暂时故障503；旧证明不会返回较新正文。
