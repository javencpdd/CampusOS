## 本人选择与来源权威

私人来源只有 `personal_document` 与 `community_thread`。当前 User 必须先核对当前来源，再针对该精确修订明确提交 `consent: true`。没有自动选择、自动追踪新版本、公开集合授权继承或外发同意。另一 User、独立 Admin（包括同数值 ID）、Integration、MCP 与插件均不能借用此入口。

原模块始终是来源权威。个人文档通过 PersonalDocuments checked metadata/TextContent Port 复核当前会话、owner、当前版本、生命周期与 Object 事实；讨论帖经 Community 自有 Port 复核 author、正文代次、格式、治理与板块/父板块生命周期。组合根不把仓储或原文 Reader 发布给插件；后台任务只读取当前来源元数据，不伪造 User 或保存其凭据。

支持本人 TXT、Markdown、CampusDoc 和本人 text/markdown discussion。CampusDoc 使用现有 Content Editor 转为纯文本；不执行 HTML、脚本、图片或附件请求。PDF、DOCX、文章富文本、图片/OCR 和附件展开不支持，上传能力不构成索引能力。正文最多 64 KiB、标题最多 1 KiB，超限拒绝而非静默截断；每人最多 100 项。文档 Feature effective/desired 必须同时启用；Knowledge 的停用、停止、会话撤销及当前来源变化均关闭读取。来源更新后先撤回旧项，再核对并明确选入新修订。

## HTTP 与页面

统一前缀 `/api/v1/knowledge/private`；全部使用当前 User access JWT 和实时会话证明，成功及鉴权前拒绝均 `Cache-Control: private, no-store`。

| 方法与相对路径 | 请求 / 结果 |
| --- | --- |
| GET `/status` | 保护准备状态、默认不入库、支持格式与容量；不是同意记录 |
| POST `/preview` | `{kind, source_id}`；当前来源元数据和可选入状态，不返回正文或写任务 |
| GET `/selections` | 本人已选元数据、任务状态与有限安全原因码；标题只从当前可读来源取得 |
| POST `/selections` | `{kind, source_id, revision, consent:true}`；密文来源与 pending 任务提交，尚非 ready |
| DELETE `/selections/:selection_id` | 无查询/正文；持久退休密钥，再删除来源和级联任务 |
| POST `/selections/:selection_id/retry` | 无查询/正文；本人核对当前来源与密钥后显式重试 |
| POST `/search` | `{query}`；仅本人当前可读、ready 的精确来源 |
| POST `/selections/:selection_id/source` | `{revision}`；重新核验当前来源、同意、密钥和会话，返回纯文本引用 |

请求拒绝未知/重复/null 字段、额外 JSON、URL 查询参数、非法 Unicode 或请求覆盖 owner/权限/Provider；JSON 上限 4096 字节。source_id 为规范正数 int64 字符串，revision 为 64 位小写十六进制，selection_id 为服务端生成的 `kp_` 加 32 位十六进制。当前 OpenAPI、路由矩阵及 JSON 是字段级合同。

搜索词最多 1024 字节、16 个字面词，AND 匹配；标题权重 10、正文 1，片段最多 240 rune。每次至多扫描 100 个本人选择、4 MiB 派生正文、5 秒；全部参与计数的候选在返回前重验，不以异步清理或旧 ready 授权。基础设施失败返回失败，不能伪装成空结果。不存在、非本人、失效密钥等不产生可读命中；旧精确修订拒绝，不自动打开新版本。400 表示请求非法，401 当前身份失效，404 不存在/非本人/不可读，409 当前修订冲突，503 尚未 ready 或功能/保护/基础设施不可用；以生成错误合同为准。

Web `/knowledge/private` 提供加载本人来源、核对、独立复选同意、状态、搜索/引用、重试和撤回。个人文档列表与本人讨论帖有选入入口，仅带 kind/id，不携带正文、查询或同意。页面进入后台、离开、修改查询、来源操作失败或权限变化时清空旧输出；取消与请求代次拒绝迟到响应。查询和正文不进入 URL、localStorage、sessionStorage 或应用响应缓存，正文只按纯文本显示。搜索、引用为 POST；普通访问日志只记录 Path，不记录请求体。

旧 `/sources/preflight` 的精确 document_id/version_id 元数据协议保留；保护和当前支持来源均满足时可报告 `can_index:true/reason:ready`，仍不记录同意、读取正文或创建任务。未配置保护时继续 `private_storage_unavailable`，PDF/DOCX 继续 `unsupported_format`。`.150` 的恒 false 结论只属于当时首片。

## 密文、密钥与任务

000034 新增 `knowledge_private_sources` 与 `knowledge_private_tasks`。持久正文/标题合并为独立 AES-256-GCM 密文；AAD 绑定选择 ID、owner、原来源类型/ID、精确修订与格式。每次选择使用新的随机 256 位 DEK，数据库/WAL/普通备份只含密文与必要的来源/任务元数据。元数据不是匿名数据；数据库仍需既有访问控制。

`KNOWLEDGE_PRIVATE_KEY_DIR` 默认空，保护不足时私人索引不可用。运维必须显式准备专用 Linux 外部密钥目录：绝对规范路径、无符号链接、0700、当前服务 UID 所有、可写且可 fsync；密钥为同 UID 的普通单链接 0600 文件。目录必须位于应用数据及全部备份输入/输出目录之外。非 Linux 当前失败关闭。没有开发默认密钥、数据库内密钥、明文索引回退或常驻解密密钥缓存。

选入在当前本人请求中有界解析并加密，随后以必需 typed 审计和仅含选择 ID 的 Outbox 事件原子提交来源/任务。正常模块常驻 Worker 取得不可复用的 5 秒租约，校验元数据后发布 ready，并周期复核；它不再次打开原文字节。失败最多 5 次后 dead，保留安全原因码；本人可在基础故障修复后显式重试。租约过期、停止或取消不能发布旧执行结果。崩溃遗留且超过一小时的无 DB 来源密钥按有限页退休，失败不清除仍有效的来源密钥。

## 撤回、备份和恢复

撤回先创建并同步不可逆 `.retired` 退休标记，再删除 DEK 并同步目录，之后才执行审计事务删除来源/级联任务。即使后续审计或数据库提交失败，旧项也已不可解密；修复故障后再次撤回可清理残留元数据。旧备份里的该密文不能重建已退休的密钥。新的读取在每次请求重验同意/原来源/密钥，撤回后拒绝；不承诺收回此前已交付给用户的文字。

无跨请求私人正文/查询/allow 缓存。原来源变更或删除时立即按当前事实拒绝新读取，常驻对账随后退休密钥并清理来源/任务。普通离线 v3 备份排除外部密钥目录，输入/输出与配置密钥目录相交时在备份发布前拒绝。

官方 `campusosctl recovery apply` 保持恢复隔离和人工审查门禁，并清除全部恢复的私人来源同意与派生任务；即使外部活跃密钥尚在，也不能借恢复重开旧私人索引。旧会话受恢复围栏约束；新会话要由本人重新选择。原个人文档/讨论帖继续按原域恢复与授权，私人知识撤回不会删除原件或原件备份。

密钥目录是独立、单实例的当前信任事实，不能随普通备份打包、克隆给另一实例或回滚密钥/退休记录。密钥损失后撤回旧引用、重新选择重建；不提供恢复旧 DEK 的路径。系统级宿主快照、磁盘管理员、已导出的明文及原件备份不属于本阶段的索引撤回机制。

迁移空私人域可 down/up，保留 `knowledge_private_epoch_seq` 高水位；任一私人来源/任务非空时 down 拒绝，不通过回退静默销毁用户数据。旧 122 张业务表和旧序列保持不变；当前 124 张业务/系统受管表加 2 张迁移执行器表、138 FK，current34/next35。Admin `/architecture` 为受版本管理的静态结构说明，不读取密钥或数据库记录。

本阶段不授权模型外发，不发布私人 MCP、Integration 或插件 Host/SDK 能力。AI/RAG、提供方出站同意和整版 Final 属后续阶段。
