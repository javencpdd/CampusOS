# v1.2 帖子作者创建接入合同

> 更新时间：2026-10-12 20:21（Asia/Shanghai）
> 责任阶段：V12-02b；当前discussion创建，不代表typed Feature创建及编辑完成。

POST `/threads` 从实际User Session导出作者，拒绝同IDAdmin及非user域。未创建帖子没有可供编辑的资源事实，此路径不虚构owner/facts_version套用edit Policy；客户端author/Principal字段被严格DTO拒绝，查询owner或认证强度不影响身份。

Community加载当前raw实际版块事实：ID、board类型、active生命周期、正版本、开放状态、default tags、上级group及线程类型配置。配置必须明确允许discussion；上级存在时须仍为active group。缺字段或Port不使用兼容默认值补成允许。事务内锁定当前用户/会话、版块及上级分组，重读类型配置与完整Principal，初始授权事实变化拒绝创建。实际写入后再次核对同一完整身份、版块/类型及返回资源owner/category/type/active。

复用实际ThreadID分配与可靠命令：帖子、内容修订、平台必需审计和outbox原子提交，失败丢弃结果并回滚，不返回未提交的新资源。普通正文采用Core纯文本规范化。Memory使用统一命令TxKernel与登记快照；PostgreSQL使用同事务执行器和行锁。
