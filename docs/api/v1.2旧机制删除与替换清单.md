# v1.2 旧机制删除与替换清单

状态：V12-G1 已冻结可机检的[16 项清单](v1.2旧机制删除与替换清单.json)；本阶段没有提前删除仍服务于当前 v1.1 的代码。每项记录当前源文件和精确锚点、责任阶段、目标合同及删除验收。检查器在每次 G1 验收时核对锚点、合同及主计划阶段，不允许把未来运行时任务误标为完成。

责任按依赖顺序执行：

- V12-02a：替换只按 User ID/动作码判定和仅以执行权授予他人的路径，用业务所有者事实与独立委托上限。
- V12-02d：分离 JWT/入口、账号、凭据、会话、角色与恢复；删除角色授予自动开通后台及 SQL 触发器，保留显式 bootstrap、最后管理员与审计保护。
- V12-03a：按单一 v5 Manifest 替换 legacy/v4 包解析和适配；旧包重建，不保留兼容 fallback。
- V12-03b：用安装、Grant、desired/observed、代次、Operation 和数据治理替换全局 Manager 状态。
- V12-03c：替换兼容能力映射、任意 map Scope 和旧事件订阅，接入类型化 Dispatcher 与安全事件投递。

每个责任阶段在新路径通过自动化及目标环境验收后，再删除对应旧路径和过时夹具；不能因为 G1 的离线合同通过就删除当前线上安全逻辑。目标 DDL 在所属迁移阶段编写，已发布迁移保持 checksum。检查命令为 make v12-g1-replacement-map-check。离线检查不证明旧机制已经从运行时移除。
