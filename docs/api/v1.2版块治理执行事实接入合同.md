# v1.2 版块治理执行事实接入合同

> 更新时间：2026-10-13 08:53（Asia/Shanghai）
> 责任阶段：V12-02b；实现、自动化及Linux目标三态通过，实际业务治理接入继续。

资源所属模块从真实资源加载版块后，向 `BoardGovernanceAuthorityReader` 提供版块与命名动作、可信当前Session resolver。查询只接受冻结的 `community.thread.take_down` 和 `community.post.delete`；不能把pin、review等其他操作别名成take_down。Principal DTO、客户端owner/角色或执行grant均不构成认证。

User授权只取当前委派kind=grant的一条完整见证：subject域及ID、具体action/board、active、有限半开时间窗、认证强度和非delegable均须同时匹配。管理授权management及Admin转授予上限bound不授权业务执行，不合并不同记录的条件。Admin只从独立Admin域的当前账号/会话与active角色绑定/角色/具体执行权限构造见证，必须有当前15分钟MFA；有效期不超过Session或MFA窗口。相同数值ID的User委派不能用于Admin。

完整委派ID/version/window/创建信息、角色/绑定/权限000017非复用版本、Admin账号与Session版本/MFA时间均在host内部opaque snapshot中绑定。冻结七字段 `ResourcePolicyGrant` 和Principal wire保持不变；返回对象JSON不包含私有见证，不能当后续执行凭证。返回前重读完整凭据及实际事实，任何变化都失败；需要锁时必须有真实事务，并实际锁定凭据及执行见证行。Memory适配器独立验证，没有裸权限码或裸actor ID回退。

Identity生产装配提供 `identity.board-governance-authority` 和 `identity.admin-session-authority` 两个窄Port。此切片交付当前执行授权事实源；实际资源策略、业务HTTP入口、CAS/必需审计、actor域存储尚须后继接入。无通用资源事实注册表，没有execute推出grant/delegable。
