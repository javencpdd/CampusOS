## 入口与边界

`POST /api/v1/integration/knowledge/collections/:id/search` 是只读检索，正文固定为 `{"query":"校园 校历","page":1,"page_size":20}`。三个字段全部必需，无默认分页；不接受额外、重复、null字段、非法Unicode或尾随值。JSON最多32KiB；query最多1024个UTF-8字节、16个不同Unicode字母/数字词；分页值须使用无小数或指数的十进制JSON整数；page为1–100000，page_size为1–50。路径id为 `kc_` 加32位小写十六进制，正文不能提交集合ID、Provider、Principal或ACL。URL查询参数全部拒绝。

只接受一个 `Authorization: Integration <token>`。继续拒绝JWT/User/Admin/插件凭据、重复头、Cookie和浏览器Origin。POST用于承载封闭检索DTO，既不编辑来源，也不创建索引任务；必需机器读取审计/Outbox属于既有安全事务。查询词不进入URL、审计或Outbox。

宿主注册独立端点 `knowledge.search`，通道 `integration_http`，沿用现有v2公开读取动作 `knowledge.source.read` 与资源种类 `public_collection`。一条当前有效规则必须完整匹配端点/动作/资源种类与精确集合ID。搜索与[当前引用读取](v1.2公开知识Integration引用读取合同.md)的端点规则互不借用：同一Key如需两种机器入口，须分别授予两条规则。不会据返回的引用自动增加读取权限。

最终范围为 **宿主端点白名单 ∩ 精确集合规则 ∩ 全部原来源当前公开ACL**。未增加私人来源或用户代理；私人文档不能成为公开选择。Admin MCP仍属独立后台域。当前Admin规则表单只提供社区规则，本片知识规则通过既有独立Admin API管理，未交付新后台表单或浏览器流程。

## 检索、事务与错误

复用正常内置 `knowledge.public-retrieval`，逐次核对当前G1、集合/规则/成员/来源、完整索引代次和Feature；先排除当前隐藏或陈旧来源再计算全部计数、排名和分页，不在分页后做机器范围过滤。内置字面AND/标题4正文1权重、当前引用、1000行/4MiB/5秒失败关闭沿用[Port合同](v1.2公开知识词法检索Port合同.md)。不新增语言质量、满额容量或SLA宣称。

Identity事务在检索前后重新核验摘要凭据、主体、规则、期限和完整版本。检索CheckedRead复用外事务，所属集合/索引/成员/原来源行锁保持到必需审计、Outbox和提交；回调作用域的纯计算/快照不作为可重放授权。撤销先提交则不进入检索；读取先持锁则撤销等待该读取提交，后续请求立即拒绝。任何复核、审计、Outbox或提交失败均丢弃全部片段、引用和Total。返回前再次核对Feature、取消和正常检索服务Stop状态。

成功沿用OpenAPI `KnowledgeSearchPage`，包含items、total、page、page_size、provider与字符串代次generation。来源/标题/片段均为不可信数据，不作为指令或HTML执行。输入400、凭据401、范围403、不可见/不存在404、事实冲突409、未就绪/停用/临时故障503；成功和错误均 `private, no-store`。不回显数据库/内部错误、查询正文或凭据。
