本切片接入八个实际入口：样式 JSON validate/preview/export、HTML validate/example、ZIP validate、拓展包 example JSON/example.zip。生产 `PersonalSpace.Module → Appearance.Application → AuthenticatedSpaceStyleReads → checked Service` 转发完整当前 SessionResolver。固定服务端 owner/style_read 纯 Policy，不接收客户端 owner/operation/path/facts/callback；缺当前证明401、缺新 Port/typed nil503，不回落旧裸 userID 或 TrackOperation。

复用 Space23 全行或默认无行/Owner，保存完整 Identity UserReader 七字段投影与当前 Feature 启用状态，在投影前后执行同一纯规则，返回前复核完整当前会话。禁用空间仍可读取元数据，不授予写权限；默认无行不会因示例/导出而创建空间。只读没有 Space/历史/Session/audit/outbox/文件/容量写入。

JSON 包在读取时深复制到全新结构，避免输入 map/slice 别名；请求输入不是授权资源事实。ZIP 在初始当前授权之后才读取，将已声明大小的一次有界输入复制成独立字节，再执行现有 strict delivery/target 校验；typed nil、短流、超量拒绝。畸形包返回原有 invalid validation 结果，但仍必须经过最终当前证明。ZIP 示例的完整压缩字节也在检查范围内生成，不能先结束检查、再到 HTTP handler 读取资料或生成内容。

HTTP：JSON 包请求最大1MiB，HTML沿用20000字节内容限制及转义余量，export正文最大64KiB；strict JSON/可选export正文，拒绝未知字段和多余JSON。ZIP使用既有16MiB/严格单file multipart/先关闭后清理临时文件；三个GET拒绝正文，全部成功响应使用 `private, no-store`。example.zip 实际返回 binary `application/zip`，OpenAPI已明确区别JSON envelope。

预览使用显式 `SpaceStylePreview` DTO，仅返回validation、manifest、layout、components、tokens、assets；不返回旧预览中的原始 Owner/Space 运维记录，也不返回事实版本、邮箱或凭据。实际Web只使用这些渲染字段，兼容当前消费者。新读取失败时清除旧预览/校验状态，保留用户草稿；示例与导出只消费当前成功结果。
