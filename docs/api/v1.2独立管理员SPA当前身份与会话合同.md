# v1.2 独立管理员 SPA 当前身份与会话合同

> 更新时间：2026-10-16 13:23（Asia/Shanghai）
> 状态：本切片实现、自动化与 Linux 真实后端浏览器目标三态完成；全阶段出口通过

所有路径前缀为 `/api/v1/admin/identity`。

| 方法与路径 | 身份和当前业务条件 | 响应 |
| --- | --- | --- |
| POST `/login` | 独立 Admin 用户名或本域邮箱/密码，当前活跃账号和实际凭据 | access_token/token_type/expires_at；独立刷新及 CSRF Cookie |
| POST `/refresh` | 当前独立 refresh 家族；浏览器 Cookie + X-Admin-CSRF-Token | 旋转后的 access_token 及两个新 Cookie；旧凭据复用撤销整族 |
| GET `/me` | 签名 Admin subject/session/protocol1，当前完整账号/会话与整批角色/权限/TOTP 事实 | 明确 AdminCurrentSelf DTO；不返回正文、邮箱、凭据、会话 ID、nonce 或审计归属 |
| POST `/logout` | 当前本人完整证明；精确会话 CAS；浏览器 CSRF | `{revoked:true}`，typed Admin 必需审计/outbox 提交后清理本域 Cookie |
| POST `/mfa/enroll` | 当前本人实际会话；活跃因素替换额外要求当前 MFA；浏览器 CSRF | 一次 otpauth_url；客户端关闭/切换身份即清除 |
| POST `/mfa/confirm` | 当前本人 pending 因素、有效 TOTP、实际会话；浏览器 CSRF | `{status:active}`；确认步同时被消费，不直接提高会话强度 |
| POST `/mfa/step-up` | 当前本人 active 因素、未使用的新 TOTP 与同一实际会话；浏览器 CSRF | `{authentication_strength:mfa}`；客户端须再读 `/me`，15 分钟当前 MFA 窗口 |

本人端点不要求管理他人的 admin_account/admin_mfa 权限。自定义/零权限角色可确认本域身份；业务页面、读写和每条批量执行仍按实际权限和命名资源 Policy 检查，元数据可读不授予私有原文读取权。

Cookie 名称为 `campusos_admin_refresh`（HttpOnly，Path=/api/v1/admin/identity）和 `campusos_admin_csrf`（可读，Path=/）；header 为 `X-Admin-CSRF-Token`，SameSite=Lax，Secure 由生产环境配置，期限为实际 refresh 期限。User 的 Cookie/header 不替代它们，也不会被本域退出清理。默认不向 JSON 返回 refresh；显式兼容配置仅对无 Cookie/Origin/Sec-Fetch-Site/browser client 信号的 CLI 生效。Cookie 请求不接受 body refresh 回退。

所有响应禁止共享缓存；本人 GET 有正文即 400，JSON 严格且有界。未认证/无效当前会话 401，缺 CSRF/越权 403，事实变化/重放/未启用因素 409，参数/验证码无效 400，基础依赖不可用 503；仅输出固定安全错误。既有业务治理拒绝保持其 403 合同，不能假设所有拒绝都具有 MFA 专用 machine code。

SPA access JWT 和当前身份仅存内存；每次受保护导航读取当前身份，只有 Me 401 可触发一次刷新。403/409/503 和身份变化清理当前状态，不回退用户角色名。退出等待已经开始的凭据操作，失败时清理本地身份及可读 Admin CSRF，并明确未得到服务器成功回执。

实现、定向与真实后端浏览器证据见 [.109 进度](../进度/v1.2-dev/v1.2.109-dev.md)。隔离探针不是共享数据库重置，也不代表 HTTPS/Windows 或后续 Integration、插件、Knowledge 阶段交付。
