# v0.12 注册邮箱验证 HTTP 合同

> 阶段：A5 验证式注册  
> 状态：已实施  
> 权威 schema：[openapi-v0.6-current.yaml](openapi-v0.6-current.yaml)

## 1. 调用顺序

```text
POST /auth/registration/challenge
  -> POST /auth/registration/verify
  -> POST /auth/register
```

注册 API 不再允许仅携带用户名、昵称、邮箱和密码的一步式创建。缺少
`challenge_id` 或 `ticket` 时固定返回 `400 identity.verification_required`，且不会写入用户或
账号记录。

## 2. 公开端点

| 方法 | 路径 | 请求 | 成功响应 | 失败语义 |
| --- | --- | --- | --- | --- |
| `POST` | `/auth/registration/challenge` | `{ "email": "..." }` | Challenge ID、用途、过期时间 | 非法 JSON/邮箱格式返回 `400 request.invalid`，保留地址等语义拒绝返回 `400 identity.registration_verification_invalid`；`429 identity.registration_verification_rate_limited` 表示按邮箱/IP 的持久限流；`503 internal.error` 表示依赖暂不可用且可重试。所有响应均不暴露账号状态。 |
| `POST` | `/auth/registration/verify` | `{ "challenge_id": "...", "code": "123456" }` | 一次性 Ticket、用途、过期时间 | `400 identity.registration_verification_invalid`；不区分不存在、过期、错误次数、用途错误。 |
| `POST` | `/auth/register` | 用户资料、`challenge_id`、`ticket` | `201 User` | 无 Ticket 为 `400 identity.verification_required`；Ticket 失效或不匹配为 `400 identity.registration_verification_invalid`；唯一性冲突为 `409 resource.conflict`。 |

所有端点使用标准响应包络和 `request_id`。客户端应依赖 HTTP 状态和 `error.code`，不能依赖
`msg` 文本。

## 3. 事务与安全边界

- Challenge 和限流先由独立可靠命令写入；Outbox payload 只有不透明 `challenge_id`。
- PostgreSQL 限流使用仅由 Scope 与 keyed digest 派生的安全 advisory lock key；数据库锁键、日志和错误响应
  均不包含邮箱或 IP 原文。
- 默认按每邮箱 10 分钟 5 次、每 IP 60 分钟 10 次的滑动窗口限制；策略由 Identity Core
  热读取，管理员只能在受约束范围内修改，不能关闭。
- 最后注册在一个可靠命令中消费 Ticket、创建 `users`、创建状态为 `verified` 的 Email Account、
  写 command audit 和用户创建 Outbox 事件。
- Ticket 消费、账号创建或 audit/outbox 任一步失败都会回滚，Ticket 保持可用直到过期或成功消费。
- 数据库、Outbox、标准日志、Admin 状态接口与 API 文档不保存验证码、原始 Ticket、密码或 SMTP
  Secret。用户创建事件只使用公开用户投影，不携带邮箱。
- 历史 `legacy_accepted` 账号可继续登录；A5 只影响新的公开注册请求。

## 4. 前端与 SDK 边界

用户前台实现位于 `web/src/modules/identity/`。Challenge ID、Code 和 Ticket 只保存在页面内存；
页面不会把 Ticket 写入 localStorage。

CampusOS 当前 Go SDK 是 External Plugin SDK，不是浏览器身份 SDK。因此它不会提供创建用户、
消费 Ticket 或读取 Challenge 的方法。插件、MCP、Agent 和 External Runtime 只能通过其明确允许
的 Host API/Gateway 能力运行，不能访问 Identity 内部 Repository。
