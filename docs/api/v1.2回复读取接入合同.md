# v1.2 回复读取接入合同

> 更新时间：2026-10-13 13:55（Asia/Shanghai）
> 责任阶段：V12-02b；回复读取实现、自动化及Linux目标三态通过；其余02b路径继续。

命名 `community.post.read/v1` 从实际父帖事实和当前完整User Principal或明确anonymous构造输入。父帖必须active；公开published/clear父帖允许公开读取，其余合法状态仅父帖本人读取。Admin同数值ID不获得本人读取例外，执行grant不转化为读权；trashed/purged父帖的回复均不可读取。详情、列表、count和page采用同一live/published回复谓词，原帖owner/version/board/state及回复owner/version/父帖关系由服务端加载。Principal/决策仅host输入，不是凭据或可重放能力。

PostgreSQL在单一SQL语句同时绑定实际父帖nonce与公开/本人谓词，形成过滤后total和分页，空页也保留父帖检查。Memory一次锁内形成Post页/count，服务前后复核实际父帖。两种适配器均整页复核成员、顺序、total、每行完整状态/非复用版本及完整当前主体；变化返回409或稳定不可用错误，不返回旧页/稀疏页/部分total。like_count和updated_at不改变授权nonce；详情复用同一检查，空/错误ID失败。

公开 `GET /api/v1/threads/:id/posts` 明确anonymous；认证 `GET /api/v1/threads/:id/posts/me` 无论公开或本人都经可信SessionVerifier/strength验证当前签名JWT tuple，缺证明不降级。HTTP输入仅分页，query/header owner、actor、strength和facts不给权限。结果保留现有回复DTO，父帖正文、内部nonce/metadata/删除actor均不输出。既有裸viewer内部helper未接受新凭据合同。
