# v1.2 Integration 凭据与接入合同

> 更新时间：2026-10-23 02:29（Asia/Shanghai）
> 范围：V12-02c 身份、摘要凭据、管理生命周期、当前认证、精确白名单及原来源交集。

Identity 独立管理 `integration_principals` 与 `integration_credentials`。机器不继承 User、Admin、插件 Host Token 或 Worker 身份，客户端不能提交 Principal、认证强度、宿主端点事实或授权决策。

## 凭据与生命周期

- 凭据由密码学随机数产生，秘密部分为 32 字节，格式为 `cint1_<16位十六进制selector>.<base64url秘密>`。服务器仅保存用途域分离的 SHA-256 摘要、22 字符可辨识前缀和受管元数据。selector 是凭据 ID，不包含秘密。
- 原始秘密只在签发或轮换的成功响应中显示一次；列表、当前身份、审计、Outbox 和日志均不包含秘密或摘要。响应为 `private, no-store`，管理页面不写 localStorage/sessionStorage，关闭、隐藏或卸载即清除显示。
- 账号状态为 `active/suspended/revoked`。暂停可恢复；永久撤销不可恢复。凭据状态为 `active/revoked`，撤销不可恢复；有效期使用左闭右开毫秒窗口，签发到期必须在未来且距当前不超过 90 天。规则窗口须包含在凭据窗口内。
- 轮换在同一事务内撤销旧凭据并创建新凭据，只有提交成功才返回新秘密；旧版本 CAS 并发只产生一个成功者。必需审计或 Outbox 失败时，两者一起回滚，不返回未提交秘密。
- 管理写操作重新加载并锁定当前独立 Admin Session、账号、角色绑定、权限及近期 MFA。`identity.integration.read` 只能读元数据；`identity.integration.manage` 可在当前公开读取清单内管理集成。仅向独立 Admin 的 `security_admin` 播种，不向用户角色授权。
- `version` / `principal_version` 是正整数的规范十进制字符串，不可作为 JS 浮点数字处理。版本由非循环序列分配，回滚、ABA、删除重插不复用。创建者是 Admin 域的逻辑审计关联，独立于 User 外键。

## 入口与范围

机器请求仅接受一个 `Authorization: Integration <token>`，拒绝 Bearer/ApiKey 兼容回退、重复头、URL 参数、Cookie 与浏览器 Origin。当前宿主注册以下固定清单；客户端规则不能注册端点。

| 通道 | 端点 ID | HTTP 入口 | 动作与资源 |
| --- | --- | --- | --- |
| `integration_http` | `public_thread.read` | `GET /api/v1/integration/threads/:id` | `community.thread.read` / `community.thread` |
| `integration_mcp` | `public_thread_read` | `POST /api/v1/integration/mcp/tools/public_thread_read/call`，正文 `{"id":"…"}` | 同上 |
| `integration_http` | `knowledge.source.read` | `GET /api/v1/integration/knowledge/collections/:id/sources/:member_id/revisions/:revision` | `knowledge.source.read` / `public_collection`，精确集合 + 当前原来源 ACL |
| `integration_http` | `knowledge.search` | `POST /api/v1/integration/knowledge/collections/:id/search`，正文query/page/page_size | `knowledge.source.read` / `public_collection`，独立检索端点 + 精确集合 + 当前原来源ACL |

每条规则必须同时匹配通道、端点、动作、资源种类与精确资源 ID，并处于有效状态/窗口。最多 64 条规则，每条最多 32 个不同 ID，规则 JSON 总量最多 24 KiB；空规则不授予任何资源读取。没有通配符、父级继承、跨规则拼接或数字 ID 规范化。未知工具与 Admin MCP 控制入口拒绝。

`GET /api/v1/integration/identity/me` 是已声明的当前机器自身身份读取，只返回 integration Principal、名称、前缀及到期时间。它只验证当前凭据，不授予资源读取，因此没有资源规则的有效凭据也可自查。该例外不适用于任何业务端点。

业务读取先核对摘要、当前账号/凭据与完整白名单，再调用 Community 的 `ContentQuery.GetPublicThread`。原模块仍要求 `published + clear + active` 及同一当前内容行；私有、待审核、下架、删除不会因凭据白名单而放行。PostgreSQL 下同时持有机器行与公开来源行锁，直到当前事实最终复核、typed Integration 审计与 Outbox 提交；随后才返回受限正文投影。撤销先提交时，后续读取不会进入原资源回调；读取先取得锁时，撤销等待该读取提交。没有缓存授权或长期允许票据。

## 管理 API

前缀 `/api/v1/admin/identity`，使用当前独立 Admin JWT/Session；浏览器写操作另需 Admin CSRF。写操作均需近期 MFA；权限不足、MFA 过期、CAS 冲突和存储故障分别失败关闭。

| 方法与路径 | 行为 | 权限 |
| --- | --- | --- |
| `GET /integrations?after=<opaque id>` | 最多100项身份、游标 | `identity.integration.read` |
| `GET /integrations/:id/credentials?after=<opaque id>` | 当前身份与最多100项凭据安全元数据 | 同上 |
| `GET /integration-endpoints` | 宿主当前固定端点清单 | 同上 |
| `POST /integrations` | 名称创建，状态由服务端初始化 | `identity.integration.manage` |
| `PUT /integrations/:id` | 当前版本、名称、状态 CAS | 同上 |
| `POST /integrations/:id/credentials` | 当前身份版本、时间窗口与完整规则签发 | 同上 |
| `POST /integrations/:id/credentials/:credential_id/rotate` | 旧凭据版本与签发字段，原子轮换 | 同上 |
| `PUT /integrations/:id/credentials/:credential_id` | 当前凭据版本与规则更新；原有效期不变 | 同上 |
| `POST /integrations/:id/credentials/:credential_id/revoke` | 当前凭据版本永久撤销 | 同上 |

JSON 使用32 KiB/64层的严格检查，未知/缺失/null/重复字段、无效 Unicode、尾随值、非规范版本及越界窗口拒绝。错误沿用结构化平台请求/认证/权限/冲突/未找到合同，暂时故障为 `identity.integration.unavailable`（503），不返回内部错误、路径或秘密。完整字段见 [OpenAPI](openapi-v0.6-current.yaml) 与 [当前路由合同](http-routes-v0.6.json)。

## 版本与后续阶段

[首片 v1](v1.2Integration请求白名单策略合同.md) 仍为 `campusos.integration-access/v1`，只允许原 `knowledge.source.read/public_collection` 纯事实组合，不改变其192例语义。[v2 schema](integration-access-v2.schema.json) 与 SDK `IntegrationRuntimeInputV2` 显式增加 `community.thread.read/community.thread` 组合，复用完整事实绑定与最终重判；两个版本各有独立192例 oracle。

当前生产注册表包含上表的 Community 只读端点和 V12-11 的 Knowledge 当前引用读取、单集合检索。新增入口复用 v2 已有 `knowledge.source.read/public_collection` 语义；规则须明确指定该端点和精确集合，不继承 Community/MCP 的规则。完整路径、当前引用及失败边界见[公开知识 Integration 引用读取合同](v1.2公开知识Integration引用读取合同.md)。机器检索使用独立 `knowledge.search` 端点与同一个公开读取动作，必须单独授予精确集合规则；合同见[Integration检索](v1.2公开知识Integration检索合同.md)。标准 MCP、知识 Host API/SDK 尚未开放；Admin MCP 仍不属于机器目录。

迁移25为前向增量；非空身份/凭据或运行期权限引用使 down 原子拒绝。空域 down/up 保留分配高水位，旧24版完整数据、typed主体及外键不变。验收 runner 为 `bash scripts/v12-02c-exit-drill.sh all`；它只使用自建临时 PG16、原生 race 二进制、当前服务器和真实浏览器，并保留日志与摘要。

完整退出进度见 [v1.2.112-dev](../进度/v1.2-dev/v1.2.112-dev.md)。同步文档后，以runner输出的验收目录设置 `CAMPUSOS_INTEGRATION_DRILL_DIR` 并运行 `bash scripts/v12-02c-exit-drill.sh final`，复核最终文档和摘要。
