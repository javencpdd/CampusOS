# v1.2 可选插件文本贡献接入合同

> 更新时间：2026-10-25（Asia/Shanghai）
> 范围：V12-14c 首片；验收状态与原始路径以 [进度 .157](../进度/v1.2-dev/v1.2.157-dev.md)为准。14c 整阶段仍进行中。

AI Feature 发布编译内部 Port `ai.plugin-text/v1`，由装配根绑定真实受管插件 Dispatcher。AI 不导入 Plugin 实现，也不将插件作为内置受管 Chat/RAG 的启动依赖。该 Port 只供可信第一方调用者使用；没有新增 HTTP、Web、MCP 或插件可调用的 Host endpoint。

调用者须让当前 User 明确选择发布者、插件 key、确切版本和贡献 ID，并只提交本次显式文本。`PluginTextRequest` 包含上述四项、RequestID、Prompt、TimeoutMS；没有 owner、Session、Profile、来源 ID、URL、Secret、上下文类型或 fallback 参数。当前会话 resolver 由宿主传入，不接收客户端自报的 Principal。

执行依次核对 AI 配置/Feature 的当前与期望启用状态、完整 User 会话、精确贡献的声明/版本/安装/Grant/配置和实例代次。仅支持 `ai.chat/v1/text` 且 `data_mode=no_host_private_data`；发送公共 SDK `V5ChatRequest`，固定 `context_class=none`。生产 Runtime 持续检查会话/Feature/安装/Grant，并在返回前重核全部事实及响应 ID/代次；没有隐式选中其他插件或重试。

输入文本最多 12000 UTF-8 字节；期限 1–5000ms，仍受插件 Grant 和部署上限取更严格值；请求/响应字节、实例并发及进程资源继续由受管 Runtime 限制。输出是缓冲纯文本及非负 token 计数、`completed/length`，不执行工具、HTML 或模型 URL。失败只返回 AI 公共错误并丢弃全部答案，不转交原始插件错误或路径。该路径不读取受管模型 Profile、不消费模型预算，不把插件自报 token 计数记作受管模型计费。

AI 模块 Stop 取消并等待活动调用；停机期间旧 Port 拒绝接单，Start 后重新读取当前安装与实例。每次调用均绑定同一完整会话，途中换会话或变更 Feature 后不释放答案。调用文本和答案不写入新增持久存储、审计正文或缓存。

本片使用 08a 的独立 SDK 回显包验证 AI Feature 实际消费贡献。回显不证明 LLM、受管 Profile 或 RAG 能力。模型消费 Host/SDK、Profile 白名单与计费、公开问答 Host API、Knowledge Provider 实际接入和双方向联合验收仍属 14c 后续工作。私人资源及逐次同意不向本 Port 授权；贡献注册不自动获得任何消费能力。

本片没有 Schema/迁移/依赖/持久数据目录变更。回退可撤销 Grant、停用插件或 AI Feature；代码回退移除装配绑定与内部 Port，不删除既有授权事实和审计。
