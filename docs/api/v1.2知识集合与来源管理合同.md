# v1.2 知识集合与来源管理合同

> 更新时间：2026-10-21（Asia/Shanghai）
> 范围：V12-09a；公开集合、选择规则、显式成员、官方/Community/RichText 来源。持久索引/回填由09b实现，检索和管理/搜索页面按后续阶段交付。

Knowledge 是默认关闭的 hot-gated Built-in Feature。管理员通过既有 Feature 管理启用后，公开读取与独立 Admin 管理 API 才可用；停用立即拒绝已保存的集合/成员引用。候选 Port、集合成员、公开可读均不授予插件/MCP/Integration或模型出站权限。

## 1. 事实与授权

迁移000030追加五张Knowledge自有表，不修改历史迁移：`knowledge_collections`、`knowledge_official_sources`、`knowledge_official_revisions`、`knowledge_source_selections`、`knowledge_collection_sources`。结构化DTO在`data`，数据库非循环序列/触发器维护`facts_version`；FK用受管生成列建立集合/规则/成员和官方修订关系。失败事务分配不回用，不能把时间戳或客户端版本当作当前权限。

独立Admin权限为`knowledge.collection.read`/`knowledge.collection.manage`，Scope固定`knowledge.collection_inventory/all`。只向security_admin参考角色播种，不产生账号/集合/官方资料。每次重新验证当前Admin账号、Session、角色绑定、精确权限及其版本；写入还要求当前MFA窗口。User JWT、伪造Principal、过期/撤销Admin会话不能管理。浏览器写入要求独立Admin CSRF cookie/header匹配。所有变更与typed Admin必需审计、低敏`knowledge.selection.changed` Outbox同事务；审计或最终权限复核失败全部回滚，事件不含标题/正文/Secret。

公开入口固定匿名主体，执行G1 `knowledge.source.read`：当前集合active、规则active/代次一致、来源当前公开可见。集合是公开引用容器，不能扩大原来源权限。返回`Cache-Control: private, no-store`；管理路由同样禁止缓存。管理端目录和审计归因不会作为公开来源正文返回。

## 2. 管理路径

以生成[OpenAPI](openapi-v0.6-current.yaml)和[授权矩阵](HTTP路由与授权矩阵-v0.6.md)为字段事实。路径前缀`/api/v1/admin/knowledge`：

- `GET/POST /collections`：集合管理目录/创建；`GET/PUT /collections/:id`：规则与成员快照/更新标题和active或disabled。
- `GET/POST /officials`：安全管理目录（content为空）/创建资料；`PUT /officials/:id`：编辑或draft/published/withdrawn；`GET /officials/:id/revisions`：最新50条完整修订，非零`next_before`作为`?before=`读取下一页。历史只向有read权限的当前Admin返回。
- `POST /collections/:id/selections`及`PUT /collections/:id/selections/:selection_id`：创建/启停规则；kind为thread、board、official，来源不可原地替换，改选需撤回旧规则后建新规则。
- `POST /collections/:id/selections/:selection_id/refresh`：当前规则的一个显式有界成员页；需要`collection_version`、`selection_version`和`page`，返回更新状态及`examined/materialized/skipped_unsupported/has_more/next_page`。
- `POST /collections/:id/members/:member_id/remove`：移除一条投影引用，`version`指当前集合版本。之后显式刷新仍可按有效规则重建；这是投影移除，不是永久排除规则。

ID由服务端随机分配；所有version均为规范十进制正整数字符串，不能用JSON Number、前导零或旧版本覆盖。更新集合/官方资料需要当前version；增改规则/刷新/移除成员还要当前集合version，规则更新/刷新要当前规则version。冲突返回409，重新读取当前状态后处理。JSON对象关闭，缺失/未知/重复键、null、无效UTF-8/代理字符、溢出版本拒绝；请求体和解码后正文分别有界。

集合目录及官方资料目录各最多1000项；每集合最多64条规则、1000条物理成员（含暂时不可见来源）；达到容量明确409，不静默截断。创建目录受事务锁保护，不能并发越过限额。需要更大范围时拆分公开集合，或按后续容量设计升级；不把当前页当成全站导入。

## 3. 官方、单篇、板块与独立成员

官方资料只接受有界text/Markdown：标题≤1024 UTF-8字节、非空单行；正文≤65536字节、非空且无NUL。每次保存将完整内容/状态/版本及变更Admin、时间追加到修订表；数据库禁止历史UPDATE/DELETE/TRUNCATE。draft或withdrawn不能作为当前来源；编辑/撤回/重新发布推进版本，旧引用条件失效。内容中的链接/指令只是数据，没有HTML执行、URL抓取、附件展开、OCR或模型调用。

thread规则以规范Community thread ID显式选择单篇，按当前类型分派到已有[Community文本Port](v1.2公开社区文本来源候选Port合同.md)或[RichText完整正文Port](v1.2公开RichText正文来源Port合同.md)。始终使用原域匿名当前策略，管理者/owner携带的证明不能扩大可见性；RichText正文从所属域主HTML提取纯文本，不用Community摘要或render缓存。其他帖子类型/格式没有隐式适配器。

board规则只选择当前active叶子板块，父group也须active；关闭发帖不等于关闭已有公开读取。Community所属`community.source-category-catalog` Port在当前事务内以稳定顺序共享锁定板块目录，防止读出期间归档。板块规则保存后独立存在，不自动等于成员：显式refresh每次读取当前公开列表的一页（50项），再逐篇检查当前正文并写引用；支持的来源数、未支持/超大数和下一页均显式返回。分页是当前列表，内容变动时可能移动页；09b才负责耐久游标、事件消费、回填重试与全量对账，本阶段不声称自动追平或分页恰好一次。

每条成员保存规则ID/代次、来源kind/ID及观察修订，不复制Community/RichText正文或ACL。撤回规则删除其投影并推进规则代次，过时刷新和旧成员ID不能复活；重开要再次显式刷新。多个规则可以各自保存同一原来源；公开输出按当前kind/ID去重，撤回其中一条不会误删另一条规则的有效授权。

## 4. 公开读取与失效

`GET /api/v1/knowledge/collections`只返回active集合；`GET /knowledge/collections/:id/sources?page=1&page_size=50`在当前有界集合中逐项复核、去重，再分页，`total`为当前可见来源数，不是存储成员数。page_size为1–50；未知查询字段/重复参数拒绝。

`GET /knowledge/collections/:id/sources/:member_id`每次读取原域当前正文；可带`?revision=<上次返回的集合来源revision>`作为版本条件，变化返回409，绝不作为Bearer能力。无此条件返回当前正文。原帖私密/下架/删除、文章单独修改或停用、移出所选板块、板块/父级归档、官方撤回、规则撤回、集合停用和Knowledge停用均实时生效。版本绑定集合、规则、成员、原域来源与板块事实，A→不可见→A不能复活旧条件。

不可见/不存在的来源不泄露私密标题、正文、owner、审核信息、附件或原库错误；列表相应省略且总数一致。来源读不增加浏览量。观察修订仅用于诊断/后续索引，不授权旧正文；数据库事务共享锁与双次原域快照复核覆盖提交/返回边界。

## 5. 运维与验收边界

五表属于数据库备份集合；原Community/RichText及其User Storage对象仍需一起备份。官方有界结构化正文类似帖子正文保存在所属域；用户文件字节仍由User Storage保存，没有新增宿主目录。任何Knowledge数据或非播种权限引用存在时000030 down原子拒绝；空域down/up保留全部旧表和非复用序列高水位，不能删历史强制降级。

复跑入口为[`scripts/v12-09a-exit-drill.py`](../../scripts/v12-09a-exit-drill.py)，只创建随机tmpfs PG16/回环监听器并清理。SQL数据库往返只证明五表及完整Schema/引用保留，不冒充08b的完整实例恢复/凭据隔离验收。真实浏览器覆盖现有Admin SPA登录及实际Knowledge HTTP，没有伪造尚属12阶段的知识管理/搜索页面。Windows延续用户明确延期，不计通过。
