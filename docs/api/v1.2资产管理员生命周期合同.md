实际 POST /admin/assets/:id/quarantine、/admin/assets/:id/restore 使用当前独立 Admin Session、实际管理域角色/绑定/权限17的 personal_space.asset.manage 与15分钟 MFA。资源 scope 由 RichText 根据实际 Asset ID 构造；User 账号、裸 ID、过期 MFA 和客户端 actor/owner/scope 无法替代。

请求仅 reason（去空白后1–500字符），未知字段与 confirm_asset_id 拒绝。独立固定 Policy 允许 active/trashed→quarantined 与 quarantined→active。治理权不赋予用户原文读取权；成功 ack/event 仅 asset_id/status。

预期 status/manual version+1/date/nonce 之外的完整 raw 字段、引用/Object/config/当前 authority 不得变化。Asset/platform audit/outbox 必需，任一写入失败、事务内额外变化或最终撤权全部回滚。迁移18 typed Admin actor_ref_id 保留独立数字或 opaque ID，legacy actor_user_id 为 NULL；User 历史保持原 User 引用。
