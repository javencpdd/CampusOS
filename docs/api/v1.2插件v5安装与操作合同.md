## 当前入口与事实源

`000026` 固定 publisher/key/version 的完整包摘要；`000027` 用8张宿主表保存包目录、全局安装、User安装、版本Grant/Consent/配置与Operation。生成列只负责关系和约束，JSON DTO是唯一状态事实；安装与授权不会互相代替。新Host Catalog只读v5事实，旧Manager没有生产写入口或运行注册，旧HTTP控制/市场/数据入口返回410。历史类型与数据保留，不继承旧权限。

| 入口（均位于 `/api/v1`） | 当前要求与结果 |
| --- | --- |
| `GET /admin/plugin-v5`、`GET /admin/plugin-v5/:publisher/:key/:version` | 当前独立Admin会话及 `plugin.plugin.read`；目录或系统域详情 |
| `POST /admin/plugin-v5/packages` | 当前 `plugin.plugin.install` 与近期MFA；multipart `package`、`release`、`idempotency_key`，包≤64 MiB，签名外封≤1 MiB |
| `POST /admin/plugin-v5/:publisher/:key/commands` | 服务按kind复核当前 install/configure/lifecycle/uninstall权限与近期MFA，路由的read权限不能替代写权限 |
| `GET /admin/plugin-v5/operations/:id` | 当前Admin read权限，安全操作投影 |
| `GET /plugin-v5`、`GET /plugin-v5/:publisher/:key/:version` | 当前User会话；列表在分页前筛选已全局安装且当前版本获批的插件；详情只返回本域配置/同意 |
| `POST /plugin-v5/:publisher/:key/commands` | 当前User会话派生owner，不接受客户端主体或owner字段 |
| `GET /plugin-v5/operations/:id` | 仅本User创建且归属本User的操作，其他owner返回404 |

所有投影 `private, no-store`。浏览器写入须匹配对应域的CSRF Cookie/Header：Admin为`campusos_admin_csrf`/`X-Admin-CSRF-Token`，User为`campusos_csrf`/`X-CSRF-Token`。JWT只提供会话线索，服务在事务内前后重新读取当前账号、会话、角色权限和MFA事实。User/Integration凭据不能进入Admin域。

列表使用`after`游标与`limit=1..50`，不公开隐藏条目总数。包`storage`是最近一次完整性/可用性观察，不能替代当前信任或执行授权。

## 操作、并发与恢复

[命令/安全投影Schema](plugin-v5-installation-v1.schema.json)、[TypeScript DTO](../../sdk/typescript/src/plugin-v5-installation.ts)不含可自填的执行事实。代次和revision使用十进制字符串，避免JavaScript精度损失。JSON拒绝重复/未知/顶层大小写别名字段、null、尾随文档和超限输入。

- Admin：`install/enable/disable/upgrade/uninstall/grant/revoke/configure/purge_release/retry`。User：前五项及`consent/configure/retry`。
- `install`默认disabled；Grant不会自动安装或启用。User安装须已有当前全局安装与该版本批准。配置、同意与安装分别有CAS版本。
- Grant只可批准声明中的精确typed consumes与有界资源。Consent绑定发布版本、owner、用途摘要和当前Grant修订；重批不复活旧同意。
- 配置按发布版本和system/User域分开；可在升级前配置已知目标版本，不改动当前代次。启用、升级与准备均按声明读取有效域，排除的域不进入私有胶囊；共享01b内核验证普通值。Selector/Secret ref须通过实际宿主Port；缺适配器关闭，不把声明或字符串当作授权。
- 同主体的`idempotency_key`绑定完整请求摘要与坐标，同请求返回既有Operation；更换参数返回409。意图、代次、操作、必需审计及Outbox同一事务提交；审计/Outbox/COMMIT失败全部回滚。
- 停用、撤权、配置变化和卸载立即改变desired代次，旧active/observed代次不再满足准入。后台以非复用租约认领有界批次；旧代次/租约/过期观察拒绝，先处理新命令，等待Runtime的条目不能饿死新工作。
- 后台准备校验当前包字节、信任、Grant/Consent/配置与账号；私有配置胶囊按owner/代次原子落盘并固定摘要。观察时再次核对全部绑定和文件摘要。重启先使旧ready代次失效，再对账持久意图；缺失/篡改包分别标为missing/quarantined，不能用元数据冒充可运行实例。

操作状态为`queued/working/waiting/done/failed/superseded`，安装observed为`pending/ready/failed/stopped`。HTTP操作投影不含请求摘要、幂等键、后台租约或私有准备文件。Outbox只保存坐标、操作ID、代次/状态等有限元数据，没有配置、私有内容或凭据。

## 升级、保留与清理

升级先固定desired版本与新代次，ready之前不修改current版本。当前仅接受相同private schema version的`preserve`模式，按版本保留旧配置和私有准备快照；回退也走相同校验。不同数据版本、需要数据迁移或无法验证的回退返回`plugin.lifecycle_rollback_unverifiable`，不能声称已有可逆迁移。

卸载默认保留自己的配置与私有数据；`purge_data=true`是显式异步清理意图，只清理本owner所有版本配置和文件，不删除历史、其他owner或全局安装。配置记录保留为空的默认值及新revision，Secret引用清空；包族与永久身份不删除。`purge_release`须所有全局/用户current及desired安装都不再引用版本，后台在持久意图提交后再复核引用和包修订，才删除包字节并标记purged；相同签名字节可使用新幂等键重新导入。

`PLUGIN_DATA_DIR/v5/packages/<digest>.tar.gz`、`prepared/<publisher>/<key>/<owner>/<generation>.json`与`data/<publisher>/<key>/<owner>/`均为私有受管命名空间，不接受客户端路径，不解压/改写宿主源码、依赖、二进制、前端产物或核心Schema。备份须包含数据库和整个v5受管目录。000027非空down拒绝，空域down/up保留代次序列；旧1–26迁移不改写。

## 本阶段出口边界

生产没有可伪造ready的观察器，因此启用通常保持`pending / plugin.runtime_unavailable`。`Observe`只供编译进宿主的未来Runtime Port；本阶段用有界合同桩验证状态机，不把它公开为HTTP或插件回调。`ExecutionFacts`只是后续Dispatcher的前置准入事实，资源ACL、Host Capability、真实贡献发布、在途调用取消与UI/Runner隔离仍由03c/04/05/06验收。当前Host能力目录为空，扩展DTO不等于安装的Provider。
