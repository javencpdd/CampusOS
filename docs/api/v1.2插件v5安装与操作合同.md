## 当前入口与事实源

`000026` 固定 publisher/key/version 的完整包摘要；`000027` 用8张宿主表保存包目录、全局安装、User安装、版本Grant/Consent/配置与Operation。生成列只负责关系和约束，JSON DTO是唯一状态事实；安装与授权不会互相代替。新Host Catalog只读v5事实，旧Manager没有生产写入口或运行注册，旧HTTP控制/市场/数据入口返回410。历史类型与数据保留，不继承旧权限。

| 入口（均位于 `/api/v1`） | 当前要求与结果 |
| --- | --- |
| `GET /admin/plugin-v5`、`GET /admin/plugin-v5/:publisher/:key/:version` | 当前独立Admin会话及 `plugin.plugin.read`；目录或系统域详情 |
| `POST /admin/plugin-v5/packages` | 当前 `plugin.plugin.install` 与近期MFA；multipart `package`、`release`、`idempotency_key`，包≤64 MiB，签名外封≤1 MiB |
| `POST /admin/plugin-v5/:publisher/:key/commands` | 服务按kind复核当前 install/configure/lifecycle/uninstall权限与近期MFA，路由的read权限不能替代写权限 |
| `GET /admin/plugin-v5/operations/:id` | 当前Admin read权限，安全操作投影 |
| `GET /plugin-v5`、`GET /plugin-v5/:publisher/:key/:version` | 当前User会话；列表在分页前筛选已全局安装且当前版本获批的插件；详情只返回本域配置/同意 |
| `POST /plugin-v5/:publisher/:key/commands` | 当前User会话派生owner，不接受客户端主体或owner字段 |
| `GET /plugin-v5/operations/:id` | 仅本User创建且归属本User的操作，其他owner返回404 |

所有投影 `private, no-store`。浏览器写入须匹配对应域的CSRF Cookie/Header：Admin为`campusos_admin_csrf`/`X-Admin-CSRF-Token`，User为`campusos_csrf`/`X-CSRF-Token`。JWT只提供会话线索，服务在事务内前后重新读取当前账号、会话、角色权限和MFA事实。User/Integration凭据不能进入Admin域。

列表使用`after`游标与`limit=1..50`，不公开隐藏条目总数。包`storage`是最近一次完整性/可用性观察，不能替代当前信任或执行授权。

## 操作、并发与恢复

[命令/安全投影Schema](plugin-v5-installation-v1.schema.json)、[TypeScript DTO](../../sdk/typescript/src/plugin-v5-installation.ts)不含可自填的执行事实。代次和revision使用十进制字符串，避免JavaScript精度损失。JSON拒绝重复/未知/顶层大小写别名字段、null、尾随文档和超限输入。

- Admin：`install/enable/disable/upgrade/uninstall/grant/revoke/configure/purge_release/retry`。User：前五项及`consent/configure/retry`。
- `install`默认disabled；Grant不会自动安装或启用。User安装须已有当前全局安装与该版本批准。配置、同意与安装分别有CAS版本。
- Grant只可批准声明中的精确typed consumes与有界资源。Consent绑定发布版本、owner、用途摘要和当前Grant修订；重批不复活旧同意。
- 配置按发布版本和system/User域分开；可在升级前配置已知目标版本，不改动当前代次。启用、升级与准备均按声明读取有效域，排除的域不进入私有胶囊；共享01b内核验证普通值。Selector/Secret ref须通过实际宿主Port；缺适配器关闭，不把声明或字符串当作授权。
- 同主体的`idempotency_key`绑定完整请求摘要与坐标，同请求返回既有Operation；更换参数返回409。意图、代次、操作、必需审计及Outbox同一事务提交；审计/Outbox/COMMIT失败全部回滚。
- 停用、撤权、配置变化和卸载立即改变desired代次，旧active/observed代次不再满足准入。后台以非复用租约认领有界批次；旧代次/租约/过期观察拒绝，先处理新命令，等待Runtime的条目不能饿死新工作。
- 后台准备校验当前包字节、信任、Grant/Consent/配置与账号；私有配置胶囊按owner/代次原子落盘并固定摘要。观察时再次核对全部绑定和文件摘要。重启先使旧ready代次失效，再对账持久意图；缺失/篡改包分别标为missing/quarantined，不能用元数据冒充可运行实例。

操作状态为`queued/working/waiting/done/failed/superseded`，安装observed为`pending/ready/failed/stopped`。V12-04操作投影新增字符串revision和审批原因；retry必须携带查询所得的expected_revision，状态变化后拒绝旧修订且不自动重试。HTTP操作投影不含请求摘要、幂等键、后台租约或私有准备文件。Outbox只保存坐标、操作ID、代次/状态等有限元数据，没有配置、私有内容或凭据。

## 升级、保留与清理

升级请求先验证目标签名/不可变包、版本Grant/所需本人Consent、配置及相同private schema的`preserve`兼容性，然后在意图/审计事务内固定当前版本检查点，记录desired版本和新代次。当前仅支持`preserve`；`migrate/reset`、不同private schema、无可验证检查点的降级及当前版本声明`rollback=forbidden`的降级返回`plugin.lifecycle_rollback_unverifiable`，不会调用任意迁移脚本。

启用中的升级撤销旧代次接单并取消在途调用，后台隔离准备、真实Configure/readiness、当前授权复核及Observe后才切换current版本并发布贡献；没有零停顿承诺。失败保留旧current与可诊断Operation，只隔离该插件；以当前版本显式enable或按当前Operation修订retry，仍须当前授权，不能悄悄运行已撤权的旧版本。候选配置变更可产生新代次并沿用同一升级检查点，旧代次/租约/句柄不能发布或释放输出。

无后端的UI-only包在已配置有效独立UI Host时，经相同签名资产、当前Grant/Consent、配置与检查点校验，在必需审计事务内激活current及恢复视图；`observed=stopped`、`active_generation=0`，不等待或制造Runner ready。用户激活仍须对应全局current已切换，旧资产租约随版本、代次或权限变化失效；每次真实资产请求重新校验当前事实。未配置有效UI Host仍保持不可用。

停用状态下的`upgrade`只准备目标版本，保持disabled/stopped和旧current；只有显式`enable`该desired目标且真实后端readiness或UI-only资产激活通过后才切换版本。准备操作done不代表候选已经成为current。Web/Admin提供“启用此版本”，以服务端current/desired/observed为准。显式停用、撤权、拒绝同意或卸载取消待完成候选，desired_version回到current；候选已经先提交切换时，携带旧版本的停用仍冲突，调用方重读当前版本与代次。

检查点仅含本安装的版本/原包摘要、本域配置（普通值和不透明Secret引用）与有界私有普通文件，固定SHA-256；不包含Grant、Consent、会话或权限事实。system与每个User分别保存，User恢复不写system/其他User配置。文件字节不超过声明的private总额度且至多1MiB，完整JSON至多2MiB、256目录项、8层、相对路径至多256字节；符号链接、特殊文件、超限、篡改、缺失或跨owner的快照拒绝。当前未发布任意私有文件Host API，也不给Runner挂载该目录；快照处理宿主受管文件，不代表开放私人资源读取。

切回最近保留检查点的版本会准备该owner的升级前配置并使用新revision，重新校验当前Selector/Secret Port；独立恢复目录的实际字节再次核验。数据视图指针只在真实后端readiness或UI-only资产激活及必需审计成功后，与current版本同事务切换，取消/审计失败保留原当前视图。恢复中目标配置的并发编辑返回冲突；重试相同恢复不因PostgreSQL JSON空白或键顺序而制造新的配置修订。回退前也保存离开版本的检查点，可在当前授权允许时再次切换；旧权限始终不从快照恢复。Grant修订变化会使旧Consent失效，须本人重新确认。

原“取消待完成升级”切片见[.130](../进度/v1.2-dev/v1.2.130-dev.md)；完整当前Linux生命周期验证见[.131](../进度/v1.2-dev/v1.2.131-dev.md)。完整证据为`v12-07-lifecycle-exit-linux-v2.json`；v1遗漏UI-only的修正记录及原历史报告保留，不冒充Windows验收。

卸载默认保留自己的配置与私有数据；`purge_data=true`是显式异步清理意图，只清理本owner所有版本配置、原数据、恢复视图和检查点文件，不删除历史、其他owner或全局安装。配置记录保留为空的默认值及新revision，Secret引用清空；包族与永久身份不删除。`purge_release`须所有已安装全局/用户current、desired及回退检查点都不再引用版本，后台在持久意图提交后再复核引用和包修订，才删除包字节并标记purged；相同签名字节可使用新幂等键重新导入。

`PLUGIN_DATA_DIR/v5/packages/<digest>.tar.gz`、`prepared/<publisher>/<key>/<owner>/<generation>.json`与`data/<publisher>/<key>/<owner>/`、`checkpoints/<publisher>/<key>/<owner>/<operation-ID>.json`和`restored-data/<publisher>/<key>/<owner>/<generation>/`均为私有受管命名空间，不接受客户端路径，不解压/改写宿主源码、依赖、二进制、前端产物或核心Schema。备份须包含数据库和整个v5受管目录。000027非空down拒绝，空域down/up保留代次序列；旧1–26迁移不改写。
