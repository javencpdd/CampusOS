> 更新时间：2026-10-14 23:44（Asia/Shanghai）
> 状态：本切片实现、自动化与 Linux PG 目标三态通过

`SpaceAuthorityReader` 仅供宿主业务构造实际私有事实，不认证调用者，也不提供文件读取或管理权限。空间/样式快照完整行与 facts_version 同源读取，实际命令使用 Space/snapshot 行锁、owner admission 和完整最终复核；空库存不跳过守卫检查。支持的仓储写入共享该 owner admission，任意外部 SQL 直接插入空快照库存不在此 admission 合同内。

000023 正 bigint nonce 由非循环共享序列分配，忽略调用者输入。完整空间配置、typed actor、日期/生命周期以及完整样式快照 metadata/排序日期均为事实；空间同步时间/错误和普通 updated_at 只属运行状态。Memory snapshot/restore 保留原内容但不倒退分配高水位，返回值和嵌套样式数据去别名。

000023 down 必须先停止依赖命令，只移除事实列/守卫，保留全部原空间/快照/主体域18/关系及序列高水位；再次 up 不复用已发证明。当前23/next24，原100业务+2执行器表及116 FK不变。未改写既有迁移。

认证、作者/治理Policy、必需审计/outbox及跨字节介质补偿需后续业务切片接入，不由数据列或原裸UserID方法自动完成。具体证据：[.96 进度](../进度/v1.2-dev/v1.2.96-dev.md)。
