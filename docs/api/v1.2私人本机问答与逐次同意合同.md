# v1.2 私人本机问答与逐次同意合同

> 更新时间：2026-10-24（Asia/Shanghai）
> 范围：V12-14b 的单个私人选择、本机模型、一次 Chat 步骤切片；整阶段仍进行中。Windows 延期。

## 入口与本人权限

正常 Server 装配内部 `knowledge.private-local-rag/v1` Port。它与[公开集合本机问答](v1.2公开集合本机引用问答合同.md)分开，只处理当前 User 明确指定的一个本人私人选择，不自动搜索或加入其他私人来源。没有新增问答 HTTP、页面、Host/MCP 或 SDK；现有私人索引页面不会因此自动获得聊天功能。

来源必须已按[私人知识索引与撤回合同](v1.2私人知识索引与撤回合同.md)逐项同意选入，并且当前 ready、精确原来源修订仍有效、保护密钥可解密。索引同意只授权受保护索引，不能替代本合同中的模型逐次同意。当前 User 会话由可信 Identity Port 解析，另一 User、同一用户的另一会话、独立 Admin（包括同数值 ID）、Integration、插件或 MCP 均不能借用批准票据。原模块继续判定 owner、当前版本、原件生命周期和可读性。

模型固定为已选中、启用的 `local-chat` Profile 与编译内置 `builtin.local-openai.text` Definition。端点来自受管部署配置，仅允许 literal loopback HTTP，不接受调用方指定 URL、模型、Provider、owner、系统提示词或权限。网关不安装模型或运行命令，远程 Profile 不会成为隐式替代。

## 准备、展示与独立同意

调用顺序是 `Prepare(ctx, currentUserResolver, question)` → 可信第一方调用者展示精确 review → 本人新作一次明确肯定操作 → `Answer(ctx, currentUserResolver, question, approval)`。准备 review、成功选入索引或管理员启用模型都不表示同意发送。

`PrivateLocalQuestion` 只有以下字段：

| 字段 | 含义 |
| --- | --- |
| `selection_id` | 一个本人已选的 `kp_` 加32位小写十六进制 ID |
| `revision` | 该选择的精确原来源修订，64位小写十六进制 |
| `question` | 问题；沿用词法查询的 Unicode、最多1024字节和16词限制 |
| `run_id` | 本次模型执行的随机 `ar_` 加32位小写十六进制 ID |
| `binding_revision` | 当前 Binding 修订，JSON 表达为十进制字符串 |

Prepare 在5秒范围内重新核验来源及保护，对该单一来源执行 AND 字面词匹配，生成最多240 rune 的纯文本片段。没有匹配证据时返回 `status=refused, reason=no_evidence`、空 evidence，不签发批准 ID，不调用模型、不预留预算、不写批准审计。来源或基础设施不可用会报错，不能伪装成无证据。

准备成功的 `PrivateLocalReview` 返回 `contract/status/request/step/model/content/evidence/digest/approval_id/expires_at_ms`。`step` 固定为 `chat`；`model` 包含确切 `profile_id/profile_revision/binding_revision/definition/model/endpoint/system_prompt/max_tokens`。`content` 是实际 user 消息的完整 JSON，只包含问题和 `E1` 的 `id/title/excerpt`；总量最多16KiB。evidence 另含选择 ID、来源 kind/ID、精确修订、格式、标题、片段和 `index_consent_version`。

**可信第一方调用者必须先展示确切问题、所发标题/片段、系统提示词、模型、目标端点、用途及 Chat 步骤，再独立收集本次肯定同意。** 用户不同意时不调用 Answer，可调用 Revoke 清理准备票据。不能预勾选、自动批准、把索引同意复制成模型同意，或只显示“允许 AI”而隐藏实际内容和目标。当前没有公开 UI/HTTP 实现这一交互，内部 Port 不能被当作已经交付的页面能力。

`PrivateLocalApproval` 仅为 `id/review_digest/consented`，其中 `consented` 必须为 true。摘要绑定准备时的完整请求、确切发送内容、来源引用/索引同意版本、模型计划和步骤；它不是可以自行构造的资源授权。

## 一次性票据与执行顺序

票据为 `kr_` 加32位随机小写十六进制，2分钟到期。账本只在当前生命周期内存保存完整 PrincipalContext 的 SHA256、review SHA256、随机 ID、时间、消费状态及进行中取消句柄，不保存私人正文、问题、回答或长期凭据。容量为每个**完整会话主体上下文**最多32项、全局256项，包括已准备和进行中的调用；不是每个 User ID 32项。容量满时拒绝，不驱逐另一会话的有效票据。到期项按有界扫描清理。

Answer 在70秒上限内从当前来源重新生成 review，检查完整当前会话、请求及精确摘要，再原子消费一次票据。错误身份、内容篡改或摘要不符发生在消费前，不消耗合法票据；一旦消费，随后取消、审计失败、配额不足、模型失败或答案被拒绝均不能重复使用。并发同票据最多一次进入执行，完成后删除。

消费后先执行必需的 `knowledge.private.rag.approve` 审计和 `knowledge.private.rag.approved.v1` Outbox，再进入 AI 预算预留及模型网络调用。审计只含既有主体/执行元数据与固定 Chat/Profile 信息，不保存问题、片段、回答、密钥或 review 正文。批准审计失败不预留预算、不连接模型，也不恢复票据。其后沿用[受管 AI 执行合同](v1.2受管AI模型与执行合同.md)的必需预留/分发/结算审计、执行事件和保守费用。

每个正常 AI guard 边界均复查票据、当前会话、Knowledge/AI/来源 Feature、本人选择/索引同意版本、原来源精确修订、密文快照、当前 DEK 的实际 AEAD 解密能力及模型计划。检查覆盖预算前后、分发前后、实际 HTTP 前后、在途观察和最终交付；密钥仍存在但已换成另一有效长度值，也必须拒绝。没有跨网络长事务或可复用的 allow 缓存。

## 缓冲答案、引用与取消

模型输入是不可信数据；固定系统提示不授予工具、文件读取、URL 获取、模型切换或新的来源权。响应必须是封闭 JSON，只有 `answer` 字符串和 `citations` 数组；拒绝未知/重复/null/非法 Unicode 字段。模型正文最多8192字节，答案最多4096字节，只允许单个宿主证据 ID `E1`。非空答案缺引用、自造 ID 或工具字段均拒绝；空答案加空引用返回 `refused/model_no_evidence`。

答案先缓冲，最终通过全部当前性检查后才以 `campusos.knowledge-private-local-rag/v1` 返回 `status/answer/run_id/citations`，必要时带 reason。宿主生成的引用包括 selection/source/revision/format/title/excerpt 和索引同意版本，不采用模型 URL。本人复开引用使用既有 `POST /api/v1/knowledge/private/selections/:selection_id/source`，正文为 `{revision}`，仍按当前身份与原来源检查；不自动打开新修订。

`Revoke(ctx, currentUserResolver, approvalID)` 要求同一个完整会话，删除票据并取消进行中调用；撤销私人索引会先退休 DEK，来源变更、撤权、Feature/模型变更和到期检查均阻止继续执行或交付迟到答案。撤销不能收回模型此前已收到的字节。实际已分发模型请求仍保守结算1请求单位；未分发失败0，不自动重试、fallback 或重放计费请求，结算审计失败也不提前交付。

Knowledge Stop 取消票据和在途工作并等待必要结算，Start/Stop 串行化；重新 Start 或完整进程重启都不会复活旧票据。账本不持久化，私人索引与模型数据继续沿用原有备份/恢复授权围栏；此次没有新增 Schema、依赖或持久正文目录。

此切片只实现一个私人选择、一个本机 Chat 步骤。当前 owned Linux 目标夹具采用 TXT `personal_document`；其他格式和讨论帖的既有私人索引证据由 V12-13 保留，不冒充本次问答目标覆盖。验收 runner 为 [v12-14b-private-local-rag-drill.py](../../scripts/v12-14b-private-local-rag-drill.py)，最终状态及原始证据以本轮进度报告为准。

真实模型语义质量、引用蕴含评测、远程模型逐步同意、Embedding/Rerank/外部解析、私人页面交互和整阶段退出不在本片通过声明内。确定性本机模型协议端验证执行与安全边界，不能代表真实 LLM 权重或问答质量。V12-14b 整体仍进行中，Windows 继续延期。
