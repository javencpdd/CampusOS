# v1.2 公开社区文本来源候选 Port 合同

> 更新时间：2026-10-21 13:01（Asia/Shanghai）
> 范围：V12-09a 首个切片；可信内置模块的来源预览与当前版本复核。本Port只处理Community discussion；公开RichText现有独立[正文Port](v1.2公开RichText正文来源Port合同.md)。集合、选择规则、成员、官方资料、索引及检索仍待后续。

`feature.knowledge` 是默认关闭的 `hot-gated` Built-in Feature。Server 生产组装注册模块；进程内 AppContext 提供 `knowledge.public-source-candidates`，类型为 `knowledge.PublicSourceCandidates`。外部插件不接收 AppContext。此切片不注册 HTTP、MCP、Integration、Host API 或 Web/Admin 页面。

```go
PreviewPublicThread(ctx context.Context, threadID string) (PublicThreadCandidate, error)
RecheckPublicThread(ctx context.Context, ref SourceReference) (PublicThreadCandidate, error)
```

调用者逐项提供规范正整数帖子 ID，无扫描全站或 owner/管理员覆盖参数。服务只消费现有 `community.content-query.GetPublicThread`，由 Community 当前匿名公开 Policy 和原子版本条件读取原始事实，Knowledge 不直接读取仓储或复制 ACL。返回前再次读取并核对同一内容/版本，任一路径失败均返回空候选；读取不增加浏览量。

当前只支持 `discussion` 帖子的明确 `text`/`markdown` 格式、`published/clear/active` 三状态和未删除事实。私密、草稿、待审、下架、回收站、已删除、缺失/无版本事实均拒绝。Article由独立RichText正文Port处理，不能从本Port的Community摘要读取；Mutual Aid、Secondhand及一般HTML仍需所属Feature后续适配。

候选只含来源 kind/id/revision、category_id、title、content、format 和同源 `/threads/<id>` 原文链接；不包含作者身份、治理原因、附件字节、角色或授权。正文最多 65536 **字节**，标题最多 1024 字节，均要求有效 UTF-8；超限明确拒绝，不静默裁剪。内容和 Markdown 中的链接、HTML 字面量、提示词均是原始不可信数据，不渲染、抓取链接、执行、展开附件或发送给模型。

修订摘要绑定合同版本、来源 ID/板块、类型/格式、标题/正文、原库 `facts_version` 与内容修订。计数与 `updated_at` 不参与摘要；实际内容、标题、移板块和公开→私密→公开 ABA 均使旧引用失效。摘要不替代当前读取。`RecheckPublicThread` 重新获取当前公开事实并比较完整引用，禁用 Feature、撤回、删除或版本不匹配均拒绝。调用者必须在自己的返回/提交边界复核；方法返回后的原库变化仍需消费端当前授权处理，不承诺跨后续操作的永久快照。

| 稳定错误 | 含义 |
| --- | --- |
| `ErrDisabled` | Knowledge 当前关闭 |
| `ErrInvalidReference` | ID、kind 或修订摘要格式不合规 |
| `ErrSourceUnavailable` | 当前来源不可读或事实/适配器不可用；不泄露存在性、私密标题或底层错误 |
| `ErrSourceChanged` | 前后读取/旧引用的来源版本不同 |
| `ErrUnsupportedSource` | 未支持的格式或所属 Feature 来源 |
| `ErrSourceTooLarge` | 正文/标题超过字节上限 |

Context 取消原样终止并返回空候选。候选不是集合成员、索引许可、插件/MCP 可读能力或模型出站同意。后续09a须持久化集合与选择规则、分离成员引用并叠加当前来源授权；09b/10/13/14继续各自职责。没有新增 migration、持久表、数据目录或依赖，current29/next30、113业务/系统受管表+2执行器不变。
