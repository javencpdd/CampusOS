# v1.2 插件通用网页读取与编辑器交接合同

> 最新更新时间：2026-11-15（Asia/Shanghai）
> 状态：v1.2.203 实现；与 `campusos.bridge/v1`、v5 不可变包及现有 Grant/Consent 共用权限模型。

## 能力和数据所有权

宿主提供 `web.public.read`、`community.article.compose` 与可选 `web.local.read`，Scope 均为 self。能力必须由当前签名版本声明、获得有效管理员 Grant，并经本人安装、用途同意和启用。服务器网络策略由部署管理员统一控制，用户和插件没有代理配置、线路选择或关闭代理的权限。具体插件名称、订阅槽位、RSS/Atom 语法、列表和预览属于插件包，宿主不按发布者或插件 key 判断业务。

公开网络读取是显式能力：目标站点会收到正常 GET 请求，但不携带用户 Cookie、JWT、助手 token、任意请求头或平台 Secret。它不授予数据库、目录、shell、系统配置或私有网络权限。纯 UI 包仍为 `runtime: none`。

## Bridge 和 HTTP

- `config.read` / `config.update`：当前插件本人普通配置。写入须宿主确认，沿用原 schema、配置事务与当前 UI proof，不约定任何业务字段名称，不暴露 Secret。
- `web.read`：精确参数 `{url, kind, client_id?}`，kind 为 document 或 image；URL 最多 2048 字符，仅公开 HTTPS、无用户凭据、无片段。返回最多 1 MiB 的可转移 ArrayBuffer 与 MIME。不接受 profile、proxy、代理地址、认证或任意请求头。
- `editor.article.import`：精确参数 `{title, summary, content_html, source, client_id?}`；标题最多 255 字符、摘要最多 1000 字符、HTML 最多 40000 UTF-8 字节。宿主显示插件名称和来源供用户确认；不会替插件证明内容真实性或转载权。图片转存固定沿用选定的服务器/客户端读取位置，不能用 media_profile 覆盖。

后端 `POST /plugin-v5/:publisher/:key/:version/ui-actions` 接收 proof/action，web.read 另需 url/kind；editor.article.import 只检查当前能力，不在该接口创建文章。不开放服务器代理目录查询和用户代理设置接口。通用 web.clients.* 只管理本人客户端配对与读取位置，不接受代理配置。未知字段、方法、owner、路径或凭据拒绝。当前 User、UI proof、不可变包、安装、Grant/Consent 在发送前和外部读取返回后核验；旧会话、跨用户或撤权后的结果不能返回。

网络复用 Egress Broker：固定 GET/Accept/User-Agent、禁重定向、DNS 所有答案及实际目标 IP 公网复核、8 秒网络期限、20 秒整体期限、4 个全局并发槽、1 MiB 响应上限。image 还须通过宿主图片解码、尺寸校验与压缩。默认不读取系统代理环境变量。代理模式仅使用管理员注册并选定的 HTTP/HTTPS CONNECT 或 SOCKS5 端点，向代理提交已验证的公网 IP，目标 TLS 仍校验原站域名与证书；不允许 socks5h 远端解析绕过公网校验。代理认证只发给代理，不能流向源站或插件。失败不静默切换直连，不自动回放写入或扩大上限，错误不透传网络内部信息。

## 宿主代理配置与读取位置

部署管理员设置 `CAMPUSOS_PLUGIN_WEB_PROXY_PROFILES` 为严格 JSON 数组，单项只包含 id、label、url；id 为 `^[a-z][a-z0-9_-]{0,63}$`，label 最多 80 个 Unicode 字符，url 最多 2048 字符。仅接受 http/https/socks5、可选认证、有效端口，无查询、片段或额外路径；最多 16 项、JSON 最多 16 KiB。无效配置使宿主启动报错；不把凭据写进错误。

```dotenv
CAMPUSOS_PLUGIN_WEB_PROXY_PROFILES='[{"id":"clash-http","label":"服务器 Clash HTTP","url":"http://127.0.0.1:7890"},{"id":"clash-socks","label":"服务器 Clash SOCKS5","url":"socks5://127.0.0.1:7891"}]'
CAMPUSOS_PLUGIN_WEB_PROXY_PROFILE=clash-http
```

`CAMPUSOS_PLUGIN_WEB_PROXY_PROFILE` 是管理员选定的唯一活动编号；空值表示管理员选择直连，非空但不存在的编号拒绝启动。此策略统一用于所有插件公开文档与图片读取，用户不能改选、禁用或绕过；代理故障也不会自动直连。示例端口须按实际 Clash 设置调整。原生 API 的 127.0.0.1 指 API 所在机器，Docker 中则指 API 容器；连接宿主机需要已配置的可达地址。修改部署环境后通过部署工具应用，插件不能写该配置或替用户打开 Clash LAN 监听。开发和部署 Compose 均显式透传这两项变量。

这里的 `web.read` 由服务器发请求，使用服务器能访问的代理。如果使用本机抓取助手，发请求的是用户电脑，应由助手使用用户端代理；这不是相同的读取位置。旧 RSS 专用助手已由通用可选客户端替代；本机代理由用户在助手中配置，仅上传协议状态。详见[本机公开读取助手合同](v1.2本机公开资源读取助手合同.md)。普通网页 [fetch 请求选项](https://developer.mozilla.org/en-US/docs/Web/API/RequestInit)没有指定 HTTP/SOCKS 隧道端口的参数；[Chrome 的代理 API](https://developer.chrome.com/docs/extensions/reference/api/proxy)需要浏览器扩展权限。浏览器代理设置与源站 CORS 是另外的边界，不能靠插件填写端口绕过。

## 可选本机读取

本机读取需额外声明并获批 web.local.read。web.clients.status/pair/select/disconnect 及宿主下载适配器使用通用协议，不含 RSS 业务。client_id 只允许当前本人、真实会话和当前插件版本的客户端，源地址先由服务端预检，再由本机 Egress 独立校验。文档、预览图片和导入图片固定同一客户端，不静默改用服务器。

普通配置更新只变更当前 UI proof；客户端凭据另固定生命周期代次、Grant/Consent 和真实会话。停用后重新启用不能使旧令牌复活。登录凭据轮换后旧连接失效，宿主保留不可用选择而不自动选择服务器，用户需重新配对或明确切换。详细参数与期限见[助手合同](v1.2本机公开资源读取助手合同.md)。

## 编辑器交接

明确确认后，宿主调用原内容清洗器。用惰性 template 解析清洗结果，最多转存 8 个不同图片地址、同时最多 2 个工作线程；图片只能经上述 Broker 验证，再调用当前 User 的原图文上传接口。失败图片变为可见占位文字，不留下浏览器直连远端图片的 src/srcset。最终 HTML 再次清洗，并附来源链接。

交接使用绑定当前身份、两分钟有效、一次消费的内存 ID，URL 不携带正文或 Token。原生编辑器回填后仍由用户选择版块、明确点击发布，沿用原权限、配额、审核、事务和审计。取消不上传；确认后已转存的图片属于本人空间，后续导入取消或超时不等于回滚文件。

Bridge 仍限制每消息 64 KiB、每端口 4096 个唯一请求与 32 个并发。普通请求 30 秒；编辑器导入含用户确认及图片转存最多 180 秒，内部工作期限更短。页面、端口、身份或 proof 变化即拒绝后续操作和迟到导航。

## 无下载的 UI 加载

UI artifact 可声明 `isolation: "opaque"`，由宿主通过 `/api/v1/plugin-v5/ui-assets/<lease>/<artifact>` 提供签名包内静态资源。它只借用当前站点的网络地址，执行身份为独立 opaque origin；iframe 与响应 CSP 同时强制 `sandbox allow-scripts`，不得加入 allow-same-origin。

插件不能读取宿主 Cookie、localStorage、DOM 或注册 Service Worker；CSP 禁止直连网络、表单、子框架和 Worker。模块资源使用不带凭据的 CORS，不能扩展到业务 API。宿主仅对来自当前 iframe 的 null-origin ready、精确包身份与随机 challenge 建立单次 MessagePort。向 opaque iframe 使用 `*` 目标是协议所需，必须同时保持 source、身份和 challenge 校验。

租约仍绑定当前身份、包、安装与配置证明，每次资源访问复核；顶层 document、Service Worker、无效租约与撤权资产拒绝。此模式只需配置精确父 Origin，不需通配 DNS、额外 UI 端口、本机助手或 Windows 启动器。需要 Worker/持久 origin 的既有插件可继续使用原独立子域模式，其部署条件保持。

浏览器 JS 不能绕过源站 CORS；`no-cors` 也不能让 JS 读取响应正文。此方案由服务器 Broker 抓取，插件 JS 解析，不通过放开浏览器安全完成。若服务器也无法访问源站，应报告源站网络错误，不伪装成功或静默安装本机程序。
