# v1.2 有据问答与逐次同意合同

> 更新时间：2026-10-24 13:45（Asia/Shanghai）
> 范围：V12-14b 当前 User 的公开集合、单项本人私人来源及受管 Chat。实现与验收状态见 [.156](../进度/v1.2-dev/v1.2.156-dev.md)。

问答依赖已启用的 Knowledge、当前可用 AI Chat Binding 和有效 User 会话。搜索继续独立于模型。公开问答读取管理员已发布的集合，私人问答只读取当前本人显式选入、修订一致且 ready 的单项来源。TXT、Markdown、CampusDoc 与本人文本讨论帖沿用私人索引解析边界。索引、搜索结果、客户端 owner 字段和模型文本均不能授予访问权。

## HTTP 与界面

| 方法与路径 | 请求与行为 |
| --- | --- |
| GET `/api/v1/knowledge/rag/status` | 当前模型、确切端点、系统提示、输出上限、Profile/Binding 修订和支持的步骤；不接受查询参数 |
| POST `/api/v1/knowledge/rag/public` | `collection_id/question/run_id/binding_revision/step`；当前公开资料检索后发送受管 Chat |
| POST `/api/v1/knowledge/private/rag/prepare` | `selection_id/revision/question/run_id/binding_revision/step`；产生独立核对单，不调用模型或预留模型预算 |
| POST `/api/v1/knowledge/private/rag/answer` | 原请求加 `approval_id/review_digest/consented:true`；原子消费一次批准后调用受管 Chat |
| POST `/api/v1/knowledge/private/rag/revoke` | `approval_id`；撤销本会话的批准 |

字段级定义见 [OpenAPI](openapi-v0.6-current.yaml)，入口授权见 [矩阵](HTTP路由与授权矩阵-v0.6.md)。正文为最多 4096 字节的封闭 JSON，修订号为规范正整数字符串；请求不能覆盖模型、端点、owner、系统提示或步骤。响应 `private, no-store`，问题和私人内容不放在 URL。

Web `/knowledge` 先选公开集合再提问；`/knowledge/private` 对 ready 项点击“对这一项提问”。私人页面先展示实际完整发送 JSON、模型目标和固定提示，用户独立勾选后才能发送；勾选默认关闭。原索引同意不包含模型同意。修改问题或来源、取消、隐藏页面、离开组件时清空正文、取消请求并撤销尚存批准，迟到结果丢弃。结果和引用均以纯文本显示，原文使用现有当前修订引用接口重开。

## 独立同意和出站边界

私人批准有效期为两分钟，仅进程内保存摘要和必要绑定元数据，每个完整会话最多 32 项、全局 256 项。批准绑定完整当前会话、问题/run、精确来源修订与索引同意版本、实际片段/完整内容摘要、固定系统提示、输出上限、确切端点与模型、Profile/Binding 修订和 `chat` 步骤。不能跨 User、同 owner 的新会话、同号 Admin、匿名或机器身份使用；并发只能成功消费一次。撤销、停止和重启使原批准失效。

当前模型可以是编译内置的 `local-chat` 或 `remote-chat`。本机端点由 AI 管理为固定 loopback；远程由共享 Egress 复核 HTTPS、公网 DNS、固定 IP/TLS，禁止请求自选地址、重定向、自动重试和静默降级。私人数据不经过外部插件。旧 `public-local-rag` / `private-local-rag` 内部 Port 继续只接受本机 Profile。

本阶段词法检索和内置文本解析不调用模型。`embedding/rerank/parser/query_rewrite/telemetry` 均不声明可用，在读取来源或网络分发前明确拒绝；Chat 同意不授权其他处理步骤。向量、重排、Office/OCR、自动工具循环和私人 Host/MCP/SDK 问答未开放。

批准必需审计/Outbox 成功后，AI 才进行持久请求单位预算预留、分发与结算。模型只接收有界证据，不获取服务或任意文件。出站前、在途和返回时复核当前会话、Feature、Profile/Binding、来源/DEK/索引同意及批准；变化取消并拒绝答案。模型返回缓冲封闭 JSON，必须引用宿主提供的 E1…E3（私人只 E1），宿主重开并重验当前引用。未知字段、工具、伪造或重复引用拒绝；无证据时不调用模型。原始问题、私人正文、模型答案和秘密不写入运行、事件、审计或 Outbox。

## 质量与证据

协议夹具验证权限、真实 HTTP、取消和失败关闭，不能证明模型事实正确。另以事前冻结的 [中文合成题集](../项目计划书v1/项目计划v1.2/evidence/v12-14b-chinese-rag-golden.json) 执行真实模型、正常生产模块和常驻索引的完整 100 公开 + 100 私人题，保留逐题实际答案及引用。冻结阈值为各域事实/抽取忠实度至少 90%、引用来源和无证据拒答 100%、泄露/不支持步骤出站/格式错误为零。

事实评分要求答案包含冻结事实句；忠实度要求归一化后为至少一段实际引用的子串。归一化只去 Unicode 标点/空白并转小写。这是短中文校园 FAQ 的抽取式验收，不能推断为通用语义问答质量、生产时延承诺或自动官方结论。完整报告、源文件/ELF/构建/文档摘要、环境清理和原始结果随 [.156](../进度/v1.2-dev/v1.2.156-dev.md) 更新。无新产品依赖、迁移或持久正文目录；Windows 沿用用户延期。
