# CampusOS Skills 文档索引

本目录集中保存项目 Skills 的调用、维护、验证和同步说明。Skill 实现代码仍保存在仓库根目录的 `skills/<skill-name>/`。

| Skill | 使用说明 | 作用 |
| --- | --- | --- |
| `campusos-readme-update` | [README 更新 Skill 使用说明](CampusOS-README更新Skill使用说明.md) | 保持根 README 精简，将详细内容路由到正确的 docs 分类并检查入口可达性。 |
| `campusos-project-onboarding` | [项目上手 Skill 使用说明](../help/skills相关/CampusOS-项目上手Skill使用说明.md) | 快速核对当前版本、模块、migration、文档和验证命令。 |
| `campusos-dev-nocommit` / `campusos-dev-workflow` | [开发流程 Skill 使用说明](../help/skills相关/CampusOS-dev流程Skill使用说明.md) | 按版本阶段完成实现、验证和进度文档。 |
| `campusos-data-architecture-sync` | [数据架构同步 Skill 使用说明](../help/skills相关/CampusOS-数据架构同步Skill使用说明.md) | 检查 migration、系统表和管理端数据架构视图是否漂移。 |

新增 Skill 使用说明优先放在本目录。历史文档可逐步迁移，但旧路径应保留跳转文件，避免进度记录中的链接失效。
