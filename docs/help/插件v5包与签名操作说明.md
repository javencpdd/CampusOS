# 插件 v5 包与签名操作说明

> 更新时间：2026-10-16 20:34（Asia/Shanghai）
> 范围：V12-03a包构建和验证；安装、启用及动态UI挂载在后续阶段提供。

先在仓库根目录显式构建两个示例：

```bash
bash scripts/build-v5-examples.sh
go run ./cmd/campusos-plugin-v5-check -root plugins
go build -o .cache/campusosctl ./cmd/campusosctl
```

PDF示例提供两个UI audience；Echo示例是无UI的Go/WASI包，使用共享Go SDK DTO。构建只发生在开发者显式运行脚本时，包内没有可触发的安装/构建命令。

打包及只读检查，输出路径必须尚不存在：

```bash
.cache/campusosctl plugin pack plugins/campusos.chat-echo --out /tmp/chat-echo-v5.tar.gz
.cache/campusosctl plugin inspect /tmp/chat-echo-v5.tar.gz
.cache/campusosctl plugin catalog
```

`plugin init <key> --dir <new-directory>`可生成无消费能力的UI-only源码模板。`plugin validate <source-directory>`检查实际产物与当前宿主目录。旧`plugin v4`、build/dev/watch和直接install不再进入旧协议；插件自身构建命令应在明确的源码目录中手工执行。

签名与核对需要操作者已有的Ed25519私钥文件、发布者信任文件。私钥文件内容为标准base64编码的64字节Go Ed25519私钥，不放入包、Git或文档。信任文件结构见[Schema](../api/plugin-v5-trust-v1.schema.json)，必须由可信操作者按publisher和key_id设置公钥及active/revoked状态。

```bash
.cache/campusosctl plugin sign /tmp/chat-echo-v5.tar.gz \
  --key-id <key-id> --key-file /path/to/private-key \
  --out /tmp/chat-echo-v5.release.json
.cache/campusosctl plugin verify /tmp/chat-echo-v5.tar.gz \
  --release /tmp/chat-echo-v5.release.json --trust /path/to/trust.json
```

只有`verify`成功才返回`signature_verified=true`；所有命令都返回`installed=false`。`pack/inspect`检查字节与合同，不将未签名包当作可信发布。签名外封在包外；相同版本改变字节必须提升版本，不能覆盖已知发布摘要。服务器可通过`CAMPUSOS_PLUGIN_V5_TRUST_STORE`加载同格式的宿主信任文件；默认信任集合为空，错误配置使模块启动失败，不退回旧Host Token。

包输入大小、路径、归档格式和签名消息详见[字节与签名合同](../api/v1.2插件v5包字节与签名合同.md)。主CLI只输出稳定错误码和安全元数据，不回显配置、私钥或完整文件路径。当前旧HTTP包入口暂不可用；v5包通过检查也不会自动安装、恢复旧v4发现或执行插件。

独立声明快照工具仍可用于离线合同测试，见[首片工具说明](插件v5声明离线检查说明.md)。它输出`installable=false`，不能把合成目录快照转换成生产权限。完整03a复验和证据见[阶段进度](../进度/v1.2-dev/v1.2.114-dev.md)。
