# 机器集成凭据

> 更新时间：2026-10-16 15:46（Asia/Shanghai）

按既有迁移流程应用新增前向迁移 `000025` 后，在管理后台的“集成中心 → 机器集成凭据”创建一个独立集成。需要独立管理员的机器集成管理权限，并在“管理员认证”完成近期多因素验证。

1. 选择集成，填写精确公开帖子 ID、HTTP/MCP 通道与1–90天有效期，签发凭据。
2. 将只显示一次的秘密保存到客户端的秘密配置。关闭、切换窗口或离开页面后不能重新查看；丢失时轮换或重新签发。
3. 轮换所选凭据会在成功提交时使旧凭据立即失效；更新范围不延长原到期时间。暂停集成会暂时禁用全部凭据，恢复后仍受原窗口和范围约束。
4. 撤销凭据或集成是永久操作。撤销集成会使其全部关联凭据失效。

客户端以 `Authorization: Integration <token>` 请求，秘密只放在该请求头，不能放 URL、Cookie 或请求正文。示例：

```bash
curl -H "Authorization: Integration ${INTEGRATION_TOKEN}" \
  http://127.0.0.1:8080/api/v1/integration/threads/123
```

白名单只允许明确资源。即使已列入白名单，帖子改为私有、待审核、下架或回收站后仍不可读取。此凭据不能用于用户、后台或旧 Admin MCP 控制接口。接口和恢复边界见 [凭据与接入合同](../api/v1.2Integration凭据与接入合同.md)。
