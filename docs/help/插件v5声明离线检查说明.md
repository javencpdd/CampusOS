# 插件 v5 声明离线检查

> 更新时间：2026-10-16 18:50（Asia/Shanghai）
> 状态：V12-03a 首片工具；生产安装路径仍使用现有协议。

开发者可先检查完整 JSON Manifest 的字段、包形态、配置默认值、consumes/provides、资源预算和发布身份，再进入后续包字节验收。工具只读取四个显式文件，不连接数据库、网络，也不执行插件。

在仓库根目录运行：

```bash
GOCACHE="$PWD/.cache/v12-g0/go-cache" go run ./cmd/campusos-plugin-v5-check \
  --manifest /path/to/manifest.json \
  --host-catalog /path/to/host-capabilities.json \
  --extension-catalog /path/to/extension-catalog.json \
  --release /path/to/release.json
```

Manifest与外封格式见[完整合同](../api/v1.2插件v5完整Manifest目标合同.md)；目录快照格式见SDK的[Host Catalog](../../sdk/typescript/src/plugin-v5-consumes.ts)与[Extension Catalog](../../sdk/typescript/src/plugin-v5-provides.ts)。当前工具只支持JSON，不将旧`plugin.yaml`转换成v5。两个目录文件必须由操作者明确选择；仓库的G1合成夹具仅用于测试，尚无生产v5目录导出或发布功能。

退出码0表示声明与所给快照一致；1表示合同或语义拒绝；2表示参数、文件或输入大小错误。输出只含稳定错误码和检查范围，不回显配置、签名内容或文件路径。成功输出仍明确`installable=false`、`package_bytes_verified=false`与`signature_verified=false`。

每个输入文件最多1 MiB，必须为普通文件。解码拒绝重复字段、大小写字段别名、null、无效Unicode、尾随值和超过32层的嵌套；包内引用必须为规范相对路径。Wasm/Container可无UI，但须有具名贡献；UI-only不带后端和宿主资源声明。声明不会产生执行权或扩大当前权限。

完整Linux原生与实际CLI复验：

```bash
bash scripts/v12-03a-manifest-drill.sh
```

该命令构建race测试二进制与CLI，以空环境执行Go路径，再将23份实际Go决策、23个CLI进程与独立G1/Ajv oracle逐项核对，结果保留在它输出的`.cache/v12-03a-manifest/acceptance.*`目录。它不安装包、不启动服务，也不重置数据库。

本工具不检查真实包内容或签名真实性。同版本摘要冲突、归档/符号链接、生产目录接入和旧示例迁移仍在03a剩余范围；安装与运行时属于03b及后续阶段。进度与证据见[v1.2.113-dev](../进度/v1.2-dev/v1.2.113-dev.md)。
