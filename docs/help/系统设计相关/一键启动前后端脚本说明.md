# 一键启动前后端脚本说明

## 1. 脚本位置

```bash
scripts/start-dev.sh
```

也可以通过 Makefile 执行：

```bash
make dev-all

STOP_EXISTING=true make dev-all
```

## 2. 默认启动内容

脚本默认会按顺序执行：

1. 启动 Docker 依赖服务：PostgreSQL、Redis、NATS、pgAdmin。
2. 执行数据库迁移：`scripts/migrate.sh up`。
3. 启动后端 API：默认 `http://localhost:8080`。
4. 启动用户前台：默认 `http://localhost:3000`。
5. 启动管理后台：默认 `http://localhost:3001`。
6. 启动官方文档：默认 `http://localhost:3002`。

日志写入：

```text
.campusos/logs/api.log
.campusos/logs/web.log
.campusos/logs/admin.log
.campusos/logs/docs.log
```

按 `Ctrl+C` 会同时停止本次脚本启动的四个开发服务。

## 3. 常用参数

跳过 Docker 依赖启动：

```bash
SKIP_INFRA=true ./scripts/start-dev.sh
```

跳过数据库迁移：

```bash
SKIP_MIGRATE=true ./scripts/start-dev.sh
```

端口被旧进程占用时自动停止旧监听进程：

```bash
STOP_EXISTING=true ./scripts/start-dev.sh
```

自定义前端端口：

```bash
WEB_PORT=3100 ADMIN_PORT=3101 DOCS_PORT=3102 ./scripts/start-dev.sh
```

## 4. 注意事项

- 默认不会强制杀掉已有进程，避免误杀其他服务。
- 如果端口已占用，脚本会提示占用的 PID。
- `.env` 会在脚本启动时读取，后端数据库连接仍以 `.env` 或环境变量中的 `DATABASE_DSN` 为准。
- 当前推荐 Docker PostgreSQL，避免宿主机 PostgreSQL 和 Docker PostgreSQL 混用导致数据不一致。
