# CampusOS 备份恢复说明

## 1. 需要备份的内容

| 内容 | 路径或服务 | 说明 |
| --- | --- | --- |
| PostgreSQL | Docker 服务 `campusos-postgres` | 用户、帖子、插件记录、个人主页、Webhook、MCP、Message 等核心数据 |
| 插件目录 | `data/plugins` 或 `PLUGINS_DIR` | 已安装插件代码和 manifest |
| 插件数据 | `data/plugin_data` 或 `PLUGIN_DATA_DIR` | Host API SQLite KV、插件运行数据和页面拓展风格包源码目录 |
| 图片和上传资源 | `data/images` | 本地图片、头像和上传文件目录 |
| 本地配置目录 | `data/config` | 本地运行配置预留目录，不应提交密钥 |
| 本地发布产物 | `data/dist` | 本地构建或发布产物预留目录 |
| 本地 skills | `data/skills` | 本地 runtime/imported skills 预留目录 |
| 配置文件 | `.env` | 数据库、JWT、AI、Host API 等本地配置 |
| 迁移脚本 | `migrations/` | 恢复后用于确认数据库结构版本 |
| 风格包示例 | `data/plugins/personal-space/styles/` | 个人主页风格包样例 |
| 个人空间文件 | `data/images/personal-space/users/` | 默认每用户 10MB，本地头像默认保留最近 3 个源文件 |

## 2. PostgreSQL 备份

当前推荐使用 Docker 内 PostgreSQL：

```bash
docker exec -t campusos-postgres pg_dump -U campusos -d campusos > backups/campusos-$(date +%Y%m%d-%H%M%S).sql
```

如果使用自定义数据库名，按 `.env` 中的 `DB_NAME` 或 `DATABASE_DSN` 调整 `-d`。

## 3. PostgreSQL 恢复

先确认容器运行：

```bash
docker ps --filter name=campusos-postgres
```

恢复：

```bash
cat backups/campusos-YYYYMMDD-HHMMSS.sql | docker exec -i campusos-postgres psql -U campusos -d campusos
```

恢复后检查迁移版本：

```bash
make migrate-status
```

如恢复的是旧备份，再执行：

```bash
make migrate-up
```

## 4. 插件与配置备份

```bash
mkdir -p backups/files
tar -czf backups/files/campusos-files-$(date +%Y%m%d-%H%M%S).tar.gz \
  .env \
  data/plugins \
  data/plugin_data \
  data/images \
  data/config \
  data/skills
```

如果 `.env` 中修改了：

```text
PLUGINS_DIR
PLUGIN_DATA_DIR
```

请把实际路径也加入 tar 包。

## 5. 恢复后的检查清单

| 检查项 | 命令或入口 |
| --- | --- |
| 数据库迁移 | `make migrate-status` |
| API 健康 | `curl http://localhost:8080/api/v1/health` |
| 管理后台 | `http://localhost:3001/login` |
| 集成中心 | `http://localhost:3001/integrations` |
| 插件列表 | 管理后台“插件管理” |
| 个人主页 | 用户侧“个人主页”设置与公开主页 |
| Webhook | 集成中心中执行测试投递 |
| MCP | 集成中心调用 `health.check` |
| Message | 集成中心发送 local `ping` |

## 6. 注意事项

1. 恢复 `.env` 后要确认 `DATABASE_DSN` 指向 Docker PostgreSQL 当前端口。
2. 目前推荐 Docker PostgreSQL，不建议同时运行宿主机 PostgreSQL，避免 5432/5433 数据源混淆。
3. 个人主页头像 URL 保存在数据库中，头像源文件保存在 `data/images/personal-space`，恢复时两者需要使用同一份备份。
4. Webhook secret、JWT secret、AI API key 属于敏感信息，备份文件不要上传到公开仓库。
5. 插件包导入后会记录 checksum，但插件目录本身仍需要文件级备份。
