# v0.5 集成中心与低风险集成指南

## 1. 功能定位

v0.5 的目标不是一次性接入所有外部平台，而是先把现有能力做成可运营、可恢复、可排错的低风险集成底座。

后台入口：

```text
http://localhost:3001/integrations
```

主要接口都在：

```text
/api/v1/integrations/overview
/api/v1/metrics/summary
/api/v1/webhooks
/api/v1/mcp/*
/api/v1/messages/*
/api/v1/platform/logs/*
```

这些接口均需要管理员登录，并使用现有 `role:manage` 权限保护。

## 2. 集成中心

集成中心通过 `GET /api/v1/integrations/overview` 聚合以下状态：

| 模块 | 说明 |
| --- | --- |
| 数据库 | PostgreSQL ping、用户/帖子/版块/插件数量 |
| 插件仓库 | 已安装、运行中、异常插件数量 |
| AI Gateway | 是否启用、是否 ready、provider 和调用日志数量 |
| 个人主页 | 主页数量、公开主页、禁用主页、已应用风格、同步异常 |
| Webhook | endpoint、启用数量、投递成功/失败 |
| MCP | 只读工具开关、工具数量、审计数量 |
| Message | local adapter、消息数量、账号绑定数量 |
| Metrics | API 请求数、错误数、最近延迟 |
| 平台日志 | 后端 API、用户前台 web、管理后台 admin 的开发期日志读取入口 |

## 3. 社区版块与默认标签

版块可以配置默认标签：

```text
categories.default_tags
```

管理员在后台“版块管理”中维护默认标签。用户在该版块发帖时，用户前台会自动带入这些默认标签，同时仍允许继续输入自定义标签。后端创建帖子时也会再次合并版块默认标签和用户提交标签，避免只依赖前端逻辑。

相关边界：

| 项目 | 当前行为 |
| --- | --- |
| 默认标签来源 | `categories.default_tags` |
| 用户自定义标签 | 发帖页 `allow-create` 多选输入 |
| 合并策略 | 先保留版块默认标签，再追加用户自定义标签，去空、去重、最多 20 个 |
| 标签表联动 | 当前仍以 `threads.tags` 存储为主，`tags` 表的聚合统计后续再做 |

## 4. 个人主页运营能力

用户侧新增：

```text
GET  /api/v1/home/config
POST /api/v1/spaces/me/styles/html/validate
GET  /api/v1/spaces/me/styles/html-example
POST /api/v1/spaces/me/styles/html/apply
POST /api/v1/spaces/me/styles/rollback
POST /api/v1/spaces/me/styles/default
GET  /api/v1/spaces/me/sync-status
```

管理员侧新增：

```text
GET  /api/v1/spaces/admin/summary
POST /api/v1/spaces/:user_id/disable
POST /api/v1/spaces/:user_id/enable
```

应用风格包前会保存快照。用户点“回滚”时恢复最近一次快照；点“默认”时清空当前风格包并回到默认布局。

`personal-space` 作为内置默认插件后，后台插件管理里的启用/禁用状态会影响用户侧个人主页、主页设置、风格包、头像上传、个人空间文件和内容同步接口。管理员禁用该插件后，相关 Space API 会返回不可用或暂停同步；重新启用后恢复。

个人主页风格包支持 `custom_html_enabled` 和 `custom_html` 字段。用户在 `/space/settings` 可以生成基于当前风格的 HTML 示例、先检测再应用。后端只接受受限 HTML 子集，脚本、事件处理器、`javascript:` URL、`data:` URL、危险 CSS 和过深/过大的片段会被拒绝；公开主页接口也会在响应前再次过滤历史不合规 HTML。

用户前台首页由 `homepage-customizer` 内置插件提供结构化配置。该插件运行时，`GET /api/v1/home/config` 会输出首页标题、副标题、背景图、背景遮罩、版块检索标签，以及通过后端安全审查的 `custom_html`；插件被禁用时，前台回退到内置默认首页配置。

## 5. 插件包治理

插件包导入前可调用：

```text
POST /api/v1/plugin-packages/precheck
```

返回内容包括：

| 字段 | 说明 |
| --- | --- |
| `manifest` | 插件清单 |
| `checksum` | `sha256:` 校验值 |
| `package_size` | 插件包大小 |
| `files` | 包内文件列表 |
| `permissions` | Host API 权限预览 |
| `events` | 事件订阅预览 |
| `conflict` | 是否存在同名插件 |
| `warnings/errors` | 风险提示或错误 |

后台“插件管理”页面导入时会先执行预检。同名插件未开启“覆盖”时会阻止导入。

插件详情和配置接口：

```text
GET /api/v1/plugins/:name
PUT /api/v1/plugins/:name/config
```

`GET` 会返回插件 `config` 与 `config_schema`；Admin 插件管理页据此渲染配置弹窗。`PUT` 会按 schema 做基础类型归一化并持久化到插件仓储。当前 `personal-space` 和 `homepage-customizer` 都是通过该机制统一配置的内置插件，其中 `homepage-customizer.custom_html` 会在写入前执行安全 HTML 审查。

## 6. Webhook

Webhook 支持 endpoint 创建、启停、测试和投递记录：

```text
GET  /api/v1/webhooks
POST /api/v1/webhooks
POST /api/v1/webhooks/:id/test
GET  /api/v1/webhooks/:id/deliveries
```

投递时会带：

```text
X-CampusOS-Signature: sha256=<hmac>
```

签名算法是 HMAC-SHA256，secret 来自 endpoint 配置。失败会记录响应状态码、错误信息和尝试次数。

## 7. MCP 只读实验

当前 MCP 是 CampusOS 内部 API 形式的只读工具闭环，不是完整标准 MCP Server。

内置工具：

| 工具 | 作用 |
| --- | --- |
| `health.check` | 检查 API 状态 |
| `categories.list` | 读取版块列表 |
| `threads.list` | 分页读取帖子 |
| `threads.get` | 读取单个帖子 |

管理接口：

```text
GET  /api/v1/mcp/tools
POST /api/v1/mcp/tools/:name/call
GET  /api/v1/mcp/audit
GET  /api/v1/mcp/settings
PUT  /api/v1/mcp/settings
```

所有调用都会写入 `mcp_audit_logs`。

## 8. Message Local Adapter

v0.5 只做平台无关协议和本地适配器：

```text
GET  /api/v1/messages/adapters
POST /api/v1/messages/local/inbound
GET  /api/v1/messages/logs
POST /api/v1/messages/bindings
```

本地测试：

```json
{
  "conversation_id": "local-room",
  "sender": { "id": "tester" },
  "content": "ping"
}
```

返回 outbound `pong`，并把 inbound/outbound 都写入 `message_logs`。

## 9. 平台日志

开发期一键启动脚本会把三个服务输出写入：

```text
.campusos/logs/api.log
.campusos/logs/web.log
.campusos/logs/admin.log
```

管理后台入口：

```text
http://localhost:3001/platform-logs
```

管理接口：

```text
GET /api/v1/platform/logs/sources
GET /api/v1/platform/logs/stream?source=api&lines=200&follow=true
```

`stream` 使用 SSE 输出日志行，当前只允许读取固定的 `api`、`web`、`admin` 三个来源，并继续受管理员 JWT 与 `role:manage` 权限保护。

## 10. 当前边界

| 暂不做 | 原因 |
| --- | --- |
| MCP 写操作 | 风险高，必须等权限和审计更成熟后再开放 |
| 真实 IM 平台适配器 | NapCat、Discord、AstrBot 等差异大，后续作为 Adapter/Plugin 接入 |
| 完整 Docker 产品化封装 | v0.5 优先保证 Ubuntu/WSL2 开发和依赖服务稳定 |
| AI 内容审核插件 | 输出稳定性不可控，暂不作为 v0.5 主线 |
| 任意 HTML/JS 渲染 | 当前只开放受限 HTML 子集，任意脚本、事件处理器、不安全 URL 和危险 CSS 仍不开放 |
| 生产级集中日志系统 | 当前平台日志面向本地开发期排障，生产环境仍需后续接入 journald、Loki、ELK 或云日志 |
