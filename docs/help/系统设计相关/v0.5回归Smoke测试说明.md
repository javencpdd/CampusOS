# v0.5 回归 Smoke 测试说明

本文说明 `scripts/smoke/v05_smoke.py` 的使用方式。它用于把 v0.5 的关键手动回归步骤沉淀为可重复执行的命令。

## 1. 运行前准备

先启动本地服务：

```bash
STOP_EXISTING=true make dev-all
```

默认 API 地址为：

```text
http://localhost:8080/api/v1
```

## 2. 只读检查

只读模式不会创建帖子或用户：

```bash
python3 scripts/smoke/v05_smoke.py
```

覆盖内容：

| 检查 | 覆盖 |
| --- | --- |
| `health` | 后端健康检查 |
| `categories` | 版块列表 |
| `threads` | 帖子列表 |
| `homepage config` | 首页插件公开配置 |
| `richtext status` | 富文本插件状态 |
| `admin login` | 默认管理员登录 |
| `plugins` | 插件列表 |
| `integration overview` | 集成中心总览 |
| `mcp tools` | MCP-like 工具列表 |
| `message adapters` | Message adapter 列表 |
| `platform log sources` | 平台日志来源 |

## 3. 写入检查

写入模式会注册一个随机 smoke 用户，并创建普通帖子、回复和富文本图文文章：

```bash
python3 scripts/smoke/v05_smoke.py --write
```

覆盖内容：

| 检查 | 覆盖 |
| --- | --- |
| 注册/登录 | 普通用户认证闭环 |
| 普通发帖 | `POST /threads` |
| 回复楼层 | `POST /threads/:id/posts` 并检查 `floor_number` |
| 富文本草稿 | `POST /richtext/articles` |
| 富文本预览 | `POST /richtext/preview` 和 HTML 清洗 |
| 富文本发布 | `POST /richtext/articles/:id/publish` 与公开详情 |

## 4. 常用参数

```bash
python3 scripts/smoke/v05_smoke.py \
  --base-url http://localhost:8080/api/v1 \
  --admin-email admin@campusos.local \
  --admin-password Admin@123456 \
  --timeout 8
```

也可以通过环境变量配置：

| 环境变量 | 默认值 |
| --- | --- |
| `CAMPUSOS_API_URL` | `http://localhost:8080/api/v1` |
| `CAMPUSOS_ADMIN_EMAIL` | `admin@campusos.local` |
| `CAMPUSOS_ADMIN_PASSWORD` | `Admin@123456` |
| `CAMPUSOS_SMOKE_TIMEOUT` | `8` |
| `CAMPUSOS_SMOKE_EMAIL_PREFIX` | `campusos-smoke` |

## 5. 结果判断

脚本输出格式：

```text
[PASS] health
[PASS] categories
[FAIL] plugins - GET /plugins returned 401: ...
```

只要有一个 `FAIL`，脚本退出码就是 `1`，可用于 CI 或本地发布前检查。
