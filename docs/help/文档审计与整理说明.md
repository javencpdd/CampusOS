# CampusOS Help 文档审计与整理说明

> 审查基线：`v0.13.0`  
> 审查日期：2026-07-29  
> 范围：本轮整理前 `docs/help/` 的 62 份 Markdown

## 1. 审查结论

不是所有 Help 文档都适合当前开发者直接使用：

- 当前指南和专项参考仍有直接操作价值。
- 历史快照、事故复盘和旧版兼容文档仍有追溯价值，但必须退出初学者主路径。
- 4 份短文已被当前指南完整吸收，且没有版本进度文档反向引用，本轮合并后删除。
- 其余历史文件暂不物理移动，避免破坏旧计划、进度、Issue 或外部书签。

本轮整理后，初学者只需从 [开发者递进入门路线](开发者递进入门路线.md) 开始，不需要自行判断全部
Help 文档的阅读顺序。

## 8. 维护规则

1. 新开发者入口最多经过两次点击到达实际教程。
2. 同一操作只保留一个当前权威正文；其他文件提供状态和链接。
3. 历史证据不静默删除，也不回写成当前事实。
4. 规划文档必须显式标注未实现。
5. 新增 Help 时同步更新本审计、Help README 和 docs-site 对应入口。
6. 文档改动至少执行 `make readme-check`、`make docs-links`、docs-site build 和 `git diff --check`。
