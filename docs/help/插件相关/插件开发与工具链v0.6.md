# CampusOS v0.6 插件开发与工具链

> `v0.6.10-dev` 之后，`scope` 只表示管理级别。新插件还应阅读 [插件前端运行时与 Extension Gateway](插件前端运行时与Extension%20Gateway.md)，按 `lifecycle` 声明后端生效方式，并通过 `campusos.ui/v1` 提供默认可用 UI。

## 1. 先选择 Runtime

| Runtime | 适合场景 | 信任边界 | 生效方式 |
| --- | --- | --- | --- |
| Built-in | 与核心服务紧密协作、由仓库维护的可信功能 | 与 API 同进程，代码审查要求最高 | builtin+system 默认整站重启 |
| gRPC process | 独立进程、可使用 Go 工具链的扩展 | 进程隔离；当前事件传输仍是 experimental | 默认只重启插件进程 |
| Wasm | 需要更强沙箱和确定资源边界的逻辑 | wazero 沙箱、显式入口和超时 | 默认热更新并原子替换实例 |

Built-in 不等于自动拥有系统权限，Wasm 也不等于无需权限。三者调用 Host API 都受 Manifest 权限限制。

## 2. 目录和最小 Manifest

插件实现放在 `data/plugins/<name>/`；运行数据、KV、风格包和版本快照放在 `data/plugin_data/<name>/`。不要把用户运行数据打进插件包。

```yaml
api_version: campusos.plugin/v1
host_api_version: v1
name: example-plugin
display_name: "Example Plugin"
version: "0.1.0"
runtime: wasm
scope: user
capabilities: [host.logs]
compatibility:
  campusos: ">=0.6.0 <0.7.0"
  host_api: "v1"
  sdk_go: "v0.6"
events:
  subscribe: [thread.created]
permissions:
  api:
    - resource: log
      actions: [write]
storage:
  type: none
config:
  module: plugin.wasm
  entrypoint: handle_event
```

未知 API 版本会被拒绝。旧 Manifest 缺少版本字段时按 v1 兼容读取，但新插件必须显式填写。

## 3. CLI 闭环

```bash
go run ./cmd/campusosctl plugin init example-plugin --runtime wasm
go run ./cmd/campusosctl plugin test example-plugin
go run ./cmd/campusosctl plugin build example-plugin
go run ./cmd/campusosctl plugin verify example-plugin --json
go run ./cmd/campusosctl plugin pack example-plugin
```

`plugin dev` 合并 test、build、verify。`verify` 会检查 Manifest、权限目录、Runtime 产物和包路径安全。可运行参考在 `examples/plugins/`。

## 4. Host API 身份和权限

运行中的外部插件由 Runtime 注入 `CAMPUSOS_PLUGIN_NAME`、`CAMPUSOS_PLUGIN_TOKEN` 和 `CAMPUSOS_HOST_API_URL`。令牌启动时生成、重载时轮换、停止时撤销，并具有过期时间。只发送插件名称会被生产 Host API 拒绝。

Go SDK 默认读取令牌环境变量。权威权限目录是 `docs/api/plugin-permissions-v1.json` 和 `docs/api/Host-API-v1权限目录.md`。

权限有三层：插件能否调用 Host 方法、当前用户是否有业务权限、目标资源是否属于允许的 owner/scope。任何一层拒绝都不能由插件配置绕过。

## 5. 测试

```go
h := campusos.NewHarness("example-plugin")
h.SetPermission("user-1", "thread", "read", true)
h.SetFailure("GetConfig", http.StatusForbidden, "permission denied")
err := h.SimulateEvent(ctx, campusos.Event{Type: "thread.created"}, handler)
```

Harness 支持配置、KV、用户、帖子、回复、通知、日志、权限允许/拒绝、失败注入和事件模拟。权限拒绝使用 `errors.Is(err, campusos.ErrPermissionDenied)` 判断。

## 6. 导入、更新与回滚

管理端预检显示 checksum、大小、权限、事件、冲突、版本变化、签名状态和风险。用户级插件覆盖更新前自动保存到：

```text
data/plugin_data/<plugin>/version-snapshots/<snapshot-id>/
  metadata.json
  <plugin>-<version>.campusos-plugin.tar.gz
```

包加载后执行 Runtime 健康检查。管理员可在“插件管理 -> 版本”恢复 checksum 匹配的快照。系统级插件不允许 Web 热替换，需回退源码并重启。

## 7. TypeScript SDK 决策

v0.6 不向浏览器暴露 Host API token，也不复制 Go Host API。TypeScript 当前只适合 Public HTTP API；待 OpenAPI 补全字段级 schema 后生成 client。风格包继续使用目标受限的 `CampusStyleSDK`，它不是通用 Host API。
