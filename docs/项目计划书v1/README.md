## 与历史计划的关系

- [v0.1-v0.14 历史计划](../项目计划书v0/README.md) 已封版，继续保留用于追溯。
- v1.0 复用 v0.9 的 Manifest v2、本地插件目录、用户授权和受管数据，复用 v0.10 的权限目录与审计边界，不从零重建。
- 当前应用启动/合同版本仍是 `v0.13.0`，v0.14-dev 已由项目所有者确认开发收尾；v1.0 数据库基础已进入开发工作树，但不代表全部 v1.0 插件功能已经完成或产品版本已经发布。

## 维护规则

1. 原始思路、会议记录和提示材料必须标记为非权威输入。
2. 正式计划只保留一个；范围变更在正式计划中记录决策和影响。
3. 计划中的表名、API 版本和性能阈值在 G0 冻结前是设计目标，实施后以生成合同为准。
4. 新增或调整权限、数据库、Host API、Manifest 时，同步更新 `docs/help/系统设计相关/`、`docs/api/` 和进度证据。
