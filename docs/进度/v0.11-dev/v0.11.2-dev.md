# CampusOS v0.11.2-dev：A1 安全评审与命令目录

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已验收（最终回归见 `v0.11.12-dev.md`）

## 阶段目标

在改造前明确事务、审计、Outbox、外部副作用和插件文件操作的边界，避免把“可靠”
写成没有失败策略的口号。

## 实际完成内容

- 新增 [ADR-0011](../../architecture/decisions/ADR-0011-可靠命令与持久事件边界.md)，
  固定 TxKernel、Outbox、至少一次消费、补偿操作和禁止事项。
- 建立 Identity、Community、Plugin/Appearance、Webhook 和可靠重放的命令目录、
  Owner、Permission/Operation/Command Code 与恢复策略。
- 明确 Webhook 不能承诺 exactly-once；External Plugin、Agent Runner 与 MCP 不得
  取得 DB、TxKernel、JWT 私钥或用户 Token。
- 形成数据所有权和安全模型文档，区分事务内数据库事实与事务外文件/HTTP 操作。

## 主要修改目录和文件

- `docs/architecture/decisions/ADR-0011-可靠命令与持久事件边界.md`
- `docs/architecture/v0.11可靠命令事件与数据所有权.md`
- `docs/architecture/v0.11Webhook可靠投递与安全模型.md`

## 架构变化

确定新增 Reliability Core，而不是把可靠性逻辑塞进 Plugin Manager、Webhook 或单个
业务模块。业务模块只依赖窄 Reliability Port。

## 兼容和迁移处理

旧 EventBus、权限审计和 Webhook 接口保持可用；兼容路径必须记录使用量，不能以
文档声明替代实际弃用证据。

## 测试与构建结果

- ADR 的禁止依赖由 `make reliability-check` 自动检查。
- 最终全量验证记录在 `v0.11.12-dev.md`。

## 回滚方式

ADR 和目录可随实现一同撤回；不包含数据迁移或不可逆代码路径。

## 已知限制

本阶段不提供完整 Agent Center、跨服务事务或统一工作流引擎。
