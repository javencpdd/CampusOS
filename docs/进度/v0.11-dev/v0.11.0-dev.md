## 架构变化

本阶段没有运行时架构变化。计划确定了后续目标链路：高风险数据库命令通过
TxKernel 原子写入业务事实、required audit 和 Outbox，提交后由有 lease、幂等、
重试和 dead-letter 的 Worker 处理外部副作用。

权限模型保持 v10 的稳定 Permission Code、路由 Operation、全局/板块作用域、
自定义角色和版主范围。v11 只增加可靠命令和事务审计边界，不替换 RBAC。
