## 1. 目标

集中修复 WebUI 验收中发现的七类问题：分组帖子聚合、二手价格小数、个人空间容量和图片体积、社区事件
通知、头像历史切换、Docker 开发日志，以及首次进入模块时类似整页刷新的体验。实现同时更新用户 Help、README、`OpenAPI` /路由合同和官方文档站。

## 2. 社区分组与二手价格

- 查询分组时，服务层把分组展开为其下所有启用板块，并按板块集合查询帖子；空分组不会错误回退为全站帖子。
- 桌面端和移动端分组导航均提供“全部帖子”入口，进入后展示该分组下所有板块帖子。
- 二手价格输入支持两位小数，前端继续以“元”输入、整数“分”提交，避免浮点数直接进入接口和数据库。

## 3. 个人空间、头像与图片压缩

### 3.1 配额

- 默认个人空间由 10 MiB 调整为 50 MiB。
- 新增 migration `000042_v13_user_storage_quotas` 和 `user_storage_quotas` 表，保存管理员对单个用户设置的覆盖配额。
- 新增管理员接口：
  - `GET /api/v1/spaces/admin/users/{user_id}/storage`
  - `PUT /api/v1/spaces/admin/users/{user_id}/storage`
- Admin 用户管理页可查看用户已用容量、有效配额，并设置单用户覆盖值；权限为 `space:manage`。
- 文件、内容图片、富文本资源和课表资源统一读取有效配额，内存与 PostgreSQL 装配保持一致。

### 3.2 图片处理

- JPEG 重新编码为质量 82，并去除编码过程中未保留的元数据；PNG 使用最佳压缩。
- JPEG/PNG 超过 1920 像素的长边会等比缩放；拒绝解码尺寸超过 4000 万像素的图片。
- 内容图片、富文本资源和头像在压缩后再检查单文件上限与用户配额。
- GIF/WebP 暂不重新编码，以免破坏动画或引入当前工具链不具备的编码依赖，但仍计入配额。

### 3.3 头像历史

- 个人设置页展示最近保留的三个头像源文件，并可直接切换当前头像。
- 新增 `GET /api/v1/spaces/me/avatars` 和 `PUT /api/v1/spaces/me/avatar`；上传接口同时返回更新后的头像列表。
- 切换只更新当前头像引用，不修改文件时间或先进先出顺序；只有上传新头像时才删除最老源文件，因此第四次上传会淘汰原始最老头像。

## 4. 社区通知

新增三种通知类型：

| 事件 | 接收人 | 通知类型 |
| --- | --- | --- |
| 管理员下架帖子 | 帖子作者 | `community.thread.taken_down` |
| 帖子收到直接评论 | 帖子作者 | `community.thread.replied` |
| 评论收到回复 | 父评论作者 | `community.post.replied` |

本人操作不会通知本人；同一回复不会向同一用户重复发送两类通知。发帖、楼层计数和通知使用可靠命令事务，通知
写入失败时一起回滚。通知链接带楼层锚点，帖子详情页提供对应 DOM 锚点。

## 5. Docker 开发日志

平台日志展示的是 CampusOS 应用进程日志；PostgreSQL、Redis、MinIO 和 Docker Engine 自身日志仍应使用
`docker compose logs` 或 Docker Desktop 查看。

## 6. 首次进入模块的“刷新”体验

根因不是业务代码主动调用浏览器刷新，而是可信模块的异步代码块首次下载，以及运行时 manifest 重复同步时曾可能重建动态路由。现在：

- 应用挂载后后台预加载核心页面和可信模块代码块；
- 可信模块共用同一组异步组件，避免预加载与路由创建产生两份加载定义；
- manifest 使用稳定指纹，相同内容不再替换快照或拆除重建路由；
- 运行时同步串行化，并跳过与静态路由重复的模块路径。

首次访问仍可能发起必要的数据 API 请求，但不应再表现为整页刷新或因为相同 manifest 重建路由。API 客户端在无法恢复的 401 会跳转登录页，这是独立的会话失效行为。

## 9. 部署、回滚与已知限制

1. 应用 migration `000042` 并重建/重启 API、Web、Admin、Docs 开发容器；仅执行普通 `up` 不能保证包含新镜像内容。
2. 生产升级前先备份数据库和用户文件目录；配额覆盖表回滚会丢失管理员设置，优先采用 forward-fix。
3. 若必须回滚，先回退依赖新表和新接口的应用，再执行 `000042.down.sql`，避免旧应用访问不存在的结构。
4. Docker 日志文件位于 `.campusos/logs`，已由 `.gitignore` 排除；本地 SMTP 密钥仍只放在被忽略的
   `deploy/docker/.env.dev.local`，不能提交。
5. 图片压缩目前只重新编码 JPEG/PNG；GIF/WebP 优化和跨功能并发配额预留可作为后续增强。
6. 当前开发容器保持运行，便于继续通过 WebUI 验收；停止时使用 `./scripts/docker-dev.ps1 down`。
