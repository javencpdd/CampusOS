## 4. 文档信息架构

```text
README.md
  -> 项目概要和最短启动
docs/README.md
  -> 仓库文档门户和任务导航
docs/help/
  -> 当前操作指南、专项参考和明确标注的历史材料
docs/api/ + docs/architecture/
  -> 当前机器合同、边界、数据所有权和设计依据
docs/项目计划v*/ + docs/计划书总结/
  -> 原始计划、有效性判断和版本演进
docs/进度/
  -> 实际实现、测试、兼容和回滚证据
docs/Todo/
  -> 未排期输入，不代表承诺
docs-site/
  -> 面向浏览器阅读的官方教程
```

同一操作只维护一个权威正文；其他位置提供短入口。代码、migration 和生成合同高于手写文档，历史材料
继续保留但退出初学者主路径。
