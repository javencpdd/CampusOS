# v0.13.39-dev：帖子列表行展示所属板块与标签

> 日期：2026-08-03
> 状态：实现并验证
> 范围：Web 帖子列表页（全部帖子与分组/板块筛选）、共享板块目录、组件测试、Help/官方文档

## 1. 目标

v0.13.36 只在讨论、互助和二手详情页展示所属板块与标签。用户在“全部帖子”和分组/板块筛选的帖子列表中
无法看到每行帖子的板块归属。本阶段在列表页每行补上板块与标签信息，且不改变 Thread API 的
`category_id`/`tags` 合同、不引入每行一次分类请求的 N+1。

## 2. 完成内容

- 列表 payload 复核：`GET /api/v1/threads` 每项已返回 `category_id` 与 `tags`（`tags` 可能缺省），
  后端和生成合同零改动。
- 新增 `web/src/modules/community/useCategoryCatalog.ts`：模块级共享板块目录，进入列表页时通过
  `GET /api/v1/categories/tree` 一次加载并递归拍平为 `Map<id, {name, icon, description}>`；
  目录加载失败只影响板块标记渲染，列表本身保持可用；导出 `resetCategoryCatalog` 供测试隔离。
- 新增 `web/src/modules/community/components/ThreadBoardChips.vue`：纯展示组件，接收预解析的
  `category` 与 `tags`，板块以 chip 形式链接到 `/threads?category_id=<board_id>`；标签经共享的
  去空白、大小写不敏感去重逻辑；板块与标签均无时整组件不渲染。
- 抽取 `web/src/modules/community/threadTags.ts`：`normalizeThreadTags` 供 ThreadTaxonomy 与
  ThreadBoardChips 共用，详情页行为不变。
- `ThreadListView.vue`：挂载时并行 `ensureCategoryCatalog()` 与列表加载；移动端 compact 行标题下、
  桌面端 `el-table` 新增“板块 / 标签”列均接入 ThreadBoardChips。全部帖子、分组聚合和单板块筛选共用
  同一组件，因此三处入口同时生效。
- 文档同步：Help《v13WebUI交互通知与个人空间治理说明》新增列表行为基线行和实现说明；
  docs-site《Web 交互、个人空间与站内通知》补充列表行板块/标签说明。API 合同无变化。
