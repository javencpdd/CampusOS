## 4. 架构变化

本阶段没有运行时架构变化。计划确定后续以现有模块化单体为基础增加：

- 显式 Observability Port 和默认安全的 Prometheus Adapter。
- 结构化 Feature 自有 Store 的批量读取 Port。
- Identity Core 内的管理员准入可靠命令和 TOTP MFA 边界。
- 保留现有 Core、Built-in Feature、External Plugin、Resource Package 和数据所有权。

External Plugin、MCP、Agent Runner 和浏览器仍不能访问数据库、AppContext、TxKernel、内部 Repository、
JWT 私钥、CampusOS Token 或宿主完整文件系统。

## 5. 兼容和迁移处理

- v0.12 Final 被定义为 v0.13 的硬前置，不使用新计划掩盖旧版本验收缺口。
- v0.13 只从当前最新编号之后追加 migration；计划中的 `000039/000040` 在实施前必须重新检查占用情况。
- 批量查询不得改变 DTO、分页、顺序、权限和缺 Detail 错误语义。
- 统一错误合同保留顶层数字 `code`、`msg` 和现有包络，采用模块渐进迁移。
- Prometheus 导出默认关闭并默认 loopback；管理员 MFA 初始可选，不直接锁死历史账号。
- 原思路文件作为历史来源保留，`00-v0.13版本计划书.md` 成为 v0.13 唯一执行基线。
