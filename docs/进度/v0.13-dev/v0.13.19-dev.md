## 7. 回滚方式

- 可独立删除本阶段新增的两个文档，并恢复对应导航链接；不会影响应用运行或用户数据。
- 回滚前应保留 `docs/help/README.md` 和 `docs/计划书总结/README.md` 的第一轮生命周期结论，
  否则旧文档会再次失去统一有效性入口。

## 8. 已知限制

- docs-site 当前仍是单版本站点，没有版本选择器和独立 release notes。
- Windows Docker Desktop 和 Linux `arm64` 的文字支持边界已有说明，但真实发行认证仍待对应 Runner。
- 标准 MCP、protobuf gRPC、远程插件市场和 Agent Runner 尚未实现，因此没有编写误导性的操作教程。
- 本阶段使用 `campusos-dev-nocommit`，未创建提交或标签。
