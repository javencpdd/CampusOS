## 4. 架构变化

- 未改变 v7-v12 已确立的模块化单体、Core / Built-in Feature / External Plugin / Resource Package 边界。
- 公开个人主页的呈现层现在将富文本摘要视为展示数据，而不是信任原始 HTML；该变化不影响文章正文、资源归属或存储路径。
- 响应式回归继续在真实页面上验证键盘可达性，不将无登录态加载中的短暂状态误判为页面没有可聚焦控件。

## 5. 兼容和迁移处理

- v13 数据库变更保持为追加 migration `000039` 与 `000040`；Final 验证包含其隔离 `up/down/up`，未改写任何历史 migration。
- API、资源包目录、插件 manifest 和存量用户数据保持兼容。版本同步仅扩展 `campusosctl` 新生成示例的兼容区间至 `<0.14.0`。
- 公开空间富文本摘要只改变列表/卡片的可读展示；原文章内容、原始资源文件和访问权限不发生迁移或删除。
- 生产回滚遵循 forward-fix 原则；已部署数据库不得为回退应用版本而执行 down migration。隔离环境可按迁移演练和备份恢复 Runbook 验证恢复路径。

## 7. 回滚方式

1. 运行中问题优先用兼容的前向修复发布；不得在生产环境执行 `000039` 或 `000040` 的 down migration。
2. 应用级回退前先确认目标二进制兼容已升级 schema；必要时从已验证备份恢复，再按 Runbook 冷启动。
3. 个人主页呈现异常可临时回退到默认样式包或关闭对应风格包应用，不删除用户个人空间、文章或资产。

## 8. 已知限制

- 隔离容量演练证明仓库回归预算，不能代替真实生产流量下的长期稳定性结论。
- Prometheus 规则、真实告警通知和外部 SMTP 投递需要在部署环境按对应 Runbook 配置和演练。
- Passkey、OAuth/OIDC、分布式 Session/限流、标准 MCP/gRPC、Agent Runner 和远程插件市场仍属于后续版本范围。
