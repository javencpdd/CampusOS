## 1. 目标

CI Backend Test 的 `make architecture-check` 失败：

```text
python3 skills/campusos-data-architecture-sync/scripts/check_architecture_sync.py --root .
python3: can't open file '.../skills/campusos-data-architecture-sync/scripts/check_architecture_sync.py': [Errno 2] No such file or directory
make: *** [Makefile:77: architecture-check] Error 2
```

根因：v0.13.36 将仓库 Skill 迁移到 `skills/sources/<name>/` 结构后，`Makefile` 与
`scripts/release-check.sh` 中仍有 4 处引用旧的 `skills/<name>/` 扁平路径。本阶段统一修正为
`skills/sources/` 实际路径。
