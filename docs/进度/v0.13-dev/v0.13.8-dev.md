# v0.13.8-dev - 内置风格包迁移与双端闭环

> 日期：2026-07-22  
> 阶段：A6  
> 实现状态：已完成  
> 验收状态：已验收；全包 PC/Mobile/768 浏览器矩阵和发布门禁通过

## 阶段目标

将仓库内置风格包迁移到严格双端合同，并在用户端提供按 Desktop/Mobile 切换的预览和安全的应用入口。

## 实际完成内容

- 迁移 `aurora-campus`、`campus-canvas`、`clean-blog`、`kinetic-journal`，并同步迁移内置首页包 `campus-hero`。
- 每个包新增 `delivery_contract`、desktop/mobile 预览声明和对应预览文件；`kinetic-journal` 的断点调整为与 CSS 实际规则一致的 `760px`。
- 全部 `resource.json` 使用 CLI 重新计算 checksum，兼容范围更新为 `>=0.13.0 <0.14.0`。
- 用户前台 `/appearance` 增加桌面端/移动端分段预览；主题目录只返回通过严格合同的包。
- 个人主页设置页为源码风格包提供 Desktop/Mobile 分段预览，且只展示安全声明的预览资源。
- 新增完整 Playwright 矩阵：遍历两套系统主题和两套个人主页包，在 `1440x1000`、`390x844`、`768x1024` 及 reduced-motion 下检查所有者/访客页面、水平溢出和可见控件越界；失败保存截图和 JSON 诊断。
- 更新风格包双端交付说明、Resource Package 标准、切换说明和 docs-site 教程。

## 架构变化

所有内置 Appearance 资源现在是严格 Resource Package，不存在于 `data/plugins` 或 `data/plugin_data`。预览资源由 target 专用的安全接口提供，包外路径和非声明资源不可读取。

## 兼容和迁移处理

- 旧 `preview.png` 继续保留，供历史客户端使用。
- 新目录增加双端预览但不移动包、ID 或应用配置。
- 个人主页已应用的历史样式不被删除；新选择和新导入必须通过严格合同。

可保留已生成的 `resource.json` 和资源目录，回退应用代码到兼容读取路径即可恢复旧选择界面。不得删除用户的个人主页样式或资源包数据。
