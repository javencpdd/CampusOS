环境备注：本机 /tmp 为 100MB tmpfs 且被其他桌面进程长期占满（含已删除文件的打开句柄），`docker exec` 的 runc 临时文件因此间歇失败。本 drill 将所有 PostgreSQL 交互改为一次性客户端容器（`docker run --rm --network container:...`，不触 /tmp）并以 psql 垫片承载 `migrate.sh` host 模式；这不改变被测对象，只改变执行通道。未删除任何其他应用的持久文件（仅清理过可自动重建的 node-compile-cache）。
