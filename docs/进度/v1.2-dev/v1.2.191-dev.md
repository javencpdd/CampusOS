- 声明admin UI但未安装、缺少完整有效审批、未启用当前版本或后端未就绪时，按钮禁用并显示相应原因。UI-only仍按实际合同处理，不把无后端的stopped观测误判为必须启动Runner。

- 补齐共享TypeScript `ConfigEntry`中既有manifest.ui的可选类型及生成声明。没有新增HTTP字段、接口、权限、宿主能力或插件包字节变更。
- 更新v5帮助和官网隔离UI说明，保留现有授权、运行配置和前序未提交工作；普通Admin源码由Vite热更新应用，无平台镜像重建或API重启。
