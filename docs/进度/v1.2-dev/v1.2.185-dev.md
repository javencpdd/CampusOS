- “知识检索”增加“知识来源管理”按钮，停用工作区增加返回内置功能的真实链接和刷新步骤。启用提示明确即时生效，不要求重启API；其他需重启的功能仍明确标注。

- Vue源码热加载已生效，无镜像重建。没有新增后端接口、权限种子、迁移或表结构。同步官网使用步骤、权限帮助、当前架构及主计划，保留工作区此前所有未提交改动。
