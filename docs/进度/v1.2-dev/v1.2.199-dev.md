# CampusOS v1.2.199-dev 进度说明

> 日期及最新更新时间：2026-11-14（Asia/Shanghai）
> 状态：已完成

## 1. 本次目标

修复用户打开“连接本机抓取助手”后弹窗下半部分不可达、页面无法上下滚动的问题，核实公共前端层的影响。

## 2. 完成内容

- 根因是公共 ThemeRoot `reveal` 和 Campus Canvas 入场动画使用 `animation-fill-mode: both`，结束后仍保留 `transform: translateY(0)`。该变换让内部 fixed 遮罩/滚动容器以页面区块为定位参照；Element Plus 正常锁住背景后，弹窗内容被页面区块限制。助手组件与普通长弹窗均能复现。
- 将这两处入场动画改为 `backwards`：保留入场效果，结束后释放变换；保留弹窗背景滚动锁。同步 Campus Canvas 资源包 checksum。
- 增加真实浏览器回归 `pnpm --dir web smoke:dialogs`，使用真实 ThemeRoot、Campus Canvas CSS 和 Element Plus，覆盖长内容底部可达、鼠标上下滚动、背景保持、关闭/Escape/卸载后的滚动恢复。
- 同步主题开发说明与官网风格包文档，注明入场变换不能长期改变弹窗定位及对应验证命令。
