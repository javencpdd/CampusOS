## 2. 完成内容

- `IdentityDomainPolicy` 仅按宿主提供的当前事实求值，按冻结次序判定：两域任一签名/存储字段（issuer/audience/key_id/凭据/会话/恢复/角色）相同即 `domain_not_isolated`；admin 以 user_role 来源激活即 `admin_auto_activation_forbidden`；非 active 账号拒绝；凭据五元组必须绑定目标域（`cross_domain_credential`）；挑战只能在签发域并对本人账号消费（`challenge_wrong_domain`）；生命周期操作：bootstrap 仅限受控 system 入口、已启用且无有效安全管理员，其余操作要求 admin 主体 + MFA，停用/撤销最后一位安全管理员拒绝。
- host JSON codec 限制 32 KiB/64 层，拒绝重复键（含转义同名）、未知/缺失/null 字段、尾随值、非法 UTF-8 与孤立 surrogate；字符串按 Schema 的 UTF-16 单元 1–128 计数；`recovery_store`/`role_store` 可缺省但出现即须合法；本合同无独立不支持版本码，合同字符串不符即 `domain_invalid`，错误不回显输入。
- 同数字 ID 在另一身份域是不同主体（user/admin 各自通过），接受不等于认证成功。
