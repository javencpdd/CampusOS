## 1. 本次目标

用户要求保存运行配置并重启时，可以选择重新输入管理员密码，避免必须绑定或输入MFA；保留MFA选项。

## 2. 完成内容

- “仅保存”和“保存并重启API”均先打开验证弹窗，默认管理员密码；已绑定验证器时可切换MFA验证码。弹窗说明重启影响，支持取消；错误、切换方式、关闭、提交及卸载时清理验证输入，失败保留编辑表单和当前登录。
- 密码由服务端Identity固定运行配置scope的内部Port验证，只接受当前独立Admin账号。校验账号状态、会话、当前凭据及角色权限，账号→凭据→角色事实锁序；凭据版本/摘要加入授权事实，意图审计和文件写入前再次复核，撤权/换密不能复用旧事实。
- 通用管理执行权限和MFA要求不变。密码确认只用于本次 `platform.runtime_config.manage`，不将会话升级为MFA、不签发复用票据、不修改管理员密码、全局MFA设置、其他管理操作或配置值。MFA选项复用既有本人step-up并刷新当前管理员资料。
- 保留CSRF、配置摘要冲突、闭集字段、凭据脱敏及必需意图审计。请求只增加方式枚举与仅写的当前密码字段；旧客户端未指定方式时沿用原会话策略。错误密码返回400、限速返回429，不触发401导致的退出。意图只记录方式，不含密码、验证码或凭据哈希。
- 每个Admin账号的失败密码尝试在单API进程中有界计数，5次失败后限制到一分钟窗口结束，成功清理计数；重启清空，不新增持久状态。
- 同步运行配置使用说明、管理员帮助、配置/身份边界、当前架构、计划备注、HTTP/OpenAPI和动态路由元数据。后台提示注明配置操作可用密码，避免暗示必须先绑定验证器。
- 没有新增或改写SQL迁移；current36/next37及数据库结构、端口、Docker启动合同保持。普通Go/Vue源码热加载，未重建镜像或重启Docker Engine。
