## 2. 完成内容

- 确认实际 API 已运行新宿主，但全局 RSS 仍安装 1.0.0。使用原受信开发发布者密钥签名已有 2.1.0 构建物，通过真实 Admin 会话和受管 API 完成导入、四项声明能力审批、升级；未修改信任配置或直接写库。
- 旧包因使用已退役接口而处于 quarantined。原检查点路径连同数据快照一起拒绝，导致升级返回 plugin.lifecycle_rollback_unverifiable。现在允许从 available/quarantined 来源保存受管数据：原包字节与不可变摘要必须相符，声明、配置及有界私有文件继续校验；目标仍独立通过签名、当前信任、审批和 preserve 兼容性。
- 此通用修复不恢复旧代码执行，不解除来源隔离，不继承旧 Grant/Consent。缺失、摘要不符或已 purged 的来源仍拒绝，失败保持当前安装不变。
- 管理列表原来给所有历史版本套用插件全局安装状态。现在版本不一致时显示“非当前版本（当前 2.1.0）”，启用步骤也核对当前及目标版本，避免旧条目被标成已启用或已就绪。未删除历史包。
- 原订阅配置、个人安装和用途同意各一条，升级前后完整快照及摘要一致。实际容器可读取五平台助手构建物。个人版本切换、新用途同意及客户端配对仍由本人正常完成，不代替用户授权。
