## 2. 完成内容

Object Put 的 reserve/commit 在账本更新事务内重新读取实际 quota；不存在 override 时使用配置默认值，持久化来源不可用则失败关闭。Memory 持有配额读锁直到本次账本变更结束；PostgreSQL 持有实际配额行 FOR SHARE 和 owner admission advisory lock，QuotaRepository.Upsert 加入同一锁与当前事务。一般 CurrentQuota 读取也加入当前事务，不能从 pool 读到事务外旧值。

commit 检查已用量、其他预留及本次实际字节。保存原 reserved ID，失败使用原 receipt 释放容量；不会因 Commit 返回空 Object 而遗漏原预留。不增加业务授权：调用方仍需验证当前完整 Principal 和真实资源 Policy。
