## 2. 审查发现与完成内容

- **身份隔离不足**：管理员表依赖 users/accounts，角色授予服务和数据库触发器自动开通后台；现有相关测试也验证该行为。V12-02d 改为独立 Admin 账号、凭据、Session/Refresh、MFA/恢复及角色绑定，加入双向拒绝、相同 ID/邮箱、最后管理员保护和真实 PostgreSQL 验收。
- **非侵入式生态**：明确不改宿主源码、依赖、构建物或核心 Schema，不重启宿主；以只读宿主和指纹对比证明。包/配置/Runtime/授权/贡献各自分离，配置 Schema、快照和幂等重载有独立约束。
- **参考取舍**：采用 AstrBot 的配置 schema、失败隔离、注册/绑定分离、权限代理、Provider 能力和响应事件；不采用同进程全能力 Context、DB 暴露、安装宿主依赖、同名覆盖或全局 Prompt hook。采用 WeKnora 的范围授权、独立机器入口与索引/模型版本治理，不采用其管理员等级全域放行或 RBAC 关闭时放行。
- **AI/RAG 内置**：零插件时内置 Adapter/检索可运行。插件消费 API 和贡献 Provider 两方向分别授权；首版只向插件/MCP 开放获准的公开知识范围，不把私人上下文交给任意插件。
- **宿主资源与事件**：业务 API 权限、运行资源批准、个人同意分开；Runner/Broker 实施硬限制。限定生命周期及白名单元数据事件，不暴露原始 Outbox、私密正文或 Prompt，外部故障不阻塞核心事务。
- **数据和交付**：补齐 Admin 表归属、主体类型、官方集合的平台归属、Secret 备份边界；同步 27 个阶段的依赖和 P0/P1/Final 验收分组。旧测试只是基线，目标代码未落地前均不记已验收。
