## 2. 完成内容

- Identity 新增命名 AdminSelfReadPolicy。本人资料读取绑定完整当前 Principal、实际独立账号与会话、完整角色绑定/角色/permission17 事实以及 TOTP 状态；整批投影后再次读取并复核。仅返回明确的 Admin 域、低敏账号/角色/权限码、当前强度及期限。自定义角色和零权限角色可以确认身份，业务动作继续由服务端权限判定。
- 生产 Module 绑定当前资料读取器和会话 HTTP 配置。五个本人端点使用独立 Admin JWT/当前会话守卫及固定 Operation，不继承管理他人账号/因素的权限。管理端账号生命周期路由仍保留原权限。读入口拒绝正文，本人组在身份守卫之前设置 private/no-store。
- 默认浏览器只接收内存 access JWT；refresh 写入独立 HttpOnly Cookie，另有独立可读 CSRF Cookie/header。刷新、本人退出及 MFA 的浏览器请求必须双提交校验，Cookie 请求不回退 JSON 凭据。明确启用兼容模式时，仅无浏览器信号的 CLI 可交换 JSON refresh。Cookie 有效期来自实际 refresh 期限，生产 Secure、SameSite=Lax；只清理 Admin Cookie。
- 修复 refresh 将原始凭据写入审计资源 ID，以及复用/过期/停用撤销随拒绝错误一起回滚的问题。以摘要标识资源，安全撤销先原子提交再返回拒绝；检查旋转 CAS，并按账号、会话顺序持有当前行锁。
- 本人退出绑定当前完整证明、完整会话回执与账号，执行精确 CAS 和 typed Admin 必需审计/outbox。PG 与 Memory 的完整回执统一时间表示；Memory 撤销及升阶的 UpdatedAt 与实际 PG 更新语义一致。
- 本人首次/待确认认证器允许实际密码会话；替换活跃因素必须已完成当前 MFA。确认因素、记录首个接受步、后续升阶及会话 CAS 同事务，实际会话绑定不可由调用者的 MFA 布尔值替代；确认码及已接受码禁止重放，审计/outbox 失败全部回滚。
- SPA 全部认证流程改为 Admin 域：用户名或管理员邮箱登录后读取当前身份，再进入后台；恢复和每次受保护导航均重新读取。JWT、身份及认证器 URI 不写 local/session storage。单次恢复共享执行，身份代次丢弃旧响应；只有 Me 401 可刷新一次。退出等待进行中的恢复/登录，失败仍清理本地身份和 Admin CSRF 并显示服务器退出未完成。
- 管理员认证器配置/确认/升阶直接在后台完成；一次 URI/密钥在关闭或身份变化时清除，确认后等待新码。升阶成功依实际当前身份确认，不要求服务端额外签发 JWT。原 MFA 策略页的升阶消费同步。
