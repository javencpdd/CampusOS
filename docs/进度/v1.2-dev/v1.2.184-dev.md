## 2. 完成内容

- 用SVG Chen图替换原表卡片关系通道。矩形表示实体、椭圆表示属性、主键加粗并带下划线、菱形表示联系，连接没有箭头；1/N标在靠实体端，单双线区分部分/全参与。提供全部11项符号图例与阅读说明。
- 生成132实体的标识符/字段/数组多值及143外键的引用字段、唯一性、必需性事实。读取当前36条迁移及Bash/PowerShell迁移执行器定义，核对两平台系统元数据相同；不连接数据库，不复制默认值、记录、凭据或本机路径。
- 物理外键替换旧手写基数，例如模型Profile→预算的唯一外键现在是1:1；复合标识符/唯一键不依赖字段顺序，主键字段的非空语义纳入必需性。外键只证明引用端全参与，不能自动推断被引用端全参与；无FK的已审阅模型引用继续标注、使用单线。
- 弱实体由模型单独审阅，不把所有带FK的表标成弱实体。执行事件依赖所属执行与局部ordinal，使用双矩形和双菱形标识性联系，局部标识符虚线下划线。帖子tags数组使用双椭圆；JSON对象不自动视为多值，已存储计数不冒充未存储的派生属性。派生属性只在图例解释，无依据时不添加到模型。
- 图以当前实体分组展示关联，避免132实体全挤一张图。支持领域筛选、跨域关联、实体键盘选择、前后组、缩放、适应宽度及独立SVG导出。下方详情展示完整标识符、实体类型、全部字段和迁移说明，目录与数据/文件/迁移标签保留。
