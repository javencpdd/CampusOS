# CampusOS v1.2.187-dev 进度说明

> 日期：2026-10-30（Asia/Shanghai）
> 状态：已完成

## 1. 本次目标

用户要求为普通用户制作支持RSS订阅和发布的插件，注意图文格式。本片按“个人订阅、主动读取、图文预览、导入原编辑器后手动发布”交付。

## 2. 完成内容

- 新增独立v5 UI-only包`campusos.rss-publisher` 1.0.0，原生HTML/JS/CSS，无新增npm或Go依赖。显式Node构建、入口摘要、包校验与签名安装分离；不自动改变真实部署的发布者信任、管理员批准或用户同意。
- 最多6个本人订阅地址，复用已有按owner/版本隔离的插件配置。用户主动读取最终公共HTTPS地址，预览最多20篇内容。新增有限Host能力rss.feed.read、community.article.compose及三个RSS Bridge方法，没有任意URL/头/用户身份代理。
- 支持RSS 2.0、RSS 1.0与Atom；优先content:encoded，保留标题/段落/强调/列表/引用/表格/图注和来源链接，处理Atom text/html/xhtml、xml:base、相对地址、懒加载图片和图片enclosure/thumbnail。摘要源保持摘要，不额外抓取或补写全文。
- XML有大小、深度、节点和实体限制，HTML用有界白名单规范化。相同GUID去重，条目具有稳定ID及正文修订；抓取、媒体及图文选择的前后授权/配置/条目修订复核，防止旧预览映射到新图片。
- 图片经现有安全出站Broker抓取，仅公共HTTPS、无跳转、固定请求头、无用户Cookie/Token；每图源文件1MiB、最多8图。复用User Storage尺寸检查与压缩，预览以受限Blob显示；导入时通过原认证上传接口存入当前用户空间，失败位置变为可见提示。解析HTML前移除原始img.src，不放开iframe网络或表单限制。
- 兼容真实局域网HTTP缺少crypto.randomUUID的环境：公共SDK使用原生安全UUID或getRandomValues生成v4请求号，不使用Math.random；插件命令和内存交接共用该方法，公开声明同步生成。
- 宿主确认后，以绑定当前用户会话、两分钟有效且一次性的内存ID交给原CreateThreadView。正文/凭据不进URL或持久浏览器存储；页面回填图文表单，用户选择版块并点击原发布按钮。沿用原HTML清洗、权限、配额、审核和事务审计；插件不直接发布。
- config.update接入宿主确认和本人配置事务，代理调用附X-Plugin-UI-Proof。在family锁内复核可用安装、当前Grant/Consent和主体/配置证明；撤权/旧证明不能借用户会话继续修改。原生本人配置路径保持，界面销毁/身份变化会阻止迟到交接。
- 订阅、图片与文章复用既有所有权；无新表、迁移或目录布局变化，current36/132表/143FK保持。同步HTTP/OpenAPI、Host目录、官网入口、插件教程、当前架构、主计划及本进度。保留此前未提交改动。
