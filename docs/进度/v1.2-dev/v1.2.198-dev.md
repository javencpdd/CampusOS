# CampusOS v1.2.198-dev 进度说明

> 日期：2026-11-04（Asia/Shanghai）
> 状态：已完成

## 1. 本次目标

按用户选择的“本机抓取助手”，让RSS在服务端或用户电脑之间选择实际抓取位置，保留图文预览、站内图片及原编辑器手动发布。

## 2. 完成内容

- 在受信宿主的RSS页面顶部增加读取位置及助手配对界面，默认服务端；用户下载对应平台助手，输入本站地址及单次配对码后，明确点击“使用这台电脑”。切换重建隔离frame清空旧预览，配置重载仍使用当前选择；助手失联不自动切回服务端。身份变化和迟到响应有隔离检查。
- 助手主动向CampusOS连接并长轮询任务，无本地监听端口或浏览器直连本机服务，因此兼容现有HTTP LAN开发地址及不允许CORS的RSS源。支持交互启动与`--server`/`--name`参数，读取完成后沿原路径返回服务端处理。
- 配对及任务以当前User主体、实际会话和完整插件坐标绑定，128位配对码两分钟/一次性、256位独立opaque token最多两小时；服务端只保存摘要和有界内存状态。原安装、包信任、RSS能力Grant/Consent、当前UI proof和CSRF仍需满足；token只能领取/完成本域只读任务，不能当作User/Admin JWT使用。
- 服务端按当前本人配置和精确条目修订选择URL；任务发放及结果返回前复核当前授权，助手用原Egress Broker核对公开DNS/拨号IP、HTTPS/TLS、跳转及字节限制。源站不接收平台/助手凭据。服务端继续解析清洗XML、验证/压缩图片、复用本人存储与原文章发布，不增加任意URL代理或自动发帖。
- 原RSS接口增加可选`reader_id`，由宿主加入；遗漏仍按服务端读取，隔离插件不能指定助手。新增配对/状态/断开、agent连接/轮询/结果、固定工具下载接口，并同步OpenAPI、路由授权合同及SDK固定安全提示。
- 提供`cmd/campusos-rss-reader`和`python3 scripts/build-rss-reader.py`，生成Windows x64、Linux x64/ARM64、macOS Intel/Apple芯片程序及SHA256清单。构建物在被忽略的`.campusos/tools/rss-reader/`；API只下载固定普通文件，拒绝未知平台/符号链接/超32MiB文件。当前真实3000端可下载且哈希与构建一致。
- 现有`rss-publisher@1.0.0`包、审批和个人订阅无需重导入或替换。无新DDL、设备账号或持久密钥，服务器重启/退出登录/权限失效后须重新配对；内置数据架构和整版Final状态保持。
