## 2. 完成内容

### 共享配置、Secret 和出站链

1. **v5 配置仓储**：新增 `000007` 与 `PgPluginV5ConfigStore`，配置定义取自不可变 `plugin_versions.manifest.configuration`，不重复保存定义。系统/用户快照分离，普通 `values` 和 `secret_refs` 分列，revision CAS 及同事务脱敏审计。受限选择器在保存、读取与引用绑定时重核，缺宿主事实验证器则拒绝。精确十进制验证 integer、范围与枚举，拒绝浮点舍入造成的误判；审计定位 owner ID，系统为 null。
2. **Secret 代用 Broker**：每次重核当前活跃版本、配置引用、Grant/Consent、资源交集和用途预算；批准精确包含 Secret 名、ref、Profile、完整 HTTPS URL、purpose。同 ref 跨名重绑定不继承批准。受信宿主构造固定 POST/Bearer，禁止重定向，只返回 HTTP 状态码，响应头/体不返插件。请求体上限 1 MiB，URL 上限 8 KiB；同版本在途计数约束所有用途的进程内并发。
3. **使用与扣费审计**：`plugin.secret.use` 在预留/发送前写入初始 Operation；成功、拒绝和网络未知结果记录计费信息。一次请求预留一单位，未知网络结果保守扣预留全额；无法确认结算以 null 表示，不能解读为零。审计初始写入失败禁止发网，最终写入失败返回失败并保留不确定 running 行，不能撤回已发送请求或盲重试。审计不存 Secret 名/ref/Profile/URL/请求/响应/凭据。
4. **Egress**：明确 HTTPS DNS origin、默认拒绝、逐连接 DNS 公共 IP 复核并固定拨号 IP、禁环境代理/连接复用、有界头/字节/时间/同源重定向。Secret 代用额外禁止所有重定向；IPv6 公共地址使用保守允许范围，拒绝协议、文档及非公共地址。
5. **宿主资源与用途预算**：合同/申请/宿主上限/管理员批准与部署安全上限的严格交集，当前授权撤销/到期优先拒绝；进程内预算原子预留、结算、无发送取消、未知全额扣费及撤销取消在途。Registry 绑定版本/purpose，替换预算会撤销旧预算。

### 后台轮换、全库引用与恢复

- Server 默认关闭后台 Worker，显式 `CAMPUSOS_SECRET_ROTATION_ENABLED=true` 才启用；周期默认 5m，可选 1s–24h。需 PG 和完整读 Keyring，否则拒绝启用；首次处理等一个周期。
- 每轮最多 25 插件、每插件一批最多 100 活跃行。真实 PG advisory lock 限制同时扫描，原行 CAS 防止覆盖 Put/Revoke；进程内游标跨轮推进，末尾回绕，持续坏密文不饿死更高 ID 的插件。错误插件隔离并写失败 Operation，租约/库存/审计基础设施失败停止 Worker；取消并等待先于连接池关闭。
- `campusosctl secret inspect-key --key-id ID` 只需 `DATABASE_DSN`，以只读可重复读快照跨所有插件/所有状态统计引用，不需 Keyring，不读取 Secret 名/密文/明文、不写审计。零快照不证明其他存储或备份无引用。
- 当前活跃行重封装、运维有界批量处理、后台处理、配置/Broker 审计均在拥有并自动清理的 PG16 tmpfs 库及独立恢复库演练。旧四切片复测脚本同步到 000007，保持旧明文 Host API/SDK 关闭。
