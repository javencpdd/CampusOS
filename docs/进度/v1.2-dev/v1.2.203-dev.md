## 1. 本次目标

完成 RSS 业务与宿主的解耦，普通浏览器使用不再依赖本机助手、Windows 启动器或通配域名。按用户明确的权限边界，服务器代理由管理员统一控制，用户只能控制自己主机客户端的代理，不能用个人插件配置改变服务器出站策略。

## 2. 完成内容

- RSS Publisher 2.0.0 为 runtime:none 的独立 UI 包，六个订阅字段、RSS 2.0/RSS 1.0/Atom 解析、列表及预览全部归插件。宿主不硬编码发布者/key，不包含 RSS 解析服务、工具栏、配对或专用路由。
- 通用 config.read/config.update、web.read、editor.article.import 复用当前安装、签名包、Grant/Consent、会话及 UI proof。公开读取有界且仅 HTTPS；图片经过原 User Storage 校验；原编辑器继续执行用户确认、内容清洗、本人转存及手动发布。
- 声明 isolation:opaque 的资产通过本站只读租约路径加载，iframe 与响应 CSP 双重禁止同源权限。null-origin 握手仍绑定精确 iframe/source/身份/challenge。无需额外 UI 监听或通配 DNS；既有独立子域插件继续沿用原部署方式。
- 服务器通过 CAMPUSOS_PLUGIN_WEB_PROXY_PROFILES 注册 HTTP/HTTPS CONNECT、SOCKS5 端点，由 CAMPUSOS_PLUGIN_WEB_PROXY_PROFILE 统一选定活动线路；两套 Compose 显式透传。地址、认证、启停、线路全部归管理员。用户 UI 没有代理选择，Bridge/HTTP 不接受 profile、proxy、media_profile，也不开放代理目录查询。
- 代理仅接收已复核的公网目标 IP；原站 TLS 校验不变；认证仅发给代理。不读系统代理环境，不允许 socks5h 远端解析，失败不自动直连。回环地址按 API 机器/容器解释，不修改 Windows/服务器代理、hosts 或 Clash LAN。
- 移除旧 RSS 专用 handler、字段适配、原生助手及分发脚本。2.0.0 走新签名版本、正常升级、管理员审批和本人用途同意；不篡改旧包，保留 feed_1 至 feed_6。当前 UI proof 在原配置事务锁内校验。
- 同步 SDK、Schema、Host 能力目录、OpenAPI、用户文档与更新时间。仅暂存本任务和必需的通用 UI/配置证明依赖，保留其他未提交的管理员、运行配置、文档及前端修改。
