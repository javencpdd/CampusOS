## 2. 完成内容

- `ResourcePolicy` 仅按宿主提供的当前事实求值：作者编辑，精确版块 grant 的帖子下架/回帖删除，个人文档本人读取，以及公开知识来源读取。未知动作、未知事实、缺失事实和不匹配主体全部拒绝。
- 版块治理每个 allow 由同一条 grant 完整见证，必须同时匹配主体域/ID、动作、版块、状态、到期和认证强度；不能跨 grant 拼接条件。admin 一律需要 MFA，作者/个人文档不因同 ID admin、插件代理或角色名放宽。
- host JSON codec 限制 32 KiB/64 层，拒绝重复键、未知/缺失/null、尾随值、非法 UTF-8、孤立 surrogate 和时间精度丢失。时间以精确 `int64` 毫秒处理；资源 ID/版本保留 G1 的 Unicode 合同约束。
- `CheckResourceDecision` 精确绑定初始 allow、完整 Principal、资源事实、grant 顺序和 policy 版本；时间只可前进并重算当前决策。撤销、到期、认证降级、owner/版块/状态/版本变化或伪造 allow 均失败关闭。它不替代调用方的事实读取、事务锁或 required audit 写入。
