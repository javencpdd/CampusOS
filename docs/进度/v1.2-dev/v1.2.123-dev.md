## 2. 完成内容

- **真实 Wasm Host 路径**：只允许精确签名的 `campusos.host_call`，请求严格 `{capability,payload}`，重复键、身份字段、未声明能力、其他 import 类型拒绝。单次最多32次 Host 请求、单帧/JSON 有界。父进程生成受管 envelope，经当前凭据/声明/Grant/所需 Consent/Feature/Core ACL 前后复核；正向公开线程读取接真实 Core Port，私密状态不返回 guest 输出。凭据不发送到 worker，未发布的 Secret/Egress 能力拒绝，不恢复旧接口。
- **固定 Linux worker 与硬限制**：宿主静态程序进入仅含 `/runner` 的 scratch 镜像，执行签名归档字节；只接受本地完整不可变 sha256 ID。network none、read-only、uid65534、cap-drop ALL、no-new-privileges、IPC none、无挂载/socket、有限环境、无容器日志。Docker 参数与 worker 实际 cgroup v2 文件均须通过，真实限制包含 RSS/编译分配、CPU quota、swap0、PID64；不是仅限制线性内存。
- **实例及总预算**：四方资源交集后收紧至每 worker 最多256MiB/1000 millicores/并发1/5000ms；单个独占宿主最多16 workers、1024MiB、4000 millicores，先预留再创建，超限拒绝。真实 OOM/超时/进程丢失会回收，邻居继续工作；先保存 OOMKilled 再移除。部分 init 最多5秒，空闲失联最长30秒自行退出。
- **生产协调器与当前事实**：事务内验证 preparation，事务外编译/初始化，再提交真实 Observe 与受管发布；审计回滚、过期 lease、readiness/Publish 失败关闭 worker。普通配置由独立快照传入，新代次取代旧代次；声明订阅须实现有限事件 ACK，来源仍是独立脱敏元数据队列。短期凭据按当前事实续期，取消/撤销关闭准入后终止实际进程。
- **围栏、退出与重启**：PG 会话 advisory guard 独占宿主；失锁关闭贡献/凭据并回收，已知 runtime_lost 持久失败，显式 enable/retry 恢复。新 Server 取得 guard 后清理同一数据库部署命名空间及保留名字/标签的旧 worker，再准备新代次；不同部署不互相清理。owner 重启等待同版本全局真正 ready。Stop 不与后台指针读写竞争。
- **装配与操作文档**：`CAMPUSOS_PLUGIN_WASM_IMAGE` 默认空，原生 Linux 宿主显式配置才启用；错误镜像、实际限制或 PG guard 缺失时关闭。Wasm 合同、架构、配置示例、v5操作说明和3002文档入口同步。插件仍不能提供 OCI 命令/挂载；开发 Compose 不挂 Docker socket，不变更共享开发栈。
