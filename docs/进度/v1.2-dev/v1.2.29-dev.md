## 2. 完成内容

- `BoardDelegationPolicy` 仅按宿主提供的当前事实求值：admin 主体、MFA、同主体当前有效的 `identity.role.assign` 管理权、匹配且 active 的收件人、候选版块全部存在且 active；随后每个候选 atom 必须由**同一条**当前有效、可委托的 bound 完整覆盖动作、精确版块、期限包含与认证强度（password 上限可收紧为 MFA，不可反向）。多条可覆盖 bounds 按 ASCII 字典序取稳定 witness；任一 atom 无 witness 整批拒绝，不返回部分结果。user/integration/plugin/worker/anonymous 主体、同 ID 跨域与代理身份均不能进入授予路径。
- host JSON codec 限制 32 KiB/64 层，拒绝重复键（含转义同名）、未知/缺失/null 字段、尾随值、非法 UTF-8 与孤立 surrogate。时间以精确整数 Unix 秒处理（`1e3`/`1000.000` 等等值整数可接受），拒绝小数、负数、溢出与超出 `0～253402300799` 的值。未知合同字符串优先返回 `delegation.contract_unsupported`；逆序/空窗口、重复版块或 bounds ID、重复候选 action/board 均为 `delegation.input_invalid`。
- `CheckBoardDelegationDecision` 复核提交前状态：决策必须等于对初始请求的完整重算（否则 `delegation.decision_mismatch`）；经验证的 deny 以 `DelegationDenyError` 保持原稳定原因，不误判为竞争。请求身份、facts_version、候选、actor 与凭据必须不变，时间只可前进；当前快照重算仍须以相同 witness 放行，撤权/暂停/到期/认证降级/事实变化均失败关闭（`delegation.facts_changed`）。它不替代调用方的事务内事实重载、原子授予写入与 required audit。

## 4. 验证结果

Go 使用 `TMPDIR=$PWD/.cache/v12-02a-delegation/tmp` 与 `GOCACHE=$PWD/.cache/v12-g0/go-cache`。

每条路径完成即执行定向：

```bash
go test -race ./internal/modules/core/identity/port ./internal/modules/core/identity/policy -run '^TestBoardDelegation' -count=1 -v
node scripts/check-v12-02a-board-delegation-output.mjs --verify .cache/v12-02a-delegation/cases.json .cache/v12-02a-delegation/go-output.json
```

结果：严格 codec 4 组（round-trip/歧义拒绝/时间精度/决策 codec）、判定次序与六类拒绝原因、单 witness 与 ASCII 字典序、整批原子性、21 项同次绑定与 64 并发路径通过；216 份 Go 实际输出与冻结 G1 oracle 一致（10 allow、189 deny、17 输入拒绝）。

完整 Linux 目标环境和共同门禁：

```bash
bash scripts/v12-02a-board-delegation-drill.sh
```

该命令先运行原 G1 Node/Ajv/TypeScript 合同（54 夹具、72 子集、17 复核、TS 编译用例），再生成 216 个独立 oracle 输入；构建两份 race Go 测试二进制，以 `env -i` 执行，复核真实 Go 输出，最后运行全量 Go、合同、架构、Docs 构建、文档链接、行尾和 diff 共 7 项共同门禁。所有命令通过；[原始报告](../../项目计划书v1/项目计划v1.2/evidence/v12-02a-board-delegation-linux.json)记录 12/12 必需原生测试、8 份目标日志、22 份源摘要、6 份前置报告、原生二进制、oracle 输入和实际 Go 输出摘要。

没有迁移、UI、Docker 或生产 API 改动，因此没有将数据库、浏览器、Admin/Docker 门禁伪报为本切片验收。
