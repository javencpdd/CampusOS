## 2. 完成内容

- `campusos.integration-access/v1`只接收宿主已验证的完整Principal、机器/凭据生命周期和时间窗口、当前端点描述及全部规则。绑定真实Integration ID/credential ID和integration_api用途；相同ID的User/Admin/Plugin/Worker/匿名均不继承机器权限。
- 首片允许integration_http/integration_mcp明确通道、knowledge.source.read和public_collection。当前端点必须启用、显式允许Integration，且通道/ID/动作/资源类型相符；原管理MCP不会自动成为机器入口。白名单通过之后仍需原资源所属模块实时ACL。
- 每个规则有独立状态、起止时间、资源类型/精确ID集合，必须由单条完整规则覆盖；不跨规则拼接，不解释通配符、父范围、路径或数字ID。最多64条规则、每条1–32个不同ID，空白名单拒绝；多条命中取ASCII字典序最小ID。
- 决策独立复制规则及ID数组，绑定完整请求；复核重算原判定，拒绝伪造allow/见证和任何当前事实/主体/端点变化。显式当前时钟可前进，重验凭据和规则到期；时钟回退或命中见证更换需重新判定，旧决策不借用另一规则。
- codec沿用32KiB/64层严格解析，拒绝重复/未知/缺失/null字段、尾随值、非法Unicode及不安全整数。毫秒按数学精确整数处理，最大JS安全整数；有效窗口和唯一规则ID另作关系校验。错误仅固定代码，没有原始凭据、摘要或私密内容字段。
- Schema、错误目录、SDK公开DTO和独立Node oracle一起交付，新增合同已接入make contracts-check。192个手写预期用例含144个主体/状态/凭据/通道组合；没有从Go实现提取oracle。
