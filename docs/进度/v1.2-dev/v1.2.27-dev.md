## 2. 完成内容

- **Principal Port**：六种主体按 `(kind,id)` 区分，精确校验用途、认证强度、凭据引用和代理配对；ID 为 1–128 ASCII。结构合法不等于认证成功，未增加接收 Principal JSON 的公共端点。
- **严格 codec**：32 KiB、64 层上限；版本分流前检查 UTF-8、单一对象、全层级重复键（含转义同名）与尾随值；随后拒绝未知字段、大小写别名、缺失和 null。未知字符串版本明确拒绝，错误不回显输入。
- **纯 Policy**：仅 `published ∩ clear ∩ active` 允许；作者、同 ID Admin、代理用户不放宽。零值可用，无缓存、仓储或全局资源加载器。每次返回独立决策，明确 request、策略版本、类型化资源、事实版本和复核义务。
- **决策消费**：严格绑定本次请求/资源/版本，拒绝未知/缺失义务、伪造私有资源 allow；当前事实逐字段加版本比对，状态/owner/版块变化即使版本漏推进也拒绝。真正事实加载、ABA 版本推进与读取/返回顺序仍由业务适配器承担。
- **合同同步**：两个 API 合同增加 Go 实现/证据入口，将已过期的“G1 未完成”尾注更正为历史记录，保留 G1 原始报告；主计划记录 02a 部分完成及剩余工作。
