## 1. 本次目标

处理用户选择已连接的RSS本机助手后，网页只剩“正在加载隔离插件界面”、看不到后续步骤的问题。助手终端负责等待和执行抓取任务，订阅、预览及编辑发布继续在网页中操作。

## 2. 完成内容

- 证实原 `IsolatedPluginFrame.vue` 仅在收到插件ready后启动超时；DNS/导航失败、页面未就绪或ready未到达时没有期限，能够永久停在空白加载界面。正常网络对照的真实助手全流程可运行，不能据截图单独认定助手故障或远端DNS故障。
- 用户端从iframe开始加载即计10秒连接期限，覆盖导航、ready及握手；超时或load error撤下空白iframe并关闭旧Port，显示失败原因、当前隔离Origin和“重新加载插件界面”。
- 重试创建新iframe和握手，保留宿主读取位置，不自动切回服务端；错误来源、身份变化、伪造握手仍拒绝，安全阻断不显示绕过按钮。旧iframe迟到load/error事件不影响新frame，切源和卸载清理旧期限。
- 同步UI/Bridge合同及官网连接说明，补充RSS后续流程：选择/添加订阅 → 读取最新内容 → 预览图文 → 导入编辑器核对并手动发布；助手终端不另开编辑窗口。
