## 2. 完成内容

- `000016` 新增 `threads.facts_version`。非循环 bigint 序列与 INSERT/UPDATE 触发器由存储端分配版本，覆盖 owner、版块、三维状态、删除标记、正文/标题/修订/格式/类型/标签及治理事实变化；忽略调用方伪报版本。计数与普通 `updated_at` 不推进；同事务或跨事务 ABA、回滚后分配、删除同 ID 再建均不复用。
- PostgreSQL/Memory 读取返回显式状态，取消读时旧状态补齐；写入兼容归一化仍在既有写边界。隐藏版本不进入 HTTP JSON。Memory 深快照保留版本，分配计数不随事务回滚倒退。
- 公开详情读取从权威 Thread 的同一行构造事实与正文，服务端生成本次 request ID，调用 `community.thread.public_read/v1` 并校验绑定决策；只用固定匿名/public 主体求公开谓词。Integration/Plugin 的真实主体、Scope、Grant/Consent 与运行状态仍由外层入口负责。
- `RecheckPublicThread` 同时限制 ID、期望版本、published/clear/active 与未物理删除；计浏览量时用条件 UPDATE RETURNING，非计数读取用同条件 SELECT。Memory 用同一锁执行。最终快照是本次返回的有效时点，之后撤权不能追溯收回已返回字节。
- 版本竞争最多三次重新读取、构造事实与新决策。撤权后重读返回 404，不给作者公开读取例外；持续竞争返回 409。`GetThread`、`GetPublicThread` 和 `/me` 已选中的公开分支接同一链，私有作者分支留后续。
- HTTP 保留当前响应包络与 `thread.not_found` / `resource.conflict` / `internal.error` 码；未知内部事实与存储故障为安全 500，不把 SQL 或资源内容放入错误正文。纯 Policy 目标错误码的完整 HTTP 映射仍留后续接入。
- Schema 合同要求新列、约束、非循环分配序列和启用的正确版本触发器；Admin 静态架构页、迁移 README、当前架构、onboarding 与 ER 同步到 16 条迁移、100 业务表 + 2 系统表。
