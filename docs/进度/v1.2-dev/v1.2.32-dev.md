## 2. 完成内容

- 新子包 `internal/modules/core/identity/delegation`（避免 service↔port 循环依赖）：`Service.GrantBoardDelegations` 从仓储构造 management/bounds/收件人事实、由调用方宿主模块经 `BoardFactsProvider` 提供版块事实（含事务内第二次重载）；`BoardDelegationPolicy` 判定后，在同一事务内用行锁（`ListByKindSubjectForUpdate`）重载授权事实并 `CheckBoardDelegationDecision` 复核，写入 grants + required audit + `authorization.changed` 事件原子提交；审计失败或事实变化整体回滚。
- 决策绑定：`facts_version` 是对全部判定事实（management/bound 行版本、收件人状态、版块状态）的确定性摘要；任何并发变更要么被行锁序列化，要么使版本摘要不匹配而失败关闭。
- `RevokeDelegation`（终态撤销 + 必需审计，CAS 失败返回版本冲突）、`CreateDelegationBound`（仅当前有效 management + MFA 管理员）；撤权在提交后对新评估立即可见。
- `HasActiveGovernanceGrant`/`ListActiveGrants` 读取 Port 供下一切片替换 PermissionService 读取路径；无入口 Principal 时 MFA 级 grants 失败关闭。
- 宿主默认：未显式期限的候选取 `[now, min(now+365d, 覆盖 bound 到期)]`，默认强度 password；显式值越界即 `outside_bounds`。
