## 1. 本次目标

用户要求在运行配置表单之外增加直接打开env文件的方式，修改后同步表单，核对后再保存并重启使用修改后的配置。

## 2. 完成内容

- 在运行配置页新增“打开配置文件”。通过当前管理员密码或MFA确认后读取部署者指定的同一个env文件，在文本编辑器中修改，点击“应用到运行配置”先生成页面草稿；常用表单同步，随后修改表单也会同步到文本。取消文本编辑不写文件，重新加载可放弃草稿。
- 完整文件读取单独使用管理权限、当前账号/会话/凭据复核、CSRF、文件摘要及必需审计。普通GET仍不回传凭据；完整env包含真实部署凭据，只放在当前页面内存中，不进入浏览器持久存储、日志、操作审计或Outbox。页面退出清除文本状态，验证密码每次请求后清除。
- 保存接口支持document或changes二选一；服务端校验全文256KiB上限、单行字面dotenv、重复键及原14项运行字段值域，保留文件版本冲突检查、私有0600备份及原子替换。语法失败仅提示行号，不回显输入；不执行变量插值或Shell，不接受客户端文件路径。
- 常用项之外的配置也可以写入完整文件，但不扩大API应用重启的14项加载目录。界面及响应deployment_keys指出哪些更改还需部署工具应用，恢复提示只确认常用运行项，不把端口、数据库、网络、镜像、挂载或密钥的保存冒充生效。数据库密码轮换仍需原维护流程。
- API沿用同一进程的优雅应用重启与代次/字段状态核对，未挂载Docker Socket、执行系统命令、重建镜像或重启Docker Desktop。当前标准Docker环境Go/Vue热加载已生效。
- 更新OpenAPI/路由及授权矩阵、官网操作步骤、Docker帮助、当前架构与主计划。复用已有权限，无新增迁移、表、业务数据或身份配置修改。保留此前未提交改动。
