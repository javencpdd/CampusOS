# CampusOS v1.2.208-dev 进度说明

> 日期及最新更新时间：2026-11-15（Asia/Shanghai）
> 状态：管理员插件授权期限快捷设置完成，当前后台桌面及375px交互验收通过。

## 1. 本次目标

管理员为插件授权时可直接选择永久或延长天数，减少反复操作日期控件；同时保证界面选项、后端有效期和保存后读回一致。

## 2. 完成内容

- 新增独立“授权期限”分组，显示已保存期限，提供永久、延长7/30/90/180/365天、自定义1–3650个整数天及指定截止时间。永久不再要求填写日期；原有永久授权准确读回为永久。
- 未到期的有限授权从原截止时间续上；已到期、新授权、永久改为限时授权，从保存时计算。页面预览新的截止时间，保存成功后读回实际截止日期，避免再次保存时重复累计天数。
- 自定义天数拒绝空值、非正数、小数及超限值；日期拒绝过去时间。只修改其他审批内容时，保留原截止时间的毫秒精度，不因日期控件只显示到分钟而截短。
- 后端保留 expires_at_ms=0 的可撤销永久语义，取消原30天上限；非零时间须为未来Unix毫秒时间且不晚于9999年。原角色/审批原因、CAS、必需审计、停用及显式启用、本人用途同意绑定继续适用。
- 同步安装合同、Schema说明、TypeScript DTO注释、操作说明、当前计划和最新更新时间；没有新增表、迁移、路由、插件包或权限项。
