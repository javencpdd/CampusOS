# CampusOS v1.2.205-dev 进度说明

> 日期及最新更新时间：2026-11-15（Asia/Shanghai）
> 状态：两种读取方式的开发实现与 Linux 目标运行验收完成；实际站点仍按正常部署、签名/升级与本人授权流程生效。

## 1. 本次目标

补齐上一轮遗漏的可选本机抓取，不恢复 RSS 专用宿主逻辑。服务器代理归管理员；用户只配置自己电脑上助手进程的代理。普通服务器读取免下载，本机读取按需使用独立程序。

## 2. 完成内容

- RSS Publisher 更新为不可变新版本 2.1.0，可选声明 web.local.read；通过 web.clients.status/pair/select/disconnect/download 管理读取位置。订阅、RSS/Atom 解析及预览继续位于插件包，任意发布者使用相同接口。
- 独立 cmd/campusos-web-companion 支持本机 HTTP/HTTPS CONNECT 和 SOCKS5，启动交互、--proxy 或 CAMPUSOS_COMPANION_PROXY 只配置当前助手进程。本站控制连接独立直连；代理地址、认证不会上传，服务端仅接收协议状态。
- 通用 Hub 只承载公开 HTTPS GET、短期配对与有界任务，不提供文件/命令/代理设置能力。本人真实会话、插件包、生命周期代次、Grant/Consent 逐次核验；128 位代码两分钟/一次，256 位独立令牌最多两小时，仅内存及摘要，不作为 User/Admin JWT。
- 配置保存保留有效本机连接；每个请求另固定当前 UI proof，迟到内容丢弃。安装 JSON 的 companion_generation 区分配置更新与停用/升级等生命周期变化，没有增加核心 DDL。停用后重启不能让旧令牌复活。
- 宿主确认配对、切换和下载；不会自动执行或安装程序。按本人/插件保存已确认的客户端编号，文档、预览、导入图片统一使用该客户端。失联或登录凭据轮换后保留不可用选择，不能隐式使用服务器；轮换后需重新配对或明确切换。
- 固定五平台构建脚本与登录用户下载接口，限定普通文件、受管目录和 32 MiB；SHA256 清单和响应摘要，拒绝未知平台及符号链接/文件替换。构建、运行与插件安装生命周期分开。
- 源地址在服务端预检，本机 Egress 再独立验证本机 DNS/公网拨号 IP/TLS，拒绝私网、凭据、重定向和 socks5h；单资源 1 MiB。返回内容不可信，沿用宿主图片校验和原生编辑器确认/清洗/本人存储及手动发布。
- 同步 SDK、能力目录、OpenAPI、架构/计划、环境示例、用户说明和文档更新时间，提交可复跑的专属验证夹具。
