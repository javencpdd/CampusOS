# CampusOS v1.2.202-dev 进度说明

> 日期及最新更新时间：2026-11-14（Asia/Shanghai）
> 状态：已完成实现及隔离后端/真实浏览器验证；Windows 页面刷新后的结果待实际使用反馈

## 1. 本次目标

修复用户端已登录访问 `/login` 未返回首页、短期凭据过期后突然进入登录页，以及 Windows 直连窗口匿名打开 RSS 时缺少后续界面的问题。用户已确认启动器能打开独立 Edge 窗口；该窗口首次需要登录是独立浏览器配置的正常行为。

## 2. 完成内容

- 首次导航前恢复并验证 Cookie 会话、同步插件路由；已恢复身份访问 `/login` 使用 replace 返回首页。
- 为未注册的外部插件入口提供受保护的回退路由。匿名访问先进入登录页，普通登录或 MFA 成功后返回经过同源路径校验的原目标；未安装、启用或同意的插件显示明确提示。
- 业务请求收到 `401` 后共享一次续期，通过 `/auth/me` 验证新凭据和用户身份。仅安全读请求最多自动重试一次；写请求不自动重放。
- 用登录代际保护延迟响应和排队重试，防止旧请求清除新登录，或以新账号执行旧请求。网络错误、`503` 保留本地身份；确认刷新凭据失效后，受保护页面才进入登录页。
- 同源标签页通过 BroadcastChannel 请求内存短期凭据，回复绑定当前 CSRF，且必须经后端验证。登录、MFA、注销和 Cookie 轮换使用 Web Locks；HTTP 局域网页面使用 IndexedDB 原子租约。IndexedDB 仅保存随机锁 owner 和过期时间，不保存 Token。
- 普通页面续期保留表单；外部插件在真实 Session 轮换后重新同步清单、重建隔离界面，旧 Bridge 与用途证明不跨会话复用。等待注销完成后再导航，避免路由守卫把注销中的用户送回首页。
- 更新会话合同及官网接口说明并注明更新时间。本次只涉及用户端会话；管理域保持独立实现，后端轮换、重放撤销和权限校验规则保持原样。
