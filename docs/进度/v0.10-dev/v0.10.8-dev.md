# CampusOS v0.10.8-dev：A4b 个人主页切换到内容事实源

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已在 A15 的统一门禁复验

## 阶段目标

让个人主页成为“按作者查询帖子”的视图，而不是另一份决定可见性的内容副本。

## 实际完成内容

- Space Service 接受并使用 Community `ContentQuery`。
- 访客主页使用 `ListPublicThreads`，作者自己的查看使用 `ListAuthorThreads`，非公开治理细节不泄露给其他用户。
- `user_space_contents` 保留同步、回填和回滚兼容路径，但生产装配优先使用 Community 的内容事实。
- 前端把同步设置解释为个人主页展示筛选，而不是复制帖子正文。

## 架构、兼容与迁移

- `user_space_contents` 仍是兼容投影，未删除也未把它误写成公开可见性的最终事实。
- 原有空间 API 和用户数据目录保持不变。

## 测试与构建结果

- `TestListOwnContentsUsesAuthorFactAndKeepsGovernanceDetailsPrivate` 通过。
- Public Space 的页面工作流和 Web 构建通过。

## 回滚方式

若滚动升级出现问题，可移除 ContentQuery 注入并临时读取旧投影；不会丢失帖子或个人主页数据。
