# CampusOS v0.10.12-dev：A8 统一布局能力层

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已在 A15 的统一门禁复验

## 阶段目标

以容器、方向、输入方式和密度描述可用布局，而不是用 User-Agent 或整页缩放猜测设备。

## 实际完成内容

- 新增 Web 和 Admin 的 `useLayoutCapability` composable。
- 输出 `compact-portrait`、`compact-landscape`、`regular`、`wide`，以及容器尺寸、方向、粗/细指针、hover、reduced motion 和密度。
- 使用 `ResizeObserver`、`matchMedia` 和窗口尺寸回退；不使用 `transform: scale()`。
- Extension Hub、权限页和课表等高密度页面按照 `isCompact` 切换卡片/表格或日程布局。

## 主要修改目录和文件

- `web/src/shared/layout/useLayoutCapability.ts`
- `admin/src/shared/layout/useLayoutCapability.ts`
- `web/src/modules/schedule/pages/ScheduleView.vue`
- `admin/src/modules/plugins/pages/ExtensionHubView.vue`
- `admin/src/modules/identity/pages/PermissionManageView.vue`

## 架构、兼容与迁移

- 旧媒体查询继续工作，页面按风险逐个迁移；没有全局替换样式系统。
- Dynamic UI 仍由已有 UI Contract 限制，布局能力不会让 External Plugin 注入任意 CSS/DOM 权限。

## 测试与构建结果

- Web/Admin TypeScript 构建通过。
- 七视口 Playwright 工作流覆盖 compact、regular、wide 和横屏模式。

## 回滚方式

页面可恢复原有媒体查询；该 composable 不持久化数据，也不影响 API。

## 已知限制

需要在真实辅助技术和不同浏览器上继续验证字号放大、屏幕阅读器语义和复杂表格操作。
