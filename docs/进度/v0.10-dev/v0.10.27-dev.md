## 回滚方式

- 代码、Admin/Web 和文档按同一版本回退，避免恢复双重生命周期所有者。
- 数据库在有备份的开发/隔离环境执行 `000026` down；生产优先 forward-fix。
- 文件执行 `migrate-v10-module-plugin-layout.sh rollback <backup-dir>`，冲突时停止。
- 完整实例使用 v2 联合备份；恢复后重新执行 migration、database-check 和浏览器 smoke。

## 已知限制

- 旧 Built-in 单项 API 和软删除历史插件行尚处于兼容期，需要后续版本基于调用统计弃用。
- Resource Package 的通用远程签名市场、跨实例分发和标准版本协商仍是后续工作。
- `runtime: grpc` 仍是受管进程兼容名称；标准 protobuf gRPC 和标准 MCP Server 未实现。
