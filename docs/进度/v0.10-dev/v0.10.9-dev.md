# CampusOS v0.10.9-dev：A5 API 入口与错误响应

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已在 A15 的统一门禁复验

## 阶段目标

让直接访问 `/api/v1` 和未知 API 时得到稳定、无内部泄漏的响应，而不干扰前端 fallback。

## 实际完成内容

- 新增 `GET /api/v1` 的 API Index，按 `Accept` 返回 JSON 资源索引或简洁 HTML 提示。
- 新增 API NoRoute，`/api/*` 未匹配路由继续使用统一错误 envelope 和稳定错误码。
- 修复包级 HTTP 处理器的模块所有者识别，使根入口也能通过路由合同检查。

## 主要修改目录和文件

- `internal/transport/httpapi/api_index.go`
- `internal/transport/httpapi/api_index_test.go`
- `internal/transport/httpapi/router.go`
- `internal/transport/httpapi/owned_router.go`

## 架构、兼容与迁移

- 现有业务 API 的路径和 `data` 结构不变。
- 非 API 请求不被 API NoRoute 接管，前端静态服务器仍可自行处理 fallback。

## 测试与构建结果

- `TestAPIIndexNegotiatesJSONAndHTML` 通过。
- `TestAPINoRouteUsesStructuredError` 通过。
- `make contracts-check` 通过。

## 回滚方式

移除 API Index 和 NoRoute 注册即可恢复旧根路径行为；不涉及数据库或用户数据。

## 已知限制

API Index 是入口说明，不是对 API 稳定性做长期承诺；实际字段合同仍由生成的 OpenAPI 和路由矩阵维护。
