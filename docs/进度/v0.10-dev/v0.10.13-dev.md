# CampusOS v0.10.13-dev：A9 重点页面七视口改造

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已在 A15 的统一门禁复验

## 阶段目标

在手机、平板、桌面和横屏下保持可读、可点击且没有非预期横向滚动的关键流程。

## 实际完成内容

- 课表在紧凑视口显示日程/分段信息，避免把桌面周表原样压缩或默认横向滚动。
- 修复帖子列表搜索输入在 320px 下造成页面溢出的问题。
- Admin 顶部导航、扩展清单和权限页面在紧凑布局下改用可换行标题、卡片或受控表格容器。
- 响应式工作流扩大为七个固定视口，并等待 Element Plus 加载层消失后截图和检查。

## 主要修改目录和文件

- `web/src/modules/schedule/pages/ScheduleView.vue`

## 架构、兼容与迁移

- 数据格式和原有路由不变，布局只调整同一任务在不同能力模式中的呈现。
- 桌面表格仍保留；紧凑界面不以隐藏权限/治理信息作为适配手段。
