# CampusOS v0.10.23-dev：管理端模块可发现性与官方入门路径

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

在不改变 v0.10 已封板架构和数据合同的前提下，核对“系统是否为单模块”、管理端为何不易发现课表与风格包，并修复入口和兼容投影展示问题；同时为 `localhost:3002` 建立从启动到插件开发的完整入门路径，插件教程以课表领域为例且严格遵守 Built-in Feature 与 External Plugin 边界。

## 实际完成内容

- 确认 CampusOS 是单 API 进程部署的模块化单体，不是单模块；Core Module、Built-in Feature、External Plugin 和 Resource Package 四类边界保持不变。
- Admin “扩展与集成”侧栏恢复内置功能、外观与风格包、外部插件和插件中心的直接入口。
- 新增 `/appearance` 独立页面，提供首页风格包筛查、切换、导入、回滚和示例导出，并展示系统主题实时目录与三类风格的选择主体。
- `/features` 继续只负责 Personal Space、RichText、Personal Schedule 和 Appearance 的启停、状态与配置；首页资源管理不再混放在功能状态表下。
- 修复 Extension Hub 把 `/plugins` 兼容投影误当 Feature DTO 的问题；共享映射现在稳定显示“个人课表”“界面与风格”等名称和真实状态。
- Admin “相关资料”增加完整入门路径和课表插件教程的直接外链。
- docs-site 新增 `/guide/getting-started`，覆盖环境、启动、服务验证、四类模块、Admin/Web 路径、代码目录、测试和排障。
- docs-site 新增 `/plugins/schedule-plugin-tutorial`，对照说明内置 `personal-schedule` 与外部 `schedule-helper`，覆盖 Manifest v2、受管用户记录、最小权限、CLI、打包、发布、授权、CRUD、搜索、停用语义和测试。
- 新增可运行 `examples/plugins/schedule-helper`；进程仅监听 loopback，不读取内置课表、数据库、JWT 或个人空间物理路径。
- 将课表示例和独立 Go 测试纳入 release-check，将 Admin Appearance 和两条文档深链接纳入认证浏览器工作流，将 `/appearance` 纳入七视口回归。

## 架构变化

- 没有把系统改成多个服务，也没有把内置课表改造成可卸载插件。`feature.personal-schedule` 仍依赖 Identity、User Storage 和 Feature Registry。
- Admin 信息架构现在直接暴露各管理入口，但聚合导航不改变后端生命周期所有者。
- Appearance 页面明确：首页包由管理员统一切换，系统主题由管理员提供且用户选择，个人主页风格由主页所有者选择。
- `schedule-helper` 是 External Plugin 教程示例，只使用宿主受管的 `owner: user` 集合；它与 `data/personal-space/<user>/file/schedule` 没有读写关系。
- `data/plugins` 继续只保存插件实现；风格资源继续位于 `data/resources` 或 `data/plugin_data` Legacy Resource Source。

## 兼容和迁移处理

- 无数据库 migration、表、API 或用户数据变化。
- `/features`、`/plugins`、`/plugin-center` 和 `/extensions` 原路径保持可用；新增 `/appearance` 是加法路由。
- 旧 `/plugins` Built-in 兼容投影仍保留，Admin 通过共享映射转换为稳定 Feature View，不修改服务端响应。
- 首页风格包原 API 和资源目录不变，只移动 Admin 展示职责。
- 新增 `VITE_WEB_URL` 仅用于 Admin 打开用户端主题页；未配置时继续使用 `http://localhost:3000`。
- `schedule-helper` 不自动安装、不自动发布，也不读取现有课表；删除该示例不会影响产品数据。

## 回滚方式

回退 Admin 新路由、共享 Feature 映射和 Appearance 页面，并恢复 FeatureManage 的首页包区域；回退 docs-site 导航、两篇教程、课表示例及新增测试。无需执行 migration down，不删除任何用户数据或风格包。若只回退页面，保留 `/plugins` 的服务端兼容投影不会影响旧 Admin。

## 已知限制

- Admin 不读取或修改任意用户的私有课表，这是有意的权限边界。
- Built-in Feature 管理 API 仍通过历史 `/plugins` 兼容投影读取；当前共享映射已固定 DTO 差异，后续可用加法端点替换而不删除兼容层。
- 系统主题仍由用户在本机账号上下文选择，尚无跨设备 Preference Store 同步。
- `schedule-helper` 是受管数据教程，不会同步内置个人课表；External Plugin 尚无稳定的个人课表 Host API。
- 当前 `runtime: grpc` 仍是受管进程加 loopback HTTP，不是标准 protobuf gRPC。
- Resource Package 新仓库与 Legacy style source 的物理迁移仍属于后续版本。
