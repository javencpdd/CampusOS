## 回滚方式

按阶段回退 UI/Adapter 或以 forward-fix 修正；不执行破坏性表、目录和用户数据删除。新增 migration 的 down 只用于受备份保护的开发或演练环境。

## 已知限制

- 授权审计不是所有业务写操作的跨表原子提交。
- 当前 `grpc` 进程 Runtime 的 Extension Gateway 使用 loopback HTTP 合同，不是标准 protobuf gRPC 协议。
- Legacy 资源包与 `user_space_contents` 的物理弃用需先完成长期统计、导入和恢复链路。

## 下一阶段任务
