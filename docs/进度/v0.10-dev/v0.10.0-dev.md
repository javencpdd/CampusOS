## 架构与产品语义结论

- v0.10 不重写模块化单体，继续保持 Core Module、Built-in Feature、External Plugin 和 Resource Package 边界。
- 内容治理优先解决下架后重发绕过，并以发布、审核、删除三个状态维度形成统一后端状态机。
- Community 作为帖子事实源，Personal Space 通过 `ContentQuery` 获取内容，`user_space_contents` 先比对和弃用，不立即删除。
- Admin 可以聚合扩展能力的产品入口，但不能合并 Plugin Platform、Feature Registry 和 Resource Repository 的生命周期。
- 权限 Code、Route Operation 和数据库数字 ID 分离；版块作用域由后端读取资源上下文，不能信任客户端 scope。
- v0.10 权限模型采用新增、回填、双读比对、切换和弃用期，不直接替换现有 `permissions` 表。
