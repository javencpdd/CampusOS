# CampusOS v0.10.16-dev：A10c 角色、权限矩阵与授权记录后台

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已在 A15 的统一门禁复验

## 阶段目标

给管理员一个可理解、受保护的角色与权限入口，同时不把系统角色、版主范围和审计记录混成可任意编辑的表单。

## 实际完成内容

- 新增 Admin `/permissions` 页面，按领域显示权限定义、风险、审计级别与允许作用域。
- 系统角色在矩阵中只读；自定义角色可创建并更新权限 Code，保存前显示新增/移除差异。
- 新增权限目录、角色权限和授权审计 API，保留原有用户角色分配和版主管理入口。
- 更新权限管理设计文档，说明迁移前置、三套授权体系、操作流程、版主 scope、开发规则、审计和回滚边界。

## 主要修改目录和文件

- `admin/src/modules/identity/pages/PermissionManageView.vue`
- `admin/src/modules/identity/api.ts`、`routes.ts`
- `internal/core/identity/handler/role_handler.go`
- `docs/help/系统设计相关/v0.10权限管理设计与使用入门.md`

## 架构、兼容与迁移

- 自定义角色 API 只接受稳定 Permission Code；系统角色不能通过普通 UI 改写。
- 原有用户角色与版主 scope API 保持可用，前端旧 URL 不被删除。

## 测试与构建结果

- Identity Service 负向授权测试通过。
- Admin 组件测试、构建及紧凑视口浏览器回归通过，最终证据见 `v0.10.21-dev.md`。

## 回滚方式

隐藏新的权限页不会删除 `000025` 表或角色绑定；旧角色分配接口仍可运行。

## 已知限制

当前 UI 不允许自由编辑系统角色，不提供任意 ABAC 表达式，也不提供跨租户策略引擎。
