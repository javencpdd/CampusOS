## 阶段目标

让管理员按业务任务找到用户、权限、内容治理、插件、资源与集成，而不混淆它们的后端生命周期。

## 实际完成内容

- AdminLayout 将菜单归入“用户与权限”“内容治理”“扩展与集成”“系统与运维”。
- 新增 Extension Hub，分别呈现 External Plugin、Built-in Feature、Resource Package 和用户目录摘要。
- External Plugin 列表显式排除 `runtime: builtin`；Legacy builtin manifest 仅作为兼容提醒显示。
- 新/旧页面继续独立懒加载，`/users`、`/threads`、`/plugins` 等已有路径保持可用。

## 主要修改目录和文件

- `admin/src/components/AdminLayout.vue`
- `admin/src/modules/plugins/pages/ExtensionHubView.vue`
- `admin/src/modules/plugins/routes.ts`
- `admin/src/router/index.ts`

## 架构、兼容与迁移

- Extension Hub 是只读聚合 Facade，不管理插件安装、Feature 启停或资源包生命周期。
- Built-in Feature 停用仍保留数据；External Plugin 和 Resource Package 的操作仍走各自服务。

## 测试与构建结果

- 深链接、移动导航、Extension Hub 和权限页已在七视口工作流复验。
