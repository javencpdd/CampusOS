# CampusOS v0.10.6-dev：A3c 内容治理与作者整改界面

> 日期：2026-07-16  
> 实现状态：已完成  
> 验收状态：已在 A15 的统一门禁复验

## 阶段目标

让作者、版主和管理员看到同一治理事实，但只在各自有权范围内看到原因、操作和恢复入口。

## 实际完成内容

- Admin 的帖子管理与审核页面增加待审核、下架、拒绝、回收站和治理动作查看。
- 帖子详情和个人主页的作者视图展示自己的状态和整改提示；公开访客不会获取治理原因。
- 前端把普通删除明确为进入回收站，把永久清除保留为管理员高风险操作。
- 置顶/取消置顶和状态控制继续以后端权限与状态机为准，前端只呈现可用操作。

## 主要修改目录和文件

- `admin/src/modules/community/pages/ThreadManageView.vue`
- `admin/src/modules/community/pages/AdminReviews.vue`
- `admin/src/modules/community/api.ts`
- `web/src/modules/community/pages/ThreadDetailView.vue`
- `web/src/modules/space/pages/PublicSpaceView.vue`

## 架构、兼容与迁移

- 不改变普通帖子和 RichText 的历史 URL；后端处理状态兼容，避免旧客户端绕过治理。
- UI 隐藏不是授权边界，所有操作仍由 API 中间件和 Service 二次判断。

## 测试与构建结果

- Web/Admin 组件测试和构建通过。
- 管理端与用户端页面进入七视口浏览器工作流，最终证据见 `v0.10.21-dev.md`。

## 回滚方式

可独立回退页面呈现；服务端状态机和已记录的治理证据不回退删除。

## 已知限制

管理端以桌面表格为主，紧凑视口采用横向可滚动表格或卡片；后续可为高频审核提供更专门的批处理界面。
