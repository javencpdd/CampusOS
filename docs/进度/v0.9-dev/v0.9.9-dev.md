# CampusOS v0.9.9-dev：A8 用户插件文件

> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

让用户级插件文件通过 User Storage 保存，并保持用户与插件双重隔离。

## 实际完成内容

- 文件实际写入 `data/personal-space/<user>/plugins/<plugin>/`，元数据保存在受管表。
- Upload/List/Download/Delete/Export 使用文件 ID 与受控下载端点，不返回绝对路径。
- 按 Manifest 校验 MIME、后缀、单文件大小、插件配额和核心用户配额。

## 主要修改目录和文件

- `internal/plugin/market.go`、`internal/plugin/market_handler.go`
- `internal/core/storage/` Adapter 接入
- `migrations/000021_v09_plugin_market.*`

## 架构、兼容与回滚

不移动旧个人文件；停用、下架和卸载不自动删除文件。回退应用后文件和元数据保留。

## 测试与构建结果

- 用户/插件命名空间、上传后路径和删除测试通过。
- Go 全量测试、数据库检查通过。

## 已知限制与下一阶段

Provider 仍为 Local，云 Provider 保留给后续版本。下一阶段完成授权和撤销闭环。
