## 架构变化

本阶段只冻结架构目标，没有修改运行时代码。计划确认以下目标边界：

- Plugin Platform 在 v0.8 边界上增加 Manifest v2、受管数据、文件网关、授权、目录、搜索和发布治理。
- 结构化插件数据由 CampusOS 托管，插件不能直接操作数据库。
- 用户文件通过 User Storage 保存到 `data/personal-space/<user-id>/plugins/<plugin-id>/`。
- Resource Package 继续作为无业务 Runtime 的资源，不进入普通插件市场生命周期。
- 插件市场首版是管理员治理的本地 Catalog，不是公开远程应用商店。

## 兼容和迁移处理

- 保留 `campusos.plugin/v1`，后续由 v1 Adapter 接入 v2 平台。
- 保留 Host API v1 SQLite KV 和 `data/plugin_data/<plugin-id>/plugin.db`。
- 不移动或删除现有 `data/plugins`、`data/plugin_data`、`data/resources` 和个人空间文件。
- 后续数据库迁移只追加，不修改 v0.8 及以前迁移。
- Built-in Feature 和 Resource Package 不重新归类为可卸载 External Plugin。
