# CampusOS v0.9.12-dev：A11 Admin Plugin Center

> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

让管理员在 Web 后台治理 v2 外部插件目录、申请、受管数据汇总与发布记录。

## 实际完成内容

- 新增 `/plugin-center` 管理入口、统计、目录可见性、用户请求审核和发布记录视图。
- PC 使用表格，移动端使用卡片；发布记录不允许管理员手工伪造 `verified` 签名状态。
- 后端提供 overview、catalog、request 与 release 管理路由并受插件管理权限保护。

## 主要修改目录和文件

- `admin/src/modules/plugins/pages/PluginCenterView.vue`
- `admin/src/modules/plugins/api.ts`、`routes.ts`
- `internal/plugin/market_handler.go`、`internal/transport/httpapi/router.go`

## 架构、兼容与回滚

保留旧 Admin 插件页面和 API；新页面只显示受管 v2 External Plugin，不能管理 Built-in Feature。

## 测试与构建结果

- Admin 组件测试、production build 和五视口流程通过。
- 服务端拒绝手动 `verified` 发布状态的单元测试通过。

## 已知限制与下一阶段

发布记录是本地审计/审批元数据，自动远程分批发布不在 v0.9 范围。下一阶段提供用户中心。
