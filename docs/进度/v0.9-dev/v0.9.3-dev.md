## 阶段目标

使 Web Header 与 Admin Shell 在窄屏具备明确、可访问的导航与内容布局。

## 实际完成内容

- Web 顶部操作区在窄屏换行，保持登录、发帖与个人入口可点击。
- Admin 在 `800px` 以下使用可关闭侧栏和遮罩，提供带 `aria-label` 的导航按钮。
- Admin 插件中心将表格转换为移动端卡片列表，指标和表单使用稳定的响应式网格。
