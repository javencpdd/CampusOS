# CampusOS v0.9.15-dev：A14 签名、升级与回滚

> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

确保本地插件包可进行确定性摘要、信任校验和安全的升级前检查。

## 实际完成内容

- 使用 Ed25519 对确定性包摘要签名，支持 trust store、`campusosctl plugin sign` 与篡改检测。
- 包预检识别 unsigned/untrusted/invalid/verified；`signature_required` 未验证时拒绝导入。
- 复用既有包 snapshot、冲突预检和 rollback；管理员发布记录不接受伪造 verified 状态。

## 主要修改目录和文件

- `internal/plugin/signature.go`、`internal/plugin/package.go`
- `cmd/campusosctl/main.go`
- `internal/plugin/market.go`、`docs-site/plugins/package-import.md`

## 架构、兼容与回滚

历史未签名包仍可作为本地 legacy 包导入，若 Manifest 要求签名则必须受信。升级失败可回滚代码 snapshot，受管数据保留。

## 测试与构建结果

- 签名验证与篡改负向测试通过。
- 插件包预检、Go 全量测试和 CLI 示例检查通过。

## 已知限制与下一阶段

v0.9 不实现远程自动发布或自动灰度执行；channel/rollout 仅为管理员治理记录。下一阶段执行最终一致性与恢复验收。
