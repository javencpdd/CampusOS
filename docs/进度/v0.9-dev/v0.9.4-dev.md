# CampusOS v0.9.4-dev：A3 关键页面与动态 UI 适配

> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

验证 v0.8 关键用户与管理端流程在固定五视口中的实际可用性，并让动态插件 UI 声明响应式边界。

## 实际完成内容

- 浏览器流程覆盖 Web 首页、帖子、外观、个人空间设置、课表、插件中心，以及 Admin 用户、插件、功能、架构和插件中心。
- Manifest UI 增加 `responsive`：支持视口、最小宽度、移动降级与溢出策略；校验器拒绝无效声明。

## 主要修改目录和文件

- `web/tests/responsive-workflow.mjs`
- `internal/plugin/ui_contract.go`、`internal/plugin/manifest.go`

## 架构、兼容与回滚

v1 UI Contract 保持原行为；只有 v2 插件可声明新增字段。删除新增字段不会影响现有动态 UI。

## 测试与构建结果

- 实际登录后的五视口流程通过，生成 60 张截图。
- 自动检查横向溢出、可聚焦控件、控制台错误、页面异常和失效图片/空 Canvas。

## 已知限制与下一阶段

该门禁覆盖高频代表性路由，而非把所有历史页面一次性重写。下一阶段处理首包体积与按需组件加载。
