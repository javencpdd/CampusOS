# CampusOS v0.9.14-dev：A13 声明式基础搜索

> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

提供不会跨用户、跨插件或扫描任意数据源的首版检索。

## 实际完成内容

- 新增 `/api/v1/plugin-market/search`，要求指定插件和 collection。
- 仅查询当前用户已授予、Manifest 标记为 `searchable` 的用户集合；服务端构建搜索文本并再次检查所有权。
- 不扫描 SQLite、文件、配置或其他插件集合。

## 主要修改目录和文件

- `internal/plugin/market.go`、`internal/plugin/market_pg.go`
- `internal/plugin/market_handler.go`
- `docs/api/Host-API-v2受管数据合同.md`

## 架构、兼容与回滚

搜索直接针对 Host 托管记录查询，关闭路由不影响源数据；没有引入独立索引服务或异步队列。

## 测试与构建结果

- 搜索仅返回当前用户 declared collection 的测试通过。
- Go 全量测试、contracts 检查通过。

## 已知限制与下一阶段

首版不提供全局搜索、向量检索、任意 JSONPath 或跨 Provider 查询。下一阶段收紧签名与升级记录。
