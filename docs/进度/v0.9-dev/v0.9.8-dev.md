## 阶段目标

## 实际完成内容

- 新增 Plugin Platform 所有的 `plugin_records` 受管表、PostgreSQL/Memory Store 和 Market Service。
- Host API v2 只可操作声明为 `owner: system` 的集合；用户集合只能通过当前用户 REST Gateway 操作。
- 实现字段校验、每集合限额、分页、声明字段筛选、搜索文本和乐观锁版本。
