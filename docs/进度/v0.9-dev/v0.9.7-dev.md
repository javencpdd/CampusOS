# CampusOS v0.9.7-dev：A6 Manifest 与 SDK v2

> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

在不破坏 v1 插件的前提下，建立可声明受管数据、文件、用户同意和响应式 UI 的 v2 合同。

## 实际完成内容

- Go Manifest、Go SDK、TypeScript SDK 与 Host API 增加 v2 类型和 `Record*` 契约。
- v2 仅接受 External Plugin 与 Host API v2；v1 默认保持原权限和 SQLite KV 行为。
- 新增机器可读 `plugin-manifest-v2.schema.json`、v2 示例和 CLI inspect 验证。

## 主要修改目录和文件

- `internal/plugin/manifest.go`、`internal/plugin/ui_contract.go`
- `sdk/go/`、`sdk/typescript/`
- `docs/api/plugin-manifest-v2.schema.json`、`examples/plugins/v2-managed-example/`

## 架构、兼容与回滚

v1 不会隐式得到 v2 数据/文件权限；移除 v2 插件时不影响旧包。结构 Schema 与服务端跨字段策略分层。

## 测试与构建结果

- Manifest/Host API 单元测试、Go 全量测试、TypeScript SDK build 通过。
- `campusosctl plugin inspect examples/plugins/v2-managed-example` 通过。

## 已知限制与下一阶段

JSON Schema 只做结构预检，导入仍以服务端校验为准。下一阶段实现 Host 受管记录。
