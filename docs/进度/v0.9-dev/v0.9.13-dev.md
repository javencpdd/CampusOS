# CampusOS v0.9.13-dev：A12 User Plugin Center

> 实现状态：已完成  
> 验收状态：已验收

## 阶段目标

让用户查看管理员发布的插件并管理自己的授权、数据导出和删除。

## 实际完成内容

- 新增 `/plugins`、用户菜单入口与 Catalog 列表。
- 展示权限用途、风险、数据能力，支持启用、撤销、申请、导出和删除个人插件数据。
- 移动端文字换行、按钮排列和空状态已通过实际截图确认。

## 主要修改目录和文件

- `web/src/modules/plugin-center/`
- `web/src/router/index.ts`、`web/src/campus-ui/CampusApp.vue`
- `internal/plugin/market_handler.go`

## 架构、兼容与回滚

用户只能操作已发布 v2 外部插件和自己的 Grant；不能从浏览器安装或执行宿主代码。

## 测试与构建结果

- Web 组件测试、production build、五视口登录流程通过。
- 用户数据路径继续由服务端的 owner 注入，不接受前端提交的用户 ID。

## 已知限制与下一阶段

用户中心不提供跨插件数据浏览。下一阶段实现声明式单集合搜索。
