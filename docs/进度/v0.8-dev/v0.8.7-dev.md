# v0.8.7-dev：A7 Built-in Feature 迁移

> 阶段状态：已完成，已验收
> 更新日期：2026-07-13
> 对应计划：[v0.8 现有功能架构收敛计划书](../../项目计划v8/00-v8版本计划书.md)

## 阶段目标

将 Personal Space、Controlled RichText Article 和 Personal Schedule 收敛为完整 Built-in Feature Module，Feature Store 成为启停状态唯一权威，三个功能只依赖 User Storage 与公开 Core Port，停用时保留用户数据。

## 当前完成内容

- 新增 `builtin_feature_states` 追加 migration（`000019`、`000020`）和 PostgreSQL/Memory Feature Store；状态和 JSON 配置都由 Store 持久化。
- Feature Registry 会优先读取持久化 Feature 状态与配置；只有没有记录的历史 builtin plugin 才在启动时读取一次并写入 Store。
- Feature 请求会持久化 desired/effective/pending-restart；重启型 Feature 不会被之后的 legacy Plugin 状态重新覆盖。
- Personal Space、RichText、Schedule 分别拥有 Module、Profile Adapter、Service 和 Handler；Server 不再创建这三个 Feature 的 Repository、Service、Handler 或文件存储。
- Space 改为通过 Identity User Reader 与 Community Content Gateway 工作；RichText 改为 Community Content Gateway；两项历史跨领域具体依赖已从架构 allowlist 清除。
- Plugin Platform 在启动期加载 legacy plugin 记录、启动期望插件并一次性初始化 Feature Store；Feature Module 只读取 Feature Store，不依赖 Plugin Manager。
- Admin 旧 Plugin enable/disable/config 路由对 Personal Space、RichText、Schedule 自动写入对应 Feature Store，保留旧 API 的兼容入口和重启语义。
- 已在本地 PostgreSQL 应用 `000020_builtin_feature_config`；Admin 数据架构视图同步增加权威 `config` 字段和迁移说明。
- 默认 `data/personal-space` 根目录注入 Core User Storage；旧自定义根目录仍走显式 compatibility adapter，避免移动用户文件或改变 URL。

## 架构变化

Feature 的状态和配置存储已从 Plugin Manager 分离，旧 Plugin API 仅保留为兼容投影。三个功能现由 Module Kernel 按依赖顺序启动；默认本地用户文件使用 Core User Storage 的根目录和配额，跨领域协作只走公开 Port。

## 兼容和迁移处理

- 历史 builtin plugin 状态和配置只在 Feature Store 缺少对应记录或空配置时初始化，不覆盖管理员后续选择。
- `000019` 和 `000020` 都是追加 migration；不修改历史 migration、不删除插件、Feature 用户数据或用户文件。
- 自定义旧根目录、URL、头像、文章资源与课表 JSON 不移动，仍保留现有 constructor 作为单向 compatibility path。

## 回滚方式

回滚应用可按逆序执行 `000020`、`000019` 的 down migration；生产回滚前必须备份 `builtin_feature_states`。Feature 文件数据和旧 Plugin 记录不删除。代码可回退到 legacy Store/constructor，但不得在两个状态源之间双写。

## 已知限制

- 自定义 legacy `file_root` 仍允许 Feature 创建本地 Adapter；下一切片将把它转换为 Storage compatibility adapter，而不是 Feature 自建 Provider。
- Feature 管理 UI 仍复用旧 Plugin 管理入口；A9/A13 将完成 Built-in Feature 与 External Plugin 的界面和 API 分离。
