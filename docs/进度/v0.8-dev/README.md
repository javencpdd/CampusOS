# CampusOS v0.8-dev 进度目录

本目录记录 [v0.8 计划](../../项目计划v8/00-v8版本计划书.md)各独立阶段的实现和验收证据。

## 编号

| 阶段 | 文档 |
| --- | --- |
| A0-A9 | `v0.8.0-dev.md` 至 `v0.8.9-dev.md` |
| A10-A16 | `v0.8.10-dev.md` 至 `v0.8.16-dev.md` |
| A16 后真实性审查与纠偏 | `v0.8.17-dev.md` 至 `v0.8.19-dev.md` |

只在对应阶段已经开始并有真实实现或验证结果时创建进度文档。当前仅建立目录规则，不代表 A0 已完成。

## 必填内容

每份文档必须记录：

1. 阶段目标和前置依赖。
2. 实际完成内容，区分实现状态与验收状态。
3. 主要目录和文件。
4. 架构、数据、API、路由和前端变化。
5. 兼容和迁移处理。
6. 定向测试及全量门禁结果。
7. 实际执行过的回滚或恢复证据。
8. 已知限制和下一阶段。

未运行的验证必须明确写明原因，不能记为通过。
