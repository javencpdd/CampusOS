## 阶段目标

- Web 页面迁入 identity、community、space、schedule、appearance 模块；Appearance Store 迁入模块，根级 Store 仅保留一行兼容导出。

- 数据架构同步 Skill 改为读取模块化 Admin 页面路径；31 张表、20 个 migration 与可视化定义再次同步。
- 桌面与移动端风格包流程通过，截图保存到 `/tmp/campusos-style-pack-final`。

根 Router 只聚合领域 Route；根 API/Store 只保留兼容导出。页面、API 和状态的主实现均位于所属模块。发布门禁与新目录结构同步，不再依赖历史根级页面路径。

## 兼容与迁移

Web/Admin URL、路由名称、localStorage key、权限结果和构建入口保持不变。文件移动不改变接口或数据库；旧 Store import 可通过兼容导出继续工作。
