关闭 v0.8 识别的旧业务装配主路径，使兼容入口只做单向转发，并将新增架构违规的允许清单保持为零。

## 实际完成内容

- Server 路由和业务装配 allowlist 清空；后端架构检查报告 0 个 legacy source、0 条 concrete edge。
- Server 目录不再出现业务路由注册或领域 Service/Handler 创建；Profile 只绑定 Adapter，Module 拥有业务装配。
- Built-in Feature 目录未发现对 Plugin Manager 的直接依赖；Plugin 子服务反向 Manager 引用继续受检查器阻止。
- Web/Admin 根 API 与历史 Store 路径均为小型兼容转发；新增检查阻止业务代码重新从 `@/api` 导入。
- 新增可执行前端构建体积预算，并将其加入发布检查。
