# v0.8.11-dev：A11 Composition Root 与 HTTP 合同收口

> 阶段状态：已完成，已验收
> 更新日期：2026-07-13
> 对应计划：[v0.8 现有功能架构收敛计划书](../../项目计划v8/00-v8版本计划书.md)

## 阶段目标

移除 Server 的具体 Gin 路由注册和大型 Handler 参数装配，使 HTTP Transport 成为唯一的路由和合同源码，并在生成合同前使用 Route Registry 验证路由元数据。

## 实际完成内容

- 新增 `internal/transport/httpapi`，承接模块已发布的 Handler、权限 Port、Feature Gate 和 `/api/v1` 路由注册。
- `internal/server/application.go` 只获取 Module Port、构建 Transport 依赖并启动 HTTP；不再注册业务路由或创建业务 Handler。
- `cmd/campusos-contracts`、路由测试和 API 文档生成改为读取 `internal/transport/httpapi/router.go`。
- `projectaudit` 在生成合同前将 148 条来源路由注册到 Platform Route Registry，校验 method/path 冲突、认证受众、管理员权限和 Feature 标记。
- 移除 Server 路由/业务装配 allowlist；架构检查维持 0 个例外。

## 主要修改

- `internal/transport/httpapi/router.go`
- `internal/server/application.go`

## 兼容与回滚

HTTP method、path、JWT、权限中间件、Feature Gate 和响应 Handler 均未改变。回滚时可将 Server 调用切回上一版应用入口；路由合同、数据库和用户数据无需迁移或清理。
