# v0.8.12-dev：A12 Web 前端领域化

> 阶段状态：已完成，已验收
> 更新日期：2026-07-13
> 对应计划：[v0.8 现有功能架构收敛计划书](../../项目计划v8/00-v8版本计划书.md)

## 阶段目标

消除 Web 端集中 API 和集中路由作为业务实现入口的问题，使领域模块拥有请求、路由和关键状态，同时不改变已有页面 URL、Token 存储或插件 UI 行为。

## 实际完成内容

- 新增共享 HTTP Client，并按 `identity`、`community`、`richtext`、`schedule`、`space`、`appearance`、`plugin-runtime`、`platform` 拆分 API。
- 根 `api/index.ts` 缩为兼容导出；现有页面、Store 和 Campus UI 已直接引用所属领域 API。
- 路由拆为 Identity、Community、Space Route 集合，根 Router 仅聚合集合与认证守卫。
- Identity Store、Plugin Runtime Store 迁入领域模块；历史 Store 路径只保留转发出口，供旧扩展继续导入。
- 前端边界检查新增根 API 禁用规则和根 API/Router 行数上限，阻止新的集中式入口回流。

## 主要修改

- `web/src/shared/api/client.ts`
- `web/src/modules/*/{api,routes,store}.ts`
- `web/src/api/index.ts`
- `web/src/router/index.ts`
- `web/src/stores/{user,uiRuntime}.ts`
- `scripts/check-frontend-boundaries.py`

## 兼容与回滚

`@/api`、`@/stores/user` 与 `@/stores/uiRuntime` 保留为无状态兼容 Facade；既有 URL、localStorage key、鉴权跳转、主题和插件运行时协议不变。回滚只需恢复 Facade 的旧实现，不涉及浏览器持久化数据。
