# v1.0.3-dev：插件三层授权主链与 v3 工具链

> 更新时间：2026-09-11  
> 状态：代码实现完成，目标环境发布证据待收集；未提交

## 本轮交付

- 建立 `campusos.capability/v1` Catalog、Manifest v3、Host API v3、`AuthorizationService` 与 PostgreSQL/内存存储适配器。
- 管理员逐能力 Grant、用户逐能力 Consent、短期 Delegation、稳定拒绝码、低敏判定审计和即时撤销。
- Host API 方法默认拒绝；`GetUser` 移除邮箱并新增独立 `GetUserContact`；事件统一为 `campusos.event/v1`。
- v3 受管记录/文件/搜索接入统一授权；旧 v1/v2 保留兼容 Grant。
- AES-256-GCM Plugin Secret Store、掩码 API、轮换/撤销、Docker 跨平台密钥配置。
- `runtime: process` 合同与启动握手；历史 `grpc` 作为兼容别名。
- CLI 增加 `doctor/watch/conformance`，Go/TypeScript SDK 增加 v3 类型，新增三个可构建参考插件。
- Admin 增加逐项授权与判定诊断；Web 增加用户精细授权。
- Admin 增加系统 Secret 保存/轮换/撤销；Web 增加个人 Secret 与一次显示的 15 分钟后台委托操作台。
- 新增 Capability 机器合同及 drift check，补充威胁模型、ADR 和开发指南。
- 修正 Secret 当前版本唯一索引，使轮换后的历史密文不阻塞新值；授权判定表不再外键依赖声明表，从而可以留存“未声明能力”拒绝证据。ER 合同随之更新为 84 表、93 条物理外键。
- 新增 `000005`，使数据库 Runtime 约束接受 Manifest v3 `process`，并保留 `grpc` 兼容回滚。
- 修复开发启动回归：同版本插件包摘要/能力指纹冲突时隔离该插件并提示提升版本，不再导致整个 API 启动失败；授权事实同步在插件启动前完成。
- ER 解析器支持后续 migration 的 `DROP CONSTRAINT` 与同名外键替换，避免把已删除外键计入当前图。
