# CampusOS v1.0.2-dev migration ER 图生成工具进度说明

> 日期：2026-09-10
> 更新时间：2026-09-10 21:17:00 +08:00
> 状态：已完成
> 提交状态：未提交、未推送

## 1. 本次目标

提供一个跨平台、只读扫描 `migrations/**/*.up.sql` 的 ER 图生成工具，从同一个解析模型输出 PNG、SVG 和中文
Markdown，准确说明实体字段、物理外键、关联类型、可空性、唯一性及引用动作，并能检测生成物漂移。

## 2. 完成内容

- 解析 `CREATE TABLE`、表内/字段级 `PRIMARY KEY`、`UNIQUE`、`REFERENCES`，以及单动作和多动作
  `ALTER TABLE ... ADD CONSTRAINT`。
- 只根据显式外键生成物理边；一对一只接受外键列同时属于全局 PK/UQ 的证据，部分唯一索引不被夸大为全局一对一。
- 生成 5024×3388 PNG、同尺寸可缩放 SVG 和 1777 行中文说明；当前模型覆盖 84 张业务表、94 条物理外键、4 条逻辑多对多。
- PNG/SVG/Markdown 写入同一个 migration SHA-256；`--check` 还会重新计算当前解析器的 SVG/Markdown 内容，防止解析器升级后旧产物误通过。
- Windows PowerShell 与 Linux/WSL2/Git Bash 均有包装入口；Git Bash 会避开不可执行的 WindowsApps Python 别名。
- Makefile 新增 `database-er`、`database-er-check`，并把 ER 漂移检查纳入 `architecture-check`。
- 修正数据库文档中旧的 97 外键统计为当前 migration 可复核的 94 条物理外键，并补充架构索引与生成入口。
