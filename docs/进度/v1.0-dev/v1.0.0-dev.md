## 3. 关键决策

1. v1.0 不从零重建插件平台；复用 v0.9/v0.10 的 Manifest v2、本地目录、用户 Grant、受管数据、签名预检和平台权限边界。
2. 有效权限采用 Declaration ∩ Admin Grant ∩ User Consent（按需）∩ Version/Scope/State/System Policy。
3. 新合同目标为 Manifest v3、Host API v3 和 `campusos.process/v1`；历史 `runtime: grpc` 明确为 loopback HTTP 进程兼容名，不宣称真实 protobuf gRPC。
4. migration 从 `000050` 起追加，保留 `000001-000049`；即使当前数据是测试数据，也同时保留 legacy fixture 升级证据。
5. 项目所有者允许测试数据重置，但只能在 development/test 精确目标、dry-run 和显式 apply 门禁下执行；本次没有重置或删除数据。
6. v1.0 目前只有计划和设计文档，未开始代码实施，不能宣称任何 v1.0 功能已上线。
