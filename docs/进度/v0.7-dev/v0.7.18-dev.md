# CampusOS v0.7.18-dev 架构完成度复核

> 日期：2026-07-12
>
> 状态：已验收

## 1. 阶段目标

不依赖既有“已完成”标记，重新核对 v0.7 架构代码是否真正接线；补齐仅有接口或兼容声明、但缺少运行时所有权的部分。

## 2. 实际完成内容

- Database 连接、fallback 状态和 Close 迁入基础设施 Bootstrap。
- 新增 Identity/Community 模块 assembly；Identity、Community、Plugin、Storage Port 增加 Repository/Manager Adapter 并注册 AppContext。
- Moderation 增加 Settings Adapter，安全 Core 始终启用，legacy 配置只控制治理动作。
- Feature restart 状态改为启动时快照；新增静态 PathGate，避免动态增删 Gin 路由。
- RichText、Schedule 实际持有 User Storage Port；Space 共享 helper 委托 Core Adapter；LocalAdapter 实现配额 Port。
- PluginCatalog、RuntimeRegistry、UIRegistry、EventRegistry、AuditLogService 获得对应状态所有权；Lifecycle/Config 公开方法实际委托子服务。
- Resource Package 增加完整字段、内容 checksum、去重、路径逃逸、符号链接和 Runtime artifact 检查。
- 新增 v0.7 回顾和后续规划文档。

## 3. 主要修改目录和文件

- `internal/server/bootstrap.go`、`module_assembly.go`、`application.go`
- `internal/core/storage`、`internal/*/port`
- `internal/platform/feature`、`internal/platform/resource`
- `internal/moderation`、`internal/plugin`、`internal/appearance`
- `docs/项目计划v0.7/01-v0.7版本回顾与后续规划.md`

## 4. 架构变化

Core 边界、公开 Port、Feature Gate、Plugin 子服务和 Resource 安全合同从“类型存在”提升为“运行时已接线并持有状态”。系统继续保持单进程模块化单体。

## 5. 兼容和迁移处理

HTTP 仍为 148 条，OpenAPI、路由 JSON 和权限合同 checksum 未变；migration 仍为 18 个；个人文件、风格包和 9 个 legacy Manifest 未移动或删除。

## 6. 测试与构建结果

`RUN_RESTORE_DRILL=true RUN_BROWSER_SMOKE=true GOCACHE=/tmp/campusos-go-cache make release-check` 通过：

- 完整 release-check 时 104 个本地文档链接通过；新增回顾与进度入口后单独复验 `make docs-links` 为 109 个；8 个有说明的架构 allowlist 通过。
- 全量 Go、database/schema/architecture、三 Runtime 模板通过。
- Web lint/format/build、Admin、docs-site、TypeScript SDK 通过。
- 隔离恢复、业务浏览器流程和 PC/移动端风格包流程通过。

## 7. 回滚方式

各项仍保留旧 Manager API、legacy feature 状态、Space helper 和 Legacy Resource Source。回滚只切换 Adapter/Facade，不执行 migration down 或数据删除。

## 8. 已知限制

8 个 allowlist、legacy builtin 兼容视图、Appearance 旧入口逐步迁移和完整 Agent 产品均保留为后续工作；它们在回顾文档中按兼容债务或 v0.8 范围分类。

## 9. 下一阶段任务

v0.7 不再扩展新功能。后续依据 [v0.7 回顾与后续规划](../../项目计划v0.7/01-v0.7版本回顾与后续规划.md)进入稳定维护或独立 v0.8 计划。
