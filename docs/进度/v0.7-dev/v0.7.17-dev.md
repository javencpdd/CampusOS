# CampusOS v0.7.17-dev 最终验收说明

> 日期：2026-07-12
>
> 阶段：Final 全链路验收
>
> 状态：已验收，发布语义 `v0.7.0`

## 1. 阶段目标

验证 A0-A8、B1a-B2 的实现、兼容、恢复和文档证据，确认 v0.7 可以结束开发阶段。

## 2. 实际完成内容

- `server.go` 只保留稳定 Server/Run 外观；基础设施和业务 composition root 分离。
- 四类能力有代码合同；Core 和 Feature 使用独立 Registry。
- Moderation 安全策略始终启用，动作开关保持可配置。
- User Storage Core 拥有安全路径和标准布局，RichText、Schedule、Space 通过 Core 能力工作。
- Resource Repository、Legacy Source 和 Appearance Facade 可并行兼容旧风格包。
- Plugin Manager 保留 API Facade，Catalog、Runtime、Lifecycle、Config、UI、Event、Audit 已有独立委托服务。
- Agent/Runner/Knowledge/MCP/Secret 只交付合同和默认拒绝策略，未开放代码执行。

## 3. 主要修改目录和文件

`internal/platform`、`internal/core/storage`、`internal/appearance`、`internal/plugin`、`internal/agentcontract`、`internal/server`、`scripts`、`config`、`data/resources`、`docs`。

## 4. 架构变化

CampusOS 保持模块化单体。新增边界没有引入微服务、反射 DI 或全局 Service Locator；External Plugin 和 Agent Runner 不能获得 AppContext。

## 5. 兼容和迁移处理

- HTTP 路由仍为 148 条；路由 JSON、OpenAPI 和权限合同 checksum 与 A0.5 基线一致。
- migration 仍为 18 个，没有改写数据库或搬迁用户文件。
- 9 个 legacy Plugin Manifest 和三种 Runtime 模板继续可用。
- `data/plugin_data/*/style-packs` 保留为 Legacy Source；`data/resources` 是加法目录。

## 6. 测试与构建结果

`RUN_RESTORE_DRILL=true RUN_BROWSER_SMOKE=true GOCACHE=/tmp/campusos-go-cache make release-check` 通过，包括：

- contracts、104 个本地文档链接、架构边界、全量 Go 测试。
- 18 个 migration、14 项零违规数据体检、30 张表架构同步和 schema contract。
- builtin、gRPC、Wasm 模板。
- Web lint/format/build、Admin、docs-site、TypeScript SDK build。
- Shell 语法、`git diff --check`、隔离恢复。
- 用户/管理业务浏览器流程和 PC/移动端风格包流程。

## 7. 回滚方式

按阶段使用旧 Bootstrap、Space helper、Legacy Resource Source 或 Manager 原方法恢复；本轮无新增 migration，不需要数据库 down，也不得删除 Feature 数据。

## 8. 已知限制

- 架构检查器仍记录 8 个有说明的历史 Repository 例外，其中两个是允许具体 Repository 装配的 Server composition root。
- Plugin 子服务使用兼容委托，旧 builtin 运行记录尚未从 Manager 物理删除。
- Appearance Facade 首版保留旧实现 Adapter；Agent 不具备任务或代码执行能力。
- Web/Admin 构建仍有既存大 chunk 告警。

## 9. 下一阶段任务

v0.7 计划内任务结束。后续只按缺陷或独立 v8 计划移除 allowlist、兼容 Adapter，并在安全隔离完成后评估 Agent 产品能力。
