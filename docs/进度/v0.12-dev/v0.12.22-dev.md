# CampusOS v0.12.22-dev QQ/Foxmail SMTP 配置示例说明

> 日期：2026-07-19
> 状态：已完成

## 1. 本次目标

补充 QQ 邮箱与 Foxmail 地址作为 CampusOS SMTP Provider 的可执行配置示例，解释为什么验证码接口返回
成功但使用 Fake Provider 时不会收到真实邮件，同时避免把真实授权码或个人邮箱写进版本库。

## 2. 完成内容

- 在邮件投递帮助文档中增加 QQ/Foxmail 配置步骤，明确使用 `smtp.qq.com:587` 与 STARTTLS。
- 给出只含占位符的 `.env` 示例，说明用户名、发件人、授权码、文件权限和服务重启方式。
- 明确当前 CampusOS SMTP Adapter 不支持 465 隐式 TLS，并补充 `535`、STARTTLS、`501`、`retry`、
  `published` 但未收件等常见问题。
- 说明 Fake Provider 已完成的旧事件不会在切换 SMTP 后补发，必须重新创建 Challenge，且不得通过清空
  限流数据规避等待窗口。
- 同步 docs-site 邮件部署页面；所有示例均未使用用户提供的真实邮箱或授权码。
