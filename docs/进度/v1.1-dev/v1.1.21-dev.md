## 2. 完成内容

1. 新增 `internal/plugin/v4`：只接受 `campusos.plugin/v4`，校验稳定 key、SemVer、发布者、UI/Bridge 版本、受限 Runtime、
   包内相对路径、Audience/Surface、PDF Preview Provider、`self` Capability、宿主 Capability Catalog、配置文件和用户配置 256 KiB 上限。
2. 新增 `campusos.bridge/v1` 静态消息校验：仅预留受限的配置、资源、具名后端、界面和记录方法；拒绝未知方法、无效请求、
   超过 64 KiB 的消息及超过 1 MiB 的 Range。此处不做授权，后续 Host Gateway 仍必须重做身份、安装、Grant、Consent 和业务 ACL。
3. 新增受限 JSON Schema 校验：只接受固定的 JSON Schema vocabulary，不接受远程 `$ref`、执行器或未知关键字；默认值保持普通 JSON，不作为授权事实。
4. 建立 `plugins/` 源码根、`.installed/.staging` 忽略规则及 `campusos.pdf-viewer` 的**声明和配置骨架**。PDF 现有 Web 页面未移动、未删除、未运行该骨架。
5. 新增 `campusos-plugin-v4-check` 和 `make plugin-v4-check`；`make contracts-check` 现会先检查 v4 源码包。
6. 新增 ADR，明确独立 Origin iframe、Bridge、用户配置和 Runtime 的信任边界与后续验收门禁；同步计划、架构与文档入口状态。
