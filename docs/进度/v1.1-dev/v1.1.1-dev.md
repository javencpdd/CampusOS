## 1. 本次目标

根据项目所有者确认的业务边界，将 v1.1 从“全面个人资产与多媒体/分享”收敛为图文文章附件、第一方 PDF
预览插件和支撑该插件的宿主管理 Plugin UI v2，同时保持未来扩展空间。

## 2. 完成内容

- 明确图片继续用于封面和正文排版；PDF、MP3/MP4、DOC/DOCX、XLS/XLSX、ZIP/RAR 只作为附件。
- `.exe`、脚本和其他主动内容默认拒绝；本版只在线预览 PDF，其他允许附件采用认证下载。
- 将数据库范围缩小为最小 User Asset、`richtext_article_attachments` 和按需 Invocation 记录，不要求一次迁移全部个人数据。
- 附件使用显式 Binding，不写入 HTML；访问继承文章草稿、私密、发布、下架和删除状态。
- 规划向后兼容的 `campusos.ui/v2`，由宿主管理 `open-surface`、modal/drawer/fullscreen/new-tab 和短期 Invocation。
- 第一方 PDF Viewer 使用编译期 `trusted-module`；真正第三方 UI Bundle 的 sandbox-iframe/CSP/签名/Bridge 顺延。
- 将原 10 周大范围计划调整为聚焦的 8 周计划，重新编排 WBS、关键路径、风险和 Final 门禁。
