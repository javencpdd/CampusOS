## 1. 本次目标

修正帖子、评论与结构化帖子将用户名误作作者对外名称的问题，并统一注册、个人主页和管理端对用户名与昵称职责的说明。

## 2. 完成内容

1. Access JWT 增加昵称展示快照；经过 Session 校验的请求会用 Identity 当前昵称刷新该展示值。用户名仍是唯一识别与个人主页路径依据，未参与授权决策。
2. 普通帖子、评论、图文文章、校园互助和校园二手的新建操作均优先将昵称写入 `author_name`；旧令牌和独立测试调用没有昵称时兼容回退到用户名。
3. `author_id` 继续作为所有权、审核与权限的唯一依据；`author_name` 明确为创建时的显示快照。既有测试数据不会被自动批量改写。
4. 注册页、个人主页配置、用户管理、版主管理和管理员准入页面统一说明：邮箱登录、用户名唯一且不可修改、昵称用于对外显示。
5. 同步更新身份与社区架构说明、账号使用说明，并补充昵称优先与服务端刷新测试。
