# CampusOS v0.6.5-dev 进度：契约、数据库与插件工具链

> 日期：2026-07-11
> 状态：已完成

## 已完成

| 范围 | 结果 |
| --- | --- |
| HTTP 契约 | `campusos-contracts` 从 `server.go` 提取 141 条路由，生成 current OpenAPI、JSON 清单和授权矩阵；管理路由缺少显式权限时失败。 |
| 权限收口 | `000017` 将插件、富文本、AI、集成、metrics、空间、Webhook、MCP、Message、平台日志和首页配置从历史 `role:manage` 拆出；锁帖改用 `thread:lock`。 |
| 数据库 | `000016` 增加稳定关系 FK、状态/计数 CHECK 和关键索引；数据体检 14 项零违规，schema contract 通过。 |
| Manifest | 增加 `campusos.plugin/v1`、Host API `v1`、capabilities 和 compatibility，旧包按 v1 兼容读取。 |
| Host API | 权限目录可生成；运行插件使用随机 Host token，重载轮换、停止撤销、30 天过期，名称不能单独认证。 |
| SDK | Go SDK v0.6 增加类型化权限错误、timeout、通知模拟、失败注入和事件模拟。 |
| CLI | `build/test/verify/dev` 可用并支持 JSON；verify 检查权限目录和 Runtime 产物。 |
| 模板 | `examples/plugins/` 提供 Built-in、gRPC process、Wasm 三类可测试、打包、预检模板。 |
