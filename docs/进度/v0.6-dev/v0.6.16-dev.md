# CampusOS v0.6.16-dev 进度说明

> 日期：2026-07-12  
> 状态：已完成（WP6）

## 1. 目标
提供当前主体可见 UI Runtime Manifest，并用 SSE revision 驱动可靠重同步。

## 2. 实际完成与核心设计
- `GET /api/v1/ui/runtime-manifest` 返回 contract、revision、插件生命周期和 UI 贡献；可选 JWT 只用于后端过滤权限 Action。
- `GET /api/v1/ui/events` 只广播 revision 和 keepalive，不泄漏 manifest。
- Web 忽略旧 revision，断线 3 秒重连，并始终用普通 API 请求获取完整合同。

## 3. 修改文件
`internal/plugin/runtime_http.go`、`manager.go`、`internal/server/server.go`、`web/src/stores/uiRuntime.ts`、`web/src/api/index.ts`。

## 4. API / 数据库 / 兼容
revision 单调递增并写入 `plugins.ui_revision`；SSE 失效时页面保留最近有效 snapshot。

## 5. 测试
`go test ./internal/plugin ./internal/server -count=1` 与 Web build：通过。

## 6. 已知限制与后续
当前为单 Core 进程内 revision；多实例部署需要 Redis/NATS 广播和全局单调 revision。
