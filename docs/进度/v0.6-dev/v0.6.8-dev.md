## 继续保留的边界

1. 字段级 OpenAPI schema 未齐全的路由仍为 experimental，不宣称 stable。
2. 标准 MCP Server、真实 Discord/OneBot adapter 和公开插件市场属于 P2。
3. 插件签名尚未强制；当前依赖 checksum、来源记录、风险预检和管理员确认。
4. 生产高可用、零停机升级和跨节点恢复不属于 v0.6 单节点开发基线。
