# CampusOS v0.6.23-dev 风格包双端与可配置能力审查

> 日期：2026-07-12  
> 状态：已完成  
> 范围：系统/个人风格包数据边界、PC/移动端、文字对比度与用户参数配置

## 1. 审查结论

`v0.6.22-dev` 的 WP0-WP11 架构主线和发布门禁已完成，但按本次新增验收条件复查时发现四项缺口：旧 `space-style.v1` JSON 仍在插件实现目录；风格包没有统一双端声明；`config.schema.json` 尚未接入用户运行时配置；Aurora 图片背景上的说明文字缺少稳定内容表面。以上问题均已修复。

## 2. 完成内容

| 项目 | 结果 |
| --- | --- |
| 数据边界 | 4 个个人主页 JSON 风格从 `data/plugins/personal-space/styles/` 迁到 `data/plugin_data/personal-space/styles/`；插件目录只保留 manifest、实现和说明。 |
| 双端标准 | manifest 新增 `viewport_support`；v2 强制 PC/移动端均为 true 且 CSS 包含宽度媒体查询；全部内置目录包完成声明和响应式规则。 |
| 对比度 | 后端对 `text_color`/`color.text` 与页面、表面背景执行 4.5:1 检查；低对比度包不能通过筛查。 |
| 动态配置 | Runtime Package 返回筛查后的 `config_schema`；`/appearance` 为当前主题生成颜色、枚举、数值和开关控件。 |
| 用户覆盖 | 配置通过 `x-campusos-binding` 绑定到已声明 token 或受控 layout 字段，按用户和主题保存在浏览器本地，可恢复包默认值。 |
| 背景资源 | 用户可从风格包声明的背景资源中选择或关闭背景图；schema 不能引用未声明图片。 |
| Aurora 可读性 | 标题区和卡片使用高不透明内容表面，正文使用主题文字 token，移动端收紧边距并增强 Header 背景，Footer 在图片上使用高对比文字。 |
| 个人主页 | `space-style.v1` 增加主要/辅助文字 token；公开主页不再硬编码正文色，并继续保持移动端单列。 |

## 5. 兼容说明

- 旧 `page-style-pack.v1` 缺少 `viewport_support` 时只产生兼容警告；`campusos.app-style-pack.v2` 按新规则严格拒绝。
- 旧风格包没有 `x-campusos-binding` 时仍可应用，其 schema 字段只作为说明，不会获得任意 CSS/路径写入能力。
- 用户设置只覆盖已声明 token 和布局字段，不允许插入 CSS、任意 URL 或未声明资源。
- `web-theme` 系统插件启停仍需重启 API；用户切换主题和修改主题参数继续热生效。
