# CampusOS v0.6.3-dev 进度说明

> 日期：2026-07-11
> 状态：已完成

## 1. 本次目标

1. 将管理端原有的大段内嵌教程收口为“相关资料”入口。
2. 提供独立、可构建、可部署且便于后续迁移的官方文档前端。
3. 参考仓库 `docs/help` 的现有实现说明，覆盖项目介绍、开发部署、接口边界、插件编写和插件包导入。
4. 将文档服务纳入本地开发脚本、环境变量、Makefile 和项目状态文档。

## 2. 完成内容

### 2.1 独立官方文档前端

- 新增 `docs-site/` VitePress 项目，不依赖 CampusOS 业务 API，可独立开发、构建和静态部署。
- 建立项目指南、安装部署、HTTP API、插件开发和数据目录五组导航。
- 文档覆盖项目定位与边界、运行架构、开发环境、配置和发布、认证与社区 API、版主管理 API、插件 Runtime、Manifest、配置 Schema、打包导入、生命周期和数据存储。
- 启用本地全文搜索、明暗主题、响应式导航、GitHub 入口和当前管理端实机截图。

### 2.2 管理端资料入口

- 将管理端“说明文档”调整为“相关资料”，不再在管理端重复维护教程正文。
- 提供官方文档和 GitHub 仓库两个外部入口，并使用新标签页安全打开。
- 支持通过 `VITE_DOCS_URL` 和 `VITE_GITHUB_URL` 配置部署后的真实地址。

### 2.3 开发与文档同步

- `make dev-all` 现在同时启动 API、用户端、管理端和文档站，默认文档地址为 `http://localhost:3002`。
- 新增 `make docs-dev`、`make docs-build`，并通过 `DOCS_PORT` 配置开发端口。
- 文档服务日志写入 `.campusos/logs/docs.log`。
- 更新根 README、文档门户、开发指南、架构概览、API 索引、v6 计划和项目 onboarding 状态。
- 明确 `docs-site/` 面向使用者和插件开发者，`docs/` 继续保存内部设计、计划、进度与维护资料。
