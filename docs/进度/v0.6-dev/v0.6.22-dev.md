## 3. 核心设计

Core 拥有 App Shell、鉴权、Gateway、UI Contract、动态注册、隔离、兼容和回退；插件拥有业务和默认 UI；风格包只拥有受控布局与视觉。运行时回退保持“兼容 override -> layout recipe -> 插件 renderer -> Core generic -> incompatible surface”。

## 8. 审查修复

最终审查修复了 SSE 导致旧 `networkidle/dump-dom` smoke 超时、AppShell 无侧栏时主内容落入 0 宽网格、Canvas 特效层遮挡页面、可选 UI 数组导致运行时异常、登录前错误显示用户插件导航、稳定健康检查造成 revision 抖动、重复停用非幂等、第三方 route/trusted-module 越界和 Runtime 空响应崩溃风险。

## 9. 已知限制和未完成事项

1. gRPC Extension Dispatch 当前使用受限 loopback HTTP envelope，不是最终 protobuf ExtensionService。
2. SSE revision 是单 Core 进程模型；多实例需要 Redis/NATS 广播和全局单调 revision。
3. 富文本和版主 thread widget 尚未拆为细粒度动态 Surface，仍走成熟旧页面。
4. TypeScript SDK 尚未发布 npm，Aurora Campus PNG 可在发布流水线继续压缩。
5. Web 主 bundle 仍有大 chunk 警告；不影响本次正确性，但应在后续性能工作包拆包。

以上均为已记录的后续增强，不阻断本次 P0-Highest 架构主线完成。
