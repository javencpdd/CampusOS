# CampusOS v0.6.21-dev 进度说明

> 日期：2026-07-12  
> 状态：已完成（WP11）

## 1. 目标

收口 Admin、Go/TypeScript SDK、API 契约、架构、插件与风格包文档，并把新增能力纳入可重复发布门禁。

## 2. 实际完成内容

- Admin 插件页分别显示 scope、backend/frontend activation mode、BackendState、FrontendState、Health、pending restart 和 UI revision；重载按钮按 activation mode 决策。
- Go SDK 同步 lifecycle/UI Contract；新增 `sdk/typescript` 的 Runtime 类型和受限 Gateway client。
- Current OpenAPI/路由/授权矩阵更新到 148 条路由，包含 UI Manifest、SSE 和五种 Gateway Method。
- 数据架构页、schema contract 和 migration 元数据同步到 `000018`。
- 官方文档站增加前端运行时、Gateway、生命周期和 app-style-pack.v2 教程；根 README/文档门户指向第三版计划和总体验收。
- 修复 Web 原有 lint/format 脚本缺少依赖与配置的问题，增加 ESLint 和 Prettier 可执行门禁。

## 3. 核心设计

SDK 只暴露稳定合同和 Gateway client，不暴露 Element Plus、全局 Router/Pinia、JWT 内容或其他插件 Store。系统级与用户级插件都必须接受 Core 最终授权；scope 和 activation mode 在 Admin 与文档中分开解释。
