# CampusOS v0.6.9-dev 进度说明

> 日期：2026-07-11
> 状态：已完成

## 1. 本次目标

复核 v0.6 版本验收中仍未被实际证明的接口字段、统一错误、分页、敏感资源归属和浏览器工作流，修复审查发现的越权与文档漂移，并将真实用户端、管理端和数据库架构流程纳入发布门禁。

## 2. 完成内容

### 2.1 HTTP 契约与兼容错误

- 保留旧顶层 `code`、`msg`、`data`，新增机器可读 `error.code`、`error.message`、`error.details`、`error.request_id`、`error.retryable` 和顶层 `request_id`。
- Trace middleware 同时返回 `X-Trace-ID` 与 `X-Request-ID`；JWT、权限和 panic 恢复统一使用同一错误包络。
- `page` 和 `page_size` 使用共享严格解析器；用户、帖子、回复和公开个人空间列表不再静默修正非法分页。
- Current OpenAPI 保持 141 条操作，增加 43 个请求体声明；身份、社区、个人空间、课表、富文本、角色/版主和风格包操作中的 23 个请求使用字段级 schema，其余 20 个动态对象明确标记 `generic-experimental`。
- 生成器测试会实际解析 YAML，检查路径与分页参数合并、核心 schema、结构化错误和请求体覆盖门槛。

### 2.2 权限与字段边界

- 修复 `PUT /users/:id` 仅登录即可修改任意用户资料的越权问题，当前只允许 JWT 本人修改。
- 强类型 JSON 请求启用未知字段拒绝；用户不能通过附加 `status` 等系统字段改变账号状态。
- 公开 `/users` 与 `/users/:id` 使用 `PublicUser` 投影，不再泄露邮箱；`/auth/me` 和登录响应仍向本人返回账号资料。
- 增加未登录、token 格式错误、普通成员权限拒绝、跨用户写入、非法字段和 request ID 负向测试。

### 2.3 真实浏览器验收

- `scripts/smoke/browser-smoke.sh` 在原页面渲染检查后运行系统 Chrome + Playwright Core 工作流。
- Web 实际完成登录、个人主页设置加载、普通文本帖子发布、首楼回复、编辑、私密/公开切换和删除。
- 同一流程对真实 API 断言跨用户更新 403、非法字段 400、非法分页 400、匿名插件访问 401 和结构化错误。
- Admin 实际完成登录、插件列表加载和数据架构页加载；官方文档站实际渲染。
- 测试创建的帖子正常路径和异常清理路径都会删除，不保留 smoke 内容。

### 2.4 数据架构与文档同步

- Admin 架构页从 migration `000015` 同步到 `000017`，明确 `000016` 已增加并验证 25 条核心外键。
- `campusos-data-architecture-sync` 检查器新增最新 migration 页头、timeline 和外键措辞检查，避免只检查表名却遗漏语义漂移。
- API、数据库、插件生命周期、AI、集成、官方文档站、README、onboarding 和 v0.6 计划同步到 `v0.6.9-dev`；清理当前说明中的旧 `role:manage` 权限表述。
