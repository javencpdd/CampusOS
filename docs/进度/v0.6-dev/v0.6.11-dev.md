# CampusOS v0.6.11-dev 进度说明

> 日期：2026-07-12  
> 状态：已完成（WP1）

## 1. 目标
让 scope 只表示管理级别，建立可兼容旧插件的生命周期和三轴状态模型。

## 2. 实际完成与核心设计
- Manifest 新增可选 `lifecycle.backend/frontend`；默认 builtin+system=`restart`、gRPC=`plugin-restart`、Wasm=`hot`、frontend=`hot`。
- 增加 BackendState、FrontendState、Health 和旧 `status` 映射；Manager 的启停/重载决策改用 activation mode。
- Wasm 候选实例先完成 ABI 校验再原子交换，候选失败时旧实例继续运行。
- `000018` 持久化三轴状态与 UI revision，并增加 CHECK 和索引。

## 3. 修改文件
`internal/plugin/manifest.go`、`runtime.go`、`manager.go`、`repository.go`、`pg_repository.go`、`internal/plugin/wasm/runtime.go`、`sdk/go/types.go`、`migrations/000018_plugin_ui_runtime.*.sql`。

## 4. API / 数据库 / 兼容
插件管理响应增加 backend/frontend/health 和两类 activation mode；旧字段继续返回。migration 只追加，旧 manifest 无需改写。

## 5. 测试
`go test ./internal/plugin/... ./sdk/go -count=1`：通过；覆盖默认推导、显式 restart 和 Wasm 失败保留旧实例。

## 6. 已知限制与后续
