# CampusOS v0.6.17-dev 进度说明

> 日期：2026-07-12  
> 状态：已完成（WP7）

## 1. 目标
提供安全的声明式默认 UI 和受限可信模块迁移路径。

## 2. 实际完成与核心设计
DeclarativeRenderer 只支持 stack/grid/card/heading/text/badge/alert/button/list 和 Campus UI primitive；按钮只能执行当前插件已声明 Action。可信 Vue module 只能使用 Core 编译期 ID，不能加载远程 URL、读取 Token、修改全局 Router/Store 或访问其他插件 DOM。

## 3. 修改文件
`web/src/campus-ui/DeclarativeRenderer.vue`、`CampusButton.vue`、`CampusCard.vue`、`PluginSurfacePage.vue`。

## 4. API / 数据库 / 兼容
Action 通过 Gateway，Method/path/body/确认/审计从服务端合同取得；未知 renderer 显示标准不兼容页。

## 5. 测试
Web TypeScript 检查和 production build：通过。

## 6. 已知限制与后续
当前 schema 不含富文本、视频、地图和图表；这些能力必须经新的受控语义组件或 Core trusted module 评审。
