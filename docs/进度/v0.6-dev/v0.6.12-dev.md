# CampusOS v0.6.12-dev 进度说明

> 日期：2026-07-12  
> 状态：已完成（WP2）

## 1. 目标
建立不能向主 Router 泄漏动态 Handler 的统一 Extension Gateway 与 Runtime 分发。

## 2. 实际完成与核心设计
- 新增 `/api/v1/extensions/:plugin/*path` 的 GET/POST/PUT/PATCH/DELETE 入口。
- Gateway 只接受 Manifest Action，执行 JWT、权限、运行/健康、1 MiB、5 秒超时、Trace 和审计。
- caller 身份只由 Core 注入；请求体 user ID 不可信。
- builtin 使用 handler registry；gRPC 只允许 loopback `extension_url`；Wasm 通过 `extension.request` JSON ABI。

## 3. 修改文件
`internal/plugin/runtime_http.go`、`runtime.go`、`manager.go`、三类 Runtime、`internal/server/server.go`、`pkg/middleware/auth.go`。

## 4. API / 数据库 / 兼容
新增 Gateway API；不允许动态插件直接注册主 Router。现有事件和 Host API 不变，审计继续写 `plugin_logs`。

## 5. 测试
`go test ./internal/plugin/... ./internal/server ./pkg/middleware -count=1`：通过；可信 caller、未声明 Action 和 Runtime 分发有定向覆盖。

## 6. 已知限制与后续
gRPC 当前桥接为 loopback HTTP envelope，正式 protobuf ExtensionService 留待下一兼容版本；Gateway 合同和安全边界已稳定。
