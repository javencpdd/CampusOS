# CampusOS v0.6.2-dev 进度说明

> 日期：2026-07-11
> 状态：已完成

## 1. 本次目标

让 `category-moderation` 的版主动作权限开关无需重启 API 即可生效，并让帖子详情中的置顶/取消置顶、锁定/解锁按钮使用与当前状态匹配的图标。

## 2. 完成内容

| 项目 | 结果 |
| --- | --- |
| 权限配置热更新 | `allow_pin`、`allow_lock`、`allow_delete_post` 保存后，版主服务在下一次授权检查时读取最新配置。 |
| 生命周期边界 | 插件整体启用/停用仍遵循系统级插件规则，需要重启 API；动作权限开关不再要求重启。 |
| 线程安全配置读取 | Plugin Manager 新增配置快照接口，返回脱离内部状态的副本，避免动态读取与配置更新发生数据竞争。 |
| 管理端提示 | “版主权限上限”明确显示保存后立即生效，成功消息不再提示重启。 |
| 用户端图标 | 未置顶显示向上图标，已置顶显示向下图标；未锁定显示锁图标，已锁定显示解锁图标。操作成功后图标随返回状态立即切换。 |
| 拒绝边界 | 动作被热关闭后，旧页面即使尚未刷新仍会被后端立即拒绝；刷新页面后对应按钮隐藏。 |
