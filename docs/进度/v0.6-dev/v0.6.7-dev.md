# CampusOS v0.6.7-dev 进度：插件供应链与单节点恢复

> 日期：2026-07-11
> 状态：已完成

## 插件供应链

| 项目 | 结果 |
| --- | --- |
| 更新前快照 | 覆盖更新用户级插件前，保存包、版本、checksum、大小、来源和时间到对应 plugin_data。 |
| 完整性 | 列表和恢复前重新计算 checksum/大小，并拒绝元数据路径逃逸。 |
| 健康检查 | 原启用插件更新并重载后执行 Runtime HealthCheck；失败写错误状态并提示使用快照回滚。 |
| 人工回滚 | 新增快照列表和恢复 API，Admin“插件管理 -> 版本”提供确认窗口并记录插件审计日志。 |
| 系统级边界 | 系统插件不允许 Web 热替换或快照热回滚，必须通过源码部署和服务重启。 |

## 备份恢复

- `scripts/backup.sh` 备份 PostgreSQL、migration、插件代码/数据、个人空间、图片和配置，并生成 SHA-256 清单。
- `scripts/restore.sh` 支持 verify、extract 和显式 `--confirm` apply，拒绝不安全 archive 路径。
- `scripts/restore-drill.sh` 在临时数据库执行非破坏性恢复。

## 实际演练

恢复后的隔离数据库读取到 5 个用户、7 个主题、8 个插件和 17 条 migration；插件代码、plugin_data 和 personal-space 文件检查通过，临时数据库已清理。
