# CampusOS v0.5.27-dev 进度说明

> 日期：2026-07-10
> 状态：已完成

## 1. 本次目标

将受控富文本图文文章的本地图片从独立的 `data/images/richtext/users/<user_id>/` 迁入用户个人空间，使头像、课表和图文文章图片使用同一份用户目录与配额。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 新图片目录 | 富文本图片现在保存到 `data/personal-space/<user_id>/img/richtext/<filename>`。 |
| URL 兼容 | 仍使用 `/api/v1/richtext/assets/<user_id>/<filename>`，已经存入 HTML 与 `richtext_article_assets` 的 URL 不需要修改。 |
| 配额统一 | 图片上传会统计整个用户个人空间；超过 `personal-space.default_quota_mb` 时返回参数错误。单张图片仍受 `controlled-richtext-article.max_image_mb` 限制。 |
| 配置收口 | 移除 `controlled-richtext-article.file_root`，富文本图片根目录始终跟随 `personal-space.file_root`；服务启动时会清理旧的持久化配置字段。 |
| 旧目录迁移 | 启动时自动迁移旧默认目录的图片。同名文件不会覆盖，而是保留为 `legacy-<timestamp>` 副本。 |
| 本地数据迁移 | 当前工作区的既有图文图片已移动到对应用户的 `img/richtext/` 目录。 |
