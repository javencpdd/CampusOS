# CampusOS v0.5.19-dev 进度说明

> 日期：2026-07-08
> 状态：已完成

## 1. 本次目标

完成风格包运营化二期：让 `data/plugin_data/<plugin>/style-packs/` 中的源码目录风格包从“知道目录名后手动应用”升级为“后端可扫描、前端可选择、失败可审查、通过后才可应用”。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 源码目录扫描 | `internal/stylepack` 新增源码目录列表能力，逐个读取 `style.yaml`，复用文件夹风格包筛查，并返回每个包的 `validation` 状态 |
| 个人主页源码包列表 | 用户端 `/space/settings` 可刷新并选择 `personal-space` 源码目录风格包，失败包显示错误且不可应用 |
| 首页源码包列表 | 管理端 `homepage-customizer` 配置弹窗从手输目录名改为下拉选择，支持刷新、状态标签和错误展示 |
| 应用前二次筛查 | 个人主页和首页仍在应用源码目录包前重新执行目标类型、HTML、CSS、资源路径和 config schema 检测 |
| 文档同步 | README、v5 第二版计划书、风格包切换帮助文档和项目上手快照同步到 `v0.5.19-dev` |
