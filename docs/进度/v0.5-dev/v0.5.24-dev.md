# CampusOS v0.5.24-dev 进度说明

> 日期：2026-07-09
> 状态：已完成

## 1. 本次目标

补齐普通文本帖子的作者治理能力，让普通文本和富文本图文文章都支持编辑与删除；同时为普通文本帖子增加私密状态，并在编辑页离开前提示保存。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 普通文本编辑 | `/threads/:id/edit` 可识别普通文本帖子，加载原标题、内容、标签和可见性后保存修改 |
| 普通文本删除 | 普通文本详情页对作者显示编辑、设为私密/公开、删除操作 |
| 私密帖子 | 新增 `private` 帖子状态，公开列表、公开详情、MCP-like `threads.get` 和公开回复列表不返回私密/非发布帖子 |
| 作者可见 | 新增登录态详情接口和登录态回复列表接口，作者可查看自己的私密帖子和回复 |
| 离开提醒 | 普通文本编辑和富文本图文编辑都增加路由离开与浏览器关闭前的未保存修改提醒 |
| 管理端列表 | 管理端帖子列表改走受权限保护的 `/api/v1/admin/threads`，并支持筛选私密状态 |

## 3. 关键实现

| 文件 | 说明 |
| --- | --- |
| `internal/community/domain/thread.go` | 增加 `private` 状态、创建私密字段和更新状态字段 |

1. 若要继续完善内容治理，可为普通文本帖子增加草稿状态和版本历史。
