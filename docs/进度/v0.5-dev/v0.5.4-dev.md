# CampusOS v0.5.4-dev 进度说明

> 日期：2026-07-02
> 状态：已完成

## 1. 本次目标

完成 Webhook 基础闭环，让 CampusOS 事件可以签名投递到外部 mock endpoint，并记录投递结果。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| Endpoint 管理 | 新增 Webhook endpoint 创建、列表、启用、禁用接口 |
| 事件过滤 | endpoint 可配置事件列表，空列表或 `*` 表示全部事件 |
| HMAC 签名 | 投递时使用 `X-CampusOS-Signature: sha256=...` |
| 重试与超时 | endpoint 支持 `max_retries` 和 `timeout_ms` |
| 投递记录 | 记录 event、目标 URL、状态、尝试次数、响应状态码和错误信息 |
| 后台测试 | 集成中心可创建、启停和测试 Webhook |

## 3. 修改文件
