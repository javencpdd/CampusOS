# CampusOS v0.5.15-dev 进度说明

> 日期：2026-07-08
> 状态：已完成

## 1. 本次目标

调整页面拓展风格包源码目录归属：`data/plugins` 只保存插件 manifest、运行入口和实现代码；可编辑的风格包源码目录迁移到 `data/plugin_data/<plugin>/style-packs/`，与插件运行/配置数据归属保持一致。
