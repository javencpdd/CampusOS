## 4. 审查发现

1. 当前 OpenAPI 仍是 `v0.3-pre` 历史草案，无法作为全部当前路由的权威契约。
2. JWT、`RequirePermission`、粗粒度 `role:manage` 和服务层 ownership 检查并存，需要统一授权矩阵。
3. 当前数据库关系主要由服务层维护，migration 没有显式 foreign key；部分 ID、状态、标签和删除策略不统一。
4. 插件已有 Built-in/gRPC/Wasm、Go SDK 和基础 CLI，但公开 Host API、兼容矩阵、测试宿主、模板和生成式权限文档仍需收口。
5. 这些缺口是 v0.6 P0；标准 MCP、真实 IM 和公开市场继续后置。
