# CampusOS v0.5.36-dev 进度说明

> 日期：2026-07-10
> 状态：已完成

## 1. 本次目标

修复个人课表“本周”回到第一周而非当天的问题，并梳理已保存学期选择、打开课表和 JSON 编辑的职责，避免用户操作后没有可见反馈。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 本周 | 点击后直接把日历定位到本地当天；当天属于当前学期时，同时切换周课表到当天所在周。 |
| 已保存学期 | 下拉框只填写待打开的年份和学期，不再在选择时隐式调用激活接口。 |
| 打开/新建课表 | 按钮明确切换或创建学期 JSON；当前学期只显示提示，目标不同才请求 `POST /schedule/me/terms/activate` 并显示成功消息。 |
| JSON 编辑 | 改名为“编辑 JSON”，只操作当前已打开学期的原始数据，不再承担切换或创建职责。 |
| 提示 | 为本周、学期选择、打开/新建和 JSON 编辑补充互不重叠的悬停说明。 |
