# CampusOS v0.5.28-dev 进度说明

> 日期：2026-07-10
> 状态：已完成

## 1. 本次目标

扩展 `personal-schedule` 内置插件，使用户可以明确课表所属年份和春季或秋季学期，设置该学期第一周的开始日期，并通过日历查看过去和未来月份中的课程安排。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 学期标识 | 课表 JSON 新增 `term_year` 和 `semester` 字段；`semester` 使用 `spring` 或 `fall`。用户端可直接选择年份与春/秋学期。 |
| 第一周日期 | 用户可设置学期第一周开始日期。周课表、周次切换和日历课程计算都以该日期为基准。 |
| 日历视图 | `/schedule` 新增“日历”标签；可通过日历组件浏览任意过去或未来月份。课程根据第一周日期、星期和课程周次显示在对应日期。 |
| 周视图联动 | 上一周、本周、下一周切换会同步日历月份；在日历中选择学期内日期时，周课表会切换到对应周次。 |
| 旧数据兼容 | 旧课表 JSON 不含学期字段时仍可正常读取。后端会按当前日期补充默认年份和春/秋学期，用户下一次保存后写入新字段。 |
| 输入校验 | 后端限制学期年份为 2000 至 2200；学期只接受春季或秋季的标准值，并兼容常见中文写法。 |
