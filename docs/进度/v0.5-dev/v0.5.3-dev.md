# CampusOS v0.5.3-dev 进度说明

> 日期：2026-07-02
> 状态：已完成

## 1. 本次目标

增强插件包治理能力，让插件包导入前可预检，导入后可追踪 checksum 和包大小。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| checksum | 插件包打包、安装和导入时计算 `sha256:` checksum |
| 包大小 | 记录插件包字节大小，便于后续排障和审计 |
| 安装预检 | 新增 `POST /api/v1/plugin-packages/precheck`，返回 manifest、文件列表、权限、事件、同名冲突和预警 |
| 路径安全 | 复用现有解包路径穿越校验，并在预检阶段提前暴露错误 |
| 后台导入 | 插件管理页导入前先执行预检；同名冲突且未开启覆盖时阻止导入 |

## 3. 修改文件

| 文件 | 说明 |
| --- | --- |
| `migrations/000011_v05_operational_features.up.sql` | `plugins` 增加 `checksum`、`package_size`、`last_preflight_at` |
| `internal/plugin/package.go` | 增加 `FileSHA256`、`PackagePrecheck` 和 `PrecheckPluginPackage` |
| `internal/plugin/manager.go` | 导入插件包时执行预检并同步 checksum |
| `internal/plugin/runtime.go` | 插件运行时记录 checksum 和包大小 |
| `internal/plugin/repository.go` | 插件记录增加治理字段 |
| `internal/plugin/pg_repository.go` | 插件仓储读写治理字段 |
| `internal/plugin/handler.go` | 新增插件包预检接口 |
| `admin/src/views/PluginManageView.vue` | 导入前预检和 checksum 展示 |
