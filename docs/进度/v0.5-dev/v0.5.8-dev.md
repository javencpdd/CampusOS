# CampusOS v0.5.8-dev 进度说明

> 日期：2026-07-07
> 状态：已完成

## 1. 本次目标

将插件、插件数据和默认风格包从分散的 `examples/`、`.campusos/` 路径收口到统一的 `data/` 目录结构，并把个人主页风格包归属到内置默认插件目录中。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| `data/` 目录基线 | 新增 `data/plugins`、`data/plugin_data`、`data/images`、`data/dist`、`data/config`、`data/skills` 目录说明和占位文件 |
| 插件默认目录调整 | `PLUGINS_DIR` 和 CLI 安装默认目标改为 `data/plugins` |
| 插件数据目录调整 | `PLUGIN_DATA_DIR` 和 SQLite-backed Host API KV 默认目录改为 `data/plugin_data` |
| 示例插件迁移 | `hello-plugin`、`hello-wasm` 从 `examples/plugins` 迁移到 `data/plugins` |
| 内置个人主页插件 | 新增 `data/plugins/personal-space`，使用 `runtime: builtin` 保存个人主页内置插件 manifest 和默认风格包 |
| Built-in Runtime | 新增 no-op built-in runtime，用于内置插件元数据和静态资产的启停、健康检查和事件允许响应 |
| 文档同步 | 更新 README、插件位置说明、插件包规范、风格包说明、备份恢复说明和项目上手快照 |
| 兼容提示 | README 和插件说明中补充旧 `.env` 仍会覆盖默认目录，需要同步更新 |
