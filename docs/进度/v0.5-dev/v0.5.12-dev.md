# CampusOS v0.5.12-dev 进度说明

> 日期：2026-07-08
> 状态：已完成

## 1. 本次目标

为 `personal-space` 和 `homepage-customizer` 增加受限 HTML 自定义能力：用户个人空间可以像首页插件一样通过 HTML 片段定制界面风格，但必须先通过后端合法性检查；首页插件的 `custom_html` 也必须经过同一套检查后才能保存和渲染。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 安全 HTML 校验 | 新增 `internal/safehtml`，限制标签、属性、URL、CSS、长度、节点数和嵌套深度 |
| 个人空间 HTML 风格 | 风格包 manifest 增加 `custom_html_enabled`、`custom_html`，应用前纳入完整风格包校验 |
| HTML 示例生成 | 新增基于当前个人主页标题、布局和色彩 token 的 HTML 示例生成接口 |
| 个人空间接口 | 新增 HTML 检测、示例生成和应用接口，复用风格快照、应用和回滚流程 |
| 公开页防护 | 个人主页公开接口在返回历史 `style_manifest` 前再次过滤不合规 HTML |
| 首页插件 HTML | `homepage-customizer.custom_html` 写入前执行安全检查，公开首页只输出检测通过的 HTML |
| 用户前端 | 首页和公开个人主页渲染已检测 HTML，个人空间设置页增加 HTML 编辑、检测、示例生成和应用按钮 |
| 文档同步 | 更新 README、插件说明、集成指南、项目状态快照和本进度说明 |

## 5. 后续任务

1. 当前 HTML 仍是受限子集，不开放任意 JavaScript；如需更自由的页面插件，需要继续增加审核流、版本回滚、CSP 和更强隔离。
2. 个人主页 HTML 片段目前跟随当前风格 manifest 存储；后续如果支持多版本、多套模板或站内风格市场，需要增加独立版本索引。
3. 首页插件的 HTML 配置目前通过通用插件配置弹窗编辑；后续可为内置页面插件增加更友好的专用编辑器和预览。
