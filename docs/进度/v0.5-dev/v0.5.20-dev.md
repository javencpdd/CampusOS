# CampusOS v0.5.20-dev 进度说明

> 日期：2026-07-08
> 状态：已完成

## 1. 本次目标

以 `controlled-richtext-article` 内置插件形式实现受控富文本图文文章 MVP，并补充“如何把 CampusOS 接口协议转换成 Discord、OneBot v0.11 这类外部协议形态”的设计说明。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 内置插件 | 新增 `data/plugins/controlled-richtext-article/`，可通过现有插件管理启用或禁用 |
| 数据模型 | 新增 `richtext_article_contents` 和 `richtext_article_assets`，以 `threads` 作为社区主表，富文本内容放插件表 |
| 后端 API | 新增草稿创建、编辑、图片上传、预览、发布、下架、删除、详情读取和插件状态接口 |
| 插件启停 | 富文本创建、编辑、预览、读取、发布、图片访问等能力均受 `controlled-richtext-article` 插件启停状态控制 |
| HTML 清洗 | 后端在保存、预览、发布和详情返回时清洗 HTML，移除脚本、事件属性、危险 URL 和不允许的标签 |
| 前端编辑 | 用户端发布页支持“图文文章 / 普通文本”模板切换，图文模式支持摘要、封面、正文 HTML、图片插入、草稿、预览和发布 |
| 详情展示 | 帖子详情页对富文本文章使用统一 `article-content` 容器渲染清洗后的 HTML，并为作者提供编辑、下架、删除入口 |
| 列表入口 | 帖子列表新增“图文文章”筛选区，并对富文本帖子显示“图文”标签 |
| 协议适配说明 | 新增 Discord、OneBot v0.11 等平台通过 CampusOS Adapter Contract 进行标准化转换的帮助文档 |

## 5. 后续任务

1. 后续可以在保持后端 API 不变的前提下，把 MVP 的 textarea HTML 编辑器替换为 Tiptap、wangEditor、BlockNote 或 Quill。
2. 管理端可继续补充富文本文章的全站治理入口，例如管理员下架、恢复、删除和审计。
3. 协议适配器后续建议先选 OneBot v0.11 或 Discord 其中一个做最小 Adapter，不要一次接入多个真实平台。
4. 下一步建议继续推进回归测试脚本化，把普通发帖、富文本文章、插件启停和风格包路径纳入 smoke。
