# CampusOS v0.5.13-dev 进度说明

> 日期：2026-07-08
> 状态：已完成

## 1. 本次目标

将 `personal-space` 和 `homepage-customizer` 的页面风格扩展从“只通过后台表单编辑 HTML 片段”推进为文件夹/zip 风格包标准。风格包可以在源码目录中维护，也可以通过前端上传 zip 导入；所有文件必须通过基础自动筛查后才允许应用，并且可以基于当前正在应用的风格生成示例拓展包。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 页面拓展风格包标准 | 新增 `page-style-pack.v1`，支持 `style.yaml`、HTML entry、CSS files、tokens、assets 和 target 区分 |
| 风格包安全筛查 | 新增文件数量、大小、路径、扩展名、HTML、CSS 和 target 校验，拒绝绝对路径、路径穿越、脚本、不安全 URL 和危险 CSS |
| 示例 zip 生成 | 用户个人主页和首页插件均可根据当前风格生成可下载的示例 zip，同时保留 JSON 文件清单接口 |
| personal-space 集成 | 支持个人主页 zip 校验、zip 应用、源码目录应用，并将拓展包编译到 `custom_html`、`custom_css` 和 `source_style_pack` |
| homepage-customizer 集成 | 管理端插件配置弹窗支持首页拓展风格包 zip 校验、示例下载、zip 应用和源码目录应用，应用后写入插件配置 |
| 前端渲染 | 用户前台首页和公开个人主页会注入已筛查 CSS，并在插件或 HTML 开关关闭时移除样式 |
| 内置源码示例 | 新增 `data/plugin_data/personal-space/style-packs/clean-blog/` 和 `data/plugin_data/homepage-customizer/style-packs/campus-hero/` |
| 文档同步 | 更新 README、插件 README、个人主页/风格包说明、插件保存位置说明、集成指南和项目上手快照 |

## 5. 后续任务

1. 当前 CSS 筛查是保守规则，仍不开放 `url()`、`@import`、固定定位和任意外部资源；后续若要支持本地图片资源引用，需要增加资源 URL 重写、CSP 和更细粒度 CSS parser。
2. 首页拓展风格包源码目录目前通过输入目录名应用；后续可以增加目录扫描列表，减少手动输入。
3. 风格包当前只记录当前应用来源，后续可以增加版本索引、回滚列表、站内安装入口和管理员审核流。
