# CampusOS v0.5.22-dev 进度说明

> 日期：2026-07-08
> 状态：已完成

## 1. 本次目标

完成 v0.5 收口阶段的插件包治理二期，并补齐前序任务遗留的首页风格回滚、富文本图文文章管理员治理和管理端帖子删除权限问题。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 插件包风险分级 | `PrecheckPluginPackage` 返回 `risk_level`、`risk_score` 和 `risk_reasons` |
| 版本比较 | 同名插件预检返回 `existing_version`、`import_version` 和 `version_change` |
| 签名预研 | 识别签名文件存在状态，v0.5 只展示 `unsigned` 或 `present_unverified`，不强制验签 |
| 导入审计 | 管理端导入成功、失败、预检失败或覆盖冲突都会写入插件日志 |
| 预检弹窗 | 管理端导入插件包前展示风险等级、版本变化、权限、警告和包内文件 |
| 首页回滚 | `homepage-customizer` 应用风格包前保存上一份 config，管理端支持一键回滚 |
| 富文本治理 | 管理端帖子页支持图文文章筛选、下架、恢复和删除 |
| 管理删除 | 新增管理员删除任意普通帖子的后端接口，避免复用作者删除接口导致权限失败 |
| 体验修复 | 管理端插件导入/导出图标语义调整；用户端帖子列表支持从 URL query 进入图文文章筛选；图文文章编辑离开前提示保存草稿或发布 |
| 治理文档 | 新增插件包治理与回滚说明 |
