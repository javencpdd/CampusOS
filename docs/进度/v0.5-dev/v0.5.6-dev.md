# CampusOS v0.5.6-dev 进度说明

> 日期：2026-07-02
> 状态：已完成

## 1. 本次目标

定义 CampusOS Message 协议和 local adapter，先完成本地可验证收发闭环，不绑定真实 IM 平台。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| Message 模型 | 定义平台、会话、发送者、方向、消息类型、内容、原始载荷和时间戳 |
| Binding 模型 | 增加平台账号与 CampusOS 用户绑定表 |
| local adapter | 新增 `POST /api/v1/messages/local/inbound`，支持 `ping` 返回 `pong` |
| 日志记录 | inbound/outbound 消息写入 `message_logs` |
| 后台入口 | 集成中心可发送本地消息并查看消息日志 |

## 3. 修改文件

| 文件 | 说明 |
