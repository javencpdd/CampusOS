# CampusOS v0.5.25-dev 进度说明

> 日期：2026-07-09
> 状态：已完成

## 1. 本次目标

新增个人课表插件，让用户可以从头像菜单进入个人课表，设置第一周开始日期，查看当前周课程，手动维护课程，并支持从示例 `.xls` 表格导入课程；课表数据继续保存在用户个人空间文件目录中。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 内置插件 | 新增 `personal-schedule` built-in 插件目录，支持管理端插件启停和基础配置 |
| 个人空间存储 | 每个用户的课表保存到 `data/images/personal-space/users/<user_id>/schedule/schedule.json` |
| 后端服务 | 新增 `internal/schedule`，提供课表读取、保存、导入、校验、当前周计算和配额检查 |
| 表格导入 | 支持解析 `docs/Todo/tmp/class.xls` 这类 `.xls` 课表，同时兼容 `.csv` 和 `.json` |
| 用户入口 | 用户前台头像下拉菜单增加“个人课表”，路由为 `/schedule` |
| 课表界面 | 支持第一周开始日期、上一周/本周/下一周、手动新增/编辑/删除课程、JSON 高级编辑和导入替换 |
| 文档同步 | README、v0.5 第二版计划书、项目上手快照同步到 `v0.5.25-dev` |
