# CampusOS v0.5.9-dev 进度说明

> 日期：2026-07-07
> 状态：已完成

## 1. 本次目标

将用户个人空间文件能力纳入 `personal-space` 内置默认插件配置，补齐头像上传、本地配额、头像源文件保留和个人主页导航行为；同时让帖子回复楼层在前端更明确展示。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 个人空间文件默认插件 | `data/plugins/personal-space/plugin.yaml` 增加文件根目录、URL 前缀、默认 10MB 配额、头像保留数量和未来云盘 provider 占位配置 |
| 本地文件存储 | 新增 `internal/space/files.go`，按用户目录保存头像，默认路径为 `data/images/personal-space/users/<user_id>/avatars/` |
| 存储配额 | 默认每用户 10MB，支持通过插件 config 的 `default_quota_mb` 或 `default_quota_bytes` 调整 |
| 头像规则 | 支持 `jpeg`、`png`、`gif`、`webp`，默认单文件 2MB，默认保留最近 3 个头像源文件 |
| Space API | 新增 `GET /api/v1/spaces/me/storage`、`POST /api/v1/spaces/me/avatar`、`GET /api/v1/spaces/files/:user_id/avatars/:filename` |
| 用户前台导航 | 顶部“个人主页”直接进入 `/u/:username`；点击自己的头像进入 `/space/settings` |
| 主页设置页 | 增加头像上传、存储配额展示，上传成功后同步顶部头像和公开主页头像 |
| 回复楼层 | 回复列表、引用回复和编辑器标题改为“第 N 楼”表达；仓储按楼层稳定排序，新增回复不复用已删除尾部楼层 |
| 文档同步 | 更新 README、插件位置说明、个人主页 Space 说明、备份恢复说明、data 目录说明和项目上手快照 |

## 5. 后续任务

1. 如需把个人空间文件扩展到非头像文件，需要补充文件索引、列表、删除、类型策略和用户侧文件管理 UI。
2. 如需接入个人云盘，可沿用 `future_storage_provider` 配置扩展 provider，并在保持公开头像 URL 稳定的前提下增加同步或代理层。
3. 个人主页能力当前仍是核心模块实现加内置插件配置归属；完全外部插件化仍需要专用 Host API 或后端扩展点。
