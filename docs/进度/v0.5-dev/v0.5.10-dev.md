# CampusOS v0.5.10-dev 进度说明

> 日期：2026-07-07
> 状态：已完成

## 1. 本次目标

修复 Admin 后台启用/禁用 `personal-space` 插件后用户端无感的问题，让该插件状态真正控制个人主页、主页设置、风格包、头像上传和个人空间同步能力；同时新增一个内置系统插件，用于通过 Admin Web 配置用户前台首页 `http://localhost:3000/` 的基础展示风格。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| `personal-space` 状态生效 | 插件 Manager 现在会持久化管理员启用/禁用状态，服务启动时恢复禁用状态；用户侧 Space API 会检查 `personal-space` 是否运行 |
| Space API 禁用响应 | 插件禁用后，公开主页、主页设置、风格包、存储配额、头像文件和内容同步返回不可用或暂停执行 |
| 插件配置 API | 新增 `PUT /api/v1/plugins/:name/config`，按 `config_schema` 归一化并持久化插件配置 |
| Admin 配置弹窗 | 插件管理页新增“配置”按钮，可按 schema 渲染字符串、文本、数字、布尔和下拉配置项 |
| 首页内置插件 | 新增 `data/plugins/homepage-customizer/`，作为用户前台首页结构化配置的内置系统插件 |
| 首页配置接口 | 新增 `GET /api/v1/home/config`，输出首页标题、副标题、背景图、遮罩和版块检索标签 |
| 用户前台首页 | 首页读取 `homepage-customizer` 配置，支持背景图和版块快捷检索标签；标签跳转到帖子列表并按版块过滤 |
| 安全边界 | 当前只渲染结构化配置，不渲染任意 HTML；`custom_html` 仅作为后续多风格界面插件的预留字段 |
| 文档同步 | 更新 README、插件说明、配置 schema、v0.5 集成指南、data 目录和项目上手快照 |
