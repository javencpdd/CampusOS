# CampusOS v0.5.30-dev 进度说明

> 日期：2026-07-10
> 状态：已完成

## 1. 本次目标

将个人课表从一个用户一个 `schedule.json` 调整为一个学期一份 JSON。用户能够选择已有的春季或秋季课表，或创建目标学期课表；第一周日期通过明确的独立按钮修改；导入数据只写入当前学期。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 学期独立存储 | 课表改存为 `data/personal-space/<user_id>/file/schedule/terms/<year>-<semester>.json`；每个文件只描述一个学期。 |
| 活跃课表索引 | 新增 `file/schedule/index.json`，仅记录用户最近选中的学期，不复制课程数据。 |
| 兼容迁移 | 读取旧 `file/schedule/schedule.json` 时自动迁移到对应学期文件；旧文件缺少学期字段时使用当前年份和春/秋季默认值。 |
| 后端接口 | 新增当前用户的学期列表和选择/创建接口；读取接口支持按年份和学期取得指定 JSON；导入接口要求目标学期。 |
| 用户端选择 | 用户可从已保存课表列表切换，也可输入年份、选择春/秋季后点击“打开课表”创建或打开目标课表。 |
| 第一周操作 | 原内联日期输入改为“设置第一周”按钮和日期弹窗，只修改当前选中学期的第一周日期。 |
| 导入隔离 | `.xls`、`.csv`、`.json` 导入会写入当前学期对应 JSON，不再影响其他学期。 |
| 悬停说明 | 学期选择、年份、春秋学期、打开课表、第一周、导入和 JSON 编辑均增加悬停说明。 |

## 5. 后续任务

3. 已选学期的删除、导出和冲突合并策略尚未提供，可在课表运营能力增强时补充。
