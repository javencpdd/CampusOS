# CampusOS v0.5.11-dev 进度说明

> 日期：2026-07-08
> 状态：已完成

## 1. 本次目标

补齐“版块 + 标签”的组合使用方式，让管理员能为每个版块配置默认标签，用户发帖时自动带入默认标签并继续添加自定义标签；同时在 Admin 管理后台增加平台日志页面，支持查看后端 API、用户前台 web 和管理后台 admin 的实时输出。

## 2. 完成内容

| 项目 | 说明 |
| --- | --- |
| 版块默认标签 | 新增 `categories.default_tags`，用于保存每个版块的默认标签 |
| 发帖标签合并 | 后端创建帖子时合并版块默认标签和用户自定义标签，执行去空、去重和数量限制 |
| 用户发帖页 | 选择版块后自动带入该版块默认标签，用户仍可继续输入自定义标签 |
| Admin 版块管理 | 版块列表展示默认标签，新建/编辑版块时可维护默认标签 |
| 平台日志后端 | 新增 `internal/platformlog`，只允许读取固定的 `api`、`web`、`admin` 三个日志源 |
| 平台日志接口 | 新增 `GET /api/v1/platform/logs/sources` 和 `GET /api/v1/platform/logs/stream`，后者用 SSE 输出日志行 |
| Admin 平台日志页 | 新增 `/platform-logs` 页面，可选择日志源、读取尾部日志并保持实时跟随 |
| 文档同步 | 更新 README、v0.5 集成指南、项目上手快照和本进度说明 |

## 5. 后续任务

1. 当前标签仍主要存储在 `threads.tags`；如需统计热门标签、标签合并和标签检索页，需要补齐 `tags` 表同步与管理 UI。
2. 平台日志当前面向本地开发期排障；生产环境建议后续接入 journald、Loki、ELK 或云日志，并增加日志保留策略。
3. 如果要允许管理员在日志页执行重启服务、下载日志或筛选关键字，需要增加更细的权限和审计记录。
