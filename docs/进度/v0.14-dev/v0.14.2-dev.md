## 关键安全与兼容边界

- 跨用户文档访问按统一 404 返回；下载使用 `Content-Disposition: attachment`、`X-Content-Type-Options: nosniff` 与私有无缓存响应。
- 文档保存、历史恢复都先创建新 Object，再追加新版本；不会覆盖旧 Object 或旧版本行。
- 旧课表 JSON 仍按原路径兼容读取。受管学期引用为新增保护，不批量迁移、重命名或删除用户历史文件。
- Converter 未达到“独立、非 root、无网络、限资源、无数据库/JWT”的隔离合同，因此不启用 DOCX/PDF 预览或在线转换。
