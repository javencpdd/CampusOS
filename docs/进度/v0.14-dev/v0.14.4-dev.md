## 4. 文档和兼容处理

- Windows、Linux/WSL2、Git Bash 的 Docker 运行与测试入口保持一致；PowerShell 不需要手写容器路径。
- 恢复演练不对运行中的开发库执行 down、reset 或删除卷；历史课表采用和对象对账的 `--apply` 仍必须由有权管理员先审阅 dry-run，再带 `--actor` 和 `--reason` 显式执行。
- 仍无实际受审查 Converter Runner。PDF/DOCX 继续安全降级为认证上传/下载，`converter_unavailable` 是预期保护，而不是漏配的静默失败。
