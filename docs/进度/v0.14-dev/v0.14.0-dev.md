## 4. 主要决策

1. AcademicTerm 是系统级目录事实；Schedule 仍是 Built-in Feature。
2. 新业务只消费 Object ID；旧 Path/URL/JSON 使用兼容 Adapter 和 shadow/dual/enforce 迁移。
3. 配额授权复用 `user_storage_quotas`，新增账户 ledger 和 Reservation，不重复实现管理员配额功能。
4. Personal Documents 不创建帖子；仅抽取 RichText 的 schema/sanitize/render 能力。
5. DOCX/PDF Converter 未达到无网络、非特权、限 CPU/RAM/时间的隔离门槛时必须降级。
6. 学期/对象/文档回滚保留数据，生产优先 forward-fix，禁止 Feature Disable 隐式删除。
