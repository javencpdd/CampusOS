# CampusOS v0.10 实测问题与验收映射

> 状态：v0.10-dev 实现映射。最终统一门禁记录见 `docs/进度/v0.10-dev/v0.10.21-dev.md`。

本表把原始十个实测问题绑定到后端事实、前端入口和可重复验证。它不把截图或页面文案当作唯一安全证据。

| 问题 | 责任边界 | 实现/测试证据 |
| --- | --- | --- |
| 用户插件中心为空 | Plugin Market + Web Plugin Center | `web/tests/plugin-center.spec.ts` 覆盖已发布目录与申请入口；空目录文案说明管理员发布前不可见。 |
| 普通用户看不懂插件 | Manifest `experience` + Plugin Center | `000024`、`internal/plugin/manifest.go`、`web/src/modules/plugin-center/pages/PluginCenterView.vue`；默认展示用途、数据、风险、关闭后行为和维护者。 |
| 个人主页不应复制帖子 | Community `ContentQuery` + Space Adapter | `internal/modules/features/personalspace/sync_test.go` 的作者/公开读路径测试；生产装配通过 `ContentQuery` 查询 `threads`。 |
| 手机课表不应默认横向滚动 | Layout Capability + Schedule UI | `web/src/shared/layout/useLayoutCapability.ts`、`ScheduleView.vue`、`web/tests/responsive-workflow.mjs` 的七视口溢出检查。 |
| 下架后编辑重发绕过审核 | Community 状态机 + RichText Adapter | `TestTakenDownThreadCannotBeRepublishedWithoutReview` 与 `TestTakenDownRichTextArticleReturnsToReviewInsteadOfPublic`。 |
| 外部插件、内置功能与资源包混淆 | Extension Hub + Feature Registry + Resource Repository | `admin/src/modules/plugins/pages/ExtensionHubView.vue`；页面只聚合摘要，不合并后端生命周期。 |
| 集成中心成熟度和帮助不足 | Integration Center + docs-site | `IntegrationCenterView.vue`、`docs-site/operations/integrations.md`；明确 Webhook、MCP-like、Message Local 的实际边界。 |
| 后台用户/内容/权限入口分散 | AdminLayout + 角色权限页 | `AdminLayout.vue`、`PermissionManageView.vue`；深链接和移动导航由响应式工作流覆盖。 |
| `/api/v1` 返回 404 | HTTP API Index / NoRoute | `internal/transport/httpapi/api_index_test.go` 覆盖 HTML/JSON 协商和结构化 API 404。 |
| 目录、生成物和表归属不清 | 架构清点、治理检查器、数据库页 | `docs/architecture/v10当前系统清点与治理.md`、`check-data-governance.py`、`check-generated-files.py`、Admin `/architecture`。 |

## 共同门禁

```bash
GOCACHE=/tmp/campusos-go-cache go test ./... -count=1
pnpm --dir web test:component
pnpm --dir admin test:component
make contracts-check
make architecture-check
make database-check
RUN_RESTORE_DRILL=true RUN_BROWSER_SMOKE=true make release-check
```

七视口浏览器回归还会检查 320、360、393、768、1024、1366 宽度和 852x393 横屏。它用于发现文本、按钮、加载层和非预期横向滚动；权限和状态转换仍以服务端合同测试为准。
