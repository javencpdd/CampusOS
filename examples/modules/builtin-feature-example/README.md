# Built-in Feature descriptor example

This directory documents the `campusos.module/v1` shape. It is not an
installable plugin package. Real compiled features live under
`internal/modules/features/<feature>` and their production descriptor lives
under `modules/features/<feature>/module.yaml`.

To create an independently installable extension, start from
`examples/plugins/grpc-example`, `wasm-example`, or `campus-welcome` instead.
