## 事故：git stash push -u 导致 .git 损坏（已完全恢复）

- 经过：为对比既有测试失败执行 `git stash push -u`，操作中途失败并清空了 `.git/refs/` 与全部 loose objects（疑似 Windows + Docker 绑定挂载环境下 stash 中途崩溃）
- 恢复：重建 `.git/refs/heads|tags` → 从 `.git/logs/HEAD` reflog 找到分支 tip（1a672d29）→ 写回 refs/heads/djw-workbuddy → `git fetch origin` 恢复对象（用户已推送两个本地提交，远端是最新）
- 教训：**本仓库禁止 `git stash push -u`**（Docker 容器实时读写工作区）；验证既有失败用 `git worktree add <临时目录> HEAD`；GOCACHE 放 `/.cache/`（已 gitignore）；reflog（.git/logs）是本地提交恢复的命脉
- 用户两次提交 f3d052c、1a672d29 已推送 origin/djw-workbuddy；本轮所有改动（通知功能+进度文档）仍未提交
