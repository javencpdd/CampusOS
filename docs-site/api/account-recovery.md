# 账号恢复与邮箱绑定

v0.12 将密码找回、个人邮箱绑定和历史账号恢复拆成受控流程。系统不会把历史邮箱登录兼容状态误当作
已经验证的邮箱所有权。

## 普通用户

1. 在登录页选择“找回密码”，输入已验证的个人邮箱。
2. 从邮件取得六位验证码；页面会在内存中自动关联本次请求，不需要手动填写请求编号。
3. 系统会退出全部已登录设备；请使用新密码重新登录。

公共请求会返回统一受理结果，避免泄露邮箱是否注册或是否可恢复。

验证码默认按每邮箱 10 分钟 5 次、每 IP 60 分钟 10 次限制。管理员可通过
[验证码策略配置](/guide/challenge-policy)热更新有界参数，不能关闭限流。

## 更换邮箱

登录后点击头像，打开“账号安全”，在“绑定邮箱”中验证新的个人邮箱。成功后新邮箱成为唯一登录和
找回邮箱，全部设备会退出以保护账号。

## 管理员辅助恢复

历史账号没有可验证邮箱时，管理员先按组织流程线下核验，再在管理端创建恢复 Case。管理员只能看到
脱敏邮箱、状态和时限，不能读取验证码、Ticket 或密码。用户必须在新邮箱完成验证码验证后自行设置
新密码。

## 部署维护

系统管理员账号不使用公网邮件找回。可信服务器的交互式终端可执行：

```bash
campusosctl identity reset-password
```

命令要求明确确认和两次隐藏密码输入，不接受密码参数或管道输入。详细接口、权限和排障请阅读仓库的
[账号恢复与邮箱绑定说明](https://github.com/javencpdd/CampusOS/blob/main/docs/help/%E7%B3%BB%E7%BB%9F%E8%AE%BE%E8%AE%A1%E7%9B%B8%E5%85%B3/v12%E8%B4%A6%E5%8F%B7%E6%81%A2%E5%A4%8D%E4%B8%8E%E9%82%AE%E7%AE%B1%E7%BB%91%E5%AE%9A%E8%AF%B4%E6%98%8E.md)。
