# 授权与资源访问

> 更新时间：2026-10-18（Asia/Shanghai）；当前适用 `campusos.plugin/v5`。

每项调用必须同时满足不可变包声明、Admin 当前版本 Grant、所需的本人用途 Consent、当前安装/配置/身份与原业务资源 ACL。Grant 的截止时间、撤销或安装代次变化都关闭旧界面和资源读取；用户不能扩大管理员批准范围。

| 角色 | 入口 | 能力 |
| --- | --- | --- |
| Admin | 管理端 `/plugins` | 显式签名导入；业务能力/运行资源分栏审批，填写原因与期限，单独启用/停用/卸载 |
| User | 用户端 `/plugins` | 自己的安装、版本用途同意与撤回；撤权/到期后仍可清理本人安装 |
| 宿主 | API、UI Host、业务资源服务 | 当前身份与配置/权限复核、资源 ACL、有限字节读取和 required audit |

两域账号和会话互不替代；Admin 配置权限不提供用户私有文件读取权。Admin 高风险写入需当前权限、近期 MFA、浏览器 CSRF 和精确 CAS；冲突或结果未知时重新读取，页面不会自动重试。

PDF 文章附件依赖原文章/附件可读政策，个人资源/个人文档依赖本人 owner。插件只取得当前选择资源的不透明句柄、名称、长度及有界 Range 字节，不取得 JWT、API 地址、路径或 Secret。无可用插件仍通过同样的原业务 ACL 下载。

普通配置与 Secret 引用在独立表单提交，共用当前修订并原子保留另一半；密钥只选当前可见引用，不读取明文。尚无 Profile/公开集合/v5 Secret 目录适配器时返回空选项，不接受任意 ID。精确数字不经浮点取整。详见配置合同（仓库 `docs/api/v1.2插件配置Schema与Secret分流合同.md`）与UI/Bridge 合同（仓库 `docs/api/v1.2插件UI宿主与Bridge合同.md`）。
