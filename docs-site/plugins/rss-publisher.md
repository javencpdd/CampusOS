# RSS 图文订阅

> 最新更新时间：2026-11-15（Asia/Shanghai）；当前插件版本 2.1.0。

RSS Publisher 把公开 RSS/Atom 内容整理成图文，预览后交给 CampusOS 编辑器，由你核对并手动发布。订阅、解析和界面属于插件；网络、配置、图片存储和发布权限由宿主通用接口管理。

## 开始使用

1. 管理员导入已签名的 2.1.0 包，安装、批准声明的能力并启用。
2. 用户在插件中心安装到本人账号，阅读当前用途说明、同意并启用。
3. 打开插件，添加最终公开 HTTPS 订阅地址；最多保存 6 个。
4. 点击“读取最新内容”，选择一篇“预览图文”，按需加载预览图片。
5. 点击“导入图文并编辑发布”，在宿主弹窗确认。图片转存后进入原生编辑器，核对来源、转载权限、图片和版块，再点击发布。

**默认服务器读取无需下载；可选本机读取使用通用助手，无需 Windows 直连启动器。** 插件使用 opaque iframe，通过本站地址加载，不依赖通配域名或额外 UI 端口。宿主仍限制它访问 Cookie、浏览器存储、页面 DOM 和业务数据。

## 抓取发生在哪里

插件 JS 负责解析和界面，通过通用 web.read 接口让服务器或本人明确选择的客户端读取公开 HTTPS 资源。浏览器不会直接跨域读取 RSS 源，所以源站没有 CORS 支持也不要求用户下载程序。服务器无法访问源站时仍会失败，应检查服务器出站访问及最终地址。

仅接受公开 HTTPS，不接受登录凭据、私网、重定向或超限文件；每个源文档/图片最多 1 MiB。预览图片使用经过宿主校验的 Blob，导入图片归本人空间。取消导入不会自动发布；已经转存的图片保留在本人空间。

## 从 1.0.0 升级

1.0.0 的专用接口和旧助手已由通用协议替代。2.1.0 增加可选 web.local.read，用于本人主动配对的电脑；管理员不批准该可选能力时仍能使用服务器读取。管理员应通过原插件中心导入新签名版本并执行升级，重新核对 web.public.read 等能力；用户按新版本用途完成同意。不能覆盖旧包或继续沿用同一版本号发布不同字节。现有订阅字段保持兼容，正常升级会保留本人配置。

原 Windows 直连启动器仅适用于仍使用独立子域的其他插件的网络排障，不是 RSS 2.1.0 的使用步骤。

## 独立构建

在仓库根目录执行：

```bash
node plugins/campusos.rss-publisher/frontend/build.mjs
node --test plugins/campusos.rss-publisher/frontend/model.test.mjs
go run ./cmd/campusos-plugin-v5-check -root plugins
```

构建仅修改插件自己的 dist 和清单摘要；签名、导入、授权、启用沿用[插件体系](/plugins/overview)。安装和卸载不能修改宿主源码、依赖锁文件、二进制或核心数据库 schema。卸载插件也不会删除已经由你发布的社区文章。

## 可选本机抓取

1. 管理员批准插件的可选本机读取用途，用户同意当前版本用途并启用。
2. 点击“连接本机助手”，经宿主确认后查看一次性配对码。
3. 下载与自己电脑匹配的助手，启动并输入本站地址、本机代理及配对码。Windows 可直接打开 exe；Linux/macOS 从终端赋予运行权限后启动。
4. 连接后在“读取位置”明确选择这台电脑，并确认切换。随后订阅、预览图片与导入图片均使用该电脑的网络。

本机 Clash 示例：在助手代理提示中输入 http://127.0.0.1:7890，或 SOCKS5 对应的实际端口。也可指定 --proxy 启动参数或本机 CAMPUSOS_COMPANION_PROXY 环境变量。代理只作用于助手进程，地址和口令不上传，不修改系统、浏览器或服务器。

保存订阅会保留连接与选择。登录凭据刷新轮换、退出、停用、撤权或助手过期后需重新配对；旧选择显示不可用，读取不会自动切回服务器。选择服务器也须本人明确确认。原助手的专用令牌不能复用。

## 服务器与本机代理的权限

服务器代理地址、认证、启停及活动线路由管理员统一配置。插件 UI 只允许选择读取位置，不提供服务器代理目录、地址或开关。管理员通过 CAMPUSOS_PLUGIN_WEB_PROXY_PROFILES 与 CAMPUSOS_PLUGIN_WEB_PROXY_PROFILE 维护服务器策略；用户个人配置不能覆盖。

本机代理由本人在自己的助手里配置；服务器仅显示代理协议，不接收或下发本机代理地址和口令。两侧的 127.0.0.1 各指所在电脑或容器，不能混用。

管理员需预先构建固定助手文件并设置下载目录 CAMPUSOS_WEB_COMPANION_TOOLS_DIR；插件安装/卸载不构建、不执行助手，也不修改宿主文件。部署命令与限额见仓库 docs/api/v1.2本机公开资源读取助手合同.md；服务器配置见[配置说明](/deployment/configuration#插件公开读取代理)。
