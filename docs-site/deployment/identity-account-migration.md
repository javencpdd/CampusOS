# 邮箱账号升级

v0.12 将登录邮箱的权威事实放在 `accounts` 中，并保留 `users.email` 作为旧接口的兼容
投影。这个调整为验证式注册、找回密码和会话撤销准备数据边界，但当前阶段不会把历史账号
自动标记为已验证。

## 升级前

1. 备份 PostgreSQL 与 `data/`，并确认可以恢复。
2. 在隔离或预发布数据库先运行 migration。
3. 如果预检报告大小写冲突、一个用户多个邮箱、资料与账号不一致、孤儿或空邮箱，请先人工
   修复数据。CampusOS 不会替你选择哪个邮箱正确。

```bash
make identity-email-check
make database-check
```

## 状态解释

- `legacy_accepted`：历史用户可继续登录，但不表示邮箱拥有权已被证明。
- `verified`：后续验证流程完成后才会使用。
- `system_managed`：部署管理账号，不走公网邮件找回。

规范化只会去掉首尾空格并转小写；不会按特定邮件服务商规则合并别名。

## 共享邮箱

历史共享邮箱只作为迁移标记保存，不能用作登录、验证码、找回或新注册邮箱。它不会显示为
用户已绑定的个人邮箱。

更完整的迁移、开发者边界和回退说明见仓库
`docs/help/系统设计相关/v12账号身份与历史迁移说明.md`。
