# 项目介绍

> 更新时间：2026-09-25
> 当前统一版本：`v1.1.0-dev`（`v1.1-dev` 主线）；尚未宣布 v1.1 正式发布

CampusOS 是面向校园社区的模块化单体：社区、个人空间、图文文章、附件、后台治理和扩展平台共享同一套认证、权限、文件归属和审计边界。

## 当前能力

| 领域 | 已实现能力 |
| --- | --- |
| 社区与治理 | 注册/登录、版块、标签、帖子和回复、富文本、审核、下架、通知、管理员与版主范围。 |
| 个人空间 | 头像、配额、个人文档、图文资源和文章附件；文件通过服务端所有权与文章阅读权保护。 |
| 管理端 | 用户、权限、内容、学期、存储配额、系统运行及插件治理。 |
| Docker 开发 | Web 3000、Admin 3001、Docs 3002、API 8080、Plugin UI Gateway 3003。 |
| v4 外部插件 | 自包含源码、不可变发布包、隔离 iframe、Bridge、三层授权与用户级配置目录。 |

当前外部插件示例是 `campusos.pdf-viewer`：它只能预览已获业务授权的 PDF，不能取得浏览器登录令牌、数据库访问或任意个人空间路径。

## 尚未承诺为正式交付

- 通用 Wasm/container 插件执行器、完整升级回滚和跨版本插件数据迁移；
- 公共远程市场的自动安装或自动信任；
- 标准 MCP、标准 protobuf gRPC、完整 Agent Runner；
- 多节点高可用、自动 TLS、跨区域容灾；
- PDF 之外的 Office/音视频在线预览。

## 技术组成

```text
Web (:3000) / Admin (:3001) / Docs (:3002)
                    │
                  API (:8080) ── PostgreSQL / Redis / NATS / 本地受控文件
                    │
          Plugin UI Gateway (:3003) ── 已校验 v4 UI 发布包
```
