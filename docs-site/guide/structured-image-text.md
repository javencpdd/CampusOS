# 分组导航与互助、二手图文发布

## 点击分组进入子板块

前台顶部的板块分组是可点击菜单。点击“分组测试”后会看到“测试板块”“版主测试”等活动子板块，选择后
进入对应帖子列表。根级板块仍是直接链接；关闭、归档和空分组不会出现在公开导航中。

## 发布图文互助或二手信息

1. 进入“校园互助”或“校园二手”，点击发布。
2. 正文选择“图文”或“纯文本”。
3. 图文模式可插入标题、段落、引用、列表和图片。
4. 图片上传后会进入正文并显示缩略预览。
5. 点击“预览”，通过服务端安全清洗后检查最终效果。
6. 选择允许该内容类型的板块，填写结构化字段后发布。

图片保存在当前用户的个人存储空间，计入用户配额。CampusOS 只接受 JPEG、PNG、GIF 和 WebP；脚本、
iframe、事件属性和危险链接不会进入发布正文。

## 管理端中的二级功能

“校园互助”和“校园二手”显示在“图文文章”能力组下面，但它们的开关和数据生命周期独立。关闭图文文章
不会自动关闭或删除互助、二手；管理员仍需分别启用目标功能，并在板块管理中允许 `mutual_aid` 或
`secondhand` 类型。

完整接口、安全边界、目录和兼容规则见仓库文档
