# 公开知识检索与管理

> 更新时间：2026-10-23（Asia/Shanghai）
> 适用：v1.2-dev 的 V12-12；Linux 当前实现与目标验收见 .149，Windows 实机延期

在 Web 顶部导航选择“知识检索”，或在手机主导航中选择同名入口，进入 `/knowledge`。
此页面查询管理员已选入公开集合、且当前仍可公开读取的资料。
登录账号不会扩大结果范围；个人文档和私人索引不在此入口中。

## 搜索与查看引用

1. 选择一个公开集合。页面不会自动选择集合或发起检索。
2. 输入关键词，点击“搜索”；手机也可按搜索框的 Enter 键。
3. 每页最多显示 20 条资料，使用“上一页”“下一页”继续查看。
4. 点击“查看当前引用”，重新核验精确修订并读取当前原文。
   社区帖子或公开文章可通过“打开原帖”进入站内原页面；官方资料在本页阅读。

标题、片段和原文均按纯文本显示。原文中的图片或 HTML 不会作为页面内容执行。
搜索词过长或格式无效时，按提示修改后重新搜索。
这仍是字面关键词检索，不提供语义问答或 AI 答案。

## 页面状态与可用操作

| 状态 | 页面表现 | 下一步 |
| --- | --- | --- |
| 未启用 | “知识检索暂未启用” | 请管理员确认 Knowledge 功能；启用后点击“重新加载集合” |
| 未配置 | 尚无公开知识集合 | 请管理员按[当前 API 合同入口](/api/contracts)与下方配置步骤配置；完成后重新加载集合 |
| 加载中 | 正在加载、检索或核验来源 | 等待当前操作；切换集合或修改词会清除旧结果并取消旧请求 |
| 空结果 | 找到 0 条公开资料 | 调整关键词或选择其他集合 |
| 请求失败 | 集合、检索或引用暂不可用 | 使用对应的重新加载、重试检索或重试引用按钮 |
| 引用已更新 | 旧精确修订不再有效 | 点击“重新搜索”获取当前引用，不会自动打开另一修订 |
| 引用不可读或移除 | 来源已转私密、撤回或不再属于当前范围 | 旧原文和片段清空，重新搜索当前公开资料 |

开始新检索、切换集合、修改关键词、页面进入后台或离开页面时，页面清除已展示的查询结果和原文。
功能在使用中关闭后，下次公开请求会清除检索表单及结果；重新启用后需手动重新加载集合。
页面不把查询或正文保存到 URL、浏览器持久存储或客户端响应缓存；公开接口请求省略 Cookie 与 Authorization。
服务端每次重新判断当前公开性和修订，页面本地状态不构成访问授权。

## 管理与验收范围

当前独立 Admin 的“知识来源管理”已提供集合、官方资料、来源规则、成员引用、索引诊断与重试。
公开搜索、管理和指标均属于本阶段；私人知识、AI/RAG、外部 Provider 属后继阶段。

本阶段的 Linux 实现、自动化和真实桌面/移动视口验收保存在仓库中：
`docs/进度/v1.2-dev/v1.2.149-dev.md` 与
`docs/项目计划书v1/项目计划v1.2/evidence/v12-12-exit-linux.json`。
移动视口由真实 Chrome 模拟；Windows 实机按用户要求延期，不记作通过。

## 在管理后台配置来源

1. 使用独立 Admin 账号登录管理后台，在“内容治理”选择“知识来源管理”。
   读取要求 `knowledge.collection.read`，写入另需 `knowledge.collection.manage` 和当前 MFA。
   写入前点击页眉“管理员认证”配置或确认认证器，再刷新工作区；页面和服务端均保留各自检查。
2. 创建公开集合，按需要启用或停用。要另建集合，点击“新建集合”。
3. 在“官方资料”填写标题和有界正文，保存草稿、发布或撤回；“查看或编辑资料”显示不可变修订。
   正文上限 64 KiB。库存不会直接带出正文，编辑时重新请求当前修订。
4. 选择管理集合，按“单篇帖子或文章”“公开板块”“官方资料”添加来源。
   单篇和板块的 ID 可从现有帖子/板块管理核对；只有当前可公开读取的来源能加入。
   官方来源选择器只列已发布资料。
5. 通过“取消选择”停止规则；“恢复选择”重新保存当前版本。
   需要手动查看某一页成员时点击“刷新来源”，有后续页时显示“继续刷新来源”。
   正常常驻索引器会独立完成分页和权威对账，页面手动刷新不是全量完成证明。

单个“移除引用”只移除当前成员，启用的规则可在后续对账重新加入；持续排除应取消来源规则。
并发编辑出现“数据已变更”时，点击“刷新工作区”后核对再提交，页面不会自动重放保存。

## 诊断与恢复

选择集合后，“索引诊断与指标”显示实际执行状态、尝试次数、安全原因码、运行/完成代次、调度/观察时间，以及规则/成员/存储投影数。
这些是管理观察，投影数可能含等待清理的旧修订，不代表所有资料目前可读。
Web 每次检索和引用读取仍按当前原来源判断。

- 诊断暂不可用：点击“刷新诊断”，或“刷新工作区”重新取得当前状态。
- 等待处理/处理中：等当前常驻任务推进，再手动刷新诊断；不并发提交新重试。
- 等待重试/重试耗尽：修复基础故障后，具有当前管理权限和 MFA 的管理员可点击“重试索引”。
- 显示“重试已受理”：只表示命令提交成功；刷新诊断确认常驻任务实际推进。
- 权限变化、功能关闭、保存失败：旧详细状态清空；先完成权限/功能/服务恢复，再刷新工作区核对。

重试同时检查集合和任务版本，当前权限与 MFA、CSRF、审计失败都会阻止提交；陈旧版本返回冲突。
详细错误与安全边界的仓库合同为 `docs/api/v1.2知识管理诊断与重试合同.md`，合同产物的阅读方式见[当前 API 合同入口](/api/contracts)。


有指标读取权限的管理员还可通过既有 `/api/v1/metrics/summary` 查看平台索引执行页计数、执行耗时和按原任务状态分类的调度延迟。
精确定义见上述仓库合同：空闲轮询不计执行页，零调度时间不伪造排队年龄，指标标签没有查询、正文或来源身份。
