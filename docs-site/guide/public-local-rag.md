# 公开集合的本机引用问答

> 更新时间：2026-10-24（Asia/Shanghai）

> 本页保留.154/.155本机内部Port的历史切片说明；当前HTTP/Web、本机或远程Chat及完整验收见[有据问答](./cited-rag.md)和仓库.156。
这是 V12-14b 的内部纵向切片：当前用户对一个公开集合提问，使用管理员已经选择的本机模型，得到带当前来源引用的缓冲答案。整阶段尚未完成；私人来源、远程出站同意及真实模型质量评测留待后续。

## 使用条件

先按公开知识教程建立启用的集合、选择来源并等待索引完成。AI 依照受管模型教程配置两个固定 Profile，再使用近期 MFA 的独立 Admin 会话把 chat Binding 选为 `local-chat`。本机模型须预先运行，端点仅允许部署固定 loopback IP 与端口；网关不会安装模型或执行命令。

此切片只有可信宿主内部 `knowledge.public-local-rag/v1` Port，没有用户聊天页面、RAG HTTP、插件/Host/MCP 或 SDK 入口。内部调用必须传当前 User 会话解析器、公开集合 ID、问题、随机 run ID 和最新 Binding 修订。不能用 Admin 会话冒充 User，也不能填入私人文档、端点、模型或权限范围。

公开检索独立于 AI。问答目前使用已有词法检索，最多选择三条当前证据；例如问题“图书馆 开放时间”需能匹配选中公开来源。没有证据时直接拒答，不连接模型，也不消耗模型预算。索引尚未就绪会报不可用，不改用旧索引或全局模型知识。

## 答案与引用

模型只收到问题和公开证据的标题/片段 JSON。来源正文中的提示指令仍是不可信数据，不允许执行工具、获取任意链接、读取私人文件或更换提供方。宿主只接受封闭答案 JSON；模型必须引用本次分配的证据 ID，不能自造链接或扩大来源范围。

答案先缓冲，引用的原来源、当前修订、索引代次、用户会话、Feature 和模型绑定在返回前重新验证。界面接入者应将答案作为纯文本处理，展示宿主返回的真实引用。复开引用使用既有公开来源接口和 `revision` 参数；修订过期后须重新检索，不能静默打开新正文。

宿主校验引用的来源与当前性，并未证明每句话的语义正确性；模型输出不代表官方结论。没有证据、模型明确拒答、结构不合格或来源变化时均不交付答案。

## 中途变化与费用

来源转私密、会话撤销、Knowledge/AI 停用、Profile/Binding变化或模块停止会取消在途调用并丢弃迟到答案。一次模型请求仍按14a的请求单位计费：未分发失败0，分发后未知或取消保守1；它不是货币价格。审计结算失败也不会提前交付答案，租约工作器只补结算，不重放模型。

私人索引同意不授权外发。当前接口拒绝远程 Profile，不会自动 fallback；私人 RAG 和按端点/内容/修订/步骤的独立同意不是本片已交付功能。

开发验收入口是仓库 `scripts/v12-14b-public-local-rag-drill.py`，详细字段与边界见 `docs/api/v1.2公开集合本机引用问答合同.md`。自建 HTTP 模型协议端用于验证真实调用链，不冒充真实 LLM 权重或问答质量；Windows目标继续延期。
