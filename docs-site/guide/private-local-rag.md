# 私人来源的本机问答与逐次同意

> 更新时间：2026-10-24（Asia/Shanghai）

> 本页保留.154/.155本机内部Port的历史切片说明；当前HTTP/Web、本机或远程Chat及完整验收见[有据问答](./cited-rag.md)和仓库.156。
V12-14b 这一切片把一个本人已选的私人来源接到本机模型，先准备要发送的内容，由本人逐次确认，再生成带当前来源引用的缓冲答案。该历史切片只有可信宿主内部 Port，没有新增聊天页面、问答 HTTP、Host/MCP 或 SDK 入口。

## 使用条件

先按[私人知识操作说明](./private-knowledge.md)准备 Linux 保护目录，由当前 User 核对并逐项选入自己的来源，等待 ready。来源更新后，旧修订不会自动获得新授权，须重新核对并选择。此次 owned 目标夹具使用 TXT 个人文档；不能据此扩大其他格式的问答验收范围。

AI 需按[受管模型教程](./managed-ai.md)配置，并由独立管理员把 chat Binding 选为启用的 `local-chat`。模型进程由运维预先运行，端点固定为部署允许的 loopback HTTP 地址，调用者不能换成远程或局域网模型。私人检索在 AI 不可用时仍保留原有能力。

选入私人索引时的同意只允许受保护索引。它没有授权把片段发给模型；管理员选择本机模型也不能替代本人的本次决定。

## 接入时必须展示的确认内容

可信第一方接入者使用当前 User 会话解析器，向内部 `knowledge.private-local-rag/v1` 的 Prepare 传单个 selection ID、精确 revision、问题、本次随机 run ID 和当前 Binding 修订。Prepare 不调用模型、不预留预算、不写批准审计。词法查询没有匹配证据时直接拒答，不签发批准 ID；来源不可用会明确失败。

准备成功后，接入者必须先向本人展示完整 review 中的以下内容，再收集一次新的明确肯定操作：

- 本次问题、实际发送的证据标题和片段，以及完整 user 消息 JSON。
- 固定系统提示词、确切模型与 Profile/Binding 修订、目标端点及输出上限。
- 当前来源、精确修订、索引同意版本和本次唯一 Chat 步骤。

不能预勾选同意，也不能把选入索引的复选框当作这次模型同意。本人同意后，Answer 使用原问题请求、服务端批准 ID、精确 review 摘要和 `consented:true`；不同意时不发送，可撤销准备票据。网页的新问答交互见有据问答教程，本节说明原内部Port。

票据2分钟到期，并绑定完整当前 User 会话；同一用户的另一登录会话也不能复用。每个完整会话最多32项、全局256项，包括进行中调用。服务端只临时保存会话/review 的 SHA256、随机 ID、期限、状态和取消句柄，不缓存私人正文或问题。满额时拒绝新票据，不踢掉其他会话的有效批准。

## 确认后的执行和引用

Answer 会从当前来源和模型配置重新生成 review，内容或修订不符时拒绝，不把旧批准套到新问题上。一个票据只能原子消费一次；消费前的篡改失败不消耗合法票据，消费后的取消、审计/预算失败或模型错误均需重新准备和确认。

批准的必需元数据审计先于模型预算和网络执行。此后在预算、实际请求、在途观察和答案交付边界持续复查当前会话、来源/索引同意、密钥可解密性、Feature、票据及模型配置。来源只作为不可信数据，不运行工具、跟随模型链接或读取其他文档。

模型答案先缓冲。宿主只接受有界的答案 JSON 和本次唯一证据 `E1`，答案最多4096字节；伪引用、无引用或额外工具字段会被拒绝。空答案和空引用表示明确拒答。接入者只按纯文本展示答案和宿主引用，不把回答当作 HTML、权限事实或官方结论。

复开私人引用沿用现有的私人来源 POST 接口，传 selection ID 与精确 `revision`，重新核验本人会话、原来源和密钥。它不会自动打开更新后的正文。宿主保证来源与当前性检查，并未证明每句话的语义正确性。

## 撤销、故障与范围

同一完整会话可调用 Revoke 撤销票据并取消在途问答。撤回私人索引、来源改变、会话失效、Feature 或模型绑定变化、票据到期都会关闭后续执行或丢弃迟到答案；撤销无法收回模型已经收到的内容。

费用沿用受管网关的请求单位：未分发失败0，已分发后未知或取消保守1；这里不是 token 价格或货币账单。审计结算失败不会提前展示答案，后台只补结算，不重新请求模型。

模块停止会取消工作并等待结算；重新启动或重启进程后旧批准失效，须重新准备和确认。批准不进入备份或私人回答历史。没有远程 RAG、Embedding/Rerank/外部解析、多步骤自动批准或私人插件/MCP 读取。

字段、取消和审计合同见仓库 `docs/api/v1.2私人本机问答与逐次同意合同.md`；目标 runner 为 `scripts/v12-14b-private-local-rag-drill.py`，实际验收结果以本轮进度及证据报告为准。协议模型端不代表真实 LLM 质量，Windows 目标继续延期。
