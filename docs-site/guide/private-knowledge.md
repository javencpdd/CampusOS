# 我的私人知识

> 更新时间：2026-10-23（Asia/Shanghai）
> v1.2-dev / V12-13；当前 Linux，Windows 实机按用户要求延期。

登录 Web 后，从“知识检索”进入“我的私人知识”（`/knowledge/private`）。
这里仅检索你明确选入、当前仍属于本人且未变更的文档和讨论帖。
所有来源默认不入库；选择私人索引不表示同意把内容发送给模型、插件或其他人。

## 选入一项来源

1. 点击“加载本人来源”，选择个人文档或本人讨论帖。
   也可从个人文档列表或本人讨论帖的“选入私人知识”入口进入，仍需下面的核对和同意。
2. 点击“核对当前来源”，检查当前标题、类型与修订。
3. 勾选本项同意，再点击“确认选入这一项”。核对不会自动选入。
4. 点击“刷新状态与列表”，等任务显示可检索后使用关键词搜索。
5. 点击“读取当前引用”重新核验来源并阅读纯文本。

支持 TXT、Markdown、CampusDoc 和本人的纯文本/Markdown 讨论帖；每项正文最多 64 KiB，每人最多 100 项。
PDF、DOCX、文章富文本和图片提取暂不支持。选择器只加载有限页，其他来源可从原文档/讨论帖入口进入。
来源编辑、回收、删除或当前不可读时，旧修订立即停止提供结果；如需索引新版本，撤回旧项后重新核对和选入。

## 状态、重试与撤回

| 状态 | 操作 |
| --- | --- |
| 保护未就绪 | 请管理员检查下方独立密钥目录；配置恢复后手动刷新 |
| 待处理/处理中 | 等待正常后台任务推进，再刷新状态；提交成功不等于可检索 |
| 等待重试/重试耗尽 | 修复基础故障后点击该项重试；页面不自动重放同意 |
| 来源不可用 | 回原页面核对当前版本、功能和权限；旧索引不会扩大原文访问权 |
| 无匹配结果 | 更换字面关键词；这里不生成 AI 答案 |
| 不再需要 | 点击“撤回并清理”；后续请求不再读取该索引 |

撤回删除独立解密密钥，并清理索引引用和任务，已有普通备份里的派生密文也无法据此恢复读取。
如果撤回期间审计/数据库失败，密钥可能已经退休、页面显示不可用；修复后再次撤回以清理元数据。
原文档或帖子及其备份仍归原模块管理；如要删除原件，请使用原页面操作。

查询和正文不保存到浏览器持久存储或 URL。修改关键词、进入后台或离开页面会清除输出，迟到响应不能恢复旧正文。
页面把引用显示为纯文本，不执行其中的 HTML、图片或脚本。

## 管理员准备保护目录

Knowledge 和个人文档功能需已启用。服务端环境变量 `KNOWLEDGE_PRIVATE_KEY_DIR` 默认空，因此私人索引默认不可用。
Linux 运维需在所有应用数据与备份输入/输出树之外，为服务 UID 单独准备现有的 0700 目录，并将该变量设为其绝对路径后重启服务。
不要把它放入 `data`、`backups`、插件数据目录、项目目录或普通备份中。服务创建的密钥必须为同 UID、0600 普通单链接文件；符号链接、权限或所有权不足会关闭访问。

该目录专用于单个当前实例，不随备份克隆或回滚；退休标记不能恢复成旧状态。
密钥损失时由本人撤回旧项并重新选择，不能从数据库恢复密钥。
官方离线恢复会先隔离实例、要求操作员核对，并清除私人索引同意和任务；恢复原件后仍需本人重新选择。

字段级和运维边界见[当前 API 合同入口](/api/contracts)，仓库合同为 `docs/api/v1.2私人知识索引与撤回合同.md`。
验收证据位于 `docs/进度/v1.2-dev/v1.2.151-dev.md`；Linux 原生模块/生产路由、独占 PostgreSQL、真实 Chrome 桌面及移动视口、离线备份恢复分别记录，不代表独立生产部署或整版 Final。
