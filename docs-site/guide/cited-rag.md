# 有据问答与私人逐次同意

> 更新时间：2026-10-24 13:25（Asia/Shanghai）。V12-14b 验收进度见仓库 `docs/进度/v1.2-dev/v1.2.156-dev.md`。

部署者先配置可用的 OpenAI 兼容文本模型，独立管理员按[受管模型指南](./managed-ai.md)启用 AI、Knowledge 和当前 Chat Profile。搜索不需要模型；模型不可用时仍可使用已启用的搜索。

在公开知识页选择一个集合，填写问题，点击“根据公开资料提问”。答案只依据当前可访问的公开片段；无证据时直接拒答。点击“复核当前问答引用”打开当前原文。来源已变化时重新搜索核对。

在“我的私人知识”中先[选入并建立私人索引](./private-knowledge.md)。索引 ready 后，对具体一项点击“对这一项提问”。填写问题后点击“核对本次发送内容”，查看本次完整发送 JSON、模型名称、确切目标、固定提示及输出上限。核对单不调用模型。只有本人独立勾选并点击“同意并发送本次”才会发送；先前索引同意不包含这次模型发送。

同意只对本会话、本问题、当前来源修订、确切目标和本次 Chat 生效，两分钟后到期且只能使用一次。模型切换、资料更新、撤回、退出或取消后，应重新核对；页面不自动沿用先前同意。修改问题/来源、隐藏或离开页面会清空本次内容并取消待处理请求。界面以纯文本显示模型回答，模型不能执行工具或读取其他资料。

私人首版每次选择一项自己的 TXT、Markdown、CampusDoc 或文本讨论帖；PDF、DOCX、富文本文章及保护不足的来源继续拒绝。Embedding、Rerank、Parser、查询改写和遥测模型步骤未开放，Chat 同意不能授权这些步骤。问答尚未提供私人插件、Host、MCP 或 SDK 接口。

模型输出可能错误，也可能拒答；应核对引用，不将模型答案当作官方结论。当前质量评测只覆盖冻结的短中文校园 FAQ 抽取任务。部署者自行运行模型，CampusOS 不下载模型、启动模型进程或替用户选择其他出站提供方。
