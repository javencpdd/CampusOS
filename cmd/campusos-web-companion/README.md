# CampusOS 本机公开资源读取助手

> 最新更新时间：2026-11-15（Asia/Shanghai）

独立运行的通用客户端，供本人明确配对的插件读取公开 HTTPS 文档和图片。不包含 RSS 解析器，不运行插件代码，也没有文件读取、shell 或服务器代理设置任务。

在仓库根目录运行 `python3 scripts/build-web-companion.py` 构建固定平台程序；用户下载后启动、配置本机代理并输入一次性配对码，再回到插件选择自己的电脑。本机 HTTP/HTTPS/SOCKS5 代理仅供当前助手进程，地址及口令不上传。服务器读取无需安装助手。

配置、权限、下载及验证命令见[助手合同](../../docs/api/v1.2本机公开资源读取助手合同.md)。
