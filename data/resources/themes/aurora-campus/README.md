# Aurora Campus

This is the reference `campusos.app-style-pack.v2` package. It demonstrates a full viewport background, App Shell layout recipe, design tokens, responsive content, a Surface override hint, and a sandboxed pointer effect.

The package changes presentation only. Routes, permissions, API methods, action bodies, confirmations, audit policy, plugin stores, and business data remain owned by CampusOS Core and the contributing plugin.

The campus image was generated specifically for this example and does not copy assets or source code from the visual reference project.
