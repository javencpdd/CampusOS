# campus-hero

Folder-based CampusOS homepage style pack example.

This source package lives under `data/resources/homepage-packs/` and follows the `page-style-pack.v1` standard:

```text
style.yaml
README.md
preview.png
templates/page.html
templates/card.html
assets/cover.webp
assets/avatar-frame.png
styles/theme.css
config.schema.json
```

Upload this folder as a zip package from the `homepage-customizer` config dialog, or edit it in source and package it manually.
