# Category Moderation

`category-moderation` 是 CampusOS 内置的系统级板块版主插件。

它负责提供管理员配置窗口和用户端治理入口；用户身份、角色权限、板块作用域匹配与越权拒绝仍由核心 RBAC 强制执行，插件不能绕过这些检查。

## 当前权限

管理员可以在插件独立页面中，为一个用户选择一个或多个板块。该用户只在这些板块中获得以下能力：

- 置顶或取消置顶主题；
- 锁定或解锁主题；
- 删除主题下的回复。

插件配置可以统一关闭其中任一能力，但不能给版主增加角色管理、用户封禁、插件管理、系统配置、平台日志或其他板块的权限。

版主范围变更和治理操作会写入 `audit_logs`。审计属于强制安全边界，不提供关闭开关。

## 生命周期

这是 `scope: system` 插件。管理端启用或停用只保存目标状态，必须重启 CampusOS API 才会改变当前运行状态。

- 运行中：已分配板块的版主可以使用启用的治理操作。
- 待重启停用：当前进程仍保持运行，直到 API 重启。
- 重启后停用：所有版主治理 API 返回插件未运行，用户端不显示治理按钮。
- 停用不会删除 `user_roles` 中的板块分配和 `audit_logs` 中的历史记录；重新启用并重启后会恢复原有范围。

插件整体启用和停用仍需重启 API。置顶、锁定、删除回复三个动作权限开关由内置服务动态读取，保存后立即作用于后端授权检查，不需要重启；已经打开的帖子页面刷新后会同步按钮状态。
