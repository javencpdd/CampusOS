# clean-blog

Folder-based CampusOS personal-space style pack example.

This source package lives under `data/plugin_data/personal-space/style-packs/` and follows the `page-style-pack.v1` standard:

```text
style.yaml
README.md
preview.png
templates/page.html
templates/card.html
assets/cover.webp
assets/avatar-frame.png
styles/theme.css
config.schema.json
```

Edit `templates/page.html`, `templates/card.html`, `styles/theme.css`, assets, or `config.schema.json`, then validate before applying.
